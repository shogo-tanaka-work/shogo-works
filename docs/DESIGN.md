# ビジュアルデザイン

このファイルをビジュアル表現の正本とする。機能・UX要件は `SPEC.md`、実装時の判断手順は `.agents/rules/ui-design.md` を読む。視覚表現が競合する場合はこのファイルを優先する。

## 目指す状態

個人の仕事を淡々と提示するサイト。装飾ではなく、余白・文字・配置で情報の階層を作る。

テンプレートから生成したような画一的な見た目を避ける。具体的には、全セクションを同じ白いカードで埋める、グラデーション文字で強調する、意味のない影と大きな角丸を重ねる、といった表現をやめる。

## 基本方針

ページと通常セクションは、一枚のキャンバスとして同じ背景で扱う。セクションごとに背景色を変えて「区画」を作らない。

**例外は、本文と並置するナビゲーション領域（記事ページのサイドバーと目次）に限る。**読み進める本文と、現在地を示す補助面を見分けるための区別であり、内容の区画分けではない。この場合は背景色の差だけで境界を作り、枠線を重ねない。

情報の階層は次の優先順で表現する。

1. 余白（セクション間・要素間の間隔差）
2. 文字（サイズ・ウェイト・色の濃淡）
3. 配置（整列・カラム分割）
4. 区切り線（1px の水平線）

上の手段で表現できない場合にだけ、下の手段へ降りる。背景・枠線・角丸・影を同じ要素へ重ねない。

## カラー

アクセントは teal 系1色に絞る。`global.css` の `@theme` で定義したカスタムプロパティを参照し、コンポーネント内に生の色値を書かない。

| 用途 | 参照するトークン |
|---|---|
| 本文 | `--color-foreground` |
| 補助テキスト | `--color-muted-foreground` |
| アクセント（リンク・強調・現在地） | `--color-primary` |
| 区切り線・枠線 | `--color-border` |
| 淡い補助背景（表ヘッダー・入力欄） | `--color-secondary` |
| ナビゲーション領域の面（記事ページのサイドバー・目次） | `--color-panel` |
| エラー | `--color-destructive` |

- グラデーションを廃止する。`gradient-text` / `gradient-border` / `glass` / `glass-strong` は新規利用しない。
- teal と emerald を混ぜて2色グラデーションにしない。アクセントは単色として使う。
- 色だけで意味を伝えない。文言かアイコンを併記する。

## タイポグラフィ

- 見出しと本文のコントラストは、ウェイトよりサイズ差で作る。
- セクション見出しの上に置く英字ラベル（`Services` 等）は、小さく・低彩度で。装飾として増やさない。
- 本文の行長は日本語で 40 字前後に収まる幅に制限する。
- 引用符や絵文字で強調しない。

## 角丸

- 通常領域（セクション、一覧、記事本文）の角丸は `0`。
- ボタン・入力欄・選択コントロールは `2px`〜`6px`。
- バッジ・ピルは形状として丸めてよい。
- `rounded-2xl` / `rounded-3xl` を新規に使わない。

## 影

影は前面へ浮く要素に限定する。

- 使ってよい: モーダル、ドロワー、ポップオーバー、ドロップダウン、固定ナビゲーション
- 使わない: 通常のカード、一覧行、セクション、画像

## 枠線・区切り

- 一覧は「行 ＋ 行間の区切り線」で表現する。要素ごとに枠で囲まない。
- 表は罫線を最小限にし、ヘッダー行にだけ淡い補助背景を敷く。
- 枠線を使う場合は 1px・`--color-border` の一種類のみ。太さや色を場所ごとに変えない。

## レイアウト

- コンテンツ幅は用途ごとに一定の値を使い、ページごとに変えない。
- 一覧＋サイドバーは2カラム。サイドバーを隠す幅では、同じ導線をセレクトまたはアコーディオンで残す。
- 記事ページは「サイドバー ／ 本文 ／ 目次」の3カラム。**本文は背景色を持たず、左右のナビゲーション領域だけが `--color-panel` を敷く。**面そのものは主張させず、`--color-secondary`（表ヘッダー・現在地）より一段淡くする。
- 追従するパネルは固定ヘッダーの直下へ吸着させる。ヘッダーとパネルの間に隙間を空けると、そこだけ本文が透けて見え、面が途中から始まったように見える。
- セクション見出しは本文の上へ左寄せで置き、スクロール追従させない。追従は固定ナビゲーションと記事ページの目次に限定する。
  セクションが1画面前後で終わる本サイトでは、追従しても現在地の把握に寄与せず、本文幅を狭める副作用のほうが大きい。
- Grid / Flex の可変領域には `min-width: 0` を設定する。
- 横スクロールを通常操作として発生させない。広い要素（表・コードブロック）はその要素自身に `overflow-x: auto` を持たせる。

## 状態表現

装飾を減らす作業で、次の表示を消さない。

- キーボードフォーカスの輪郭
- 現在地（`aria-current="page"`）
- 選択中・展開中
- エラー・警告
- 無効化

## 許可する例外

- 数値サマリーを比較させたい箇所の細い外枠
- ステータスバッジのピル形状
- ボタン・入力欄の小さな角丸
- オーバーレイ（モーダル・ドロワー・メニュー）の白背景と影
- 記事本文（`.knowledge-prose`）のコードブロック・引用の背景

例外を使う場合も、同じ要素へ背景・枠線・角丸・影をすべて重ねない。
