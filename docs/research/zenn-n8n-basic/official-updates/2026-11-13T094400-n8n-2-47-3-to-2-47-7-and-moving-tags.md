## 公式内容の日本語要約（内容のある変更）

**実行データのマスキングに関する修正（2.47.7 / 2.48.4）**: `core: Stop redacting executions that use global credentials`。グローバル資格情報を使う実行までマスキング対象になっていたのを止めた。2.46.0 の「チームプロジェクトで個人の資格情報を使える」機能に伴って入った実行データの非表示が、過剰に効いていた分の巻き戻しである。

**Public API の挙動変更（2.47.5 / 2.48.2）**: `API: Reject edits to read-only credential nodes in the Public API`。読み取り専用の資格情報ノードへの編集を Public API が拒否するようになった。**Public API 経由でワークフローを書き換える自動化を持っている場合、従来通っていた更新がエラーになる可能性がある。**

**暗号鍵・キャッシュまわり（2.47.6 / 2.48.3）**: 保存時の鍵と異なる鍵でレガシー形式のデータを読む修正（`Read legacy-format data with the instance key when the stored key differs`）、trusted-source のキャッシュキーを Redis クラスタの単一スロットに収める修正、エンドポイントが cache フィールドを拒否する場合にエージェント側で prompt caching を切れるようにする変更。

**3.2.0（pre-release）で入った統制・境界系**: 送信リクエストガードの既定ブロック IP レンジの拡大（`Expand default blocked IP ranges for outbound request guard`。**自己ホストで私有レンジへ発信しているワークフローは影響を受け得る**）、マスキングポリシーをログストリーミング・テレメトリ・エラーレポートにも適用、ワークフローを編集できるユーザーだけが移行所見を所有できるようにする変更、chat hub モジュールの既定オフ、`N8N_NODES_API_VERSION` を 3 へ、Microsoft Work IQ の OAuth2 資格情報の追加、Gateway クレジット残高が空になったらエージェント実行を停止。

**軽微な修正**: 式ランタイムの性能改善、Pinecone Vector Store ノードの documents API 経由検索、エディタの JSON ハイライト色、ノード枠線のアニメーション位置など。

## 影響範囲

- 対象ユーザー: 自己ホスト運用者（版の選択と `stable` / `beta` の指す先に注意）、Public API でワークフローを操作している利用者
- 対象プラン: Cloud / self-hosted 共通。3.2.x は pre-release のため本番採用の対象外
- 要対応: Public API での資格情報ノード編集、3.x 系へ上げる場合の送信先 IP レンジ
