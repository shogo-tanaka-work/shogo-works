# 2026-08-11 n8n 2.35.0

## 公式内容の日本語要約

2.34.0 からのマイナーリリース。エージェント関連の機能追加が中心で、同日 08:00:26Z に stable タグが更新された。

Agent Builder にテスト実行が入り、あわせて human-in-the-loop（HITL）にも対応した。作ったエージェントを公開前に走らせ、途中で人の判断を挟んで検証できる。エージェントのチャットチャネルには Discord が加わった。ローカルでのエージェントトークンカウントも実装され、消費量を手元で把握できる。

管理・API 面では、カスタムロールを作成するエンドポイントと、ワークフロー更新エンドポイントの `publishIfActive` オプションが追加された。MCP の `get_workflow_details` には `detailLevel` オプションが入り、返す情報量を選べる。

ワークフローレビューの流れも強化された。レビュー詳細ペインに変更差分タブが付き、レビュー提出時にバージョンの説明を書けるようになった。ノード側では Kafka ノードの v2（新ライブラリ経由の送信と圧縮オプション）、Salesforce Trigger の OAuth2 JWT 認証、Slack ノードの Real-time Search API 利用が加わった。

修正側にも権限まわりの変更がある。Code ノードの console 出力に redaction ポリシーが適用されるようになり、data table への書き込みが行を返す場合は行の読み取りスコープを要求するようになった。過大なエージェントツールの結果には上限が設けられた。

## できるようになったこと

- Agent Builder でテスト実行ができ、HITL を挟める
- Discord をエージェントのチャットチャネルとして使える
- エージェントのトークン消費をローカルでカウントできる
- カスタムロールを API から作成できる。ワークフロー更新に `publishIfActive` を指定できる
- MCP の `get_workflow_details` で `detailLevel` を指定できる
- ワークフローレビューで変更差分を確認し、提出時にバージョン説明を付けられる
- Kafka ノード v2、Salesforce Trigger の OAuth2 JWT、Slack の Real-time Search API を使える

## 影響範囲

- 対象ユーザー: n8n でエージェントを構築するチーム、セルフホスト運用の管理者
- 対象プラン: セルフホスト / クラウド（stable 2.35.0）
- API / UI / 管理者機能: エディタ UI + Public API + MCP + ノード
