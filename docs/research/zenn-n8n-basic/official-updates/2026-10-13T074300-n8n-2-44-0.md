# 2026-10-13 n8n 2.44.0（beta チャネル）

## 公式内容の日本語要約

**2.44.0 が pre-release として公開され、窓内に 2.44.1 / 2.44.2 / 2.44.3 の3つのパッチが続いた。** `beta` moving tag は 2.44.3（2026-10-16T07:22Z）を指す。2.44.0 の changelog は **feature 約55件・bug fix 約78件・performance 5件**で、**breaking change の節は無い。**

**AI / エージェント関連**: Google Vertex AI の credential、**WhatsApp をエージェントのチャネルとして使える**、エージェントへのワークフローツール入力、**Azure AI ノードと credential を Microsoft Foundry へ改名**。

**統制・ポリシー関連**: **credential transfer policy の強制ポイント**、credential type policy による credential 専用ノードの非表示、外部エージェントチャネルでの budget-stop メッセージ。

**データテーブルと移行**: パッケージインポート時のスキーマ衝突ポリシー（上書き）、ID による列の対応付け、移行ルール詳細の state 列。

**可観測性**: **すべての OpenTelemetry span に execution identity を付与**、DB 接続復旧中の Prometheus メトリクス、オプトインの start marker span。

**エディタ**: コマンドバーの作り直し、個人設定ページの作り直し、エージェントのセットアップチェックリスト、**Microsoft SharePoint Trigger ノード**。

**bug fix 側は n8n Assistant / agent builder 関連が多い**（承認待ち、セッション処理、ツールポリシーの適用）。キューモードと worker 停止でジョブが正しくキューへ戻る修正、エディタ・ノード個別（Databricks、Google Gemini、Invoice Ninja、Odoo、S3、Microsoft Outlook Trigger）の修正も含む。**アクセス制御に関わる項目もいくつかある**（単一ノード実行に workflow create スコープを要求、テストとプローブにも credential policy を適用）が、**公式はこれらを security fix としてラベルしていない。**

**performance**: agent builder の system prompt を静的化してプロンプトキャッシュに乗せる、agent builder の設定書き込みの高速化、Instance AI skill sandbox の事前準備。

## できるようになったこと

- credential transfer policy を強制でき、credential 専用ノードを type policy で隠せる
- OpenTelemetry の全 span に execution identity が入り、実行単位で追跡できる
- WhatsApp をエージェントのチャネルに、SharePoint をトリガーに使える

## 影響範囲

- 対象ユーザー: `beta` タグで追従している self-hosted 利用者。stable 利用者には未到達
- 対象プラン: 記載なし
- API / UI / 管理者機能: core、credential ポリシー（管理者）、OpenTelemetry 出力、エディタ、ノード追加

## 教材化メモ

- **credential の移転と表示をポリシーで縛る方向**が入った点が、統制面で最も効く。**「このワークフローを別の人へ渡すと credential も一緒に動く」**という運用上の穴を、ポリシーの強制ポイントで閉じる設計である。
- **OpenTelemetry の span へ execution identity を付ける**のは、**同週に Claude Code 側が GenAI semantic conventions 属性と auto mode の classifier decision を OpenTelemetry へ出した**のと同じ方向である。**ツールを跨いで「エージェントの実行を1つのトレースで追う」方向へ揃ってきている。**
- **agent builder の system prompt を静的化してプロンプトキャッシュへ乗せる**のは、課金構造が実装に出た例。Claude Code のアイドル圧縮（キャッシュ失効前に圧縮）と並べられる。
- **アクセス制御の修正が security ラベル無しで並んでいる**点は、一次情報の読み方の注意点。ラベルが無くても権限に関わる修正は拾う必要がある。
