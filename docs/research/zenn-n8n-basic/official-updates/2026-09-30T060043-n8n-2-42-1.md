# 2026-09-30 n8n 2.42.1

## 公式内容の日本語要約

2.42 系列（beta チャネル）の修正版。

**Bug Fixes**

- **Public API spec で、型のない値に対して妥当なスキーマを出力**するよう修正
- 保存された **trace context が不完全な場合でも実行を返す**よう修正
- Cloud UBB アカウントでの Assistant バナーのクレジット表示を修正

**Features**

- canvas-only モードで canvas に n8n のロゴを表示

実質的に 2.42.0 の追随修正であり、既定値の変更・権限モデルの変更・セキュリティ修正は含まれない。

## できるようになったこと

- Public API spec の自動生成クライアントが型なし値で壊れない
- trace context が欠けた実行も API から取得できる

## 影響範囲

- 対象ユーザー: Public API を使う利用者、Cloud UBB アカウント
- 対象プラン: beta チャネル
- API / UI / 管理者機能: Public API spec

## 教材化メモ

- **Public API spec の不正なスキーマは、API 利用側のコード生成を壊す**。OpenAPI から型を生成する運用では、仕様側の小さな不備が利用側のビルド失敗になる。**仕様ファイルを信頼する設計のリスク**として、前日の 2.42.0 の `OpenAPI path parameter names validated` と並べて読める。
- **trace context が不完全なときに実行を返さない**実装だったという点が示唆的である。観測のためのメタデータの欠落が、本体機能（実行の取得）を落としていた。**可観測性の仕組みが可用性の単一障害点になる**型の不具合である。
