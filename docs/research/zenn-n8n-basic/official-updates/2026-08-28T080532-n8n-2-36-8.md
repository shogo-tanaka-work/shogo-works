# 2026-08-28 n8n 2.36.8

## 公式内容の日本語要約

## できるようになったこと

## 影響範囲

- 対象ユーザー: n8n セルフホスト運用者。特に**資格情報にドメイン制限をかけて配っている組織**
- 対象プラン: 全般
- API / UI / 管理者機能: 資格情報の権限判定

## 教材化メモ

- **「絞りすぎて正規の用途まで塞ぐ」タイプの権限不具合**である。ドメイン制限は外部への持ち出しを防ぐための機能なのに、本来の利用先まで拒否していた。**制限機能は、拒否が正しいかだけでなく許可が正しいかも試験しないと運用で使えなくなる**、という教材になる。
