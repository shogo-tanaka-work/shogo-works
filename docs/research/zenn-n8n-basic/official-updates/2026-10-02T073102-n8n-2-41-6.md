# 2026-10-02 n8n 2.41.6

## 公式内容の日本語要約

2.41 系列の修正版。**公式記載は Bug Fixes 1件のみ**である。

- 「**未処理の promise rejection が起きても task runner を動かし続ける**」

**窓の終端時点で `stable` タグが指すのはこのバージョンである**（前週終端は 2.40.7）。つまりこの窓のあいだに **stable 系列が 2.40.x から 2.41.x へ切り替わった。** あわせて `beta` は 2.41.3 から 2.42.2 へ、`v1` は 1.123.82 から 1.123.83 へ動いている。

機能追加・既定値の変更・セキュリティ修正は含まれない。

## できるようになったこと

- task runner が未処理 rejection でプロセス終了しない

## 影響範囲

- 対象ユーザー: task runner を使う全環境（セルフホスト / Cloud）
- 対象プラン: **2.41 系列（窓終端時点の `stable`）**
- API / UI / 管理者機能: task runner の耐障害性

## 教材化メモ

- **`stable` タグが 2.40.7 → 2.41.6 へ移ったことが、この窓で最も運用に効く事実である。** バージョン番号を固定せず `stable` タグで追随している環境は、**この窓のあいだにマイナー1つ分を自動で跨いだ**。2.41 系列には実行権限のプロジェクトロール化（2.41.0）や Agents の既定有効化（2.41.1）が含まれるため、**「パッチ追随のつもりで機能変更が入る」**構造になる。moving tag で運用する場合の既知のリスクの実例である。
- **未処理 promise rejection でプロセスを落とさない**という変更は、方針として両面ある。可用性は上がるが、**握りつぶしに近い状態を許容する**ことにもなる。自前実装で同じ判断をするときは、落とさないかわりにどこへ記録するかを必ず決める、という形で教えられる。
