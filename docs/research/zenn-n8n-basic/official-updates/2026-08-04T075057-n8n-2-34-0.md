# 2026-08-04 n8n 2.34.0

## 公式内容の日本語要約

n8n 2.34.0 が公開されました。GitHub 上のフラグは pre-release ですが、同時刻帯に `stable` の moving tag も更新されています。

機能面で目立つのはワークフローの**レビュー・承認フロー**です。レビュー要求の詳細エンドポイント追加、承認 / 変更要求、承認時の自動 publish、レビューがオープンな間の publish ブロックが揃い、変更を publish する前に人が挟まる運用が組めるようになりました。

管理・自動化まわりでは、instance MCP に **Agent 管理**が追加されました。MCP サーバーの利用イベントをログストリーミングへ流せるようにもなっています。Public API には **LDAP 設定**と **OIDC SSO 設定**のエンドポイントが加わり、認証まわりを API から構成できます。webhook ノードには n8n ユーザー認証（OAuth2）モードが入りました。

インフラ側は AWS リージョン `ap-east-2` / `ap-southeast-6` の追加、`get.n8n.io` のワンスクリプト docker compose セットアップ、durable scheduler の misfire ポリシー追加などです。

修正は広範で、queue モード実行の OTel span 出力、SSE push 接続の本番修正、外部シークレットの再読み込み中の可用性維持、再起動後のキュー投入済み実行の復旧、サブエージェントのツール承認伝播などが含まれます。

## できるようになったこと

- ワークフローのレビュー → 承認 → 自動 publish のフローを構成できる（レビュー中の publish はブロック）
- instance MCP から Agent を管理でき、MCP サーバー利用イベントをログストリーミングへ送れる
- Public API から LDAP / OIDC SSO の設定を操作できる
- webhook ノードで n8n ユーザー認証（OAuth2）を使える
- AWS `ap-east-2` / `ap-southeast-6` リージョンに対応

## 影響範囲

- 対象ユーザー: n8n セルフホスト運用者、SSO / MCP を使う組織
- 対象プラン: SSO 系（LDAP / OIDC）は上位プラン機能
- API / UI / 管理者機能: Public API、instance MCP、ワークフローレビュー UI、webhook ノード

## 教材化メモ

- レビュー・承認フローは「n8n を業務プロセスに組み込むときのガバナンス」の題材として使える。既存の n8n 教材が「作って publish して終わり」の流れで書かれている場合、承認を挟む選択肢があることを補足すると実務寄りになる。
- instance MCP の Agent 管理は、n8n を MCP サーバーとして外部エージェントから叩く構成の説明材料になる。Claude Code / Codex からワークフローを操作する導線として教材に接続できる。
- Public API での LDAP / OIDC 設定は情シス向けの話題。個人利用者向け教材には不要で、組織導入編にだけ入れる。
