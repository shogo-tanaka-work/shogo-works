# 2026-08-25 n8n 2.36.6

## 公式内容の日本語要約

2.36 系の backport リリース。公式リリースノートに記載された変更は Bug Fixes 1件のみである。

**エディタ**: Instance AI のランディングページで、パーソナライゼーション調査とコミュニティ登録モーダルを表示するよう修正（#36826）。

新機能・破壊的変更の記載はない。

## できるようになったこと

- Instance AI ランディングページで所定のモーダルが表示される

## 影響範囲

- 対象ユーザー: n8n セルフホスト運用者
- 対象プラン: 全般
- API / UI / 管理者機能: エディタ UI のみ
