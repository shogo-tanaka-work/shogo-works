# 2026-09-10 n8n 2.38.6

## 公式内容の日本語要約

2.38 系のバックポートリリース。**source control の push 時にピークメモリを抑える**改善（`Bound peak memory during source control push`）が入っている。Git 操作中の安定性向上が目的である。

2.39 系が先行して出ているなかで 2.38 系にも継続して修正が入っており、**窓内では 2.38.6 / 2.38.7 の2版が出た。**

## できるようになったこと

- source control の push でメモリを使い切りにくくなった

## 影響範囲

- 対象ユーザー: n8n の source control（Git 連携）を使う運用者
- 対象プラン: セルフホスト / エンタープライズ機能
- API / UI / 管理者機能: source control

## 教材化メモ

- **ワークフロー数が増えるとメモリで詰まる**という、規模が出てから現れる問題である。小規模で検証して導入したものが、本番規模で止まるパターンの典型。
- **2.38 系へのバックポートが継続している**点は、n8n の版運用を追うときの実務知識。`stable` タグを追うだけでは 2.39 系の内容が見えず、逆に最新版だけを追うと 2.38 系にしか入らない修正を見落とす。**moving tag と実バージョンを必ず突き合わせる**という `source-catalog.md` の指示どおりの運用が要る。
- 記事化はしない（週次確認ソースのマイナーアップデート）。
