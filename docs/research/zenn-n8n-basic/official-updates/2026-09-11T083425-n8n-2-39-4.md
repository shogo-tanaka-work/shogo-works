# 2026-09-11 n8n 2.39.4

## 公式内容の日本語要約

パッチリリース。**サンドボックスの `npm install` フラグをプロバイダー別に選択する**ようになった（`Select sandbox npm install flags by provider`）。依存関係のインストール処理の扱いを改善するもの。

**moving tag の `beta` は、2026-09-11T08:31:07Z 時点でこの 2.39.4 を指している。** `stable` は 2.38.7 を指す。窓内の最新版である。

## できるようになったこと

- サンドボックスのプロバイダーに応じた `npm install` フラグが使われる

## 影響範囲

- 対象ユーザー: コードノード / AI サンドボックスで外部パッケージを使う n8n 運用者
- 対象プラン: セルフホスト / クラウド
- API / UI / 管理者機能: サンドボックス実行環境

## 教材化メモ

- **サンドボックスのプロバイダーが複数ある前提の変更である。** 同じ週に Dify がローカルサンドボックスと E2B の使い分け（1.17.0 系の流れ）を持ち、Cursor が Cloud Agents とローカルエージェントを使い分けている。**「エージェントのコードをどこで実行するか」が製品横断で選択制になりつつある**という整理ができる。実行場所ごとに依存解決の条件が変わるため、こうしたフラグ調整が要るわけである。
- 記事化はしない（週次確認ソースのマイナーアップデート）。
