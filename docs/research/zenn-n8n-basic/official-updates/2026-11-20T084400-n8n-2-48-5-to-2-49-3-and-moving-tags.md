# n8n - 窓内の12版と moving tag

## 公式内容の日本語要約

対象期間（2026-11-16T00:30Z〜2026-11-23T00:30Z）に**12版**が出た。`stable` / `beta` は moving tag のため、タグが指す実バージョンを確認した。

| 系列 | 窓内の版 |
| --- | --- |
| 2.48.x（安定） | 2.48.5（11-18）、2.48.6（11-19）、2.48.7（11-20） |
| 2.49.x（pre-release） | 2.49.0（11-17）、2.49.1（11-18）、2.49.2（11-19）、2.49.3（11-20） |
| 1.123.x（backport） | 1.123.97（11-16）、1.123.98（11-18）、1.123.99（11-19）、1.123.100（11-20） |
| 3.x（pre-release） | 3.3.0（11-17） |

**moving tag の実体**: `stable` → **2.48.7**（11-20T08:36Z）、`beta` → **2.49.3**（11-20T08:18Z）。前週は `stable` → 2.47.7、`beta` → 2.48.4 だったため、安定線が 2.47 系から 2.48 系へ上がった。2.49.0 と 3.3.0 はいずれも `Pre-release: yes` で、同日・ほぼ同内容（3.3.0 は次期メジャー系列の並行プレリリース）。

**資格情報・権限まわりの修正**（2.48.5 / 2.49.0）:

- `core`: インスタンスの owner と admin を、資格情報チェック上チームプロジェクトのメンバーとして扱う（#44183）
- `API`: Public API で読み取り専用の資格情報ノードへの編集を拒否（#42764）
- `core`: **資格情報の許可ドメイン比較を ASCII 形式で行う**（#43291）。国際化ドメイン名による許可リスト回避の余地をふさぐ変更と読める
- `core`: discovery が失敗したときに OIDC のキャッシュ済み設定をクリア（#43075）
- ログストリーミング送信先の資格情報ロールを検査（#43622）
- `API`: パッケージインポートで実際に使う API キースコープだけを要求（#43293）
- `API`: Public API のレート制限が変わったときに監査イベントを送る（#43825）
- `core`: 新規インストールにランダムな instance ID を付与（#44276）
- `editor`: Sharing ライセンスなしでもワークフローをチームプロジェクトへ移動できるようにした（#44116）

**その他の修正**: AI Agent Node のツール呼び出し履歴を入力アイテムごとに分離（#44044 / #43890）、ストリーミングされたテキストチャンク間に改行を入れない（#43822 / #43252）、メモリガードが hold-limit 停止でメモリを解放できなかった場合に hold を解除（#44463 / #44462）、スクリプティングノードのエラー出力に素のまま入力データを保存（#44530 / #44529）、HTTP Request Node のページネーションで空レスポンスボディを処理（#44443）、Microsoft Teams Trigger がバッチ化された変更通知を全件発行（#43857）、Qdrant Vector Store でリバースプロキシのサブパスを client prefix として保持（#43922）。

## 影響範囲

- 対象ユーザー: セルフホストの n8n 運用者。`stable` タグを使った自動更新をしている環境は 2.48.7 へ上がる
- 対象プラン: 資格情報チェックとチームプロジェクトまわりの変更は、プロジェクト機能を使う環境に影響
- API / UI / 管理者機能: Public API の挙動変更（読み取り専用資格情報ノードの編集拒否、スコープ要求の縮小、レート制限変更の監査イベント）
