# 2026-10-01 n8n 2.42.2

## 公式内容の日本語要約

2.42 系列（beta チャネル）の修正版。**公式記載は Bug Fixes 1件のみ**である。

- 「**キュー済み実行について Bull の `job.finished()` の待機を止める**」

機能追加・既定値の変更・セキュリティ修正は含まれない。窓の終端時点で `beta` タグが指すのはこの 2.42.2 である。

## できるようになったこと

- キューモードで、完了待ちのハンドルがプロセスを占有しない

## 影響範囲

- 対象ユーザー: キューモードで運用しているセルフホスト環境
- 対象プラン: beta チャネル（2.42 系列）
- API / UI / 管理者機能: 実行キュー

## 教材化メモ

- **2.41.4（09-30）の「キュージョブ結果を自プロセス投入分に限定」と同じ領域が、2日で再度修正されている。** キュー実行の完了検知は、水平スケール時にずれが出やすい箇所である。**同じ領域の修正が短期間に続くときは、根本の設計が動いている**と読むのが実務的で、「社内標準バージョンを1〜2版待つ」判断の根拠になる。
- Bull の `job.finished()` のような**ライブラリ側の完了待ち API に依存する設計**は、分散実行では待機ハンドルがリークしやすい。自前でジョブキューを組むときの注意点としてそのまま流用できる。
