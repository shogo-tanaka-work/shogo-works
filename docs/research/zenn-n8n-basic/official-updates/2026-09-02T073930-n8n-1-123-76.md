# 2026-09-02 n8n 1.123.76

## 公式内容の日本語要約

1.x 系の backport リリース。**セキュリティ修正を含む。** 公式の記載は "Bump browserslist to 4.28.7 to clear CVE-2026-73088/73089" で、**依存ライブラリ browserslist を 4.28.7 へ引き上げ、CVE-2026-73088 / CVE-2026-73089 を解消**したもの。

**1.x 系にまだ backport が出ている**点は、旧系列を使い続けている環境がサポート対象であることを示す。窓内には 1.123.77（2026-09-03T08:00:09Z）も出ており、`v1` タグの実体は 1.123.77 である。

## 影響範囲

- 対象ユーザー: n8n 1.x 系を運用している環境
- 対象プラン: セルフホスト中心
- API / UI / 管理者機能: ビルド時依存（browserslist）

## 教材化メモ

- **依存ライブラリの CVE 解消が backport として旧系列へ届く**という運用は、**メジャー更新を止めている環境でもセキュリティ更新は受け取れる**ことを意味する。「最新に上げないと危ない」と「最新に上げないと直らない」は別であり、**LTS 的な系列の有無は移行計画の重要な変数**になる。
- 一方で、**backport が続く保証はない**。1.x 系を使い続ける判断をするなら、**backport の提供がいつまでかを確認する**のが本来の手順である。
