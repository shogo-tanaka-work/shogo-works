# 2026-09-09 n8n 2.39.1

## 公式内容の日本語要約

保守リリース。**ブートストラップ時に旧形式のデータ暗号鍵を修復する**修正が入っている（`Repair legacy-format data-encryption keys during bootstrap`）。

暗号鍵が旧形式のまま残っている環境で、起動時に整合性が取れなくなる問題への対処である。修正はデータ整合性の維持を目的としたもので、利用者側の設定変更は案内されていない。

窓内の n8n は 2.39 系（2.39.1〜2.39.4）と 2.38 系のバックポート（2.38.6 / 2.38.7）が並行して出ている。**moving tag の `stable` は 2.38.7、`beta` は 2.39.4 を指す**（2026-09-11 時点）。

## できるようになったこと

- 旧形式のデータ暗号鍵を持つ環境が、起動時に自動修復される

## 影響範囲

- 対象ユーザー: n8n セルフホスト運用者（旧バージョンから継続運用している環境）
- 対象プラン: セルフホスト
- API / UI / 管理者機能: 起動処理（暗号鍵の取り扱い）

## 教材化メモ

- **暗号鍵の形式移行が起動時の自動修復として入る**のは、長期運用しているセルフホスト環境でしか顕在化しない類の問題である。新規構築では一度も踏まない。**「動いている環境ほど、移行の負債が見えないまま溜まる」**という、セルフホスト運用の一般則の実例。
