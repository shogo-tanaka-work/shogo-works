# 2026-09-15 n8n 2.40.0（pre-release）

## 公式内容の日本語要約

**窓内で唯一のマイナー版**で、pre-release として公開された。バグ修正は150件超あるため、ここでは運用判断に効くものだけを拾う。

**非推奨と破壊的変更**: **Chat Hub が非推奨になり、移行警告が出る。** `N8N_DB_PING_TIMEOUT` などの環境変数も非推奨となり、起動時に警告が出る。

**権限・資格情報**: **global member が API キーへフォルダスコープを付与できる**ようになった。secret コンテナ内の不透明なフィールド値を、**全インスタンス種別で redaction 対象**に含めるよう修正。**データテーブル一覧のアクセスが、グローバルなゲートではなくプロジェクトロールでスコープされる**よう変更。**エンドユーザーの資格情報チェックを、到達可能なノードだけにスコープ**するよう変更。

**ノード・エージェント**: Microsoft Dataverse のコアノード追加。Microsoft Teams のオンライン会議操作とチャット管理を追加。AI Agent で**初回イテレーションでのツール呼び出しを強制**できる。**エージェント主導のエピソード記憶キャプチャ**に対応。

**基盤**: Git ベースのデプロイで**選択的なプロモーション**、structured output parser の検証、**エフェメラルなサンドボックス**対応。HTTP Request ノードが WebDAV メソッド（`PROPFIND` / `MKCOL` / `MOVE` / `COPY` / `REPORT`）に対応。

## 影響範囲

- 対象ユーザー: n8n 管理者、Chat Hub 利用者、API キー運用者
- 対象プラン: 記載なし。pre-release（`beta` タグ系列）
- API / UI / 管理者機能: 権限スコープ、API キー、環境変数、ノード

## 教材化メモ

**権限スコープの粒度が一段下がった週として記録する。** データテーブル閲覧が**グローバルゲートからプロジェクトロールへ**、資格情報チェックが**到達可能なノード限定へ**、API キーが**フォルダスコープ付きへ**。**3つとも「広すぎた範囲を実際に必要な範囲へ絞る」方向**で、同じ週の Claude Code のコマンド単位 `allowed_domains`（2.1.271）と設計の向きが一致している。**最小権限の粒度を下げるのが今の潮流である**という主張を、2製品の独立した実装で裏づけられる。

**Chat Hub の非推奨は期限が示されていない。** 移行警告が出る段階なので、**利用している環境は代替の確認を始める**という扱いにとどめる。
