# 2026-08-06 n8n 2.34.1 / 2.34.2

## 公式内容の日本語要約

前日の 2.34.0（ワークフローレビュー承認フロー、instance MCP の Agent 管理）に続くパッチが 2 本。いずれもバグ修正のみで新機能はない。

`2.34.1`（2026-08-05）は、応答しなくなったタスクランナーの復旧処理（#35527）と、長いラベルを持つエージェント機能チップの表示崩れ修正。`2.34.2`（2026-08-06）は、Markdown エディタでツールバーより先に入力欄へフォーカスする修正と、エージェントツールの認証情報を設定より上に表示する UI 変更。

保守ブランチ側も同時に更新されており、`2.33.4`（タスクブローカーの耐障害性向上、AI Assistant での冗長なワークフロー編集承認のスキップ）、`2.33.5`（Markdown エディタのフォーカス修正）、`1.123.69` が出ている。

タスクランナーの復旧処理が 2.33 系・2.34 系の両方に入っている点は、セルフホスト運用者にとって実務的な意味がある。

## できるようになったこと

- 応答しないタスクランナーからの復旧処理が入った（2.33.4 / 2.33.5 / 2.34.1）
- タスクブローカーがランナー停止時により堅牢に動作するようになった
- Markdown エディタが入力欄へ先にフォーカスするようになった
- エージェントツールの認証情報が設定より上に表示されるようになった

## 影響範囲

- 対象ユーザー: n8n セルフホスト運用者、エージェント機能利用者
- 対象プラン: OSS / Cloud 共通（stable）
- API / UI / 管理者機能: 実行基盤の安定性 + エディタ UI

## 教材化メモ

- パッチ単体では教材化しない。ただし「タスクランナーが応答しなくなる」事象は n8n セルフホストの運用教材で扱う典型的な障害パターンなので、バージョン更新が対処の第一手であることの実例として保持する。
