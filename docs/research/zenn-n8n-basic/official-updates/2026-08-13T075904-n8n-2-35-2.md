# 2026-08-13 n8n 2.35.2 / 1.123.71

## 公式内容の日本語要約

2.35.2（pre-release、2026-08-13T07:59:04Z）は core のバグ修正1件。publication outbox 経由で有効化されたトリガーについて、実際の activation mode が正しく報告されるようになった（#36151）。

1.123.71（2026-08-13T08:06:46Z）は 1.x 系のバックポート。

2 日連続でパッチが出ている（前日は 2.34.5 / 2.35.1 / 1.123.70）。2.35.0 の機能リリース（Agent Builder のテスト実行と HITL、Discord チャネル、カスタムロール API）以降、追随の修正が続いている状態である。stable 側に新しい機能リリースはない。

## できるようになったこと

- publication outbox 経由で有効化したトリガーの activation mode が実態どおりに報告される

## 影響範囲

- 対象ユーザー: セルフホスト運用者、特にワークフローの有効化状態を監視・記録している環境
- 対象プラン: セルフホスト / クラウド共通
- API / UI / 管理者機能: core（トリガーの有効化処理）

## 教材化メモ

- activation mode の誤報告は、**監視・監査の観点で見ると地味に効く不具合**である。ワークフローがどの経路で有効化されたかを記録している運用では、記録が実態とずれる。自動化基盤の運用を扱う教材で「動いているように見えて記録が違う」類の障害例として使える。
- 2.35.0 のリリース後、2 日連続でパッチが出ている事実そのものが教材になる。**機能リリース直後の版を本番へ即時適用しない**という運用判断の裏づけとして、日付とバージョン列をそのまま示せる。
