# 2026-09-18 n8n 2.39.8（stable）

## 公式内容の日本語要約

**Bug Fixes が3件。窓の終端時点で `stable` タグが指している実バージョンである。**

**生のインスタンス鍵として保存されたデータ暗号鍵を修復する。**

**完了済みのサブ実行に対して、親プロセスが停留したままになる**問題を修正。サブワークフローが終わっているのに親側が解放されない形で、**長時間動かしている環境ほど実行スロットを食い潰す。**

**AI Assistant 内でワークフロープレビューが空白になる**問題を修正。

**`stable` / `beta` は moving tag であるため、実バージョンを必ず確認する。** 窓の終端時点で **`stable` = 2.39.8（09-18T07:55:08Z 更新）、`beta` = 2.40.3（09-18T07:41:25Z 更新）** である。

## できるようになったこと

- 誤形式のデータ暗号鍵が起動時に修復される
- 完了したサブ実行の親が正しく解放される
- AI Assistant のワークフロープレビューが表示される

## 影響範囲

- 対象ユーザー: `stable` チャネルの利用者全般。**サブワークフローを多用している環境**
- 対象プラン: 記載なし
- API / UI / 管理者機能: 起動時の鍵修復、実行エンジン、AI Assistant

## 教材化メモ

**「完了しているのに親が解放されない」は、リソースリークの教材として分かりやすい。** エラーにならず、実行は成功扱いのまま、**スロットだけが減っていく。** 症状は「だんだん遅くなる」「同時実行数に届かなくなる」という形で現れ、**原因に辿り着くまでが遠い。** 監視で見るべきは成功率ではなく**実行中の滞留数**である、という具体例にできる。

**n8n を自動化基盤として社内へ入れる場合の運用ポイントにも直結する。** サブワークフローを積極的に使う設計ほどこの影響を受けるため、**構成の選択が運用リスクの大きさを決める**という話に繋げられる。
