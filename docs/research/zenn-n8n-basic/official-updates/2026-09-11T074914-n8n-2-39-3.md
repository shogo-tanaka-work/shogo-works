# 2026-09-11 n8n 2.39.3

## 公式内容の日本語要約

小規模な修正リリース。**source control の HTTPS remote に対して、`GIT_SSL_CAINFO` が指す CA 証明書を信頼する**ようになった（`Trust the CA from GIT_SSL_CAINFO for source control HTTPS remotes`）。

社内 CA で署名された Git サーバーへ HTTPS で接続する構成で、証明書検証に失敗していた問題への対処である。

## できるようになったこと

- `GIT_SSL_CAINFO` で指定した社内 CA を使って、HTTPS の Git remote へ接続できる

## 影響範囲

- 対象ユーザー: 社内 CA 配下の Git サーバーへ source control 連携している運用者
- 対象プラン: セルフホスト / エンタープライズ機能
- API / UI / 管理者機能: source control（TLS 検証）

## 教材化メモ

- **社内 CA 環境で動かないのは、AI / 自動化ツール導入で定番の詰まりどころである。** 同じ週の Claude Code の前週ぶん（2.1 系）でも Bedrock の社内ルート CA 環境での失敗が修正されており、**製品を問わず同じ壁に当たる。** 企業導入の事前チェックリストに「社内 CA 配下で TLS 検証が通るか」を入れる根拠として、複数製品の実例が揃ってきた。
