# 2026-10-09 n8n の stable が 2.42 系へ昇格

## 公式内容の日本語要約

moving tag の **`stable` が指す実バージョンが 2.42.6（2026-10-09）になった。** 前週（2026-10-05 の週次サマリー）時点では **`stable` = 2.41.6、`beta` = 2.42.2** だったため、**本窓で 2.42 系列が stable へ昇格した。**

**これにより、前週に「beta チャネルのため stable では使えない」と記録した 2.42.0 の統制機能が stable で利用できるようになった。** 該当するのは、**インスタンス資格情報に対する view / use / manage のカスタムロール**、粒度の細かい資格情報共有の feature flag、**資格情報を workflow runner に対して検証**、保存 / 公開 / 実行の拒否時にポリシー違反をスコープ付きで表示、SSO 有効時に SSO を主要なサインイン手段として表示である。

**`beta` は 2.43.3（2026-10-09）を指す。**

2.42.6 自身の内容は 2.43.3 の backport で、**Features 2件**（**deprecated node を使うワークフローの作成・更新をブロック**、Google Gemini ノードの画像モデル一覧へ Nano Banana 2.1 / 2 Lite 追加）である。bug fixes の記載は無い。

**窓内に出た 2.42 系の backport は 2.42.4（10-07）、2.42.5（10-08）、2.42.6（10-09）の3本**で、それぞれ 2.43.1 / 2.43.2 / 2.43.3 に対応する。**1.x 系の LTS backport として 1.123.84（10-08）も出ている**が、**GitHub Releases のページに changelog 本文が載っておらず、内容は確認できていない。**

## できるようになったこと

- stable チャネルで資格情報の view / use / manage カスタムロールが使える
- stable で deprecated node を使うワークフローの作成・更新がブロックされる

## 影響範囲

- 対象ユーザー: n8n セルフホスト運用者（stable チャネル）
- 対象プラン: 記載なし。資格情報のカスタムロールは enterprise 機能として扱われる想定だが本リリースノートに明示なし
- API / UI / 管理者機能: 資格情報の権限管理、ワークフローの保存・公開・実行

## 教材化メモ

- **前週に「次の昇格を待つ」と書いた項目が、1週で解消した。** 継続案件として残した判断が機能した形である。**moving tag を追う運用では、「機能が出た日」と「stable で使える日」を別に記録する必要がある**という原則の実例になる。
- **`deprecated node を使うワークフローの作成・更新をブロック`は、破壊的変更に近い。** 既存のワークフローの実行は止まらないが、**編集して保存できなくなる**。deprecated node を抱えたまま運用している環境は、**更新前に棚卸しが必要**である。リリースノートでは Features 扱いだが、利用者側から見れば移行作業の締切が入ったのと同じである。
- **1.123.84 の内容が公式ページから読めない**点は、「リリースノートが空のリリース」の2例目である（同じ窓で Codex 0.161.0 も同じ症状だった）。**版は出たが内容は未公開、と書き切る。**
