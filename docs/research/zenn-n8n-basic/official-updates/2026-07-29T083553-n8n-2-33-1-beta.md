# 2026-07-29 n8n 2.33.1（beta）

## 公式内容の日本語要約

n8n の beta 版 2.33.1。追加は1件で、ライフサイクルの external hooks に workflow hook context を渡すようになった（#35084）。external hooks 側でワークフロー実行のコンテキスト情報を参照できるようになるため、セルフホスト環境で独自のフック処理を書いている場合に扱える情報が増える。

同日に beta タグも 2.33.1 を指すよう更新されている。前日の 2.33.0（2026-07-28）に続く beta リリース。

## できるようになったこと

- ライフサイクルの external hooks から workflow hook context を参照できる

## 影響範囲

- 対象ユーザー: external hooks を実装しているセルフホスト運用者
- 対象プラン: セルフホスト（beta チャネル）
- API / UI / 管理者機能: core（external hooks）

## 教材化メモ

- external hooks は n8n をプラットフォームとして拡張する際の接点。監査ログや通知を自前で挟む構成の説明で参照できる
