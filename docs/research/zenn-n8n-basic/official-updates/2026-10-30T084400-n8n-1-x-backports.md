# 2026-10-30 n8n 1.x 系 backport

## 公式内容の日本語要約

窓内に 1.x 系の backport が4本出た。

- **1.123.88**（10-26T06:49Z）: 書き込み用コネクションのオープン失敗時に SQLite の書き込みロックを解放、task runner の certifi を 2026.10.23 へ更新。
- **1.123.89**（10-28T07:28Z）: Google Drive ノードの v1 API リクエストでのページネーション無限ループ、**MCP Server Trigger ノードでアイドルセッションを退去させてメモリリークを防ぐ**（#42120）。
- **1.123.90**（10-29T09:00Z）: **招待の受理に署名付きトークンを要求**（#42292）。Google Drive Trigger ノードが変更一覧ではなく監視対象アイテムを直接読む性能改善。
- **1.123.91**（10-30T08:44Z）: レガシー Code ノード出力に対する `$('Node')` 式が null を返す問題の修正。

## 影響範囲

- 対象ユーザー: n8n 1.x 系を使い続けているセルフホスト環境
- 管理者: **1.123.90 の「招待の受理に署名付きトークンを要求」はアカウント招待フローのセキュリティ修正**。1.x 系に留まっている環境はこの版以上へ上げる

## 教材化メモ

記事化しない（週次ソースの巡回記録）。1.x 系にもセキュリティ修正（招待受理の署名付きトークン要求、MCP Server Trigger のメモリリーク）が入っており、**2.x へ上げられない環境でも 1.123.90 以上への追従は必要**である。「メジャーを上げられないから放置」という状態が成立しないことの実例。
