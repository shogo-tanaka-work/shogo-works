# 2026-10-08 n8n 2.43.2

## 公式内容の日本語要約

**pre-release**。Features の記載は無く、**Bug Fixes 2件**である。

**core**: **セルフホスト Assistant で Kimi K3 とその他の OpenAI 互換 Assistant モデルプロバイダーが動かなかった問題**を修正（#40552）。

**editor**: builder が Agent artifact を作成している間、その artifact を表示する（#40550）。

**2.42 系へは 2.42.5（2026-10-08T07:21 頃）として backport されている**（editor 側の #40551 のみ）。

## できるようになったこと

- セルフホスト Assistant で Kimi K3 など OpenAI 互換プロバイダーを使える
- Agent artifact の生成中も内容が見える

## 影響範囲

- 対象ユーザー: n8n セルフホストで Assistant に自前のモデルプロバイダーを設定している利用者
- 対象プラン: 記載なし（セルフホスト）
- API / UI / 管理者機能: core（Assistant のモデルプロバイダー）、editor

## 教材化メモ

- **「OpenAI 互換」を謳うエンドポイントが、実際には互換でない箇所で落ちるという典型例である。** セルフホストで自前のモデルを挿す構成は、**互換性の差分が修正されるまで使えない期間が出る。** 本番の自動化を自前モデルに寄せる場合、**プロバイダー差分の修正が上流のリリースサイクルに依存する**というリスクを計上する必要がある。
- backport の対象が editor 側だけで、**core 側の修正（Kimi K3）は 2.43 系にしか入っていない**可能性がある点は、**stable を使う運用では修正が届く時期が遅れる**という具体例として記録しておく。
