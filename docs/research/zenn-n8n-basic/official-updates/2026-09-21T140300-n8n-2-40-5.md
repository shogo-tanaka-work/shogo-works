# 2026-09-21 n8n 2.40.5

## 公式内容の日本語要約

n8n `2.40.5` が 2026-09-21T14:03Z に公開された。**リリースノートの記載は bug fix 1件のみ**である。

- **Limit declarative routing during base URL ownership checks**（#39147、commit `ebe5a73`）

**前週からの系列として読むのが正確である。** 09-16 の `1.123.80`（declarative ノードのリクエストに資格情報の許可ドメインが適用されていなかった）と 09-17 の `1.123.81`（絞りすぎて正常利用まで弾く追随修正）と同じ **declarative routing と base URL の扱いの系列**にあたる。**ただし公式リリースノートはコミットタイトル1行のみで、資格情報の許可ドメイン制限との関係を明言していない。** 断定はせず、**同系列の追随修正と見られる**にとどめる。

**チャネルの位置づけが前週から変わっている。** 前週の窓の終端では `stable` = 2.39.8、`beta` = 2.40.3 だった。**本週の終端では `stable` = 2.40.7、`beta` = 2.41.3 で、2.40.x が beta から stable へ昇格している。**

## できるようになったこと

- base URL の所有確認時に declarative routing が制限される（修正）

## 影響範囲

- 対象ユーザー: n8n 2.40.x 系の利用者
- 対象プラン: セルフホスト / クラウドとも
- API / UI / 管理者機能: declarative ノードのリクエスト経路
