# 2026-08-18 n8n 2.36.0

## 公式内容の日本語要約

窓内に n8n の release が 5 本出ました。本ファイルは中身が最も大きい 2.36.0 を主対象とします（他は下記「窓内の他リリース」参照）。

**破壊的変更が3件**あります。1 つ目は式（expression）の `Array.merge` の廃止と `Array.mergeIntoObject` の追加。既存ワークフローの式に `Array.merge` を使っている場合、書き換えが必要になります。2 つ目はエンドユーザーによる認証情報（credential）作成が team project 内に限定されたこと。個人スコープで認証情報を作らせる運用をしていた組織は、権限設計の見直しが要ります。3 つ目は durable poller が重複したトリガーノード ID を持つ場合に有効化を拒否するようになったことです。

機能面は Agent 周りが中心です。新規 agent のモデルが妥当な既定値で自動選択されるようになり、MCP server のツールを skill builder から使えるようになりました。agent サンドボックスが principal 単位で実行を分離するようになったのはセキュリティ上の変更です。Agent Knowledge が n8n Sandbox に対応し、agent 向けの Slack 連携チャネルが追加されました。

ワークフロー運用では、Schedule Trigger がダウンタイム後のキャッチアップ実行をまとめる（coalesce）ようになりました。停止から復帰したときに溜まった実行が一斉に走る問題への対処です。猶予期間付きの未実行ハンドリングも追加されています。MCP 経由でのデータテーブル行の読み取り、フォルダ作成、ワークフロー移動も可能になりました。パッケージエクスポートでワークフローのバージョンポリシーを保持できます。

API はロール管理エンドポイント（一覧、個別取得、ロールマッピング規則の作成、カスタムロールの更新）が追加されました。ノードは Discord にメンバーモデレーション操作、Confluence Cloud に OAuth2 資格情報とページ取得、そして **Google Ads ノードが API v21 から v25 へ移行**しています。

## できるようになったこと

- 新規 agent のモデル既定値の自動選択、skill builder からの MCP server ツール利用
- agent サンドボックスの principal 単位分離、Agent Knowledge の n8n Sandbox 対応、agent の Slack チャネル
- Schedule Trigger のキャッチアップ実行の集約と猶予期間付き未実行ハンドリング
- MCP 経由でのデータテーブル行読み取り・フォルダ作成・ワークフロー移動
- ロール管理 API（一覧 / 取得 / マッピング規則作成 / カスタムロール更新）
- Discord のメンバーモデレーション、Confluence Cloud OAuth2、Google Ads v25

## 影響範囲

- 対象ユーザー: セルフホスト / クラウドを問わず 2.36 系へ上げる全利用者。特に式で `Array.merge` を使っている作成者、個人スコープで認証情報を作らせている管理者
- 対象プラン: stable チャネル。team project 関連の変更は複数人運用の組織に影響
- API / UI / 管理者機能: 破壊的変更3件は管理者の事前確認が必要
