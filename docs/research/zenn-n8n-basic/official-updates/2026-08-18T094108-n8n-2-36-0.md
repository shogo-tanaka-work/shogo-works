# 2026-08-18 n8n@2.36.0（beta）

## 公式内容の日本語要約

2.35.0 からの minor リリース。GitHub 上は prerelease で、`beta` タグが 2.36.0 を指す一方、`stable` タグは 2.35.3（2026-08-14）のままである。安定版利用者にはまだ届かない。

**MCP まわりの拡充**が目立つ。`get_workflow_versions_diff`（ワークフローのバージョン差分取得）、フォルダ作成とワークフロー移動、データテーブル行の読み取りが MCP tool として追加された。新規ワークフローを設定のトグルで自動的に MCP へ公開する機能、MCP トリガーのツールへ受信リクエストヘッダを渡す修正、MCP 2026-07-28 のルーティングヘッダを CORS で広告する対応も入っている。

**Agent 実行環境**では、Agent sandbox を principal 単位で分離し、Instance AI のセットアップから有効化できるようになった。Agent Knowledge が n8n Sandbox に対応し、エージェントに書き込み可能なワークスペースを持たせられる。Slack 連携も新規に追加された。

**API では role 関連のエンドポイントが揃った**。ロール一覧、単一ロール取得、カスタムロール更新、role-mapping ルール作成が追加され、n8n User Auth（OAuth2）が GA になった。

Bug Fixes は ai-builder と core が大半で、AI Assistant がワークフローを編集してもノード ID を保つ、Anthropic の thinking 履歴をエージェントのターン間で保持する、といった修正が含まれる。

## できるようになったこと

- MCP tool の追加（バージョン差分、フォルダ作成 / ワークフロー移動、データテーブル読み取り）と新規ワークフローの MCP 自動公開トグル
- Agent sandbox の principal 単位分離、Agent への書き込み可能ワークスペース、Slack 連携
- ロール系 REST API の追加と n8n User Auth（OAuth2）の GA

## 影響範囲

- 対象ユーザー: n8n の beta channel 利用者。stable 利用者には未提供
- 対象プラン: ロール・role mapping はエンタープライズ機能相当
- API / UI / 管理者機能: Public API に role 系エンドポイントを追加

## 教材化メモ

- **MCP を「n8n から外部を呼ぶ」だけでなく「n8n 自身を MCP サーバーとして外へ出す」方向**が進んでいる。ワークフローの自動公開トグルとバージョン差分ツールは、AI エージェントに n8n の運用を任せる前提の作りになっている。教材で MCP を扱うなら、この双方向の構図として説明できる。
- Agent sandbox の principal 単位分離は、複数人・複数プロジェクトで n8n のエージェントを動かすときの分離境界の話。セキュリティ設計の例として使える。
- 速報記事化は見送った。beta channel のみで stable 利用者に影響がなく、stable 昇格時に扱う方が読者の判断材料として明確なため。
