# 2026-09-25 n8n 2.41.3

## 公式内容の日本語要約

n8n `2.41.3` が 2026-09-25T07:28Z に **pre-release（beta 系列）**として公開された。内容は **プロジェクトの span 属性をノードの span へ伝播させる**修正である。OpenTelemetry のトレースで、**どのプロジェクトの実行かをノード単位のスパンから辿れるようになる。**

**窓の終端（2026-09-28T00:30Z）時点で、`beta` moving tag が指す実バージョンは 2.41.3 である。**

## できるようになったこと

- OpenTelemetry のノード単位スパンにプロジェクトの属性が伝播する

## 影響範囲

- 対象ユーザー: n8n の beta チャネル利用者で OpenTelemetry を使っている環境
- 対象プラン: セルフホスト / クラウドとも
- API / UI / 管理者機能: OpenTelemetry のスパン属性

## 教材化メモ

- **`stable` / `beta` が moving tag である**ため、タグ名だけで環境を特定できない。**「beta を使っている」という申告は、いつ取得したかによって中身が違う。** 環境の再現性を担保するには実バージョンで固定する、という運用の基本。
