# 2026-09-17 n8n 1.123.81（1.x backport）

## 公式内容の日本語要約

**1.x 系への backport。Bug Fixes が4件で、うち3件が依存ライブラリの更新である。**

**資格情報**: **ドメイン制限付きの資格情報が、自分のノード内で動くようにする**（#38786）。前日の 1.123.80（#38723）で **declarative ノードのリクエストへ許可ドメインを適用**したことに対する追随で、**適用範囲を広げすぎて自ノードでの正常利用まで弾いていた**形と読める。

**依存更新**: **undici 7.29.1**（#38849）、**vm2 3.12.2**（#38846）、**Snowflake SDK 3.3.0**（#38831）。undici は HTTP クライアント、**vm2 は JavaScript のサンドボックス実行**にあたる。

**公式リリースノートは各項目を "fix" としか書いておらず、CVE 番号やセキュリティ勧告への言及は無い。** 脆弱性修正であるかどうかは、**この一次情報だけからは確定できない。**

## 影響範囲

- 対象ユーザー: 1.x 系を使い続けているセルフホスト環境。資格情報のドメイン制限を使う組織、Snowflake 連携の利用者
- 対象プラン: 1.x LTS 系列
- API / UI / 管理者機能: 資格情報のドメイン制限、HTTP クライアント、コード実行サンドボックス

## 教材化メモ

**2日で「絞る → 絞りすぎを戻す」が起きた点が、統制変更の実務そのものである。** 1.123.80 で許可ドメインを declarative ノードへ適用し、1.123.81 で自ノードでの利用を回復した。**権限を締めると、意図した抜け穴と一緒に正当な利用も止まる。** 本番へ入れる前に**「止まってほしくない経路」を先に列挙して確認する**という手順の根拠になる。

**依存更新の扱いは、記録の仕方に注意が要る。** `vm2` はサンドボックス実行ライブラリで、過去に脱出系の脆弱性が繰り返し報告されてきた経緯がある。ただし**今回のリリースノートは CVE を示していない**ため、**「セキュリティ修正である」と本メモで断定しない。** 実際の適用判断は、各パッケージの changelog / advisory 側で確認する。
