# 2026-09-17 n8n 2.39.7

## 公式内容の日本語要約

**Bug Fixes が2件で、同日の 2.40.2 と同内容のバックポートである。**

**core: ルールが例外を投げても breaking change 検出を継続する**（#38790）。

**editor: 資格情報の入力欄で数値を数値として送信する**（#38881）。

PR 番号は 2.40.2 側（#38789 / #38880）と別で採番されているが、変更内容は対応している。commit は `829b4ac`。

## できるようになったこと

- 一部の breaking change ルールが失敗しても、残りのルールによる検出が続く
- 資格情報の数値フィールドが正しく送信される

## 影響範囲

- 対象ユーザー: 2.39.x（`stable` 系列）を使っている環境
- 対象プラン: 記載なし
- API / UI / 管理者機能: 起動時の breaking change 検出、資格情報エディタ

## 教材化メモ

**2.39.x（stable）と 2.40.x（beta）へ同日に同じ修正が入る運用は、週次巡回の読み方に直結する。** 版数だけを並べると「今週 n8n は10版出た」に見えるが、**実体は同じ修正が2系列＋1.x backport へ配られているだけ**のことが多い。**版数を数えるのではなく、修正の本数を数える。**

本週の10版は、**実際の変更内容で数えると6系統**（資格情報の失効、breaking change 検出の継続と v3 ルール、暗号鍵の修復、AI Assistant プレビュー、資格情報の許可ドメイン、依存更新）に収まる。週次まとめで扱うときはこの粒度に直す。
