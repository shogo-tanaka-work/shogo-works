# 2026-10-22 n8n stable が 2.44.6 へ

## 公式内容の日本語要約

**窓内（2026-10-19〜10-26）に 2.44 系の patch が3版出て、`stable` タグが 2.44.6 を指すようになった。** 前週時点の `stable` は 2.43.7 だったため、**`stable` がまたマイナーを跨いで動いた**（2.43.7 → 2.44.6）。`stable` は moving tag であり、タグ名だけでは実バージョンが分からない。

各版の内容はいずれも小規模な修正で、新機能の記載はない。

- **2.44.4**（10-19 07:23）: Core — webhook 宛のログストリーミングが既存接続を再利用する（毎回新規接続を開かない）。Core — expression spans を既定で無効化。
- **2.44.5**（10-21 07:26）: Core — シャットダウン後の再開時に job outcome を job 単位でキー付けする（#41404）。Editor — 起動時に credential types を読み込む（#41405）。
- **2.44.6**（10-22 09:21）: Nodes — Postgres ノードがグローバルな pgtypes を上書きしないよう修正（#41667）。セキュリティ関連の記載はなし。

同じ窓内に 2.43 系の最終 patch（2.43.8）と 1.x 系の backport（1.123.86 / 1.123.87）も出ている。詳細は別メモ（`2026-10-23T075100-n8n-1-x-backports.md`）。

## 教材化メモ

- **`stable` タグが 2.43.7 → 2.44.6 とマイナーを跨いだ。** 前週の記録でも同じこと（2.42.6 → 2.43.7）が起きており、**2週連続で `stable` 追従が実質的なマイナーアップグレードになっている。** `image: n8n:stable` のような指定で運用している環境は、patch 相当のつもりで minor を取り込むことになる。**バージョン固定の是非を考える題材としてそのまま使える。**
- `2.44.4` の「expression spans を既定で無効化」は、**前週に既定有効化されたものが1週で既定無効へ戻された**形である（2.43.8 にも同じ修正が入っている）。可観測性の追加が性能や安定性の問題を起こして戻される、という流れの実例。
- Postgres ノードの「グローバル pgtypes の上書き」は、**ノードがプロセス全体の状態を書き換えてしまう種類の不具合**である。プラグイン的に拡張できる仕組みで共有状態を触ることの危険性の例になる。
