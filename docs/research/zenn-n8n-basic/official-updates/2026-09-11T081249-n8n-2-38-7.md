# 2026-09-11 n8n 2.38.7

## 公式内容の日本語要約

2.38 系のバックポートリリース。バグ修正3件を含む。

**MCP toolkit のメンバーを worker 上で実行する**（`Execute MCP toolkit members on workers`）。**フロー途中で認証した場合の consent grant 再利用**（2.39.2 と同内容のバックポート）。**source control の HTTPS remote における CA 信頼設定**（2.39.3 と同内容のバックポート）。

**moving tag の `stable` は、2026-09-11T08:07:35Z 時点でこの 2.38.7 を指している。** `beta` は 2.39.4 を指す。

## できるようになったこと

- MCP toolkit のメンバーが worker 上で実行される
- フロー途中の認証で consent grant が再利用される（2.39.2 のバックポート）
- 社内 CA 配下の HTTPS Git remote へ接続できる（2.39.3 のバックポート）

## 影響範囲

- 対象ユーザー: 2.38 系を使い続けている n8n 運用者、MCP 連携を使う環境
- 対象プラン: セルフホスト / クラウド
- API / UI / 管理者機能: 実行基盤（worker）、認証フロー、source control

## 教材化メモ

- **MCP toolkit のメンバーを main プロセスではなく worker で実行する**のは、実行分離の話である。MCP サーバーは外部プロセスを起動しうるため、main で走らせると1つの重い呼び出しがインスタンス全体を詰まらせる。**AI 連携を本番運用へ載せるときの構成論点**として、素直な教材になる。
- **`stable` が 2.38.7、`beta` が 2.39.4** という状態は、`source-catalog.md` が指示する「moving tag の実バージョン確認」をまさに要求するケース。**「stable を使っています」だけでは何版か分からない。**
