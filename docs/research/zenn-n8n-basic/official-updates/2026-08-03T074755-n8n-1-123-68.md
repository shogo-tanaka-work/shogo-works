# 2026-08-03 n8n 1.123.68

## 公式内容の日本語要約

現行の 2.x 系ではなく、1.x 系へのバックポートリリース。含まれる変更は Bug Fixes 1件のみで、Onfleet Trigger ノードの content type の扱いを修正した（PR #24878、1.x backport）。

新機能・破壊的変更・ポリシー変更は含まれない。2.x 系利用者には影響がなく、1.x 系に留まっている環境で Onfleet Trigger を使っている場合のみ関係する。

## できるようになったこと

- 1.x 系で Onfleet Trigger ノードの content type 起因の不具合が解消される

## 影響範囲

- 対象ユーザー: 1.x 系を継続利用しており、かつ Onfleet Trigger ノードを使っている環境のみ
- 対象プラン: セルフホスト / クラウド共通（該当ノード利用時）
- API / UI / 管理者機能: ノード実装のみ。設定・API の変更なし

## 教材化メモ

- 単一ノードのバグ修正バックポートのため AIニュース記事化は見送り。`selection-rubric.md` の D（小規模バグ修正のみ）に該当する。
- n8n が 2.x 系と並行して 1.x のバックポートを出し続けている点は、バージョン固定運用をしている組織向けの補足として使える。
