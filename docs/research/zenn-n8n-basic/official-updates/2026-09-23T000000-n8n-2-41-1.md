# 2026-09-23 n8n 2.41.1

## 公式内容の日本語要約

n8n `2.41.1` が **pre-release（beta 系列）**として公開された。**リリースノートの記載は2件のみ**である。

- **Features / Core: Enable Agents by default**（#39328）
- **Bug Fixes / Core: Redis 再接続後の pubsub 購読の復旧と、half-open な subscriber 接続の検出**（#39241）

**`Enable Agents by default` の中身は、公式リリースノートに説明が無い。** 対象機能の範囲・影響・無効化の手段はいずれも記載されておらず、**リンク先の issue #39328 を見ないと分からない。** 本メモでは**「Agents が既定で有効になった」という事実のみを記録し、内容の推測はしない。**

**既定値の変更である点は運用上重要である。** 利用者が何も設定しなくても挙動が変わる類の変更であり、**beta チャネルを使っている環境は 2.41.1 を入れた時点で Agents が有効になる。**

## できるようになったこと

- Agents が既定で有効になる（**機能範囲は公式リリースノートに記載なし**）
- Redis 再接続後に pubsub 購読が復旧する（修正）

## 影響範囲

- 対象ユーザー: n8n の beta チャネル利用者
- 対象プラン: 不明（リリースノートに記載なし）
- API / UI / 管理者機能: **既定値の変更**。無効化の手段はリリースノートに記載なし

## 教材化メモ

- **「既定で有効化」とだけ書かれたリリースノート**の扱い方が題材になる。何が有効になるのか、止められるのか、が書かれていない。**既定値を変える変更は、変更内容そのものより影響範囲の説明が要る**という、リリースノートを書く側の教材にもなる。
- **Redis の half-open 接続の検出**は、症状が「エラーにならず動かない」型の障害である。**接続が生きているように見えて購読が届かない。** 監視の設計で、接続の有無ではなくメッセージの到達を見る必要がある例。
