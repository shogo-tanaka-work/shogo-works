# 2026-08-14 n8n 2.34.6 / 2.35.3

## 公式内容の日本語要約

**2.34.6（stable、2026-08-14T08:12:03Z）** はバグ修正3件。

- **Google Ads ノードが sunset 済みの v21 API から v25 へ移行**（#36260）。提供終了した API を叩き続けていた状態の解消であり、Google Ads ノードを使っているワークフローには実害が出ていた可能性がある。
- **Microsoft Teams ノードの `Group.ReadWrite.All` OAuth2 スコープを復元**（#36187）。過去に外れていたスコープを戻す修正で、Teams ノードの一部操作が権限不足で失敗していた状態が直る。
- `continueErrorOutput` モードで `details` フィールドを許可（#36229）。

**2.35.3（pre-release、2026-08-14T10:21:09Z）** は上記に加えて次を含む。

- 機能追加: **同一の Instance AI セッション内で作成されたワークフローについて、更新承認をスキップ**（#36106）。AI がワークフローを作った直後の編集で、毎回承認を求められる煩雑さを解消する変更である。
- ワークフロー publication outbox のレコード処理に中断デッドラインを設定（#36286）。
- エディタの ready-to-run デモテンプレートを現行の OpenAI モデルへ更新（#36201）。

3日連続でパッチが出ている（08-12、08-13、08-14）。stable 側は 2.34 系のバックポートが続いており、2.35 系の stable 昇格はまだない。

## できるようになったこと

- Google Ads ノードが現行の v25 API で動く
- Microsoft Teams ノードの `Group.ReadWrite.All` を要する操作が通る
- 同一 Instance AI セッション内で作成したワークフローの更新に承認が不要（2.35.3）

## 影響範囲

- 対象ユーザー: Google Ads ノード / Microsoft Teams ノードの利用者、Instance AI 利用者
- 対象プラン: セルフホスト / クラウド共通
- API / UI / 管理者機能: Google Ads ノード、Microsoft Teams ノード、core、エディタ

## 教材化メモ

- **Google Ads の v21 sunset 対応は、外部 API 依存の自動化が抱える構造的リスクの実例。**ワークフロー側は何も変えていないのに、依存先の API 提供終了で止まる。n8n 教材で「作って終わりにできない」ことを説明する具体例として使える。しかも利用者は n8n のリリースノートを読まない限り、なぜ止まったか分からない。
- ここから **依存ノードの更新情報をどう追うか**という運用の話へつなげられる。使っているノードの一覧を持ち、リリースノートで該当ノード名を検索する、という具体的な手順まで落とす。
- Microsoft Teams の OAuth スコープ復元は、**権限スコープが変わると何が壊れるか**の題材になる。スコープは目に見えないため、失敗して初めて気づく。認証まわりを扱う教材で使える。
- 「同一 Instance AI セッション内なら更新承認をスキップ」は、**AI が作ったものへの承認をどこまで求めるか**という設計判断の実例。毎回聞けば安全だが使われなくなる。セッション単位で緩めるという折衷案として整理できる。
- 3日連続のパッチという事実は、機能リリース直後の版を本番へ即時適用しない運用判断の裏づけとして引き続き使える。
