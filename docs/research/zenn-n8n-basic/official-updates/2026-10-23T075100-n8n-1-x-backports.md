# 2026-10-19〜23 n8n 2.43.8 と 1.x backport

## 公式内容の日本語要約

窓内に、現行系列（2.44 / 2.45）以外の保守リリースが3版出た。

- **2.43.8**（10-19 07:23）: Core — expression spans を既定で無効化（#41310）の1件のみ。新機能なし。**2.44.4 と同じ修正が 2.43 系へも入った**形である。
- **1.123.86**（10-22 10:11）: 1.x 系の保守リリース。
- **1.123.87**（10-23 07:51）: 1.x 系の保守リリース。**公式ページにリリースノート本文が無く、compare リンク（`n8n@1.123.86...n8n@1.123.87`）と guided diff ボタンのみ。** セキュリティ関連の記載もなし。コミットは GitHub の verified signature 付き（GPG key ID B5690EEEBB952194）。

**1.123.86 / 1.123.87 は本文未取得である。** 1.123.87 はページ自体にリリースノートが存在せず、1.123.86 は個別本文を取得していない。**前週の 1.123.85 でも同じ症状（本文なし）を記録しており、3週連続である。**

## できるようになったこと

- （保守リリース。2.43.8 は expression spans の既定無効化のみ）

## 影響範囲

- 対象ユーザー: 2.43 系または 1.x 系で運用を固定している環境
- 対象プラン: 記載なし（OSS / self-hosted）
- API / UI / 管理者機能: Core（2.43.8）、1.x 系は不明

## 教材化メモ

- **1.x 系の backport はリリースノート本文を持たない運用になっている。** 3週連続で本文が無いため、取得失敗ではなく**n8n 側の運用**と判断できる。変更内容は compare リンクのコミット差分を読むしかなく、**「LTS 相当の系列を使うと、変更内容の把握コストが上がる」**という保守戦略のトレードオフの実例になる。
- 2.43.8 と 2.44.4 に同じ修正（expression spans の既定無効化）が入っている点は、**複数系列を並行保守するときのバックポートの見え方**として分かりやすい。同じ日（10-19 07:23）に両系列が出ている。
- 窓内に n8n は実バージョン10版（2.43.8、2.44.4〜2.44.6、2.45.0〜2.45.3、1.123.86、1.123.87）と moving tag 2本（`stable`、`beta`）が出ている。**日次で追うと毎日「n8n に更新あり」になるが、運用判断に効くのは `stable` の指す先が動いたことと 2.45.0 の既定変更の2点だけである。** 週次へ移した判断の妥当性がそのまま確認できる。
