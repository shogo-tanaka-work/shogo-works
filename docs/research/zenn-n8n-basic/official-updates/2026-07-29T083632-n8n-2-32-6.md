# 2026-07-29 n8n 2.32.6（stable）

## 公式内容の日本語要約

n8n の stable 版 2.32.6。修正は1件のみで、Schedule Trigger が5フィールド形式の cron 式を受け付けるようになった（#35013）。n8n の cron は秒を含む6フィールド形式も扱うため、一般的な5フィールド表記を書いたときに弾かれていたケースの修正にあたる。

同日に stable タグも 2.32.6 を指すよう更新されている。

## できるようになったこと

- Schedule Trigger で5フィールドの cron 式（分 時 日 月 曜日）が使える

## 影響範囲

- 対象ユーザー: Schedule Trigger を cron 式で設定している利用者
- 対象プラン: セルフホスト / クラウド共通
- API / UI / 管理者機能: core（Schedule Trigger）

## 教材化メモ

- 教材で cron 式を扱う場合、n8n は秒を含む6フィールドも受け付ける点が混乱の元になる。5フィールドが通るようになったのはこのバージョン以降という前提を書き添えられる
