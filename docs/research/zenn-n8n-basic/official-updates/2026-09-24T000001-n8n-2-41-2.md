# 2026-09-24 n8n 2.41.2

## 公式内容の日本語要約

n8n `2.41.2` が **pre-release（beta 系列）**として公開された。**OpenTelemetry 関連の修正と、n8n Assistant のテスト実行の記録**が含まれる。同日の 2.40.6（stable 系列）と重なる修正がある。

## できるようになったこと

- n8n Assistant のテスト実行が記録される
- OpenTelemetry 関連の不具合が修正される

## 影響範囲

- 対象ユーザー: n8n の beta チャネル利用者
- 対象プラン: セルフホスト / クラウドとも
- API / UI / 管理者機能: OpenTelemetry のトレース出力、n8n Assistant

## 教材化メモ

- **AI アシスタントのテスト実行が記録される**というのは、エージェントの動作を後から検証できるかという論点に触れる。**何を試したかが残らないと、挙動の再現も原因調査もできない。** 同週の Claude Code v2.1.283（MCP ツール出力のログ記録）と同じ方向の変更として並べられる。
