# 2026-09-24 n8n 2.40.6

## 公式内容の日本語要約

n8n `2.40.6` が公開された。**OpenTelemetry とインスタンスレポート関連の修正**が含まれる。**2.40.x 系列への修正であり、同内容は beta 系列の 2.41.2 にも入っている**（同日公開）。

**同系列の修正が複数チャネルへ配られるのが n8n の常態である。** 版数で数えると多く見えるが、**内容で数えると系統は少ない。** 本週も 2.40.x（stable）・2.41.x（beta）・1.123.x（1.x backport）の3系列へ同じ修正が配られている。

## できるようになったこと

- OpenTelemetry とインスタンスレポートの不具合が修正される

## 影響範囲

- 対象ユーザー: n8n 2.40.x 系の利用者
- 対象プラン: セルフホスト / クラウドとも
- API / UI / 管理者機能: OpenTelemetry のトレース出力、インスタンスレポート

## 教材化メモ

- **n8n の版数の読み方**を毎週記録しておく価値がある。**同じ修正が3系列へ配られるため、版数の本数はリリースの活発さを表さない。** 「更新が多いツール」と評価する前に系統で数える、という読み方。
