# 2026-07-31 n8n 2.32.7（stable）/ 2.33.3（beta）

## 公式内容の日本語要約

同日に stable 2.32.7 と beta 2.33.3 がリリースされた。

**2.32.7（stable、2026-07-31T07:56:03Z）**: security audit の risk reporters を拡張子付きで import するよう修正（#35267）。1件のみ。

**2.33.3（beta、2026-07-31T07:57:44Z）**: 上記と同じ修正（#35275）に加え、MCP Server Trigger ノードで実行データの保存をツール呼び出しの完了後に行うよう修正（#35284）。

同日に stable タグと beta タグもそれぞれ更新されている。

## できるようになったこと

- security audit の risk reporters が正しく読み込まれる
- （beta のみ）MCP Server Trigger で、ツール呼び出しの完了後に実行データが保存される

## 影響範囲

- 対象ユーザー: security audit を利用している運用者、MCP Server Trigger を使うワークフロー作成者（beta）
- 対象プラン: セルフホスト / クラウド
- API / UI / 管理者機能: core（security audit）、MCP Server Trigger ノード

## 教材化メモ

- MCP Server Trigger の実行データ保存タイミングの修正は、n8n を MCP サーバーとして公開する構成でログの正確さに関わる。MCP 連携の教材で運用上の注意として触れられる
