# 2026-09-30 n8n 1.123.83

## 公式内容の日本語要約

1.x 系列への backport リリース。**公式の記載は1行のみ**である。

- **Bug Fixes**: 「review finding に対応するため **cjs-module-lexer を 2.2.0 に pin**」

**CVE 番号の言及はない。** 「review finding」という表現から、外部からの指摘に基づく依存バージョンの固定であることは読めるが、**脆弱性かどうかは公式記載からは判断できない。**

窓の終端時点で `v1` タグが指すのはこの 1.123.83 である。

## できるようになったこと

- 1.x 系列で `cjs-module-lexer` のバージョンが 2.2.0 に固定される

## 影響範囲

- 対象ユーザー: 1.x 系列を使い続けているセルフホスト環境
- 対象プラン: 1.x backport（`v1` タグ）
- API / UI / 管理者機能: なし（依存更新のみ）

## 教材化メモ

- **「review finding に対応して依存を pin」という書き方は、脆弱性対応とも品質対応とも読める。** CVE 番号が無いため、**利用者側は緊急度を判断できない。** 前週の 1.123.82（adm-zip 0.6.1 へ、同じく CVE 言及なし）と同じ形で、**2週連続で判断材料のない依存更新が 1.x へ入っている。**
- **1.x 系列が今も保守されている**という事実自体が運用判断の材料になる。2.x へ上げられない環境が残っていることの裏返しで、**メジャーアップグレードを先送りするコストが「判断材料の薄い backport を追い続けること」として現れる。**
