# 2026-07-28 n8n 2.33.0（beta）

## 公式内容の日本語要約

窓内にn8n betaチャンネルの `2.33.0` が公開された（`n8n@2.32.0` からの複数コミットをまとめた差分）。AI Builder/エージェント関連の機能追加とバグ修正が多数含まれる。

主な新機能:

- **Add admin-managed instance credentials**: インスタンス管理者がクレデンシャルを一元管理できる仕組みを追加
- **ai-builder**: 検証済みコミュニティノードをエージェントのツールとして利用可能に
- **API**: ワークフローのバージョン履歴を取得するエンドポイント `GET /workflows/{id}/history` を追加
- **API**: OpenTelemetry設定用の公開APIエンドポイントを追加
- Microsoft Azure Monitor / Dynamics / Graph Security / Azure Storage、および残りのGoogle系クレデンシャルでカスタムOAuthスコープを許可
- コミュニティノードパッケージ向けESLintルール（require-files-array）を追加

主なバグ修正: AI Builderのエージェントプレビュー/トレース周りの不具合多数、MCP OAuth2トークン期限切れ・PKCE処理、5フィールドcron式のスケジュールトリガー対応、SQLite上でのアクティブワークフローMCP更新失敗など。

## できるようになったこと

- インスタンス管理者がクレデンシャルを一元管理できる
- 検証済みコミュニティノードをエージェントのツールとして呼び出せる
- ワークフローのバージョン履歴をAPI経由で取得できる
- OpenTelemetry設定をAPI経由で操作できる
- Azure/Google系クレデンシャルでカスタムOAuthスコープを指定できる

## 影響範囲

- 対象ユーザー: AI Builder/エージェント機能利用者、インスタンス管理者、API利用者
- 対象プラン: betaチャンネル利用者（先行導入）
- API / UI / 管理者機能: 新規APIエンドポイント2件、管理者向けクレデンシャル管理UI、OAuthスコープ設定
