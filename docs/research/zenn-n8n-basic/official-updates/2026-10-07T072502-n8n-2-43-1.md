# 2026-10-07 n8n 2.43.1

## 公式内容の日本語要約

**pre-release** として公開された。Features の節は無く、**Bug Fixes 1件と Performance Improvements 2件**である。

**Bug Fixes**: editor — n8n Assistant と Execute ボタンの UI 詳細の調整。

**Performance Improvements**: core — **agent builder のシステムプロンプトを静的に保ち、プロンプトキャッシュを効かせる**。core — **インスタンスの AI skill sandbox をバックグラウンドで事前準備する。**

**2.42 系へは 2.42.4（2026-10-07T07:26:18Z）として backport されている。**

## できるようになったこと

- agent builder の応答が、プロンプトキャッシュにより速く・安く動く
- AI skill の sandbox が事前に用意され、初回実行の待ちが減る

## 影響範囲

- 対象ユーザー: n8n の agent builder / AI skill 利用者
- 対象プラン: 記載なし
- API / UI / 管理者機能: editor（Assistant / Execute）、core（agent builder、AI skill sandbox）

## 教材化メモ

- **「システムプロンプトを静的に保つ」ことがパフォーマンス改善として明示された点が使える。** プロンプトキャッシュは**先頭が一致している限り効く**ため、システムプロンプトに日付や動的な値を混ぜるとキャッシュが毎回外れる。**自社でLLMを組み込むときの設計原則として、公式のリリースノートで裏づけられる形になった。**
- **sandbox の事前準備は、エージェントの初回実行コストを隠す工夫である。** 自前で実装する場合も、**サンドボックスの起動を要求が来てから行うか先回りするか**は体感速度に直結する。
