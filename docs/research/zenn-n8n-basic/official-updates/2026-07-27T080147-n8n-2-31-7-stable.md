# 2026-07-27 n8n 2.31.7（stable）

## 公式内容の日本語要約

窓内にn8n stableチャンネルの `2.31.7` が公開された。新機能追加はなく、バグ修正2件のみ。

- **core**: クレデンシャルのセキュリティ監査実行時に、実行データ（execution data）を不要にロードしていた問題を修正（監査処理の効率化・意図しないデータアクセス防止）
- **core**: S3オブジェクトパスの署名を厳密なRFC 3986エンコーディングに準拠させる修正

## できるようになったこと

- （新機能なし。いずれもバグ修正）

## 影響範囲

- 対象ユーザー: クレデンシャルセキュリティ監査機能の利用者、S3連携ノード利用者
- 対象プラン: stableチャンネル利用者
- API / UI / 管理者機能: 該当なし（内部バグ修正）
