# 2026-10-20〜23 n8n 2.45 系（beta）

## 公式内容の日本語要約

**窓内に 2.45 系の pre-release が4版出て、`beta` タグが 2.45.3 を指すようになった**（2.45.0 = 10-20 09:10、2.45.1 = 10-21 12:56、2.45.2 = 10-22 09:27、2.45.3 = 10-23 07:25）。いずれも pre-release 表示である。

**2.45.0 の内容が、この系列で実務に効く部分である。**

- **Core**: **durable scheduler と、ノード／資格情報タイプのポリシーを既定で有効化。** 加えて、移行時の findings 通知、削除済みノードの自動マイグレーション、シャットダウン時に実行中の production execution を suspend する挙動。
- **Agents / Editor**: **MCP ツール権限の全面的な見直し（overhaul）。** WhatsApp チャネル設定の作り直し、ログに応答モデル名を表示。
- **API**: Public API の POST リクエストで `Idempotency-Key` を尊重。workflow 読み取りエンドポイントが親フォルダを返す。
- **Nodes**: Azure OpenAI Foundry 資格情報に任意の Project 欄。**新規ノードとトリガーの既定が Kafka v2 へ。Monday.com も V2 が新規ノードの既定へ。** Text Classifier が opt-in で確信度スコアを出せる。

**公式ページに breaking changes の節は無い。** ただし既定の変更（durable scheduler、ポリシー、Kafka / Monday.com V2）は既存環境に影響しうるため、公式はアップグレード前にリリースノート全文を確認するよう促している。

修正は多数で、代表的なものは AI Agent が Anthropic の thinking ターンをツール引数込みで再生する、Core の MCP ブラウザセッションの接続リーク、active workflows エンドポイントでの publish 失敗、**サブワークフローが制限付き資格情報を使う場合の親 execution の秘匿（redaction）**、IMAP トリガーのメールボックス確認、Send Email の配列宛先、Postgres のカンマを含むパラメータ、画像操作時の OpenAI トークン使用量レポート、SSO サインインのリダイレクト。

## できるようになったこと

- durable scheduler とノード／資格情報タイプのポリシーが既定で有効になる（2.45 系）
- MCP ツールの権限設定が見直される
- Public API の POST が `Idempotency-Key` で冪等に扱える
- Text Classifier が確信度スコアを返せる（opt-in）

## 影響範囲

- 対象ユーザー: n8n の beta チャネル追従者、および次の stable を見越して検証する運用者
- 対象プラン: 記載なし（OSS / self-hosted）
- API / UI / 管理者機能: Core（スケジューラ、ポリシー）、Public API、Agents / Editor（MCP 権限）、各ノード

## 教材化メモ

- **「breaking changes の節が無いのに既定が変わっている」典型例である。** durable scheduler の既定有効化、ノード／資格情報ポリシーの既定有効化、Kafka と Monday.com の V2 既定化は、どれも**既存環境の挙動を変えうる**。公式が breaking と呼んでいないものを自分で breaking と判定する必要がある、という読み方の教材になる。
- **MCP ツール権限の overhaul は、GitHub Copilot（MCP servers in Copilot のポリシー統制）と Microsoft Copilot（federated コネクタ）と同じ週に出ている。** 3製品が同じ週に MCP の権限まわりへ手を入れており、**MCP が「つながる」段階から「誰に何を許すか」の段階へ移った**ことが週次でまとめて見ると明確になる。
- 「サブワークフローが制限付き資格情報を使う場合の親 execution の秘匿」は、**実行ログが資格情報の漏えい経路になる**という話である。ワークフロー自動化で秘密情報を扱うときの定番の落とし穴として扱える。
- `beta` も moving tag であり、2.45.3 を指している。**`stable` と `beta` の両方が動くため、タグ名での固定は再現性を担保しない。**
