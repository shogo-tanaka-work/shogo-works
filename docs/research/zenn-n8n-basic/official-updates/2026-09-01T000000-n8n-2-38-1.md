# 2026-09-01 n8n 2.38.1

## 公式内容の日本語要約

2.38 系のパッチ。修正範囲が比較的広く、**MongoDB のパラメータバインド**、**AI Builder の改善**、**API 資格情報の扱い**、**Slack Block Kit のバリデーション**、**OAuth トークン管理**などコア寄りの安定化が含まれる。
