# 2026-09-25 n8n 2.40.7

## 公式内容の日本語要約

n8n `2.40.7` が 2026-09-25T07:51Z に公開された。内容は **プロジェクトの span 属性をノードの span へ伝播させる**修正で、**同日 07:28Z の 2.41.3（beta 系列）と同内容**である。

**窓の終端（2026-09-28T00:30Z）時点で、`stable` moving tag が指す実バージョンは 2.40.7 である。** 前週の終端では `stable` = 2.39.8 だったため、**本週のあいだに stable 系列が 2.39.x から 2.40.x へ切り替わった。**

## できるようになったこと

- OpenTelemetry のノード単位スパンにプロジェクトの属性が伝播する

## 影響範囲

- 対象ユーザー: n8n 2.40.x 系（stable）の利用者
- 対象プラン: セルフホスト / クラウドとも
- API / UI / 管理者機能: OpenTelemetry のスパン属性

## 教材化メモ

- **stable 系列のメジャー相当の切り替わり（2.39.x → 2.40.x）は、リリースノートには書かれない。** moving tag が指す先を毎週記録していないと気づけない。**「stable を追っている」運用は、実は系列の切り替えを自動で受け入れている**ことになる。前週の記録と突き合わせて初めて見える情報の例。
