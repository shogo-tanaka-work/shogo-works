# 2026-08-25 n8n 2.36.7

## 公式内容の日本語要約

2.36 系の backport リリース。窓内の n8n リリースでは最も内容がある。

**Bug Fixes（4件）**: バイナリデータのエンドポイント調整。デコレータルートでの JSON content type 要求。起動時のリーダー引き継ぎにおけるライセンス自動更新の整合。**OAuth2 のトークン要求が、全プロセスで環境プロキシを経由するよう修正**。

**Features（1件）**: ワークフロー履歴一覧エンドポイントから `offset` クエリパラメータを削除。

破壊的変更の記載はない。

## できるようになったこと

- プロキシ配下の環境で OAuth2 トークン要求が正しく経由するようになった

## 影響範囲

- 対象ユーザー: n8n セルフホスト運用者。特に**送信プロキシを挟んでいる環境**
- 対象プラン: 全般
- API / UI / 管理者機能: 認証（OAuth2）・API エンドポイント

## 教材化メモ

- **「プロセスによってプロキシ設定が効いたり効かなかったりする」**のは、閉域・プロキシ必須の企業環境でよく踏む形の不具合である。一部のワーカープロセスだけ直接外へ出ようとして失敗する、あるいは監査ログに載らない、という事故につながる。**プロキシ経由の一貫性は、機能ではなく監査要件**として説明できる。
- 記事化しない（週次確認ソースの通常更新）。
