# 2026-10-30 n8n の stable が 2.44.6 → 2.45.7 へ

## 公式内容の日本語要約

**`stable` moving tag が 2.45.7 を指すようになった**（2026-10-30T08:24Z、コミット `01cb29d`）。前週の `stable` は 2.44.6 だったため、**3週連続で `stable` がマイナーを跨いだ**（2.42.6 → 2.43.7 → 2.44.6 → 2.45.7）。窓内の該当リリースは次のとおり。

- **2.44.7**（10-26T06:22Z）: サブワークフローの pre-run チェック失敗時にエラーワークフローを起動、IMAP の再接続バックオフ、Microsoft SharePoint ノードの column mapper 403 と Map Automatically の空項目の修正、task runner の certifi を 2026.10.19 / 2026.10.23 へ更新。
- **2.45.4**（10-26T06:24Z）: 上記と同趣旨の修正に加え、削除された n8n-sandbox サンドボックスの再作成とワークスペースセットアップの再実行、v3 breaking changes ページへのドキュメントリンク修正。機能面はマイグレーションレポートのプロジェクト別フィルタなど。
- **2.45.5**（10-28T07:16Z）: 縮小ビルドで `ExpressionError` の名前が保持されない問題、QuickJS 式結果で undefined が落ちる問題、エディタの初回読み込み速度改善、カスタム OTel 属性キーの prefix を設定可能に。
- **2.45.6**（10-29T08:30Z）: キューモードでの dynamic time saved の記録、サイドバーのアイコンサイズ。
- **2.45.7**（10-30T08:24Z）: **workflow-scoped routes が実行データを読むときに `execution:read` を要求**（#42446）、アクティベーション後の IMAP トリガー式の解決、`__isError` キーを持つユーザーデータを式でデータとして返す。

## 影響範囲

- 対象ユーザー: n8n セルフホスト（`stable` チャンネル）
- 管理者: `stable` を追っている環境で、**2.45 系の権限変更（MCP ツール権限の全面見直し、`execution:read` の要求）が今週まとめて降りてくる**

## 教材化メモ

記事化しない（週次ソースの巡回記録）。`stable` が毎週マイナーを跨ぐため、**「stable を使っているから変更は小さい」という前提が n8n では成立しない。** 2.45 系には 2.45.0 の MCP ツール権限の全面見直し（前週記録）が含まれており、`stable` 追従の環境は今週それを受け取る。`source-catalog.md` の注意どおり、タグが指す実バージョンと channel を毎回確認する必要がある。
