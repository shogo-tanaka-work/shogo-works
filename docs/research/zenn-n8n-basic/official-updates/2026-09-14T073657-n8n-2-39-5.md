# 2026-09-14 n8n 2.39.5

## 公式内容の日本語要約

2.39.x 系のパッチ。項目は2件である。

**Bug Fixes**: エディタで、**一部のユーザーが自分のエンドユーザー資格情報を失効（revoke）できなかった**問題を修正（#38455）。

**Features**: core に **instance reports 向けのログストリーミングイベント**を追加（#38483）。

**資格情報を失効できないのは、統制上は「止めたいのに止まらない」状態**にあたる。退職者・委託終了時の権限剥奪が UI から完了しないケースが存在したことになる。

## できるようになったこと

- エンドユーザー資格情報をエディタから失効させる
- instance reports 向けのログストリーミングイベントを受け取る

## 影響範囲

- 対象ユーザー: n8n セルフホスト・クラウド利用者。資格情報の棚卸しを行う管理者
- 対象プラン: 記載なし
- API / UI / 管理者機能: エディタ（資格情報）、core（ログストリーミング）

## 教材化メモ

**「失効できない」は、権限管理の不具合の中でも見つかりにくい類型である。** 付与の失敗はすぐ気づくが、**剥奪の失敗は誰も困らないまま残る。** 棚卸しの手順に「剥奪したあと、実際に使えなくなったことを確認する」を入れる根拠として使える。
