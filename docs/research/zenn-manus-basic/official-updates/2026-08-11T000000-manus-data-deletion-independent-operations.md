# 2026-08-11 Manus のデータ削除告知

## 公式内容の日本語要約

Manus は、独立した企業としての運営に戻ることを公表した。この移行と特定法域の規制対応のため、一部ユーザーが 2025-12-29 以降に生成したデータを削除する。

削除の実施は 2026-08-23 8:00 SGT から 2026-08-24 までである。対象ユーザーは 2026-08-23 7:59 SGT までバックアップでき、2026-08-25 8:00 SGT から復元できる。バックアップウィンドウが閉じたあと、対象ユーザーは復元まで自分のアカウントへアクセスできない。

対象かどうかはアプリ内通知とメールで案内される。Apple ID または Facebook アカウントで登録した利用者にはメールアドレスを保有していないため、アプリ内通知を確認するよう明記されている。ヘルプセンターのガイドから自分が対象かを確認することもできる。

バックアップツールは複数回の実行に対応しており、バックアップ後に新しいタスクデータを作った場合は取り直す必要がある。バックアップ期間中（2026-08-11〜08-23 SGT）は対象ユーザーへの課金を停止し、復元後に復帰ボーナスを提供するとしている。

公式は、この措置がセキュリティインシデントによるものではなく、独立運営への移行と規制対応に起因すると説明している。対象外のユーザーは通常どおり利用でき、作業は不要である。

## できるようになったこと

（機能追加ではなくデータ削除の告知）

- 対象ユーザーは 2026-08-23 7:59 SGT までにデータをバックアップする必要がある
- 復元は 2026-08-25 8:00 SGT から可能
- バックアップ期間中は対象ユーザーへの課金が停止される
- 対象かどうかはアプリ内通知・メール・ヘルプセンターのガイドで確認できる

## 影響範囲

- 対象ユーザー: 特定法域の Manus 利用者のうち、2025-12-29 以降にデータを生成した対象者
- 対象プラン: プラン横断（対象判定は法域と生成日）
- API / UI / 管理者機能: アカウントデータ（バックアップ / 復元ツール）
