# 2026-10-01 Manus の Video Editor

## 公式内容の日本語要約

Manus 2.0 の一部として **Video Editor** が公開された（2026-10-01）。編集経験がない利用者が AI 生成動画を仕上げられるようにする機能である。

**要点はレイヤー構造である。** 公式の説明では「**Manus が使うすべての素材——生成されたショットや画像、キャプション、モーショングラフィック、ナレーション、音楽、効果音——がそれぞれ独自のレイヤーに載る**」。手動調整と自然言語での指示の両方で変更できる。

**実行場所に制約がある。** タイムライン機能の全体を使うには **Manus Studio（macOS / Windows のデスクトップアプリ）**が必要で、**Web からは編集を開始できるがデスクトップアプリのダウンロードが必要**になる。

ローカル素材の取り込み、AI による初回カットの生成、そこから各要素を個別に調整する流れで、**フラット化された動画ファイルではなく編集可能なプロジェクトのまま残る。**

価格・クレジット消費についての記載はない。

## できるようになったこと

- 生成動画を素材レイヤーごとに調整（手動 / 自然言語）
- ローカル素材の取り込みと初回カットの自動生成
- 編集可能なプロジェクトとしての保持

## 影響範囲

- 対象ユーザー: Manus Studio（macOS / Windows）の利用者
- 対象プラン: 記載なし（クレジット消費の言及なし）
- API / UI / 管理者機能: **全機能はデスクトップアプリ必須**

## 教材化メモ

- **「出力をフラット化しない」という設計判断**が要点である。生成系ツールの多くは完成物だけを返すため、修正は再生成になる。**レイヤーを保持したまま渡す**と、修正コストが再生成から編集へ下がる。生成 AI を業務に組み込むときの評価軸として「出力が編集可能な中間表現で返るか」を立てられる。
- **Web で始めてデスクトップで仕上げる**という導線は、ブラウザだけで完結しない前提を持ち込む。社内でツールを配るとき、**デスクトップアプリのインストール可否が機能の可否を決める**ため、端末管理ポリシーと機能要件を突き合わせる必要がある。
