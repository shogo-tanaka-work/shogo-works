# 2026-10-01 Manus の Game Dev

## 公式内容の日本語要約

Manus 2.0 の一部として **Game Dev** が公開された（記事公開は 2026-10-01、機能自体は Manus 2.0 と同じ 2026-09-28 のローンチに含まれる）。コード経験がない利用者が AI でゲームを作れるようにする機能である。

公式が挙げる中核機能は3つ。

- **Tweak Panel** — プレイ中にリアルタイムでゲームのパラメータを調整する
- **Assets Management** — ビジュアルとキャラクターをカスタマイズする
- **Multiplayers** — 複数人で遊べるようにする

提供プラットフォームは**デスクトップ（macOS / Windows）とモバイル（iOS / Android）**。

**Cloud Computer への明示的な言及はない**が、マルチプレイヤー機能について **Manus が利用者の代わりにサーバーのデプロイを行う**旨が書かれている（Manus 2.0 の告知では、常時サーバーが必要なマルチプレイヤーゲームが Cloud Computer の用途として挙げられている）。

価格・サブスクリプション条件についての記載はない。

## できるようになったこと

- プレイ中のパラメータ調整（Tweak Panel）
- アセット・キャラクターのカスタマイズ
- マルチプレイヤー対応（サーバーデプロイは Manus 側）

## 影響範囲

- 対象ユーザー: Manus のデスクトップ / モバイル利用者
- 対象プラン: 記載なし
- API / UI / 管理者機能: マルチプレイヤー用サーバーのデプロイを Manus が代行

## 教材化メモ

- **「サーバーのデプロイをベンダーが代行する」構成が、個人向け機能として出てきた点**が実務的に重要である。常時稼働のサーバーを利用者が意識せず持てるということは、**課金条件を意識せず持ててしまう**ことでもある。価格表記がないのと合わせて、**無意識の常時課金**になりうる構造として記録する。
- **Tweak Panel は「実行中に挙動を変える」UI** であり、エージェント製品の設計として応用が利く。生成してから評価する流れでは試行のコストが高いが、**走らせたまま触れる**と評価の速度が変わる。ハーネス設計で「実行中に介入できる口を残す」という観点の実例になる。
