# 2026-10-13 Manus × OPPO

## 公式内容の日本語要約

**Manus が OPPO と提携し、Manus のエージェント機能を OPPO AI Mind Pilot へ統合する。** 公式は、複雑な多段タスクを使える成果物へ変えられるようにするもので、OPPO の掲げる Personalized Proactive Intelligence（AI が利用者を理解し能動的に手伝う）構想を進めるものだと述べている。

**初出は OPPO Find X10 シリーズ（ColorOS 17）で、AI Mind Pilot の新しい Agent Mode に Manus の機能が入る。** AI Mind Pilot は一問一答を超える設計で、**最終目的を理解し、複数ステップへ分解し、関連情報を特定し、適切なツールを選び、完成した成果物を出す**（端末に保存されたファイル・写真を直接扱うことを含む）。

例として挙がっているのは旅程の整理である。**端末上の別々のアプリに散った航空券・ホテル予約・レストラン予約・観光チケットを見つけて整理し、オンライン情報と合わせて日程別の旅程を作る。** 利用者が自分で情報を集めてアップロードする必要はない。写真の整理・検索、既存ファイルとオンライン情報からのプレゼン・提案書・ポートフォリオ作成も、1つのプロンプトでできるとされる。

**プライバシー設計が明記されている。** ColorOS 17 は**端末上のモデル**で関連情報をローカルに理解・整理する。**ファイルや写真の検索・整理・リネームのようなローカルタスクでは、元のコンテンツは端末に残り Manus へ共有されない。** 外部処理が必要なタスクでは、**関連コンテンツのアップロード・共有の前に明示的な確認を求める。** どの情報へアクセスするか、どの操作を行うか、外部処理を許すかは利用者が制御する。

## できるようになったこと

- OPPO Find X10 シリーズ（ColorOS 17）の AI Mind Pilot Agent Mode から Manus のエージェント機能を使える
- 端末上の複数アプリに散ったデータを横断して多段タスクを実行できる

## 影響範囲

- 対象ユーザー: OPPO Find X10 シリーズ（ColorOS 17）の利用者
- 対象プラン: 記載なし
- API / UI / 管理者機能: 端末 OS の UI（AI Mind Pilot）

## 教材化メモ

- **エージェントの実行場所が「クラウド」から「手元の端末」へ寄る流れ**の一例。同じ系統の動きとして、**GitHub Copilot の computer use（10-01 記録）、Cursor の remote control（10-06 記録）**がある。**人が使う画面・手元のデータを触る口が、ベンダー横断で増え続けている。**
- **ローカル処理と外部処理の境界を明示し、外部処理の前に確認を取る設計**が、プライバシー設計の実例としてそのまま使える。「端末に残る／出ていく」の線引きを利用者へ見せる、という要件である。
- **端末内の複数アプリを横断してデータを集める**機能は、**OS ベンダーしか持てない権限**の上に成り立つ。アプリ単体のエージェントとの能力差が構造的に生まれる点を説明できる。
