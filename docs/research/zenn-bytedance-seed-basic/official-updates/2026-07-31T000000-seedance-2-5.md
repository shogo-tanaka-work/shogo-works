# 2026-07-31 Seedance 2.5

## 公式内容の日本語要約

ByteDance Seed が動画生成モデル Seedance 2.5 を公開した。Seedance 2.0 からの大幅な前進とされ、「基礎生成」と「参照ベース生成」の両方を軸に、単発クリップの生成から完成された創作物へ踏み込むことを狙う。

主な特徴は次のとおり。

- **長さ**: 高品質な30秒の音声付き動画をワンパスで生成。複数ラウンドの延長にも対応し、より長い尺を作れる
- **マルチモーダル参照**: 最大30枚の画像、10本の動画クリップ、10本の音声クリップを同時に入力として受け付ける
- **精密な編集**: タイムスタンプ単位で音声と動画を対象指定して編集できる。グリーンスクリーン、カメラ視点、参照ベースの変更に対応
- **品質**: ショット間の遷移、シーンの連続性、視覚的なリアリティが従来世代より改善

提供は Jimeng AI プラットフォーム、Doubao Pro 経由。API は BytePlus ModelArk 経由で「近日提供」とされている。

想定用途として、教育（歴史的場面の可視化）、製造（ロボット向け合成訓練データの生成）、自動運転（複雑なシナリオのシミュレーション）が挙げられている。

## できるようになったこと

- 30秒の音声付き動画をワンパスで生成、複数ラウンドでの延長も可能
- 画像30枚 / 動画10本 / 音声10本を同時に参照入力として指定できる
- タイムスタンプ単位での音声・動画の対象指定編集
- グリーンスクリーン、カメラ視点、参照ベースの変更

## 影響範囲

- 対象ユーザー: Jimeng AI / Doubao Pro の利用者。API 利用は BytePlus ModelArk 経由で近日提供
- 対象プラン: 上記プラットフォーム
- API / UI / 管理者機能: 現時点ではプラットフォーム UI が中心。API は未提供

## 教材化メモ

- 「単発クリップの生成」から「参照を大量に与えて一貫した作品を作る」への移行は、動画生成の実務利用における転換点。同時期の `grok-imagine-video-1.5` の reference-to-video 対応と同じ方向
- 30秒ワンパス + 音声付きという条件は、実務で使える最小単位（SNS 動画、説明動画）に届き始めている目安として使える
- タイムスタンプ単位の編集は、生成物を「作り直す」のではなく「直す」対象として扱えるようになったことを示す
- `src/content.config.ts` の `aiNews.tool` enum に ByteDance Seed は含まれないため、AIニュース記事化はできない。動画生成の動向を扱う際の参照資料として残す
