# 2026-08-05 ByteDance Seed SeedRealtime

## 公式内容の日本語要約

ByteDance Seed が「SeedRealtime」を公開した。音声と映像を扱う全二重（full-duplex）の LLM で、オムニモーダルな自然対話を目指すものと位置づけられている。公式ブログの Models カテゴリで 2026-08-05 付けの告知。

全二重は「話しながら聞く」を同時に成立させる方式で、従来の交互ターン型の音声対話と比べ、割り込みや相槌を含むやり取りに近づく。

なお本サイトの AIニュース記事の `tool` enum に ByteDance Seed は含まれていないため、速報記事化の対象外。日次サマリーと本詳細メモにのみ記録する。

## できるようになったこと

- 音声・映像の全二重対話に対応した LLM が公開された
