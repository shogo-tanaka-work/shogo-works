# 2026-09-01 Claude Fable 5.1 と Claude Mythos 5.1

教材化メモ: src/content/ai-news-notes/claude/claude-fable-5-1-mythos-5-1.mdx

## 公式内容の日本語要約

Anthropic が **Claude Fable 5.1** と **Claude Mythos 5.1** を公開した。両者は**同一のモデル重みを持つ2つの構成**で、違いはセーフガードの水準だけである。Fable 5.1 は一般提供、Mythos 5.1 はサイバーセキュリティとライフサイエンスの領域で制限を緩めた構成で、審査を通った組織（Project Glasswing）にのみ提供される。

性能面では、前世代 Fable 5 からの伸びが大きい。Terminal-Bench-Science 0.1 が 24.7% → **52.6%**、Terminal-Bench 4.0 が 42.0% → **55.8%**（Mythos 5.1 は 60.9%）、AutomationBench が 17.1% → **31.4%**、GDPval-AA v2 が 1723 → **1853**。Humanity's Last Exam はツールなしで 60.9%。いずれも Opus 5 を上回る。

**価格は Fable 5 と同一で、キャッシュ読み込みのみ値下げされた。** 公式は「典型的なワークロードで約25%安く、エージェント的な用途では最大約45%安くなる」と説明している。仕様は 1M トークンのコンテキスト（全域が標準単価）、最大出力 128k トークン、adaptive thinking は常時オンで `effort` パラメータで深さを制御する。Claude Code では既定が High、Cowork と claude.ai では Medium。

セーフガードも変更された。**サイバーセキュリティ領域の誤検知（false positive）が従来比60%減**。Fable 5.1 はソースコード中の脆弱性の発見に使えるようになったが、エクスポイト開発は引き続き不可。バイナリベースの脆弱性スキャンとペネトレーションテストも制限対象のまま。生物領域のセーフガードは、良性のリクエストへの介入が Fable 5 launch 時比で**85%減**。介入が起きた場合は Opus 系モデルへフォールバックする。

データ保持については、別発表の Enterprise Frontier Safeguards（EFS）と連動する。EFS 提供までの間、対象顧客は Fable 5 / Fable 5.1 でゼロデータ保持を受けられる。

## できるようになったこと

- Claude API で `claude-fable-5-1` を利用可能（全顧客）
- AWS（Bedrock: `anthropic.claude-fable-5-1` / Claude Platform on AWS）、Google Cloud、Microsoft Foundry でも同日提供
- claude.ai では Pro / Max / Team / Enterprise が利用可能
- Fable 5.1 でソースコードの脆弱性発見が可能に（エクスポイト開発は不可のまま）
- `effort` を Low / Medium に落としても Fable 5 の High 相当以上の結果が得られる（コスト最適化の選択肢が増えた）

## 影響範囲

- 対象ユーザー: Claude API 全顧客、claude.ai の Pro / Max / Team / Enterprise、主要3クラウドの利用者
- 対象プラン: Mythos 5.1 のみ Project Glasswing 参加組織に限定（現時点では米国組織のみ）
- API / UI / 管理者機能: モデル ID の追加。既存の Fable 5 呼び出しは維持されるが、同一価格でキャッシュ読み込みが安くなるため移行の経済合理性が高い
