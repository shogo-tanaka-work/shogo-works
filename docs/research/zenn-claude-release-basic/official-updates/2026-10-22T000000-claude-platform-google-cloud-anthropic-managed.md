# 2026-10-22 Claude Platform の全機能が Google Cloud で一般提供（Anthropic managed）

## 公式内容の日本語要約

Claude Models on Google Cloud (Anthropic managed) が一般提供。Google Cloud IAM 認証・請求・コミットメント充当で Claude Platform の全機能（Managed Agents、コード実行、computer use、Skills、MCP コネクタ、プロンプトキャッシュ等）を新機能当日から使える。US とグローバルのエンドポイント。Opus 5.5 の Fast mode も GA（入出力 8/40 ドル per 100万トークン）。Google managed 版も継続し、データ処理者や地域要件で使い分ける。
