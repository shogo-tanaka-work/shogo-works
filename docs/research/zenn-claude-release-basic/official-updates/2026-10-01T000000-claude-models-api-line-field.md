# 2026-10-01 Claude の Models API に `line` フィールドが追加（追補）

## 公式内容の日本語要約

Claude Platform の API リリースノート 2026-10-01 付エントリで、**Models API に `line` フィールドが追加**された。各モデルがどの系列（model line）に属するかを示すもので、値の例として **`opus`、`sonnet`** が挙げられている。

**本エントリは 2026-10-02 / 10-03 の日次実行の窓に当たるが、どちらの日次サマリーにも記録が無かった。** 本日の巡回で Claude Platform の API リリースノートを確認した際に判明したため、追補として記録する。

**モデル一覧を動的に扱う実装には実利がある。** 従来はモデル ID の文字列（`claude-opus-5-5` など）をパースして系列を推定する必要があったが、`line` を見れば系列で分岐できる。モデル ID の命名規則に依存したコードを、API のフィールドに置き換えられる。

**公式の記述は1文程度で、取りうる値の完全な一覧は示されていない。** 列挙値として扱う実装を書く場合は、未知の値が来たときのフォールバックを前提にする必要がある。

## できるようになったこと

- Models API のレスポンスでモデルの系列（`opus` / `sonnet` 等）を直接取得できる
- モデル ID 文字列のパースに依存せず系列で分岐できる

## 影響範囲

- 対象ユーザー: Claude API でモデル一覧を動的に扱う開発者
- 対象プラン: Claude Platform（API）
- API / UI / 管理者機能: API（Models API のレスポンススキーマ）
