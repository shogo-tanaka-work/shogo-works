# 2026-07-24 Claude Opus 5 発表

## 公式内容の日本語要約

Anthropicは新しいOpusモデル「Claude Opus 5」を発表した。公式は「Fable 5のフロンティア級知能に迫りながら価格は半分」と位置付けている。価格はOpus 4.8と同じ入力$5/百万トークン、出力$25/百万トークン（Fast modeは基本価格の2倍で約2.5倍高速）。Claude.ai、Claude Code、Claude Cowork、Claude API（モデルID `claude-opus-5`）で即日利用可能。

## できるようになったこと

- ソフトウェアエンジニアリング: Frontier-Bench・CursorBenchで最高水準の性能
- 未知の問題解決: ARC-AGI 3で競合モデルの3倍のスコア
- 業務自動化: Zapier AutomationBenchで他モデル比1.5倍のパス率
- ライフサイエンス: 有機化学・タンパク質関連研究タスクの性能向上
- 可視化生成: 技術図解・インタラクティブなイラスト生成能力の強化
- Effort設定（低/中/高）で知性とコストのバランスを調整可能
- Anthropicは「最もアラインされたOpusモデル」「誤用に対して最も耐性がある」とも説明

## 影響範囲

- 対象ユーザー: Claude.ai（Max/Pro）、Claude Code、Claude Cowork、Claude API利用者
- 対象プラン: Claude Maxではデフォルトエンジン、Claude Proでもプレミアム階層として利用可能
- API / UI / 管理者機能: API経由では `claude-opus-5` を指定。GitHub Copilotなど主要開発者プラットフォームでも同日提供開始（詳細は GitHub Copilot 側の別記録を参照）

## 教材化メモ

- Claude Codeのv2.1.219リリースと同日発表で、Claude Codeでは「Opus 5が新しいデフォルトOpusモデル」として即座に統合された（1M context、Fast modeが$10/$50/百万トークン）。両者は同一モデルの異なる切り口の発表なので、記事化する場合は「モデル発表」と「Claude Code側の対応」を分けて扱うか、まとめて1本にするか検討する。
- 「Fable 5に迫る性能を半額で」という価格訴求は、既存Opus利用者への乗り換え訴求として教材価値が高い（コスト最適化の実例として）。
