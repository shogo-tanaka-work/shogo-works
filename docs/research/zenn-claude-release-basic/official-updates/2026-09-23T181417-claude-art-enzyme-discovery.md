# 2026-09-23 Claude が新規酵素システム ART を発見

## 公式内容の日本語要約

Anthropic は 2026-09-23、**社内に生命科学研究グループと実験ラボを設立した**ことを発表し、最初の成果として **Claude が新規の酵素システムを自律的に発見した**と報告した。研究グループは2026年春に組成されたもので、DNA データセットから未特性のタンパク質ファミリーを探し、仮説を大量に生成し、自社ラボで実験して検証する、という一連の流れをエージェントと人間の協働で回す体制を作ることを目的にしている。

発見されたのは **ART（array-associated reverse transcriptases、アレイ随伴逆転写酵素）** と名付けられたシステムで、主にバクテリオファージ（細菌に感染するウイルス）に見られる。逆転写酵素（RT）本体、その隣の相棒遺伝子、そして等間隔に並ぶ長い DNA リピート配列の3要素からなる。リピートの並びは CRISPR アレイに似ており、最初の実験では ART のアレイが複数の短い RNA として発現していることが確認された。RT 本体自体は先行研究で同定済みだったが、非コード DNA のアレイと機能未知のアクセサリータンパク質という「システムとしての特徴」に気づいたのは Claude が初めてだという。

**探索の規模と手順が具体的に開示されている点が実務的には重要である。** 人間の関与は最初のプロンプトとラボ作業に限られ、**約950のエージェントが21時間かけて2億1,000万トークンを使って**巨大な DNA 配列データベースを探索した。そのうち1つのエージェントが、奇妙な RT の遺伝子の隣に反復パターンがあることに気づき、リピート数を数え、間隔を測り、既知の RT システムと配置を比較し、文献に先行報告がないかを調べたうえで、人間のレビュー用にレポートを提出した。

Anthropic は ART の一次機能の解明は継続中とし、査読前のプレプリントと技術レポートを公開している。CRISPR ゲノム編集の先駆者である MIT / Broad Institute の Feng Zhang 氏がプレプリントをレビューしコメントを寄せている。一方で、The Verge は「CRISPR に匹敵する応用があるかは不明で、発表は早い段階のものだ」と指摘している。ラボはヒトに感染しない対象のみを扱い、実験作業はすべて人間の科学者が行うとしている。

## できるようになったこと

- Anthropic 社内に生命科学研究グループと実験ラボが設置された
- Claude が DNA 配列データベースから未報告の酵素システム ART を自律的に検出した事例が公開された
- プレプリントと技術レポートが公開され、探索の規模（950エージェント / 21時間 / 2億1,000万トークン）が開示された
