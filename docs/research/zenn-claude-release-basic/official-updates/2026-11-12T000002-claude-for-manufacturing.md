# 2026-11-12 Claude for Manufacturing

## 公式内容の日本語要約

製造業向けプラグイン。17 のスキル（見積、品質、故障診断、調達、設計、生産レポート等）と 4 つのコネクタ（Autodesk Fusion、Infor、Microsoft 365、Oracle NetSuite）で構成。成果物は人の承認で終わる設計。設備の操作はしない。Team / Enterprise で導入可。Infor は変更操作用の自社プラグインも提供。
