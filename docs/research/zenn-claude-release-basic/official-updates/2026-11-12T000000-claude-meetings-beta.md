# 2026-11-12 Claude Meetings（beta）

## 公式内容の日本語要約

Claude が Google Meet の通話に可視の参加者として入り、ノート作成・質問への回答・docs や whiteboard の共同作成ができる。Team / Enterprise でベータ展開。保存するのは文字起こし・要約・画面の説明で、音声は保存しない。ZDR・HIPAA-ready・CMEK の組織は対象外。ノートと回答はベータ中無料、通話中に作る成果物は 2027-02-10 まで無料。
