# 2026-08-14 Claude のテキスト透かし

## 公式内容の日本語要約

Anthropic が、今後の Claude モデルが**透かし入りのテキストを生成する**ことを説明した記事を公開した。目的は、そのテキストの生成に Claude が関与した可能性を判定できるようにすることである。**EU AI Act への準拠**が理由で、他の主要 AI プロバイダーも同じ Code of Practice に署名しており、それぞれ独自の透かしを実装する。

仕組みは、生成時の「どちらでもよい選択」を利用する。言語モデルは1語ずつ次の語を選ぶが、「今日の天気は寒くて…」の次に来るのが `overcast` か `grey` かは、意味をほとんど変えない。通常この選択は乱数で決まる。透かしは、この乱数の出どころを変える。任意の乱数生成器の代わりに、**鍵と直前の数語から次の語を決める**。語の選ばれ方はランダムなままだが、鍵を持つ者は語の並びが鍵と整合するかを検査でき、そこから Claude が生成した確率を割り出せる。

公式が明示している性質は次の通り。出力の品質や内容に実用上の影響はない。透かし入りと透かしなしのテキストを読者が区別することはできない。**テキストに何も追加されず、隠し文字も入らない**。追加のトークンを要さず、費用も増えない。**識別情報は含まれず、特定の個人・組織・チャットへ辿ることはできない**。

適用範囲は、**2026-08-02 以降に EU で提供開始されたモデルは提供開始時点から**機械可読なマーキングに対応する。それ以前に提供が始まったモデルについては、今後数か月かけて展開される。Anthropic は**透かし検出 API を近く提供する**としている。

なお、Claude が翻訳したテキストも透かしを持つ。すべての語を Claude が選んでいるためである。

## できるようになったこと

- 生成テキストに Claude 由来かどうかを判定できる透かしが入る（読者には不可視）
- 透かし検出 API が近く提供される予定

## 影響範囲

- 対象ユーザー: Claude の全利用者。特に EU 市場向けにサービスを提供する事業者
- 対象プラン: モデル単位で適用。2026-08-02 以降に EU で提供開始されたモデルは提供時点から、それ以前のモデルは数か月かけて展開
- API / UI / 管理者機能: 出力に対する透過的な変更。設定は不要。検出は今後の API 経由
