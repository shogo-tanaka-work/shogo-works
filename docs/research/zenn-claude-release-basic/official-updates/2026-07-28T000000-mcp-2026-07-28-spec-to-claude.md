# 2026-07-28 MCP 2026-07-28 仕様のClaude対応

## 公式内容の日本語要約

Model Context Protocol の新仕様 `2026-07-28` が確定版として公開され、あわせて Anthropic が Claude 側での対応内容を `claude.com/blog` で発表した。仕様側の変更は Model Context Protocol 公式ブログ、Claude 製品での提供内容は Claude 公式ブログが一次情報となる。

仕様側（`blog.modelcontextprotocol.io`）の主な変更:

- **ステートレスコア化**: 双方向ステートフルなプロトコルから、リクエスト/レスポンスモデルへ移行。`initialize` / `initialized` の交換と `Mcp-Session-Id` ヘッダーが廃止され、各リクエストが独立して成立するようになった。これによりサーバーレス／エッジ基盤へのデプロイが可能になる。
- **拡張フレームワークの正式化**: Tasks が実験的コアから `io.modelcontextprotocol/tasks` 拡張へ移行。MCP Apps、Enterprise Managed Authorization (EMA) とあわせて、コアプロトコルを変更せず機能追加できるバージョン付き拡張フレームワークが導入された。
- **認可の強化**: RFC 9207 に基づく発行者検証、Dynamic Client Registration (DCR) から Client ID Metadata Documents (CIMD) への移行、認可サーバー間での認証情報の再利用防止。
- **その他**: Multi Round-Trip Requests (MRTR) による双方向ストリーム不要化、ヘッダーベースのルーティング、`ttlMs` / `cacheScope` を伴うキャッシュ可能なリスト結果。
- **後方互換性**: Roots / Sampling / Logging は非推奨化されたが、少なくとも12か月間は機能継続する廃止予定期間が設定されている。Tier 1 SDK（TypeScript / Python / Go / C#）は公開時点で新仕様に対応済み。

Claude 側（`claude.com/blog`）で提供される内容:

- **MCP Apps**: MCPサーバーが会話内に直接インタラクティブUIをレンダリングできる。ユーザーはコネクタの動作を確認しながら、タブを切り替えずにインラインで操作できる。
- **エンタープライズ管理認証**: 管理者が自社IdP経由でMCPコネクタを組織全体にプロビジョニングできる。管理者が一度認可すれば、ユーザーは既存のIdPグループを通じてアクセスを継承し、初回ログイン時に接続される（エンドユーザー側はゼロタッチ）。
- **開発者向けオブザーバビリティ**: Claudeのコネクタディレクトリに掲載済みのコネクタに対し、Claude各製品面での利用状況・パフォーマンスを追跡するダッシュボードを提供。採用状況の把握とエラー診断に使える。
- **MCPトンネル（リサーチプレビュー）**: プライベートネットワーク内のMCPサーバーへ、パブリックインターネットへ公開することなくClaudeを接続できる。ファイアウォール設定やIP許可リストなしで社内ツールを統合できる。

なお、MCPのSDK月間ダウンロードは4億回を突破し、年内で4倍に増加したと公式が言及している。

## できるようになったこと

- MCPサーバーをサーバーレス／エッジ環境にデプロイできる（ステートレス化による）
- MCPサーバーがClaudeの会話内にインタラクティブUIを表示できる（MCP Apps）
- 管理者がIdP経由でMCPコネクタを組織全体に一括プロビジョニングできる
- コネクタ開発者が利用状況・エラーをダッシュボードで確認できる
- プライベートネットワーク内のMCPサーバーへ公開なしで接続できる（リサーチプレビュー）

## 影響範囲

- 対象ユーザー: MCPサーバー開発者、Claude Platform利用者、コネクタを組織導入する管理者
- 対象プラン: 公式ブログでプラン別の提供条件・提供時期の明記なし
- API / UI / 管理者機能: プロトコル仕様、Claudeの会話UI（MCP Apps）、管理者向けコネクタ管理、コネクタディレクトリのダッシュボード

## 教材化メモ

- MCP教材の「プロトコルの前提」節は、ステートフル前提（`initialize` / `Mcp-Session-Id`）の説明が古くなるため、次回改訂時にステートレスコアへ更新が必要。
- Roots / Sampling / Logging を扱う教材は「12か月の廃止予定期間あり」の注記が必要。
- 拡張フレームワーク（Tasks / MCP Apps / EMA）は、コア仕様と拡張の区別を説明する新しい導入口として使える。
