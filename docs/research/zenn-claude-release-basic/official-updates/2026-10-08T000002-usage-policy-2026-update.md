# 2026-10-08 2026 年版 Usage Policy 改定（2026-11-12 発効）

## 公式内容の日本語要約

Anthropic が年次の Usage Policy 改定を公表した。**更新後の Usage Policy と Supported Regions Policy は 2026-11-12 に発効する。** 公式は「大半は既存ルールの明確化と、Claude がより長く自律的に働くようになったことに合わせた例示の追加」と説明しつつ、影響工作・兵器開発・監視の悪用パターンへの対応も含むとしている。

**新設**: 偽アカウント・偽ニュースサイト等の規定が、選挙 / 詐欺 / プライバシー / 偽情報の各節から1つの節（Do Not Engage in Deceptive Campaigns or Artificial Activity）へ統合された。政治・商業を問わず、発信主体を隠すこと、偽アカウントによる増幅、影響工作用のツールやインフラの構築を禁じる。

**選挙関連は範囲が狭くなった**（Do Not Undermine Democratic Processes へ改称）。有権者を騙す行為・選挙の妨害に焦点を絞り、**個別化された投票・選挙キャンペーンのターゲティングの一律禁止は削除された**。NPO による多言語の有権者向け情報提供のような正当な市民活動は許容される。欺瞞や個人データの不正利用を伴うターゲティングは他の節で引き続き禁止。

**兵器**は、兵器を機能させるソフトウェアや部品、ドローンや自律車両の武装化を明示的に対象とした（公式は従来の運用の明文化と説明）。**監視・法執行**は書き直され、同意のない追跡（リアルタイムと既収集データの分析の両方）、誰を捜査・逮捕・起訴するかの判断や推奨、監視ツールの構築・改良を禁止する。同意のある追跡（不正検知等）、コンテンツモデレーション、報道、法務リサーチは引き続き許容。

**高リスク用途**の中核要件は変更なし（有資格者がレビュー・変更できること、AI 利用を対象者へ通知すること）。**新設として、自律的な物理動作を行うハードウェアに Claude を接続する場合の要件**が加わった。有資格のオペレーターが装置を監視・停止できること、Claude が切断されても装置が安全な状態を保つこと。**モデルへの虐待的行為の禁止**も新設され、目的の見出せない極端なケースに限って適用される。

**Supported Regions Policy** は執行範囲が明確化された。非対応地域に物理的に所在する個人、そこで設立・本社を置く法人、そこの個人・法人が過半を所有または支配する法人による利用を禁止する。

## 影響範囲

- 対象ユーザー: Claude の全利用者・全開発者
- 対象プラン: 全プラン
- API / UI / 管理者機能: **2026-11-12 発効。** 利用規程・社内ガイドラインの棚卸しが必要
