# 2026-08-28 Claude for Teachers が学校・教育委員会単位で利用可能に

## 公式内容の日本語要約

Anthropic は 2026-08-28、これまで個人教員向けだった **Claude for Teachers を、学校・教育委員会（district）単位で使える無償の Enterprise 提供として公開**した。

K-12 教員向けに、**授業設計のスキル、州の学習基準とその下にある高品質カリキュラム、教員が既に使っている K-12 ツールとの連携**が含まれる。

学校・教育委員会として利用する場合、**ロールベースアクセス制御（RBAC）とシングルサインオン（SSO）といった Enterprise 機能**が付く。管理者は職員の追加・削除、ポリシー設定、学校をまたいだ利用状況の把握ができる。

2026年秋には、**Detroit Public Schools Community District で評価パイロット**を実施し、教員の負担感（wellbeing）と実務への影響を調査するとしている。

申込は**米国の K-12 の学校・教育委員会のリーダー**が対象で、学区を認証して開始する。**2027-06-30 までに申し込んだ適格組織は、1年間の無償利用**が受けられる。

## できるようになったこと

- 学校・教育委員会単位で Claude for Teachers を導入できる（RBAC / SSO 付き）
- 管理者が職員管理・ポリシー設定・学校横断の利用状況把握を行える

## 影響範囲

- 対象ユーザー: 米国 K-12 の学校・教育委員会と、その所属教員
- 対象プラン: 無償の Enterprise 提供（申込期限 2027-06-30、以後1年間無償）
- API / UI / 管理者機能: 管理者コンソールでの職員管理・ポリシー・利用状況

## 教材化メモ

- **「個人向け無償」から「組織向け無償 Enterprise」への拡張**は、ベンダーの普及戦略として典型的な形。個人利用で現場の支持を取ってから、管理機能を付けて組織契約へ上げる。**SSO と RBAC が付いた時点で、情シスが正式導入を検討できる状態になる**という順序は、社内へ AI ツールを入れる立場でも押さえておくと交渉の見通しが立つ。
- **申込期限（2027-06-30）と無償期間（1年）が明記されている**点は、期限付き告知の読み方として使える。無償期間の終わりに何が起きるか（有償化か、機能縮小か）が書かれていない告知は、**導入判断時に「終わったあとの想定」を自分で埋める必要がある**。
- 対象が米国 K-12 に限定されており、本サイトの読者（企業の AI 導入・副業活用）への直接の実務影響が薄いため記事化は見送る。**日本を含む地域展開、または企業研修向けの類似プログラムが出た時点で拾い直す。**
