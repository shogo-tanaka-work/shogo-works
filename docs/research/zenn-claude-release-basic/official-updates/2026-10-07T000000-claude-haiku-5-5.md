# 2026-10-07 Claude Haiku 5.5 公開

## 公式内容の日本語要約

Anthropic が小型モデルの新版 `claude-haiku-5-5` を公開した。公式は「これまでに出した中で最も安く、最も速く、最も高性能な小型モデル」と位置づける。高ボリューム・低レイテンシ用途（分類、ルーティング、抽出、サブエージェント）を想定する。

仕様は 1M トークンのコンテキストウィンドウ、最大出力 128k トークン（Batch API では `output-300k-2026-03-24` beta ヘッダで 300k）。Haiku 4.5 の 200k / 64k から拡大した。adaptive thinking に対応し、`effort` パラメータが使える Haiku は初。既定 effort は `medium`。知識カットオフは 2026年6月、退役は 2027-10-07 より前には行わないとされる。

**価格は Claude で初めてプロンプト長に応じた段階制になった。** 100,000トークン以下のプロンプトは入力 $0.10 / 出力 $0.50（per MTok）、100,000トークン超は入力 $0.50 / 出力 $2.50。Haiku 4.5 は $1 / $5 だったため、10万トークン以下の領域では10分の1である。Batch は半額（$0.05 / $0.25、$0.25 / $1.25）。キャッシュ読み取りは $0.01 / $0.05。Claude 4.6 以降は「1M 全域を標準価格」が原則だが、**Haiku 5.5 はその例外として明記されている。**

提供先は Claude API、Claude in Amazon Bedrock（`anthropic.claude-haiku-5-5`）、Claude Platform on AWS、Google Cloud、Microsoft Foundry、および Claude Code。claude.ai では Free / Pro / Max / Team / Enterprise が web / iOS / Android で選択できる。

**Haiku 4.5 向けコードは壊れる可能性がある。** `budget_tokens` による手動 extended thinking は 400 エラー、`temperature` / `top_p` / `top_k` の非既定値も 400 エラー、assistant prefill も 400 エラー。computer use は `computer_toolset_20260801` へ差し替えが必要。adaptive thinking が既定オンのため応答が `thinking` ブロックから始まり得る。トークナイザが Claude 4.7 系と同じになり、同じ文章が約30%多いトークンになる。

## できるようになったこと

- 10万トークン以下のプロンプトで、Haiku 4.5 の10分の1の単価で小型モデルを回せる
- Haiku で初めて `effort` によるコスト・品質のトレードオフ調整ができる
- Haiku で 1M コンテキスト・128k 出力・browser use tool が使える

## 影響範囲

- 対象ユーザー: Claude API / Bedrock / Vertex / Foundry の開発者、claude.ai 全プラン
- 対象プラン: Free / Pro / Max / Team / Enterprise（claude.ai）、API 全ティア
- API / UI / 管理者機能: API（破壊的変更あり）、claude.ai のモデル選択、Claude Code
