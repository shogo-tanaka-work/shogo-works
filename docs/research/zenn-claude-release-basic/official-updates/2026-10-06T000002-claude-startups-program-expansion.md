# 2026-10-06 Claude Startups プログラムの拡張

## 公式内容の日本語要約

Anthropic が **Claude Startups プログラム**を拡張し、対象となる創業者の範囲を広げた。あわせて **Claude Startup Stack** を新設した。これはスタートアップが使う周辺ツール（営業、デザイン、データエンジニアリングなど）側の特典をまとめたものである。

提供内容は、**Claude 製品とクレジットで合計最大 $7,000**、**Claude Team の1年無償**（Premium シート最大5席、$6,000 相当）、**API クレジット $1,000（1回）**、**Startup Stack 経由のパートナーツール割引が最大 $45,000** である。Applied AI チームとのオフィスアワー、コミュニティへの参加も含む。

応募資格は **創業から5年以内、または直近2年以内に資金調達をした企業**である。申請期限は本文に記載がない。応募は Claude Startups のページから行う。

## できるようになったこと

- 創業5年以内 / 直近2年以内に調達した企業が、**Claude Team 1年＋API クレジットを含む最大 $7,000 相当**を申請できる
- **Startup Stack** でパートナーツールの割引（最大 $45,000 相当）を受けられる

## 影響範囲

- 対象ユーザー: 創業5年以内、または直近2年以内に資金調達をした企業の創業者
- 対象プラン: Claude Team（最大5 Premium シート）＋ API クレジット
- API / UI / 管理者機能: 該当なし（プログラム・課金特典）

## 教材化メモ

- **本件は AIニュース記事化を見送った（スコア5）。** プログラムの応募条件と金額は変わりやすく、半年後には数字が合わなくなる性質の情報である。恒久的な教材に入れる価値は低い。
- **ただし「個人事業・小規模法人が AI コストをどう下げるか」という相談では実務的に効く。** 法人格があり創業5年以内なら候補に入る。**個人事業主（法人なし）が対象に入るかは公式に明記がない**ため、教材で紹介するなら「要確認」と添える必要がある。
- **各社のスタートアップ支援を一覧化した教材は作らない方がよい。** 条件と金額の更新頻度が高く、維持コストが見合わない。代わりに「**支援プログラムを探すときに確認する項目**」（応募資格の定義、クレジットの有効期限、プラン無償期間の終了後の扱い、パートナー割引の実効性）を教える形にする。
