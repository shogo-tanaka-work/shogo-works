# 2026-09-22 Claude Opus 5.5

## 公式内容の日本語要約

Anthropic は 2026-09-22、**Claude Opus 5.5**（モデルID `claude-opus-5-5`）を公開した。公式の位置づけは「**大半の作業で Claude Fable 5.1 と同水準の性能を、Opus 5 比で約40%安い運用コストで出す**」。出力速度も Opus 5 比で30%以上速いとしている。

ベンチマークは、エージェント的コーディングの Terminal-Bench 4.0 が 66.4%（Opus 5 は 52.3%）、FrontierCode v1.1 が 54.4%（同 48.0%）、CursorBench 4.0 が 57.8%（同 46.6%）。ナレッジワークの GDPval-AA v2.1 は 1846 Elo で、Fable 5.1 の 1735 を上回る。コンピュータ操作の OSWorld 2.0 は 81.8%。

**価格は入力 $4 / 出力 $20 per Mtok**（Opus 5 は $5 / $25）、キャッシュ読み取り $0.20（同 $0.50）、キャッシュ書き込み $5（同 $6.25）。Fast mode は入力 $8 / 出力 $40。キャッシュ読み取りの下げ幅が最も大きい。

安全性では、アライメント評価の改善に加え、**プロンプトインジェクション耐性の向上**（封じ込め境界の回避試行が約85%減）を挙げている。サイバーセキュリティ・生物分野の安全策は Fable 5.1 と同等のものが適用される。

## できるようになったこと

- Claude.ai（Pro / Max / Team / Enterprise）、Claude Platform API、AWS、Google Cloud、Microsoft Azure で利用できる
- 5時間ごとの利用上限が拡大された
- Life Sciences Verification Program と拡張された Cyber Verification Program の対象として、規制業務での利用枠がある
- Claude Code は `v2.1.280`（2026-09-22）で Opus 5.5 を既定の Opus モデルとして取り込み、**Pro / Team Standard プランの既定モデルを Sonnet から Opus へ変更**した

## 影響範囲

- 対象ユーザー: Claude.ai 有料プラン全般、Claude Platform API 利用者、3大クラウド経由の利用者
- 対象プラン: Pro / Max / Team / Enterprise
- API / UI / 管理者機能: API 価格表、モデル選択、既定モデルの3点が同時に変わる。**Opus 5.5 では thinking を無効化できない**（新しいコンプライアンス要件に合わせた変更）。preserved thinking は 2026-08-31 以降に作成された API アカウントへ適用される
- 後続: Claude Sonnet 5.5 と Claude Haiku 5.5 が数週間内に予定されている
