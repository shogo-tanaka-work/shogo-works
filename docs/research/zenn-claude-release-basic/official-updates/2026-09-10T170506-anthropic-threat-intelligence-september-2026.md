# 2026-09-10 Anthropic 脅威インテリジェンスレポート（2026年9月版）

## 公式内容の日本語要約

Anthropic の Threat Intelligence チームが、**2025年12月〜2026年8月に検知・停止した Claude 悪用事例**をまとめたレポートを公開した。約154ページ。前回は2025年3月・8月・11月で、今回が4本目にあたる。

対象は**7つの被害領域**である。サイバー作戦、影響工作（influence operations）、監視、詐欺・不正、生物学的悪用、通常兵器開発、蒸留（distillation）。**悪用に使われたのは Claude Haiku / Sonnet / Opus で、Fable / Mythos クラスは違法な蒸留事例1件を除いて確認されていない。**

**中心的な論点は「攻撃の高度さ」ではなく「攻撃の経済性が変わった」ことである。** レポートは、ハクティビスト（GTG-50029）、認証情報を収集する金銭目的の集団（GTG-50014）、国家系スパイ活動（GTG-20006）が**同じ方法論**を取っていたと指摘する。従来は潤沢な資源を持つ組織だけが可能だった偵察・侵害・ツール開発・データ処理が、**すべて AI へ委譲され、ハーネス上で並列かつ機械速度で走る。** 結果として**2〜3時間で侵害が完了し、1人の攻撃者が数十の標的を並行して扱う**数値が出ている。新しい脆弱性が使われたわけではない（盗まれた認証情報、未パッチのエッジ機器、SQL インジェクション、フィッシング）。

**自律性は連続的な幅を持つ**という整理も提示された。会話的な補助（マルウェア・フィッシングキットの作成支援）から、人が標的判断をしつつ Claude が実行する段階、そして**人の監督がほぼ無いまま多段エージェントが偵察・侵害・窃取を並行実行する**段階までが観測されている。

影響工作は9件で、ロシア・イラン・トルコ・湾岸諸国・南アジア・アフリカ・欧州を起点に6大陸の受け手を標的とした。**偽の SNS アカウント群とニュースサイトを構築して出自を隠す**手口が中心である。

生物学的悪用については、**AI 事業者が自社モデルの生物兵器関連の悪用検知を公表した初の事例**とされる。チクングニア熱ウイルスの機能獲得研究の助成金申請案、鳥インフルエンザのパンデミック能力を持つ変異株の探索などが含まれる。Anthropic は「生物学の能力はデュアルユースであり、ワクチン開発と兵器開発を切り分けるのは難しい」と述べ、**攻撃者がそのデュアルユース性を「もっともらしい否認」の手段として使っている**と指摘している。

各事例で Anthropic はアカウントを停止し、学習内容を安全策へ反映し、当局・業界パートナーと情報共有したとしている。
