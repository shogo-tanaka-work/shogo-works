# 2026-11-24 月次リキャップ（Reflect）がベータ終了

## 公式内容の日本語要約

設定の月次リキャップ（Reflect）が Free / Pro / Max / Ultra のウェブ・Desktop・モバイルでベータから正式提供になった。Claude Code のセッションとクラウドの Cowork タスクもリキャップの対象になり、保存済みリキャップをページから削除できる。過去の PR では未記録だったため補完。スコア 5（1/1/1/1/1）で見送り（個人向け機能で、公式の説明が短い）。
