# 2026-08-27 Anthropic の研究者向け支援拡大

## 公式内容の日本語要約

Anthropic が科学研究コミュニティ向けの支援を拡大した。柱は3つある。

**Claude Team Plan for Scientists**: 世界の研究者向けに **10,000席**を、1年間、無償または割引で開放する。標準席は**無償**、利用上限が5倍のプレミアム席は**月額15ドル**。対象は学術機関または非営利研究機関の principal investigator（PI）またはそれに相当する立場の人。登録は発表と同時に開始され、Anthropic は今後数か月で**初期の10,000席をさらに超えて拡大する**としている。

**AI for Science プログラムの対象拡大**: これまで生物系中心だった対象を他の科学分野へ広げ、**計算資源を多く要する野心的な研究**も支援対象に含める。採択されたプロジェクトには**最大 50,000ドル**分のクレジットが提供され、所属を問わず応募できる。

**製品面**: 監査可能なアーティファクトと柔軟な計算資源を備えた研究向けツール **Claude Science**。モデルとしては、生物・化学の研究者向けに Opus クラスを引き続き提供し、ライフサイエンス従事者向けに政府連携経由で **Mythos クラス**の展開が進む。

## できるようになったこと

- 学術・非営利研究機関の PI が Claude Team の無償席／月額15ドルのプレミアム席へ登録可能
- AI for Science へ所属を問わず応募可能（最大 50,000ドル分のクレジット）
- Claude Science の利用

## 影響範囲

- 対象ユーザー: 学術機関・非営利研究機関の研究者（PI 相当）
- 対象プラン: Claude Team（無償席／月額15ドルのプレミアム席）、AI for Science クレジット
- API / UI / 管理者機能: Claude Science（研究向けツール）

## 教材化メモ

- **「無償席＋クレジット＋専用製品」の3点セット**は、垂直市場への入り方のテンプレートとして読める。席を配って裾野を作り、クレジットで重い用途を掘り、専用製品で定着させる。企業向け AI 導入の段階設計にも同じ構造を当てられる。
- **監査可能なアーティファクト**を売り文句に置いている点が示唆的。研究用途では「結果」より「再現できる過程」が価値になる。**AI の出力を業務に組み込むとき、監査可能性が要件になる領域は研究以外にもある**（規制業種、品質保証）という一般化ができる。
- 記事化は見送った（本数上限・スコア7）。日本の一般企業・副業層への実務影響が限定的で、対象が学術・非営利の PI に絞られる。
