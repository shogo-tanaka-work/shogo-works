# 2026-11-10 Claude 新アーティファクトと対話型コネクタ

## 公式内容の日本語要約

チームと Claude が共同で作る新アーティファクト Sheets・Whiteboards・Data（旧 Dashboards）を発表。パートナーのアプリを Claude 内に埋め込む対話型コネクタも開始。Claude Meetings は近日提供予定。

## できるようになったこと

- 表計算・ホワイトボード・ダッシュボード/データストーリーの共同作成
- Adobe・Atlassian 等のアプリを Claude 内で操作。Salesforce（ベータ）・NetSuite・Workday（ベータ）プラグイン
