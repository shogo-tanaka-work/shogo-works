# 2026-10-02 Claude Frontier Academy

## 公式内容の日本語要約

Anthropic が初の研修プログラム **Claude Frontier Academy** を発表した。**1億ドルを投じ、2027年末までに1万人の Frontier Deployed Engineer（FDE）を育成**する。企業の AI 人材ギャップを埋めることを狙う。

設計のモデルは**医療のレジデンシー（研修医制度）**である。実務者から学び、現実のケースを扱い、能力が実証されたところで資格が与えられる、という構造を踏襲している。

**2段階で構成される。**

**(1) 初期フェーズ** — Anthropic のエンジニアとの**数日間の対面研修**。企業導入のシミュレーション、セキュリティレビュー、採点付きの実技評価を行う。修了で **Claude Resident Engineer** バッジ。

**(2) レジデンシーフェーズ** — **12週間**、自社で実際の Claude プロジェクトをリードする。Anthropic のエンジニアと同期コホートが支援する。修了で **Claude Frontier Deployed Engineer** バッジ（**最初の取得者は 2027年初頭**の見込み）。

**対象は「基礎のしっかりした実務エンジニア」**である。LLM での構築実績、他者の AI 導入を助けた経験、自社の重要課題に取り組む習慣が挙げられている。**エージェント構築の経験は必須ではない。**

**初回コホートは 2026-10-02 に San Francisco / New York / London で開始**した。参加は **Anthropic のアカウントチームまたはパートナーアカウントマネージャー経由の推薦制**で、公募ではない。初回コホートには Accenture、Bain、Capgemini、Commonwealth Bank of Australia、Deloitte、McKinsey、Morgan Stanley、Novo Nordisk のエンジニアが含まれる。

## できるようになったこと

- Anthropic 公式の認定（Resident Engineer / Frontier Deployed Engineer）が存在するようになった
- 企業が「Claude 導入できる人材」を社外の基準で確認できるようになる見込み

## 影響範囲

- 対象ユーザー: 企業の AI 導入担当エンジニア、SIer / コンサルの実装部門
- 対象プラン: 推薦制。**公募ではなくアカウントチーム経由**
- API / UI / 管理者機能: 該当なし（人材・認定プログラム）
