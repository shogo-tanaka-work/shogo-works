# 2026-09-28 Claude Sonnet 5.5

## 公式内容の日本語要約

Anthropic が Claude 5.5 ファミリーの2番目のモデルとして **Claude Sonnet 5.5**（`claude-sonnet-5-5`）を公開した。9月22日の Opus 5.5 に続くもので、**Opus 5.5 が「判断を要する複雑な仕事」、Sonnet 5.5 が「範囲の決まった日常業務・バグ修正・成果物作成」**という役割分担が公式に示されている。

**価格は入力 $2 / 出力 $10 per MTok**、キャッシュ読み出し $0.20、キャッシュ書き込み $2.50。Opus 5.5（$4 / $20、キャッシュ書き込み $5）のちょうど半額である。プロンプトキャッシュで最大90%、バッチ処理で50%の削減。**出力生成は Sonnet 5 比で30%以上高速、1タスクあたりのコストは最大30%減**とされる。

ベンチマークでは **Terminal-Bench 4.0 が 70.6%**（Sonnet 5 は 10.3%、Opus 5.5 は 66.4%）で、エージェント型コーディングでは Opus 5.5 を上回る。OSWorld 2.1 は 80.1%（Sonnet 5 は 57.0%）、GDPval-AA v2.1 は 1844（同 1449）、CursorBench 4.0 は 55.5%（同 34.1%）。FrontierCode 1.1 は 46.2% で Opus 5.5（54.4%）に及ばない。**スクリーンショットのみでポケモン赤をクリアした初の Sonnet** でもある。

提供先は **Claude API / Amazon Bedrock / Claude Platform on AWS / Google Cloud / Microsoft Foundry**。Claude Code は同日の v2.1.284 で既定の Sonnet として取り込んでいる。**Claude Haiku 5.5 は「数週間のうちに」追加予定**とされる。

**Claude Platform のリリースノートには破壊的変更が4点明記されている。** (1) 強制ツール利用（`tool_choice: "any"` / `"tool"`）が 400 エラーになる。(2) `high` 以下の effort で前段の thinking を切るには `thinking: {"type": "between_tools"}` を使う（`"disabled"` は不可）。(3) 旧 `computer_20251124` ツールは Claude API と Google Cloud で拒否される（Bedrock では継続動作）。(4) Advisor ツールが Opus 4.8 / 4.7 / Sonnet 5 を advisor として拒否する。加えて **thinking ブロックがアカウントに紐づき、別アカウントのリクエストでは推論前に破棄される**。

## できるようになったこと

- Sonnet 系で Terminal-Bench 4.0 70.6%、Opus 5.5 を上回るエージェント型コーディング
- 入力 $2 / 出力 $10 での 1M 級ワークロード（Opus 5.5 の半額）
- Sonnet 5 比で30%以上速い出力生成と最大30%安い1タスクあたりコスト
- Bedrock / AWS / Google Cloud / Microsoft Foundry での同日利用

## 影響範囲

- 対象ユーザー: Claude API 利用者、Bedrock / Vertex / Foundry 経由の利用者、Claude Code 利用者
- 対象プラン: API 全般。consumer プラン側の扱いは公式ページに明示なし
- API / UI / 管理者機能: API に破壊的変更4点。`tool_choice` 強制指定と `thinking: disabled` を使う既存コードは 400 エラーになる
