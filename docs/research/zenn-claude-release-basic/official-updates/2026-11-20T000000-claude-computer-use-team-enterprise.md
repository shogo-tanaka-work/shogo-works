# Claude - Computer use（beta）が Team・Enterprise プランへ

## 公式内容の日本語要約

Claude が画面を見て許可アプリを操作する Computer use を Team・Enterprise でベータ提供。組織へは段階展開。ヘルプ（support.claude.com/en/articles/18483812）によると既定オフで、Owner が Capabilities から有効化。Enterprise はカスタムロール、アプリ単位のブロック／許可リスト、MDM（computerUseEnabled）で制御。サンドボックスなし、フォルダ制限は効かない。HIPAA・ZDR・CMEK・FERPA 設定の組織は不可。
