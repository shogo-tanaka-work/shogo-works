# Enterprise Frontier Safeguards（ZDR）公開ベータ

## 公式内容の日本語要約

入出力を顧客所有のストレージ（S3 / GCS）に置き、Anthropic もクラウド事業者もデータを保持しないまま、複数リクエストにまたがる不正利用を自動監視する EFS が公開ベータに。運営側の人間レビューなし、学習利用なし。検知時は入出力を含まない Safety Case を顧客チームが確認（報道では7暦日以内）。Claude Platform / on AWS / Bedrock / Google Cloud 対応、Foundry は近日。EFS 自体は無料。
