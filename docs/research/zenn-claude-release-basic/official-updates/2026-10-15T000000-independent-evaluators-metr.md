# 2026-10-15 Anthropic が独立評価者への社員相当アクセスを開始

## 公式内容の日本語要約

**Anthropic が、フロンティアモデルを評価する非営利団体 METR のチームに「社員相当（employee-like）」のアクセスを与え始めたと発表した。** 背景として、前月に第三者による独立評価の強化を約束しており、**White House Accord on Super Intelligence**（独立した外部監査者・評価者との協働を含む）に署名していることが挙げられている。

**具体的な内容は次のとおり。** **METR の社員6名**に、会社支給のハードウェア、オフィススペース、そして **Anthropic 自身のリスク評価チームとおおむね同等の社内ツール・システムへのアクセス**が与えられた。

**公開の扱いが要点である。** **Anthropic は METR の公開物に拒否権を持たない。** ただし**事前に定義された狭いカテゴリ**については削除（redaction）を求められる。対象は**顧客データ、弁護士・依頼者間の秘匿特権に関わる情報、モデルアーキテクチャの詳細**の3つである。さらに **METR は、その削除が妥当だったと考えるかどうかを、削除内容を明かさずに公表できる。**

**情報の横流れは遮断されている。** この作業を行うチームは METR 内の他のスタッフから分離されており、**他組織が Anthropic・顧客・パートナーの情報を得る経路にはならない**と明記されている。

**アクセスは3段階（tier）で整理されている。**

- **Tier 1**: 狭いリスク調査。アクセス範囲も公開可否も Anthropic が判断する。
- **Tier 2**: 評価者は承認なしに公開でき、得られる情報も増える。ただし特定カテゴリの削除要求は残る。
- **Tier 3**: 今回の METR の形。社員相当アクセスで、公開権限は Tier 2 と同等。

**他の評価者との取り組みも並行している。** **SecureBio** が 2026年8月のリスクレポートの化学・生物兵器の章をレビュー中（前回レポートのパイロットレビューに続くもの）で、このレビュー後にアクセス拡大を検討する。**Accenture と Faculty** は、モデル評価・レッドチーミング・アライメント評価・セーフガード試験を含む広範なパートナーシップへ向けて作業中である。**Hugging Face を含む他組織とも初期段階の協議**にある。

**新しい製品・機能の発表は含まれない。** 評価と監督の体制に関する発表である。

## できるようになったこと

- 外部の評価者（METR）が Anthropic 社内のリスク評価相当の環境でモデルを評価し、その結果を Anthropic の承認なしに公開できる
- 削除要求の対象カテゴリが事前に3つへ限定され、評価者側が削除の妥当性について見解を公表できる
- 評価者のアクセス水準が Tier 1 / 2 / 3 として言語化され、どこまで開いているかを外部から比較できる

## 影響範囲

- 対象ユーザー: 独立評価者、Anthropic のリスク・安全性チーム、および評価結果を読む一般
- 対象プラン: 該当なし（製品機能ではない）
- API / UI / 管理者機能: 該当なし。ガバナンス・監督体制の変更
