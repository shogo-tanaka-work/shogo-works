# 2026-11-09 Claude Fable 5.2 / Mythos 5.2

## 公式内容の日本語要約

Anthropic が Fable 5.2 と Mythos 5.2 を公開した。両者は同一の基盤モデルで、Fable は強いサイバー・生物のセーフガード付きで全ユーザーに提供、Mythos は Cyber / Life Sciences Verification Program 参加組織向け。5.1 比で出力最大30%高速。価格は入力 $8 / 出力 $40 per MTok（5.1 は $10 / $50）、キャッシュ読み出し $0.20。fast mode は最大2.5倍速で $16 / $80。API ID は `claude-fable-5-2`。AWS / Google Cloud / Azure で同日提供。

## できるようになったこと

- コーディング・推論・視覚の改善、数百〜千超のサブエージェントを束ねる長時間エージェント運用
- Claude Code でも fast mode が使える（2.1.321 で既定の Fable モデルに）
- 米国内推論は 1.1 倍価格

## 影響範囲

- 対象: Pro / Max / Ultra / Team / Enterprise、API
- Mythos 5.2 は審査済み組織のみ。Mythos の fast mode も同様
