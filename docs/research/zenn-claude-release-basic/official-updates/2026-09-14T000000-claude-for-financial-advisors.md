# 2026-09-14 Claude for Financial Advisors

## 公式内容の日本語要約

Anthropic は 2026-09-14、**Claude for Financial Advisors** を公開した。ファイナンシャルアドバイザー（資産運用アドバイザー）向けの **コネクタ群とワークフロースキル群**で、リサーチ・面談準備・記録作成といった、顧客と向き合う時間を奪っている作業を対象とする。**既存の Claude for Financial Services の拡張**という位置づけである。

提供形態は **Claude Cowork から使うプラグイン**で、**Enterprise プランの既存契約者は即日利用できる。** 公式は Enterprise を推奨しており、理由として**記録保持に必要な監査ログが含まれる**点を挙げている。新規の Enterprise ライセンスはリクエストフォーム経由で、**2026-09 末までに申請したものには一度限りの利用クレジットが付く。**

新規コネクタは **11件**である。Addepar、BlackRock Advisor Center、Charles Schwab Advisor Services、Envestnet（Tamarac / MoneyGuide）、iCapital、Orion、SS&C Black Diamond Wealth Solutions、Wealthbox、Wealth.com、Vanguard、Zocks。既存の Microsoft 365、Salesforce、DocuSign、Box、FactSet、S&P Global、Morningstar 連携に加わる形になる。

新規スキルは **8件**である。オンボーディング、オルタナティブ投資のブリーフ、コンプライアンスレビュー、相続・税務ブリーフ、ポートフォリオのリバランス、面談後メモ、面談前準備、見込み客のインテーク。

料金は個別に開示されておらず、既存の Claude Enterprise の料金体系に従う。

## できるようになったこと

- **Claude Cowork のプラグイン**として、アドバイザー業務向けのコネクタとスキルをまとめて導入する
- 主要な資産管理・カストディ・CRM プラットフォーム **11件**へ接続する
- 面談前準備・面談後メモ・コンプライアンスレビューなど **8つの定型業務をスキルとして呼び出す**

## 影響範囲

- 対象ユーザー: ファイナンシャルアドバイザー、ウェルスマネジメント部門。**Enterprise 契約者は即日**
- 対象プラン: Enterprise 推奨（監査ログを含むため）。新規は申請フォーム、**2026-09 末までの申請に一度限りのクレジット**
- API / UI / 管理者機能: Claude Cowork のプラグイン。コネクタ単位の接続設定と監査ログ
