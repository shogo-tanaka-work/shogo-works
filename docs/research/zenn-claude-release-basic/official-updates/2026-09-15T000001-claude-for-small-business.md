# 2026-09-15 Claude for Small Business の拡張

## 公式内容の日本語要約

Anthropic は 2026-09-15、**Claude for Small Business** の拡張を発表した。**43のワークフロー**と**27の新規連携**、そして全米規模の無料トレーニング施策が同時に出ている。

新規連携27件には、Shopify、Salesforce、TikTok、Atlassian、Zoom、Xero、Gusto、Square、Stripe、Zapier のほか、Apollo、Clay、Expensify、monday.com、RingCentral、Wix など17件が含まれる。**会計・決済・EC・人事・SNS が一通り揃っている**点が特徴で、業務システムというより中小事業者が実際に契約しているサービスの束に近い。

43のワークフローは、週次の事業ブリーフ（資金繰り・売上・パイプライン）、リード対応と選別、提案書作成と価格設定、SNS コンテンツ計画、月次決算と突合をカバーする。公式は創業者の声として「120時間かかっていたことが5分になった」を引用している。

提供形態は **Claude Cowork デスクトップアプリ経由で即日利用可能**。**すべての有料プラン**が対象で、複数人の事業者には Team プランを推奨している。本リリース専用の新価格帯は設定されていない。

トレーニングは3系統。**2026年秋のワークショップツアー**が全米10都市（Boston / Pittsburgh / Detroit / Minneapolis / Phoenix / Memphis / Savannah / Bentonville / Tampa / Raleigh）でパートナー Tenex と無料半日開催。**パートナー14社のウェビナー**が9〜11月（Notion 09-25、Zoom 10-08、HubSpot 10-20 ほか）。さらに **150名以上の認定 SMB トレーナー**が750回以上の地域ワークショップを計画している。

## できるようになったこと

- 43のワークフローを Claude Cowork から選んで導入できる
- Shopify / Stripe / Square / Xero / Gusto など中小事業者の実利用サービス27件と接続できる
- 月次決算・突合、週次事業ブリーフ、提案書作成を定型手順として回せる

## 影響範囲

- 対象ユーザー: 中小事業者、個人事業主、少人数チーム
- 対象プラン: すべての有料プラン（複数人は Team 推奨）
- API / UI / 管理者機能: Claude Cowork デスクトップアプリ（UI）、各種 SaaS 連携
