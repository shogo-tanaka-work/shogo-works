# 2026-09-14 医療組織での Claude Tag 活用事例

## 公式内容の日本語要約

Anthropic は 2026-09-14、**Claude Tag（beta、Slack に Claude をチームメイトとして入れる機能）の医療分野での活用事例**を公開した。取り上げられているのは Insight Health、Tennr、Medallion の3社で、**本番アラートのトリアージ、社内ツールの保守、支払者ルールに関する問い合わせ対応**に使っているとされる。

**公式が明記しているのは「Claude Tag は Anthropic の BAA（Business Associate Agreement）の対象にまだ入っていない」**点である。そのうえで、複数の医療組織が **PHI（保護対象保健情報）に触れないチャネルとコネクタに限って**今日も使っていると説明している。

統制面として公式が挙げているのは3点である。**(1) Claude Tag は既定でオフにでき、承認したチャネルだけで有効化できる。DM は無効化でき、コネクタはチャネル単位でスコープできる。(2) Claude Tag は Slack 全体を読むわけではなく、ワークスペースメンバーが見えるものだけを見る。公開チャネルはキーワード検索できるが、招待されていないプライベートチャネルにはアクセスできない。(3) アクセスバンドルにより、あるチャネルではコードベースと issue tracker を接続しつつ、EHR・臨床システム・患者コミュニケーションには到達できない構成にできる。**

**期限付きの記載が1つある。** Claude Tag を有効化して GitHub と接続した Enterprise 組織には **$25,000 の Claude Tag クレジット**（10シート以上の Team 組織は $2,500）が付与されるが、**このクレジットは 2026-10-01 に失効する。**

## できるようになったこと

- （製品機能の追加ではない）**BAA 未対応の AI 機能を、規制対象データを回避する構成で使う**具体例が公式から参照できるようになった

## 影響範囲

- 対象ユーザー: 医療・規制産業で Slack を使う組織、情シス・コンプライアンス担当
- 対象プラン: Claude Tag は beta。クレジットは Enterprise（$25,000）と 10シート以上の Team（$2,500）、**2026-10-01 失効**
- API / UI / 管理者機能: チャネル単位の有効化、DM の無効化、コネクタのチャネル単位スコープ、アクセスバンドル

## 教材化メモ

**単独記事にはしない（スコア5点）が、教材の題材としては強い。** 理由は、この記事が**「規制対象データを扱えないツールを、扱えない前提のまま実務投入する」という設計パターン**の実例になっている点である。BAA 非対象という制約を、機能の可否ではなく**接続先の切り分け**で回避している。AI ガバナンス教材で「使えない／使える」の二分法を崩す題材として使える。

**アクセスバンドルの考え方は、他ベンダーにも一般化できる。** 「エージェントに何を見せるか」をチャネル（＝作業文脈）単位で束ねる設計で、ロールベースのアクセス制御とは粒度が違う。**エージェント固有のアクセス設計**という章を作るときの中心例になる。

**「ワークスペースメンバーが見えるものだけを見る」という原則**は、受講者が最も誤解しやすい点なので必ず扱う。Slack に入れた AI が全社の会話を読んでいると誤解されやすい。

**クレジットの 2026-10-01 失効は日次サマリーの期限管理に転記する。** 記事化はしないが、検討中の組織には期限のある判断材料になる。
