# 2026-08-28 Claude for Teachers（米国 K-12 学校・学区向け）

## 公式内容の日本語要約

Anthropic が **Claude for Teachers** を米国の K-12 学校および学区向けに提供開始した。個人教員向けだった提供形態から、**学区単位で導入・管理できる Enterprise 提供**へ広がった形になる。

**費用は無料。2027-06-30 までに申し込んだ適格組織は、1年間の無料アクセス**を受ける。既定では超過課金が発生しない設計と説明されている。

機能面では、学習科学に基づく教育向けスキルが用意され、**米国50州すべての学習指導基準（academic standards）と紐づく**。今回、**授業準備（lesson preparation）と理解度確認（check for understanding）の2つのスキル**が追加された。

管理面では **SSO、ロールベースのアクセス制御、ドメイン claim** が使える。学区管理者はドメインを検証したうえで、アカウント管理・ポリシー設定・アクセス権限の制御・職員の追加削除・学校横断の利用状況把握を行える。

データ保護は **FERPA に沿った扱い**で、K-12 向けデータ処理契約（K-12 Data Processing Agreement）により生徒情報を保護する。**データはモデル学習に使われない**。

## できるようになったこと

- 学校・学区単位で Claude for Teachers を **無料の Enterprise 提供**として導入できる（2027-06-30 までの申込で1年間）
- **授業準備**と**理解度確認**の2スキルが追加された
- SSO / ロールベースアクセス / ドメイン claim による学区単位の統制ができる

## 影響範囲

- 対象ユーザー: **米国の K-12 学校・学区**の管理者、教員、職員
- 対象プラン: 無料（Enterprise 提供形態）。申込期限 **2027-06-30**
- API / UI / 管理者機能: 管理者コンソール（ドメイン検証、アカウント・ポリシー管理、利用状況の可視化）

## 教材化メモ

- 記事化しないため、この節を残す（本数上限による見送り）。**「無料で1年」+「申込期限あり」+「ドメイン claim による組織単位の囲い込み」**という組み合わせは、AI ベンダーの教育市場アプローチとして OpenAI の ChatGPT for Teachers（08-26 に米国学区へ拡大）と正面から重なる。同じ週に両社が同じ市場へ同じ形の提供を出した、という並びで教材化できる。
- **ドメイン claim の意味**は企業向け研修でも使える論点。「組織のドメインを検証して、そのドメインの個人アカウントを組織管理下へ取り込む」動きは、シャドー IT を正規化する標準手段になっている。教育機関に限らず、企業が個人契約の AI 利用を把握する手口として同型。
- 対象が米国 K-12 に限定されており、日本の読者への実務影響が薄いため単独記事化は見送る。日本を含む他地域への展開、または同型の提供が国内で始まった時点で拾い直す。
