# 2026-09-17 Life Sciences Verification Program（LSVP）

教材化メモ: src/content/ai-news-notes/claude/life-sciences-verification-program.mdx

## 公式内容の日本語要約

Anthropic は 2026-09-17、**Life Sciences Verification Program（LSVP）**を発表した。審査を通過したライフサイエンス専門職に対し、**生物学関連の作業について通常より緩和されたセーフガード**を適用した Mythos / Opus / Sonnet モデルへのアクセスを与える。早期アクセスで既に数十組織をオンボードしており、今回から広く応募を受け付ける。

**ベータ提供で、初期対象はチームと研究機関。** 個人の Pro / Max プランへの拡大は「時間をかけて」とされている。

LSVP の目的は、**一般提供されている Fable 系モデルでは現在ブロックされる作業**——創薬、研究生物学、臨床開発、製造——を可能にすること。対象はアカデミアのラボ、スタートアップ、製薬企業など。

**審査では、研究者としての資格、セキュリティ基準、倫理的な研究監督体制がレビューされる。** 通過後、必要に応じて2種類の grant を申請する。

- **Standard Use**: ライフサイエンス業務の大半をカバー。**チーム全体へ拡張可能で、更新は年1回**。Mythos 5.1 / Opus 5 / Sonnet 5 と今後のモデルに適用。基礎研究、R&D、サプライチェーン・製造、臨床開発、品質保証、規制対応、投資・デューデリジェンスまで含む
- **High-risk Use**: Standard Use でもブロックされる領域向けのアドオン。**ライフサイエンス要求をブロックする全セーフガードを解除**する。**適用は単一の研究プロジェクト単位で、更新は6か月ごと**

grant は **Claude Science / Claude.ai / Claude Code / API の全プロダクト面**で利用できる。

## できるようになったこと

- 審査を通した組織が、生物学領域の拒否を「回避」ではなく「申請」で解消できるようになった
- チーム単位（Standard）とプロジェクト単位（High-risk）で、必要な緩和幅を選べる

## 影響範囲

- 対象ユーザー: ライフサイエンス専門職（アカデミア、スタートアップ、製薬、製造）
- 対象プラン: ベータ。当初はチーム・機関向け。個人 Pro / Max は将来
- API / UI / 管理者機能: 全プロダクト面に適用。**セーフガードが顧客ごとの審査結果で変わる**という構造変化
