# 2026-10-22 Agent Skills を Agentic AI Foundation へ寄贈

## 公式内容の日本語要約

Anthropic が Agent Skills の標準、名称・ロゴ、GitHub 組織、agentskills.io ドメインを Linux Foundation 傘下の AAIF に寄贈。70以上のプラットフォームが対応し、公開スキル100万件・インストール約2.8億件。Anthropic・Google・OpenAI 等の個人が保守し、Lead Maintainer は David Soria Parra と Mahesh Murag。ロードマップはバージョン付きリリース、正式な提案プロセス、スキルの作成・導入のセキュリティ指針。
