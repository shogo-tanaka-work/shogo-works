# 2026-10-14 Anthropic: 2026年米国中間選挙への対応

## 公式内容の日本語要約

Anthropic が**2026年米国中間選挙に向けた対応**を公表した。利用実態の数値、製品側の変更、ポリシーの明確化、検知と執行の強化が1本にまとまっている。

**利用実態の数値が示されている。** 米国の Claude.ai 会話のうち政治・政策・社会課題に関するものが約 **5.75%**、選挙・投票に特化したものが約 **0.51%**。「誰に投票すべきか」を尋ねるものは約 **0.01%**、選挙公正性ポリシー違反は約 **0.002%**。投票日が近づくにつれ増加が見込まれるとしている。

**製品側の変更は3点。** (1) **2026年10月中に、Claude.ai が Democracy Works から公式の投票情報を取得する**（米国ユーザー向け。投票場所や必要な身分証を会話の中で州別に回答）。(2) **選挙当夜とその後数日は、現在の公式開票数を表示する。** (3) 登録・投票所・日程の質問には TurboVote へのバナーを継続表示する。**企業向け固有の変更は記載がない。**

**政治的中立性は評価値で示されている。** Claude Opus 5.5 / Sonnet 5.5 / Haiku 5.5 が自社の political evenhandedness 評価で **99%**。外部3団体（The Future of Free Speech、Foundation for American Innovation、Collective Intelligence Project）のレビューでは、**求められていない留保や反論を付けることがある**という指摘が出ている。Foundation for American Innovation は Sonnet 4.5 について**右寄りの主張を相対的に弱める傾向**を指摘した。改善予定として、Yes/No や短答での均衡、留保の付け方の一貫性、候補者・投票を含む評価範囲の拡大が挙がっている。

**検知側の強化が、実務上もっとも参考になる部分である。** 外部機関（ISD、McCain Institute）の検証で、**単発の有害リクエストは確実に拒否する一方、無害に見えるタスクへ分割された悪意あるキャンペーンは見落とす可能性がある**と判明した。これに対し**多段ミスユース（multi-step misuse）向けの新しい分類器**を投入している（偽のソーシャルアカウント、政治議論を狙うニュースサイト、金銭目的の選挙スキーム）。実際に、外国の運営者が偽ニュースサイトで Claude に中間選挙報道を作らせていた事例と、広告収益目的の偽ニュース生成事例があり、**いずれもアカウントを BAN した。**

**ポリシー面では、前週に公表された 2026 Usage Policy update が選挙関連ルールの対象範囲と対象外を明確化し、例示を追加している。** 選挙キャンペーン向けのガイドも公開され、**許可される用途**（プレス文面やファンドレイジングメールの下書き、ディベート準備、投票率データ分析、有権者向け資料）と**禁止される用途**（実在人物を装う偽ペルソナ、量産されたエンゲージメント、独立系報道を装うサイト向けのコンテンツ）が示された。

## できるようになったこと

- 米国ユーザーが Claude.ai の会話内で、州別の公式投票情報（投票場所・必要な身分証）を受け取れる（2026年10月中）
- 選挙当夜以降、公式開票数を会話内で確認できる
- 多段に分割されたミスユースを検知する分類器が稼働する（利用者側の操作は不要）

## 影響範囲

- 対象ユーザー: Claude.ai の米国ユーザー（製品側の変更）、全利用者（ポリシーと検知）
- 対象プラン: 記載なし。企業向け固有の変更は示されていない
- API / UI / 管理者機能: Claude.ai の UI。分類器と執行はプラットフォーム側
- 地域: 米国。ローカライズされた保護措置は米国・イスラエル・ブラジルの3地域
- 期限: 公式投票情報の接続は **2026年10月中**。選挙日は 2026年11月
