# 2026-08-25 Dify 1.17.0

## 公式内容の日本語要約

窓内の Dify リリースは 1.17.0 の1件（pre-release ではない）。**セルフホスト運用者に作業が発生する破壊的変更を含む。**

**破壊的変更**。**環境変数 `EDITION` が `DEPLOYMENT_EDITION` へ改名**された。エージェントランタイム・E2B・認証・トレーシング向けの環境変数が複数追加されている。**DB マイグレーションが必要**（手動のバックフィルは不要）。**Docker Compose の構成が更新**されており、独自の compose ファイルを持つ環境は再適用が要る。実行タイムアウトの既定値が引き上げられた（`APP_MAX_EXECUTION_TIME` と `WORKFLOW_MAX_EXECUTION_TIME` が 1200秒 → 3600秒）。

**エージェントとサンドボックス**。ローカルサンドボックスに加えて **E2B のクラウドサンドボックス**をエージェント実行に使えるようになった。ビルド時のホームスナップショットで公開時点のファイルシステム状態を取り込み、以降の実行で復元する。**ワークスペース単位のスキル管理**（下書き→公開のバージョンライフサイクル付き）。文脈長超過を防ぐ履歴の圧縮。

**ワークフロー**。LLM 用の環境変数を一度定義して使い回せる。**ループ / イテレーションノードの中で human-in-the-loop フォームが動く**ようになった。Phoenix と LangSmith のアダプタによる、プロバイダー非依存の統一トレーシング。

**認証・セキュリティ**。ログインエンドポイントでの **Cloudflare Turnstile CAPTCHA** 対応。外部管理の暗号鍵を使う **Azure Key Vault 連携**。メールコードログインの試行回数制限とトークン有効期限の強化。データセット・ドキュメント・会話のアクセス制御とオーナーシップのスコープ見直し。**SSRF と外向き通信の強化**（タイムアウトの上限設定）。

**ナレッジ・検索**。TiDB Vector の全文検索・ハイブリッド検索、vision 対応モデル向けのマルチモーダル画像ファイル処理、ODT 抽出、音声 MIME 型の検証改善。

**開発体験**。⌘K / Ctrl+K の「Go to Anything」コマンドパレット、ラオ語対応。

## できるようになったこと

- E2B クラウドサンドボックスでエージェントを実行できる
- ワークスペース単位でスキルを下書き→公開のライフサイクル付きで管理できる
- ループ / イテレーションノードの中で human-in-the-loop フォームを使える
- Azure Key Vault で暗号鍵を外部管理できる

## 影響範囲

- 対象ユーザー: Dify のセルフホスト運用者、ワークフロー・エージェントの開発者
- 対象プラン: セルフホスト（OSS）
- API / UI / 管理者機能: 環境変数（破壊的変更）・DB マイグレーション・Docker Compose 構成

## 教材化メモ

- **環境変数の改名（`EDITION` → `DEPLOYMENT_EDITION`）は、更新を止める典型的な理由**になる。セルフホストの更新コストは「新機能の魅力」ではなく「移行作業の量」で決まる、という話の具体例として使える。
- **実行タイムアウトの既定が 1200秒 → 3600秒**へ延びたのは、エージェント処理の実行時間が前提として長くなっていることの現れ。同期的な HTTP リクエストの発想で設計すると破綻する領域に入っている。
- **ループの中で human-in-the-loop が動く**ようになった点は、「人の承認を挟むワークフロー」の設計自由度を大きく変える。承認が外側にしか置けないのと、繰り返しの各周回に置けるのとでは、業務適用の範囲が違う。
- 記事化はしない（週次確認ソースの通常更新）。ただし**破壊的変更を含むため、セルフホスト運用者向けには週次サマリーで明示する**。
