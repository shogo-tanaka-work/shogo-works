# 2026-07-28 Dify 1.16.1

## 公式内容の日本語要約

窓内（2026-07-27T01:43:14Z〜2026-07-28T12:41:04Z目安）にDify `1.16.1` が公開された。ワークフロー・エージェント関連の新機能複数と、コラボレーション/RAG周りのバグ修正多数が含まれる。

主な新機能:

- **Tool Multi-Select Input**: ワークフローのToolノードで、パラメータ設定時に事前定義リストから複数値を選択できるマルチセレクト入力に対応
- **Workflow Node Locator**: 実行ログやエラーメッセージ中の `node_id` をクリックすると、ワークフローエディタのキャンバス上で該当ノードにジャンプ・ハイライトできるように
- **Block Selector Improvements**: ノード追加時のブロック選択パネルにキーボードナビゲーション、カテゴリプレビュー、検索性向上を追加
- **Export Agent DSL from Sidebar**: エージェントアプリをサイドバーメニューから直接DSL（YAML）としてエクスポート可能に。バックアップ・バージョン管理が容易に
- **Knowledge Tracing**: ナレッジ/RAGのドキュメント処理にトレース（可観測性)を追加、インデックスパイプラインの可視性向上

バグ修正は、コラボレーション編集中の下書き消失・保存エラー、RAGの文字化け・スペース保持、エージェントプレビューの会話ID継承、Webアプリ側のJWT期限設定など多数。

## できるようになったこと

- ワークフローToolノードで複数値パラメータを一括選択できる
- 実行ログのnode_idクリックでキャンバス上の該当ノードへジャンプできる
- エージェントアプリをサイドバーからDSL(YAML)として直接エクスポートできる
- ナレッジ/RAGドキュメント処理の内部トレースを確認できる

## 影響範囲

- 対象ユーザー: ワークフロー/エージェント機能を使う全ユーザー
- 対象プラン: Dify Community / Cloud 双方（OSSリリースのため機能はセルフホストにも反映）
- API / UI / 管理者機能: ワークフローエディタUI、エージェントアプリのサイドバーUI、内部トレースログ

## 教材化メモ

- Tool Multi-Select InputとWorkflow Node Locatorは日常的なワークフロー構築の効率化に直結するため、Dify教材の「ワークフロー構築Tips」章に反映候補。
- Export Agent DSLはエージェントのバックアップ/移行手順の説明に使える。
