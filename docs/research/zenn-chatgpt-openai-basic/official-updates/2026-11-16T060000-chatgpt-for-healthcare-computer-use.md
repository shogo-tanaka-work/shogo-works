# 2026-11-16 ChatGPT for Healthcare: computer-use agents と医療向けプラグイン20件超

## 公式内容の日本語要約

ChatGPT for Healthcare に、画面操作でEHRや保険ポータルをまたいで作業する computer-use agents の強化、臨床検索（根拠の検索・評価・引用）の改善、Luma Health・Redox・UpToDate など20件超の医療向けプラグインが追加された。アクセス制御と監査ログを備え、BAA 対象サービスの利用で HIPAA 対応のワークフローを組める。関連記事 advancing-computer-use-for-healthcare-teams では GPT-6 Astra の評価と Abridge / Cigna / CVS Health 等の導入が紹介されている。API、ChatGPT for Healthcare、ChatGPT for Clinicians から利用可能。

## 影響範囲

- 対象: 医療機関・クリニシャン。一般企業・個人の業務には直接関係しない。
