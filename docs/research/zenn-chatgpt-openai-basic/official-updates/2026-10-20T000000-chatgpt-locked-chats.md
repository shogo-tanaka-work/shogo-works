# 2026-10-20 ChatGPT Locked chats

## 公式内容の日本語要約

選択した会話を通常のチャット履歴・ピン留め・検索から隠し、4桁のアカウント PIN または対応デバイス認証でのみ開けるようにする機能。保持設定とモデル改善設定は変わらない。Free / Go / Plus / Pro に順次展開され、Web・iOS・Android・新しい ChatGPT デスクトップアプリ（macOS / Windows）で使える。チャットの「…」メニューから「Lock chat」を選ぶ。

日付は Exa 取得時の見出し「October 20, 2026」による（個別の時刻なし）。

## できるようになったこと

- 特定の会話を履歴・検索・ピン留めから隠す
- PIN またはデバイス認証で開く

## 影響範囲

- 対象ユーザー: Free / Go / Plus / Pro（順次）
- 対象プラン: Business / Enterprise への言及なし
- API / UI / 管理者機能: UI のみ。管理者制御の記載なし
