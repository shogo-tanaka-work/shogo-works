# 2026-10-08 GPT-6.1 Sol Ultrafast が提供開始

## 公式内容の日本語要約

OpenAI が **GPT-6.1 Sol の Ultrafast** を提供開始した。API 面と製品面の2か所で同日に告知されている。

**これは新設ではなく、約束の履行である。** Ultrafast ティア自体は **2026-09-29 の DevDay で新設**され、当時提供中だったのは **GPT-6 Astra Ultrafast** のみ、**Sol 版は「近日」**とされていた（2026-09-29 の日次サマリーと記事 `chatgpt-openai/gpt-6-1-sol-and-ultrafast-tier` に記録済み）。今回それが実現した。

**API 面**（`developers.openai.com/api/docs/changelog`、Feature / `gpt-6.1-sol` / Responses API）では、**Responses API の `service_tier` に `"ultrafast"` を指定する**と、生成される出力トークンの間隔が短くなる。対象は **API の全ユーザー**で、レート上限の範囲内で使える。処理は global で、**US と EU のデータレジデンシー**に対応する。

**製品面**（`learn.chatgpt.com/docs/changelog`）では、Ultrafast が **Codex と ChatGPT Work** で使えるようになった。対象は **Pro 500 と、条件を満たす Enterprise / Edu プラン**である。**Enterprise では既定で無効**で、workspace の owner が有効化する必要がある。

**単価は公式 Pricing で確認できた**（changelog 側には金額の記載がないため、`developers.openai.com/api/docs/pricing` で裏取りした）。`gpt-6.1-sol` の 100 万トークンあたりの単価は次のとおり。短コンテキストは入力 272K トークン以下、長コンテキストはそれ超。

| ティア | 標準比 | 短 入力 / 出力 | 長 入力 / 出力 |
| --- | --- | --- | --- |
| Standard | 1倍 | $2.00 / $10.00 | $4.00 / $15.00 |
| Fast | 2倍 | $4.00 / $20.00 | $8.00 / $30.00 |
| Ultrafast | 6倍 | $12.00 / $60.00 | $24.00 / $90.00 |
| Flex / Batch | 0.5倍 | $1.00 / $5.00 | $2.00 / $7.50 |

速度の倍率は公式説明で **Codex 最大8倍、API 最大6倍**。公式コミュニティの告知では **Sol Ultrafast は Astra の約1.2倍のコスト**と説明されている。

**前日（2026-10-07）の Codex CLI 0.161.0 で GPT-6.1 Sol が既定モデルになっており、既定モデルが Sol へ寄った翌日に Sol の速度ティアが開いた**という順序になる。

## できるようになったこと

- Responses API で `service_tier: "ultrafast"` を指定できる（全 API ユーザー）
- Codex と ChatGPT Work で Ultrafast を選べる（Pro 500 / 条件を満たす Enterprise・Edu）
- global 処理、US / EU のデータレジデンシーに対応

## 影響範囲

- 対象ユーザー: API は全ユーザー、製品側は Pro 500 / Enterprise / Edu
- 対象プラン: 上記。**Enterprise は既定で無効（owner が有効化）**
- API / UI / 管理者機能: API パラメータ1つと Enterprise の管理者設定。**単価は標準の6倍**
