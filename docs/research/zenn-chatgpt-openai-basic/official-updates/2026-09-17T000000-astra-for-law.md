# 2026-09-17 OpenAI Astra for Law

## 公式内容の日本語要約

**前日窓（2026-09-17）の取りこぼしを追補したものである。** 公開日は窓外だが、前日サマリーに記録が無く、本日の巡回で公式ページを確認できたため記録する。

OpenAI が **Astra for Law** を発表した。位置づけは「法律事務所とリーガルテック企業が自社の専門性の上に AI 製品とワークフローを構築するための新しい基盤」で、**GPT-6 Astra に、法務業務向けの設定・ツール・コンテキストを組み合わせたもの**である。

中核は**法務検索インデックス**である。米国の判例法・制定法・規則・裁判所規則・行政決定を、**2億3,000万を超える URL のコーパス**から検索でき、ソースは日次で追加される。CourtListener を運営する非営利の **Free Law Project との協業により、公表済みの米国先例判例の 99.9% 超をカバーする判例コレクション**が検索対象に入る。公式は Thomson Reuters のような事業者から提供されるライセンスコンテンツや専門製品を**置き換えるのではなく補完する**と明記している。

**評価値も公開されている。** Vals AI の Legal Research Bench の非公開検証セットから米国法のリサーチ設問200問でテストしたところ、両システムとも最高の reasoning effort で、**全体の正答チェック通過率は Astra for Law が 54.0%、web 検索のみの GPT-6 Astra が 38.7%**（相対で40%改善）。判例中心の設問では**参照判例を24%多く発見**し、監査対象の目標パッセージでは**正しい判決文から最大54%多く関連パッセージを取得**した。

**提供形態は限定的である。** まず **ChatGPT と Codex の Trusted Access を通じて選定された法律事務所へ提供**され、API は後日。モデルピッカーでは **「GPT-6 Astra Law」**、API では **`gpt-6-astra-law`** として現れる。**機密性の高い依頼者業務向けに、プライバシーとガバナンスの専用コントロールを拡張中**とされている。

あわせて、**ChatGPT を法律事務所が既に使っている専門ツール（Relativity、Clio など）へつなぐ 26 個のエコシステムプラグイン**が公開された。二次報道（The Next Web、2026-09-18）によれば、同日に iManage / Intapp / DeepJudge なども含まれ、Thomson Reuters は HighQ の案件コンテキストを ChatGPT へ持ち込み CoCounsel Legal コネクタをプレビュー、**ChatGPT for Word が同日に一般提供（GA）**になったとされる。**26プラグインと Relativity / Clio の名前は公式ページで確認できるが、個別ベンダー名と ChatGPT for Word の GA は公式ページ上で確認できていない。**

## できるようになったこと

- 米国法のリサーチを、判例・制定法・規則・裁判所規則・行政決定を横断する専用インデックス上で実行できる
- 法務分析・法務文書作成向けの指示が組み込まれた状態で、争点の弱点や契約例外のリスク配分まで扱わせられる
- ChatGPT を Relativity / Clio など既存の法務ツールへ 26 プラグイン経由でつなげる
- API 顧客（Harvey、Legora）が自社製品の上に同じ基盤を載せられる（API 提供は後日）

## 影響範囲

- 対象ユーザー: 米国法を扱う法律事務所、リーガルテック企業、法務部門
- 対象プラン: Trusted Access に選定された法律事務所（ChatGPT / Codex）。API は "coming soon"
- API / UI / 管理者機能: モデルピッカーに `GPT-6 Astra Law`、API に `gpt-6-astra-law`。プライバシー・ガバナンスの専用コントロールを拡張中
