# 2026-09-10 Deep Research が ChatGPT Work と Codex で利用可能に

教材化メモ: src/content/ai-news-notes/chatgpt-openai/deep-research-work-codex.mdx

## 公式内容の日本語要約

**Deep Research が ChatGPT Work と Codex で使えるようになりました。**

Web、自分のファイル、対応する接続済みアプリを横断して複雑な問いを調査し、その結果を **引用付きの編集可能なドキュメント** に落とし込めます。調査の途中で方向を修正でき、利用可能なツールに応じて **ドキュメント / プレゼンテーション / スプレッドシート / Site** のいずれかを成果物として要求できます。

起動方法は、Work で **`@Deep Research`** と入力するか、明示的に deep research を依頼します。

### 提供範囲と課金

対象は **Work アクセスを持つ Plus / Pro / Business / Enterprise / Edu** のユーザーで、**web、デスクトップ、iOS、Android** で利用できます。

課金は **既存の Work / Codex の allowance またはクレジットを消費** します。**Chat 側の deep research の上限は変更されません。**

## できるようになったこと

- Work / Codex から Web・自分のファイル・接続済みアプリを横断した調査
- 引用付きの編集可能なドキュメントへの落とし込み
- 実行中の方向修正（steering）
- 成果物形式の指定（ドキュメント / プレゼン / スプレッドシート / Site）

## 影響範囲

- 対象ユーザー: Work アクセスを持つ Plus / Pro / Business / Enterprise / Edu
- 対象プラン: 上記。web / デスクトップ / iOS / Android
- API / UI / 管理者機能: UI。課金は既存 Work / Codex allowance・クレジットを消費（Chat 側上限は不変）
