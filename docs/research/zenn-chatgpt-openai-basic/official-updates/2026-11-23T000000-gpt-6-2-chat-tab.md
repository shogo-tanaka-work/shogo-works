# GPT-6.2 が ChatGPT の Chat タブに登場

## 公式内容の日本語要約

Chat タブ向けに最適化した GPT-6.2（Sol 系を日常会話向けに調整）を Plus / Pro / Business / Enterprise へ順次展開。画像理解 47.4%→71.7%、難しい指示の追従 62.5%→78.1%（OpenAI 社内評価）。Work と Codex のモデルは変わらない。Enterprise は管理者設定に依存。日付は Exa 取得のリリースノート見出し（November 23, 2026）による。
