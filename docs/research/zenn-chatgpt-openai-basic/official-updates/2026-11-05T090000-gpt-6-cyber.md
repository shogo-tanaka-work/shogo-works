# 2026-11-05 GPT-6 Cyber

## 公式内容の日本語要約

サイバーセキュリティ特化モデル GPT-6 Cyber を発表。ExploitGym は GPT-5.6 Cyber の 32.1% から 48.5%、範囲外サービスを攻撃しなかった割合は 99.93%（プロンプトなし）。OpenAI の研究者が Linux の権限昇格エクスプロイト 948 件、Firefox の高重大度の未知の脆弱性 81 件を発見。Preparedness Framework のサイバー区分は Critical。Daybreak Red が GPT-6 Cyber を使い、Daybreak Blue は検証済みの防御担当者向け。
