# 2026-10-27 OpenAI expands partnership with Oracle

## 公式内容の日本語要約

OpenAI と Oracle が、Oracle のアプリケーションとデータを ChatGPT に取り込み、Oracle の新製品を OpenAI のモデルで動かす提携拡大を発表した。Oracle は 13万人の ChatGPT 利用者と 9.5万人超の Codex 利用者を報告している。

Oracle は「Oracle AI Workspace」を開発中で、ChatGPT から Oracle アプリの情報検索や承認付き業務フローを実行することを目指す（提供時期は未記載）。新オファリングは Oracle AI Security Mesh（OpenAI のサイバーモデルによる脆弱性検出）、Oracle AI SMB Bundle（ChatGPT Business と Codex と OCI クレジット）、Oracle App Composer（Codex で業務アプリを構築）。米国の Oracle 顧客は Oracle Marketplace 経由で OpenAI API、Codex、ChatGPT Work を購入できる。
