# 2026-10-28T13:15:00Z OpenAI と ServiceNow が提携拡大（ChatGPT 連携、MCP プラグイン）

ServiceNow の業務コンテキストとアクションを ChatGPT から使う連携を発表。ServiceNow MCP プラグインは OpenAI marketplace で提供開始済みで、機能拡張は2026年末までの予定。ServiceNow の AI Workflow Factory への Codex 統合、サイバーセキュリティの共同ソリューション、音声体験は計画段階。ServiceNow は全従業員に ChatGPT Work と Codex を展開する計画。
