# 2026-10-19 OpenAI: 低リソース言語のコーディング

## 公式内容の日本語要約

OpenAI は COBOL、OCaml、Fortran、Visual Basic など学習データの少ない言語での構築・移行能力が最新モデルで向上したと発表した。2つの評価を新設: MultiLangBench（20言語で SQLite 互換 DB エンジンをゼロから作る。評価セットを GitHub で公開）と COBOL 移行評価（C++ / Java / Kotlin / Python / Rust へ、出力のバイト単位一致で判定）。

MultiLangBench では GPT-6 Astra が平均87.4%（GPT-5.6 Sol は26.8%）、GPT-6 Luna が40.3%（推定 API コスト約78%減）。COBOL 移行では GPT-6.1 Sol が低推論で86.6%（GPT-5.6 Sol は5.4%、コスト39%減）、高推論で97.9%。本番適用には専門家のレビューとテストが必要と注記されている。製品機能や料金の変更ではなく、評価結果の公開。
