# 2026-09-10 ChatGPT Library に Box / Dropbox / SharePoint が追加

教材化メモ: src/content/ai-news-notes/chatgpt-openai/library-box-dropbox-sharepoint.mdx

## 公式内容の日本語要約

ChatGPT Library の接続先に、既存の Google Drive に加えて **Box、Dropbox、SharePoint** が加わりました。

接続すると、利用可能なファイル・フォルダを **ブラウズおよび検索** でき、`Add from Library` または `@メンション` で会話に持ち込めます。**再アップロードは不要** です。対応形式のファイルは会話の横にプレビューを開いたまま作業でき、引用から出典へ辿れます。

**フォルダ単位の指定** も可能で、「このフォルダ配下のファイル全体に対して作業して」という指示ができます。ファイルは元のソースに紐づいたままなので、原本へ戻るのも容易です。

### 提供範囲

Web 版の Chat / Work 両方で、**Go、Plus、Pro、Business、Edu、Healthcare、Enterprise** へ順次展開中です。**既存のファイル権限とワークスペース統制がそのまま適用** されます。モバイル対応は後日とされています。

## できるようになったこと

- Box / Dropbox / SharePoint のファイル・フォルダを ChatGPT Library からブラウズ・検索
- `Add from Library` / `@メンション` による、再アップロード不要の会話への取り込み
- 会話の横でのファイルプレビュー表示と、引用から出典への遡及
- フォルダを選んで配下ファイル全体を対象にした指示

## 影響範囲

- 対象ユーザー: Web 版の Chat / Work 利用者。モバイルは後日
- 対象プラン: Go / Plus / Pro / Business / Edu / Healthcare / Enterprise（順次展開）
- API / UI / 管理者機能: UI。既存のファイル権限・ワークスペース統制が適用される
