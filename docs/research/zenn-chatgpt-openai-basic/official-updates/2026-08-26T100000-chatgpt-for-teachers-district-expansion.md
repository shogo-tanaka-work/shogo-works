# 2026-08-26 ChatGPT for Teachers 学区拡大

## 公式内容の日本語要約

2025年に約15万人の教職員向けに開始した ChatGPT for Teachers を、**20州の55学区へ拡大**し、**10万人以上の教職員**が追加で利用可能になった。累計では **30州・100超の K–12 組織・30万人以上**の教職員へ無償提供と研修を提供する規模になる。新規コホートには全米最大級の公立学区20校のうち5分の1が含まれる。

同時に、**16州にまたがるデータプライバシー協定**を Student Data Privacy Consortium の枠組みで締結したと発表した。公式は「業界初」と表現している。学区ごとに個別交渉することなく、州・地域の要件に沿った共通の枠組みで ChatGPT for Teachers を評価・採用できる。対象州は Illinois、Iowa、Maine、Massachusetts、Missouri、Nebraska、New Hampshire、New Jersey、New York、Ohio、Rhode Island、Tennessee、Texas、Vermont、Virginia、Washington の16州（California は別協定でカバー）。

ChatGPT for Teachers は引き続き**管理者・教員・教職員限定**で、生徒は対象外。**認証済み米国 K–12 教育者に対して 2028年6月まで無償**。

## できるようになったこと

- 対象学区の教職員が ChatGPT for Teachers を無償利用（研修付き）
- 16州の学区が、個別交渉なしに共通枠組みでプライバシー要件を評価できる

## 影響範囲

- 対象ユーザー: 米国 K–12 の教職員・学区管理者
- 対象プラン: ChatGPT for Teachers（2028年6月まで無償）
- API / UI / 管理者機能: 学区単位の導入・契約枠組み

## 教材化メモ

- **「アクセス提供」と「調達・法務の枠組み提供」を同時に出している**点が本質。ツールを配るだけでは組織導入は進まず、プライバシー評価の手続きを共通化したことが実質的な障壁除去になっている。**AI 導入が止まる場所は機能ではなく契約と手続き**という論点の教材にできる。
- **2028年6月という無償期限が明示されている**。期限付き無償は導入判断を早める一方、期限後の予算措置を先に議論させる。日本企業向けの AI 導入研修でも「無償期間の終わりから逆算する」という話に接続できる。
- 記事化は見送った。米国 K–12 限定の施策で、日本の読者の実務判断に直結しにくい。ただしプライバシー協定の設計思想は上記のとおり一般化できるため、教材側で扱う。
