# 2026-08-21 ChatGPT Release Notes

## 公式内容の日本語要約

ChatGPT Release Notes の 2026-08-21 見出しに6項目が掲載された。**本日の窓（2026-08-23 09:04 JST 〜）には入らない**が、前回巡回（2026-08-21 09:20 JST 締め）の直後に出たもので、いずれの日次サマリーにも記録されていなかったため、未巡回ギャップ分として記録する。

**プラグイン推薦の順位付けが変わった**。web とモバイルで、インストール後も使われ続けているプラグインを上位に出すようになった。デスクトップは対象外。プラグインの提供可否はプラン・地域・ワークスペース設定に依存する。

**ローカル時刻をより正しく考慮する**ようになり、時刻に依存する質問の回答が会話中の現地時間に沿うようになった。

**web の長い会話の読み込みが改善**され、会話全体を一度に取得するのではなく分割して読み込むようになった。あわせて、生成中のインタラクティブコンテンツが完成前から段階的に表示されるようになった。

iOS では `+` ボタンの長押しで最近の写真を開けるようになり、接続待ちのステータス表示が明確になった。Android（1.2026.216 以降）では生成画像が会話幅いっぱいに表示され、サイドバーの最近の会話が最大8件表示になった。

いずれも機能追加というより既存 UX の改善で、料金・提供範囲・管理者設定の変更は含まれない。

## できるようになったこと

- web / モバイルで、継続利用されているプラグインが推薦上位に出る
- 時刻依存の質問でローカル時刻が考慮される
- web で長い会話が分割読み込みされ、インタラクティブコンテンツが段階表示される
- iOS: `+` 長押しで最近の写真、接続状態の明示
- Android: 生成画像の全幅表示、サイドバーに最近8件

## 影響範囲

- 対象ユーザー: ChatGPT の web / iOS / Android 利用者。デスクトップはプラグイン推薦の対象外
- 対象プラン: 記載なし（プラグインの可否はプラン・地域・ワークスペース設定に依存）
- API / UI / 管理者機能: UI のみ。API・管理者機能の変更はなし

## 教材化メモ

- 「プラグイン推薦の順位が継続利用ベースに変わった」は、社内向けにプラグインを配布する側の論点になる。**入れてもらうこと（インストール）ではなく使い続けてもらうこと（リテンション）が露出に効く**構造なので、社内ツールを ChatGPT プラグインとして出す場合の評価指標を「導入数」から「継続利用率」へ寄せる根拠に使える。
- ローカル時刻の考慮は、プロンプト設計教材で扱える。これまで「今日の日付を明示する」ことが定石だったが、モデル側が文脈として時刻を持つようになると定石が変わる。**外部条件の変化でプロンプトのお作法が陳腐化する例**として使いやすい。
- 長い会話の分割読み込みと段階表示は、「会話を伸ばし続ける運用」の負担が下がった変化。ただし読み込みが速くなることと、長い会話が有効であることは別問題である。教材では、UX 改善を文脈設計の改善と取り違えない、という注意点まで書く。
- プラットフォーム差（デスクトップは対象外、Android はバージョン指定あり）は、社内マニュアルにスクリーンショットを載せるときの前提明示の実例になる。
