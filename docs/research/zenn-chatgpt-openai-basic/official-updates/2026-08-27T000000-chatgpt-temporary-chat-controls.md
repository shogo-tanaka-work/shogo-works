# 2026-08-27 ChatGPT 一時チャットの新しい制御

## 公式内容の日本語要約

ChatGPT の一時チャット（Temporary chat）に2つの選択肢が追加された。これまで一時チャットは「何も引き継がず、何も残さない」一択だったが、**個人設定を効かせるかどうか**と**後から保存するかどうか**を利用者が選べるようになった。

**個人設定あり（Personalized）**: 一時チャットの開始時に選ぶと、そのチャットは既存のメモリ・カスタム指示・プラグインを参照して応答する。ただし**新しいメモリは作らず**、保存しない限りチャット履歴にも残らない。この設定は**チャット開始時にしか指定できず、会話開始後は変更できない**。

**個人設定なし（Non-personalized）**: 既定はこちら。メモリ・カスタム指示・プラグインのいずれも使わず、新しいメモリも作らない。従来の一時チャットと同じ挙動。

**一時チャットの保存**: 会話が後々役に立つと判断したら、チャット履歴へ追加できる。保存すると**通常のチャットへ変換され**、以降はアカウント側の個人設定とモデル改善の設定に従う。たとえばメモリを有効にしている状態で保存すれば、その内容は履歴の一部となり、以降の応答の個人化に参照されうる。

要点は「一時的であること」と「個人化されていること」がこれまで束になっていたのを、公式が**2つの独立した軸に分離した**ことである。

## できるようになったこと

- 一時チャット開始時に、メモリ・カスタム指示・プラグインを使う個人化モードを選択（開始後は変更不可）
- 個人化した一時チャットでも、新規メモリは作られず履歴にも残らない
- 一時チャットを後から通常チャットへ保存・変換

## 影響範囲

- 対象ユーザー: ChatGPT 利用者全般
- 対象プラン: 公式記載なし（段階的ロールアウト）
- API / UI / 管理者機能: ChatGPT の UI（一時チャット開始時の選択と保存操作）
