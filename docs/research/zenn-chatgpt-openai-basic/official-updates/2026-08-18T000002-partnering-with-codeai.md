# 2026-08-18 CodeAI との提携

## 公式内容の日本語要約

OpenAI と CodeAI（旧 Code.org、2026-06-02 にリブランド）が、学生と教師に向けた AI リテラシー教育で提携する発表。同日の ChatGPT for Teens 公開に合わせたもので、公式は「テクノロジーを取り巻く教育」を担う位置づけと説明している。

今後1年間の取り組みとして4点が挙がっている。**授業への支援**として、OpenAI の AI システム・安全性・責任ある利用の専門家が CodeAI のカリキュラム開発の相談先になる（CodeAI の無償・1年間の高校向けコース AI Foundations を含む）。**合同アドバイザリー協議会**を設置し、児童発達・青少年政策・学習科学の専門家が新たなリスクと責任ある実践について継続的に助言する。この助言は ChatGPT for Teens の今後の開発にも反映される。**Hour of AI** を通じて数百万人の学生に AI の基礎を紹介する。**Builders Challenge**（初開催）では、高校生が AI で制作し、OpenAI メンバーのメンタリングを受け、担当教師とともに全国規模で発表する。加えて **Career Journeys** で OpenAI の研究者・エンジニアが仕事の実際を学生に伝える。

製品・機能・API のいずれにも変更はない。

## できるようになったこと

- 製品変更ではない。教育分野でのパートナーシップと無償プログラムの提供

## 影響範囲

- 対象ユーザー: 高校生、教師、教育機関
- 対象プラン: 該当なし（CodeAI 側のプログラムは無償）
- API / UI / 管理者機能: 変更なし

## 教材化メモ

- **AI リテラシー教育の枠組みとして「使い方」ではなく「疑い方」を掲げている点**が特徴。CodeAI CEO の Karim Meghji は「技術を疑い、誤りを捕まえ、信じるのをやめる時を知る」と述べている。企業研修の設計でも転用できる観点。
- ChatGPT for Teens（`2026-08-18T000000-chatgpt-for-teens.md`）とセットの発表。教材で扱うなら製品側を主、こちらを背景として置く。
