# 2026-08-31 ChatGPT Ads が年換算10億ドル規模に到達、セルフサービス提供を拡大

## 公式内容の日本語要約

OpenAI が公式ポスト「A milestone in expanding access to AI」で、**ChatGPT Ads がローンチから200日未満で年換算収益ラン・レート（annualized revenue run rate）10億ドルに到達**したと公表した。利用する広告主は数万規模に達しているとしている。

あわせて、**Ads Manager 経由でのセルフサービス購入を、インド・欧州・中東・北アフリカへ拡大**すると発表した（公式表記は「Starting later today」）。ChatGPT Ads 自体は OpenAI Ads Solutions チームおよび代理店・技術パートナー経由で**40か国以上**で提供済みで、今回はそこにセルフサービス経路が加わる形になる。

OpenAI は広告を、コンシューマー向けサブスクリプション、エンタープライズ向け提供、従量課金 API と並ぶ**事業モデルの一本の柱**と位置づけている。**広告収入に支えられた無料ティア**が、週間アクティブユーザー10億人超への提供を成立させているという説明である。

広告の設計原則として、**広告は常に明示的にラベル付けされ、ChatGPT の回答とは分離される**こと、**広告が回答内容に影響を与えない**こと、**広告主は利用者の非公開の会話にアクセスできない**こと、**利用者が広告のパーソナライズ度合いを制御できる**ことを挙げている。広告の関連性判定には現在の会話の文脈を用い、国と利用者設定によっては ChatGPT 利用全体の文脈も使われる。

## できるようになったこと

- Ads Manager によるセルフサービスでの ChatGPT 広告出稿が、インド・欧州・中東・北アフリカで可能に
- 既存の40か国以上での提供（Ads Solutions チーム・パートナー経由）に、セルフサービス経路が追加

## 影響範囲

- 対象ユーザー: 広告主（出稿側）。および広告が表示される無料系ティアの利用者
- 対象プラン: 公式ポストでは広告表示対象ティアの明示なし。有料購読者の扱いについて本ポストは言及していない
- API / UI / 管理者機能: Ads Manager（出稿側 UI）
