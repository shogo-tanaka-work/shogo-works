# 2026-08-12 From assistance to execution

## 公式内容の日本語要約

OpenAI が企業のAI活用実態に関する2本の調査を公開した。1本は自社のエンタープライズ顧客基盤を対象にしたレポート Enterprise Signals、もう1本は導入が企業・職種・職位をまたいでどう広がるかを扱う研究論文 How Organizations Use AI: Evidence from ChatGPT である。製品リリースではない。

主要な数字は5点。第一に、企業利用がエージェント寄りに移っている。2026年6月時点で、エンタープライズ顧客における Codex と ChatGPT の合計出力トークンのうち **64% を Codex が占めた**。第二に、フロンティア企業（月次の利用量上位10%）とそれ以外の差が開いている。アクティブユーザーあたりの出力トークンは典型企業の **8.3倍**で、1月時点の 2.6倍から拡大した。

第三に、フロンティア企業は高度な機能をより使う。週あたりのアクティブユーザーのうち Plugins を使う割合は、フロンティア企業で 21%、典型企業で 9%。OpenAI 社内では従業員の 95% が週次で Plugins を使っており、まだ伸び代が大きいことを示している。第四に、エージェント利用が知識労働全般へ広がっている。2月以降の週次アクティブな企業 Codex ユーザーは、法務で 108倍、営業で 41倍、採用で 41倍、その他職種でも大きく伸びた。

公式はここから実務的な示唆として、エージェントを仕事に必要な文脈とツールへ接続すること、権限・レビュー・ガバナンスを明確にすること、個人単位で機能したワークフローを組織の共有された仕事の仕方へ変えること、の3点を挙げている。

## 教材化メモ

- 「出力トークン量を利用の深さの代理指標にする」という測り方は、社内のAI活用度を評価する枠組みとしてそのまま流用できる。導入研修の効果測定を扱う教材で使える。
- Codex が企業の出力トークンの 64% を占めるという数字は、「AI活用＝チャットで質問すること」という前提を持つ読者の認識を更新する材料になる。ただし OpenAI 顧客基盤に限った統計であり、市場全体の話ではない点は明示する。
- Plugins 利用率 21% 対 9% の差は、「機能を配っただけでは使われない」ことの実データとして、社内展開の設計を扱う教材に接続できる。
