# 2026-10-16 ChatGPT Slides

※ 10-17〜10-18 の日次巡回では `help.openai.com` を取得できず、取りこぼしていた。本日 Exa で Release Notes を取得して発見した（追補）。日付は二次報道（10-16 付の release notes と複数報道）と、ヘルプ記事の「Updated: yesterday」から 2026-10-16 と判断した。Release Notes の最新ブロックには日付見出しが無い。

## 公式内容の日本語要約

ChatGPT に Slides が加わった。会話・ファイル・アウトラインから ChatGPT Work でプレゼンを作り、Space の中でチームと共同編集する。例となるデッキを渡すと、その文体とレイアウトに寄せて作る。

テキスト・画像・図形・表・グラフは直接編集でき、要素を選んで Request edits と書けば ChatGPT がその部分だけ直す。共同編集はリアルタイムで、共有コメントと @mention（ChatGPT または dot）に対応する。ウェブから PowerPoint / PDF / Google Slides へ書き出せ、デスクトップアプリでは PowerPoint / Keynote で開ける。

提供は Space にアクセスできる Pro / Business / Enterprise で、ウェブとデスクトップアプリ。順次ロールアウト中。コメント専用の権限は初期提供では無い。Windows 10 と、必要コンポーネントが無い Windows 11 のデスクトップでは共同編集 Slides ではなく .pptx を使う。

## できるようになったこと

- 会話・ファイル・アウトライン・見本デッキからスライドを生成
- 直接編集と「Request edits」による部分修正
- リアルタイム共同編集、共有コメント、@mention
- PowerPoint / PDF / Google Slides への書き出し（ウェブ）

## 影響範囲

- 対象ユーザー: Space にアクセスできる利用者
- 対象プラン: Pro / Business / Enterprise
- API / UI / 管理者機能: UI。Enterprise の共有は Space 側の設定に従う
