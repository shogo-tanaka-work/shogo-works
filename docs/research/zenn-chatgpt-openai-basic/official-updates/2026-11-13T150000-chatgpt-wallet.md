# 2026-11-13 ChatGPT Wallet

## 公式内容の日本語要約

エージェントがカード情報なしで支払える ChatGPT Wallet を発表。購入ごとに商品・合計・カードを確認し、Face ID 等で承認。決済ネットワークが支払いトークンを発行し、実カード情報は事業者・エージェントに渡らない。カード特典と対象の紛争保護は維持。Amex / Mastercard / Visa と提携。dots 経由で、米国の ChatGPT Pro（18歳以上、米国発行の対象カード）に提供開始。事業者向けに Commerce Partner Playbook（Web Bot Auth、商品フィード、決済・不正検知、プラグイン / WebMCP）を公開。
