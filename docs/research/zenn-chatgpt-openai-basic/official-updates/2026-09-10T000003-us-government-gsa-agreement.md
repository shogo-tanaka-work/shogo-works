# 2026-09-10 米政府（GSA）との複数年契約

## 公式内容の日本語要約

OpenAI for Government と **米国 General Services Administration（GSA）** が新たな複数年契約を発表した。**通常 $15/ユーザー/月 のライセンス料を $0**、**従量課金を50%引き**とする内容で、**連邦政府だけでなく州・地方・部族政府にも同じ条件を拡大**する。

**契約期間は 27 か月（2026-10-01 〜 2028-12-31）** と明記されている。最低利用量のコミットは不要。対象は約 2,300 万人規模の米国公共部門の労働力で、既に 100 万人超の政府職員が既存契約で ChatGPT を利用している。

サイバー防御側の支援も含まれる。**検証済みの政府機関はすべて `Daybreak Blue`（高度サイバー防御向け）を標準商用価格の50%引きで承認**され、トレーニングと導入支援が付く。脆弱性調査・エクスポイト検証・レッドチーム向けの `Daybreak Red` は標準商用価格で申請できる。これは先週発表された「Daybreak for Frontline Defenders」（10億ドル規模のグローバルコミットメント）の上に積まれたものである。

GPT-6 Astra を含む最新モデルへのアクセス、ChatGPT Enterprise のデータ非学習保証、支出管理・FinOps ガイダンス・Government Academy の拡張も含まれる。

## できるようになったこと

- 連邦・州・地方・部族政府がライセンス料 $0 で利用できる（通常 $15/ユーザー/月）
- 従量課金が50%引きになる。最低コミットなし
- 検証済み政府機関は Daybreak Blue を50%引きで利用できる
- 契約期間は 2026-10-01 〜 2028-12-31（27か月）

## 影響範囲

- 対象ユーザー: 米国の連邦・州・地方・部族政府職員（約2,300万人規模）
- 対象プラン: ChatGPT Enterprise、Daybreak Blue / Red
- API / UI / 管理者機能: 調達・契約条件

## 教材化メモ

日本の読者にとって直接の適用はないが、**「公共調達で AI の単価がどう決まるか」の実例**として使える。注目点は価格そのものではなく、(1) ライセンス料を無償化して従量課金で回収する構造、(2) 27か月という期間の明示（予算年度をまたぐ調達の安定性）、(3) サイバー防御専用モデルを価格政策の中心に据えた点の3つである。日本の自治体・公共系案件の提案書で「海外の公共 AI 調達はこう組まれている」と引く素材になる。
