# 2026-10-22 Decisions API が GPT-6 Luna で一般提供

## 公式内容の日本語要約

分類・ルーティング・次の行動選択など答えが限られた判断に特化した Decisions API が一般提供（RSS pubDate 2026-10-22 19:00 GMT）。GPT-6 Luna を使い、Responses API 経由の Luna より最大10倍速い。答えは predicate（確率）/ choice（選択肢）/ score（採点）の3種類。公開ベータ以降、GPT-Live 連携、プロンプトキャッシュ、米国・EU のデータ所在地指定、JSON 入力、画像入力、1リクエスト400問（従来の2倍）を追加した。料金は別ページ参照で、本文では未確認。
