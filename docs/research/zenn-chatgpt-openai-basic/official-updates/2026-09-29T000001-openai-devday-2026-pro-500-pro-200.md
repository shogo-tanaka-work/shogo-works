# 2026-09-29 DevDay 2026: Pro 500 新設と Pro 200 の減枠

## 公式内容の日本語要約

DevDay 2026 で ChatGPT の有料プラン構成が変更された。**新設の Pro 500 は月額 500 ドル**で、OpenAI が販売する中で最大の利用枠を持ち、**新しい高速ティア Ultrafast（Astra Ultrafast）への独占アクセス**を含む。Codex では最大 300 トークン/秒、標準ティアの約8倍の生成速度とされる。Plus 比で **25倍の利用枠**。

同時に**既存の Pro 200（月額200ドル）が減枠される**。**2026-10-30 から、Work と Codex の利用枠が現行の半分**になる。全体の利用枠は Plus の20倍から**10倍へ半減**、ChatGPT の週あたり GPT-6 Pro メッセージ数は **200から100へ**。

既存の Pro 200 契約者に対しては緩和措置がある。**2026-10-29 までは現行の上限が維持され**、加えて**一度限りの 2,500 ドルぶんの利用クレジット**が付与される（年末失効）。

あわせて、**5時間の利用ウィンドウが恒久的に撤廃**された。週あたりの上限を、リセット時刻を気にせず必要なときに使えるようになる。

## できるようになったこと

- Pro 500 で Ultrafast（Astra Ultrafast）を利用できる
- 5時間ウィンドウの制約なしに週次上限を消化できる

## 影響範囲

- 対象ユーザー: ChatGPT Pro 200 / Pro 500 契約者
- **期限**: 2026-10-30 から Pro 200 減枠（2026-10-29 まで現行維持）。補填クレジット 2,500 ドルは年末失効
- API / UI / 管理者機能: プラン選択と原価計算の見直しが必要
