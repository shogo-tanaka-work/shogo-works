# 2026-09-16 ChatGPT Ads の AI 化（Sponsored Agents ほか）

教材化メモ: src/content/ai-news-notes/chatgpt-openai/chatgpt-ads-sponsored-agents.mdx

## 公式内容の日本語要約

OpenAI は 2026-09-16、**ChatGPT Ads に4つの更新**を発表しました。公式は「広告を人にとってより有用に、事業者にとってより簡単にする」と位置づけています。

**1つ目は Sponsored Agents のテスト開始です。** ChatGPT 内の広告をクリックした利用者が、**事業者がスポンサーする専用エージェントとの会話を開始**できます。公式は「**明確にラベル付けされた会話**」であり、**ChatGPT 自身の独立した回答からも、利用者が元々始めた会話からも分離される**と明記しています。利用者は重視する点を説明し、追質問し、準備ができたら事業者サイトへのリンクをたどれます。**現在は米国内の一部広告主に限定したテスト**で、他市場への展開時期は示されていません。

**2つ目は Ads Manager プラグインです。** 広告主は **ChatGPT Work 上の自然言語プロンプトでキャンペーンの作成・更新・分析**ができます。Web サイトや企画書をキャンペーンへ変換し、成果を把握し、次の打ち手の推奨を得る、という流れが示されています。

**3つ目は Ads Manager 内の AI 支援です。** 広告作成時に、**ランディングページとキャンペーン目的にもとづいた文案と画像の候補**が提示されます。公式は「広告主が主導権を保つ」とし、追加前にレビュー・編集できると明記しています。加えて**オプトイン方式の AI テキストカスタマイズ**があり、既存の見出しと説明文を会話の文脈に合わせて調整し、利用者の希望言語へ自動翻訳します。

**4つ目は外部ツール連携です。HubSpot が初の CRM パートナー、Shopify が初の EC パートナー**となります。HubSpot 利用企業は当日から HubSpot 内で ChatGPT Ads アカウント接続・広告作成・成果追跡・リード対応ができます。**米国の Shopify 事業者は当日から Shopify App Store の ChatGPT Ads アプリを利用可能**で、Shopify Catalog 経由で商品が既に連携済みのため即時開始できます。**同アプリは 2026-09-23 から、ChatGPT Ads が提供されている他市場へも展開されます。**

## できるようになったこと

- **Sponsored Agents**（米国の一部広告主でテスト）— 広告クリック後に事業者スポンサーのエージェントと会話
- **Ads Manager プラグイン** — ChatGPT Work 上の自然言語でキャンペーン作成・更新・分析
- **Ads Manager の AI 支援** — LP とキャンペーン目的から文案・画像を提案（編集可）
- **AI テキストカスタマイズ**（オプトイン）— 見出し・説明文を会話文脈へ適応し、希望言語へ自動翻訳
- **HubSpot 連携**（初の CRM パートナー）— HubSpot 内で広告作成からリード対応まで
- **Shopify 連携**（初の EC パートナー）— 米国は当日、**他市場は 2026-09-23 から**

## 影響範囲

- 対象ユーザー: ChatGPT Ads の広告主。Sponsored Agents は**米国の選抜広告主のみ**
- 対象プラン: 広告は Free / Go 向けに表示（Plus / Pro / Business / Enterprise は広告なし）
- API / UI / 管理者機能: Ads Manager の UI 追加、ChatGPT Work のプラグイン追加、HubSpot / Shopify アプリ
- **期限のある項目: Shopify アプリの国際展開が 2026-09-23**
- 申込: ads.openai.com
