# 2026-07-29 ChatGPT for Academic Researchers

## 公式内容の日本語要約

OpenAI が学術研究者向けプログラム「ChatGPT for Academic Researchers」を発表した。最終的に10万人の研究者へ、ChatGPT の最上位モデルを含む機能を無償提供する。同社が公表している 2.5 億ドル規模の科学支援イニシアチブの一部という位置づけ。

初期段階では限られた大学の1万人を対象に開始し、その後9万人へ順次オンボードする計画。開始時点で Institute for Advanced Study、École normale supérieure などの機関で利用可能。選ばれた研究者は所属機関内の共同研究者を4名まで招待できる。

提供内容は GPT-5.6 Sol Pro を含む最上位モデルへのアクセスと、ビジネス相当のプライバシー・セキュリティ保護。入力データはモデル学習に使われない。OpenAI は用途として、ChatGPT 側で仮説生成・知識獲得・論文執筆などの思考支援、Codex 側でコード記述と結果解析などの実行支援を挙げている。

## できるようになったこと

- 対象に選ばれた学術研究者が、GPT-5.6 Sol Pro を含む上位モデルを無償で利用できる
- 研究者1名あたり同一機関の共同研究者を4名まで招待できる
- データがモデル学習に使われず、ビジネス相当のプライバシー・セキュリティ保護が適用される
- ChatGPT に加えて Codex を研究の実行（コード記述・解析）に使える

## 影響範囲

- 対象ユーザー: 学術機関の研究者（申請制・段階的拡大）
- 対象プラン: 無償提供（プログラム枠内）
- API / UI / 管理者機能: 主に ChatGPT / Codex の UI 提供。API 提供の記述は確認できず

## 教材化メモ

- 「上位モデルの無償枠」は費用がボトルネックになっている層に対する典型的な普及施策。企業導入の文脈でも「まず限定枠で配って使い方を作る」設計として参照できる
- データが学習に使われない条件はプランではなくプログラムで担保されている点に注意。教材で「無償だから学習される」という単純化をしない
