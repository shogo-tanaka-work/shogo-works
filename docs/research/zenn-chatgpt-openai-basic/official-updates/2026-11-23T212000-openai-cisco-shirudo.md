# OpenAI と Cisco が Shirudo（eBPF による稼働中 Linux の一時防御）を公開

## 公式内容の日本語要約

eBPF の shield で、パッチ適用前の脆弱性を再起動なしで塞ぐオープンソースのランタイム。署名検証と TPM による検証記録を備える。Codex が生成した shield で Java4Shell の悪用を稼働中の Elasticsearch 上で阻止した例を提示。BSD 2-Clause。12/15 にウェビナー。運用者向けの研究・OSS 発表で、製品・プランの変更なし。スコア5で見送り。
