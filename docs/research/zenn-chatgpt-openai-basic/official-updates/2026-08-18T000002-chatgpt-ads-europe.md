# 2026-08-18 ChatGPT Ads 欧州31か国へ拡大

## 公式内容の日本語要約

OpenAI が ChatGPT Ads を欧州 31 か国へ拡大すると発表しました。展開開始は発表の翌週です。対象にはドイツ、フランス、スペイン、イタリア、スウェーデン、ノルウェー、デンマーク、オランダ、オーストリアなどが含まれます。2026 年 2 月の米国パイロット開始から 6 か月で 8 市場に広げてきた実績があり、今回の 31 市場追加は同社にとって過去最大の拡大です。

広告主の入り口は当初、OpenAI Ads Solutions チーム、代理店パートナー、テクノロジーパートナー経由に限られます。Ads Manager によるセルフサービスは「今夏後半」に提供予定とされています。

利用者側の条件は既存市場と同じで、**広告が表示されるのは Free と Go プランのみ**です。Plus / Pro / Enterprise は引き続き広告なしです。OpenAI は広告原則として、会話内容を広告主へ渡さないこと、顧客データを販売しないこと、広告は回答と明確に区別してラベル表示すること、広告が回答内容に影響しないこと、利用者が広告パーソナライズを制御できることを挙げています。

プラットフォーム側の機能拡張も並行して進んでおり、CPM / CPC に加えたコンバージョン最適化、ジオターゲティングとカスタムオーディエンス、OpenAI Pixel / Conversions API / サードパーティ計測連携による効果測定が導入済みです。これまでに数万の広告主が ChatGPT 上で出稿したとしています。

## できるようになったこと

- 欧州 31 か国の広告主が ChatGPT Ads へ出稿可能に（翌週から、当初は営業・代理店・技術パートナー経由）
- コンバージョン最適化入札、ジオターゲティング、カスタムオーディエンスの利用
- OpenAI Pixel / Conversions API / サードパーティ計測による成果計測

## 影響範囲

- 対象ユーザー: 欧州 31 か国の広告主・マーケター。および 現地の Free / Go プラン利用者
- 対象プラン: 広告表示は Free / Go のみ。Plus / Pro / Enterprise は広告なし
- API / UI / 管理者機能: Ads Manager セルフサービスは今夏後半予定。OpenAI Pixel / Conversions API は提供済み
