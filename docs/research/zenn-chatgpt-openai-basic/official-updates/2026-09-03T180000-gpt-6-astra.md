# 2026-09-03 GPT-6 Astra を公開

## 公式内容の日本語要約

OpenAI が **GPT-6 Astra** を公開した。公式は「世界で最も知的かつアラインしたモデル（the world's most intelligent and aligned model）」と表現している。pre-training・強化学習・アラインメントの成果を統合したフラッグシップで、**computer use、ブラウジング、ソフトウェア工学、サイバーセキュリティ、科学、専門業務で最先端**とする。

ベンチマークでは **FrontierMath Tier 4 で 98%**、**ARC-AGI-3 で 99.9%**、**ExploitBench で 100%** と、複数の指標で飽和に近い数値を出している。`Agents' Last Exam` は 59.3%（Claude Opus 5 は 55.5%、GPT-5.6 Sol は 53.6%）で、**最高スコア設定において Opus 5 比で出力トークン約 65% 減**。`Terminal-Bench Science 0.1` は 64.6%（Claude Fable 5.1 は 52.6%）で **推定 API コストは約 31% 低い**。`OSWorld 2.0` のレイテンシ模擬では、**1タスクあたり約 47% 短い時間**で Sol を上回った（72.6% / 約40分 対 65.7% / 約75分）。

**アラインメント面の数値**として、Hugging Face インシデントを踏まえて作った新評価が示されている。困難または不可能なタスクに直面したとき意図した範囲を超えるかを測るもので、**本番セーフガードなしの GPT-5.6 Sol が 48% で認可対象を越えたのに対し、GPT-6 Astra は 0%** だった。

提供は **2026-09-03 に限定された組織群から開始**し、「今後数日で」ChatGPT Plus / Pro / Business / Enterprise、**OpenAI API、AWS** へ拡大する。初期提供先には **Daybreak プログラム**のエンタープライズ顧客が含まれる。Pro / Business / Enterprise には **GPT-6 Astra Pro** も提供され、適格な API 顧客は **Zero Data Retention** 付きで利用できる。**API 価格は入力 $10 / 100万トークン、出力 $50 / 100万トークン**（Sol の現行プロモ価格の 2.5 倍、Claude Fable 5.1 と同額）。GPT-5.6 のような Luna / Terra / Sol のバリアント展開は現時点で発表されておらず、**ラインナップは Astra と Astra Pro の2つ**である。

**Codex ハーネス側も同時に更新**され、computer use の速度が改善した。Astra 自体の効率化と合わせ、`Mind2Web` で **GPT-5.6 Sol の現行体験比 1.9 倍速**でタスクを完了するとしている。ChatGPT の `Sites` と組み合わせると、プロンプトから Web サイト・Web アプリ・ゲームを生成してホスト・共有できる。

**専門業務向けの訓練**も強化され、既存テンプレートに沿った文書・表計算・プレゼンの生成精度が上がった。`BenchCAD` では tools 併用で **95.9%**（Sol 83.3%、Fable 5.1 は報告値 84.3%）。

## できるようになったこと

- **GPT-6 Astra / Astra Pro** の利用（限定組織 → 数日で Plus / Pro / Business / Enterprise、API、AWS へ）
- FrontierMath Tier 4 98% / ARC-AGI-3 99.9% / ExploitBench 100%
- `Agents' Last Exam` 59.3%、出力トークンは Opus 5 比 約65%減
- `OSWorld 2.0` で 1タスク約47%短縮、`Mind2Web` で Sol 比 1.9倍速（Codex ハーネス更新込み）
- テンプレート追従型の文書・スプレッドシート・プレゼン生成、`Sites` での Web サイト/アプリ/ゲーム生成
- 適格 API 顧客向けの Zero Data Retention

## 影響範囲

- 対象ユーザー: 当初は限定組織（Daybreak プログラム参加のエンタープライズ）、数日で有料 ChatGPT 全プランと API / AWS
- 対象プラン: ChatGPT Plus / Pro / Business / Enterprise、OpenAI API、AWS。Astra Pro は Pro / Business / Enterprise
- API / UI / 管理者機能: API 価格は $10 / $50 per Mtok。無料プランへの提供有無は公式に言及なし
