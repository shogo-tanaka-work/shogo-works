# 2026-08-28 OpenAI x MHESI AI Accelerator（タイ）

## 公式内容の日本語要約

OpenAI がタイの高等教育科学研究イノベーション省（MHESI）と共同で、**8週間のアクセラレータプログラム**を発表した。健康・ウェルネス・教育分野の**10社のスタートアップ**を対象に、AI プロトタイプを実運用に耐える製品へ引き上げることを目的とする。**OpenAI にとってタイ政府との初の官民連携**にあたる。

実施は国家イノベーション庁（NIA）、マヒドン大学、Techsauce と共同。各社には **OpenAI API クレジット 2,000 ドル**、専任メンターの伴走、最新モデルへのアクセスが提供され、週次セッションでプロダクト設計・評価（eval）・責任ある AI・プライバシー・セキュリティ・資金調達を扱う。**11月にバンコクで Demo Day** を開催し、投資家・政府機関・大学・病院・学校へ成果を発表する。

背景として OpenAI は、**タイが ChatGPT の週間アクティブ利用者数で世界上位20か国に入る**こと、**Codex の週間アクティブ利用が 2026 年初頭から 350 倍以上に伸びた**ことを挙げている。
