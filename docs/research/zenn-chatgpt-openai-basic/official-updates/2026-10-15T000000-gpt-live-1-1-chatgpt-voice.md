# 2026-10-15 GPT-Live-1.1 が ChatGPT Voice へ展開

## 公式内容の日本語要約

**ChatGPT Release Notes の 2026-10-15 エントリで、GPT-Live-1.1 と小型版の GPT-Live-1.1 Quip が ChatGPT Voice へ展開されると告知された。** 狙いは**各言語でより自然なアクセント**である。GPT-Live は 2026年7月に登場した音声モデルで、今回はその更新版にあたる。

**新しい音声は6言語ぶんが挙がっている。** **フランス語・ドイツ語・ヒンディー語・日本語・韓国語・メキシコスペイン語**に新しい選択肢が加わり、英語には **Bubbie** が加わった。**日本語の音声が追加対象に含まれている点**が、日本語話者には直接効く。二次報道では各言語2つずつ＋英語1つで計13音声とされているが、**音声の数は公式リリースノートの記載から一意に確定できない。**

**表示される音声は地域とアカウントによって変わる**と公式が明記している。

**「checking…」の繰り返しが緩和された。** GPT-Live-1 では検索中の短い音声キューが同じ言い回しを繰り返しがちだったが、今回は**その言い回しに変化が付く。**

**展開先は ChatGPT Voice、デスクトップ、dots、Codex が挙がっている。** OpenAI スタッフの発言としては、**多言語対応の改善、より自然な委譲（delegation）、ステアラビリティの向上**が挙げられている。

**API では未提供である。** 公式は「API には近日提供（coming soon）」としている。**開発者はまだ使えない。**

## できるようになったこと

- ChatGPT Voice で GPT-Live-1.1 と小型版 Quip が使える
- 日本語を含む6言語に新しい音声が加わる
- 検索中の相づち（「checking…」系）の繰り返しが減る

## 影響範囲

- 対象ユーザー: ChatGPT Voice / デスクトップ / dots / Codex の音声利用者
- 対象プラン: 公式リリースノートに明示なし。表示される音声は地域とアカウントで変わる
- API / UI / 管理者機能: ChatGPT のクライアント UI。**API は未提供（coming soon）**
