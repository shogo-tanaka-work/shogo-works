# 2026-09-01 ChatGPT for iOS 1.2026.237

## 公式内容の日本語要約

iOS 版 ChatGPT の 1.2026.237 が公開された。

**添付ファイルが、接続されている全ホストで機能するようになった。** Windows と Linux を含み、**動画にも対応**する。従来はホストの種類によって添付の可否が分かれていた。

**Priority ビュー**が追加された。実行中のタスクと保留中の項目を1か所に出すもので、複数のタスクを並行させたときの状態把握を助ける。

**キューに入れたプロンプトがホストと同期し、編集可能なまま保持される。** 送信待ちのプロンプトを、別デバイスから確認・修正できるということになる。

## できるようになったこと

- Windows / Linux を含む全接続ホストで添付が使える（動画を含む）
- Priority ビューで実行中タスクと保留項目を一覧できる
- キュー中のプロンプトがホストと同期し、編集できる

## 影響範囲

- 対象ユーザー: iOS 版 ChatGPT 利用者
- 対象プラン: 記載なし（アプリ更新で提供）
- API / UI / 管理者機能: クライアント UI のみ

## 教材化メモ

- **「実行中のタスク」を一覧する UI が必要になった**こと自体が、エージェント的な使い方の定着を示している。**同期的な一問一答なら Priority ビューは要らない。** 非同期のタスクが並行して走る前提になると、状態の可視化が必須機能になる——**UI の変化から利用形態の変化を読む**という見方の実例。
- **キュー中プロンプトのホスト同期**は、デバイス間の作業継続という文脈。「どのデバイスで始めたか」に縛られない設計へ向かっている。
- 記事化は見送り（スコア4点）。クライアントアプリの利便性向上に留まり、業務判断や手順が変わる範囲が狭いため。
