# 2026-07-30 ChatGPT デスクトップアプリ v26.727

## 公式内容の日本語要約

ChatGPT / Codex の changelog に、デスクトップアプリ v26.727 の更新が掲載された。3つの領域に分かれている。

**ブラウザ機能の強化**: アドレスバーに直接入力して閲覧履歴からページを開き直したり、Google 検索したりできるようになった。タスクの遂行に過去に見たページを探す必要がある場合、ChatGPT が閲覧履歴を検索できる。Chrome 拡張側では、開いているタブをメンションしたり、ハイライトしたテキストをサイドチャットへ取り込んだりできる。YouTube 動画について質問することもできる。

**複数リポジトリのレビュー**: 複数フォルダを含むプロジェクトで、すべてのリポジトリと変更行数を1つのビューに表示するようになった。「Review」を選ぶと、レビューウィンドウを切り替えずに複数リポジトリの差分を確認できる。

**画像生成の refinement**: 生成された画像が拡張ビューアで開くようになり、「Focused view」と「Canvas view」を選べる。コメントを付ける、好みの画像を選ぶ、対象を絞った編集指示を出すといった操作を、会話から離れずに行える。

このほか、サイドバーの新しいアクティビティビュー、Windows でのインストールの信頼性向上、全般的なパフォーマンス修正が含まれる。

## できるようになったこと

- ブラウザのアドレスバー入力による履歴からの再訪問と Google 検索
- タスク遂行時に ChatGPT が閲覧履歴を検索できる
- Chrome 拡張で開いているタブのメンション、ハイライトテキストのサイドチャットへの取り込み、YouTube 動画への質問
- 複数リポジトリの変更を1ビューで確認し、切り替えなしで差分レビュー
- 生成画像の拡張ビューア（Focused view / Canvas view）、コメント付与、対象を絞った編集指示
- サイドバーのアクティビティビュー
- Windows インストールの信頼性向上

## 影響範囲

- 対象ユーザー: ChatGPT デスクトップアプリ利用者
- 対象プラン: changelog に個別プランの記載なし
- API / UI / 管理者機能: デスクトップアプリ UI と Chrome 拡張

## 教材化メモ

- 閲覧履歴の検索は「AI がユーザーの行動ログを参照する」機能。業務端末で何を参照させるかの線引きの教材素材になる
- 複数リポジトリレビューは、モノレポやマイクロサービス構成でのレビュー導線の改善例。Codex のプロジェクト単位の使い方と接続できる
- 画像生成の Canvas view / Focused view は、生成 → 部分修正の反復という画像生成の実務フローの説明に使える
