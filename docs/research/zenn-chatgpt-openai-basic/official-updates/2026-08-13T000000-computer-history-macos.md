# 2026-08-13 Computer History for macOS

## 公式内容の日本語要約

ChatGPT の macOS アプリに **Computer History** が加わった。オプトインの機能で、ChatGPT と Codex が、ユーザーが選んだアプリや Web サイトの活動を参照できるようになる。狙いは、毎回すべてを説明し直さずに作業を続けられるようにすることである。

記録されるのは**操作イベント**であり、スクリーンショット、画面録画、マイク入力、システム音声は含まれない。プライベートブラウジングも対象外である。

**既定ではオフ**で、Pro / Business / Enterprise が対象。**Business と Enterprise はメンバーがオプトインする前に管理者がアクセスを許可する必要がある**。ユーザー側は Computer History を一時停止でき、対象に含めるアプリとサイトを選び、タイムラインの項目を確認・削除できる。

**EEA、英国、スイスでは現時点で提供されない。**

本エントリは 2026-08-13 付だが、2026-08-14 の巡回時点では ChatGPT release notes に掲載されていなかった。ChatGPT のリリースノートは過去日付のエントリが後から追加されるため、今窓で追補として記録する。

## できるようになったこと

- ChatGPT / Codex が、選択したアプリ・サイトの操作履歴を文脈として参照できる
- 対象アプリ・サイトの選択、一時停止、タイムライン項目の確認・削除ができる

## 影響範囲

- 対象ユーザー: ChatGPT macOS アプリの Pro / Business / Enterprise 利用者
- 対象プラン: Pro / Business / Enterprise。**既定オフ**。Business / Enterprise は管理者の許可が前提
- API / UI / 管理者機能: macOS アプリの設定、管理者コンソール（アクセス許可）
- 地域制限: EEA / 英国 / スイスでは未提供
