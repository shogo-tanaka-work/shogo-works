# 2026-10-07 ChatGPT for iOS 1.2026.272

## 公式内容の日本語要約

ChatGPT の iOS アプリ 1.2026.272 が公開された。主な内容は次のとおり。

**追加**

- 応答内に**インラインのページプレビュー**を表示
- **Codex のタスクリンクを iOS で開ける**ようになった

**変更**

- 承認ピッカー（approval picker）を再設計
- プラグインの発見経路を、コンポーザーの「＋」メニューへ統合
- 長いスレッドでのストリーミングを改善
- worktree 対応を改善し、デスクトップのチェックアウトとファイルが一致するようにした

**修正**

- 接続直後にタスク一覧が空になる不具合を修正

Codex タスクリンクと worktree の扱いが入っていることから、**iOS アプリ側から Codex の作業を確認する経路が実用段階に寄せられている**ことが読み取れる。前版 1.2026.267（2026-10-02）では Home Screen ウィジェット（直近タスク、残り利用量とリセット時刻）が追加されていた。

## できるようになったこと

- iOS の ChatGPT アプリから Codex のタスクリンクを直接開ける
- 応答内のリンクをページプレビューとして確認できる

## 影響範囲

- 対象ユーザー: ChatGPT iOS アプリ利用者、特に Codex を併用する開発者
- 対象プラン: 記載なし（アプリ更新）
- API / UI / 管理者機能: モバイル UI

## 教材化メモ

- **「モバイルがエージェント作業の確認面になる」流れの観測点として記録する。** Codex タスクリンクと worktree 一致は、**開発作業の実行はクラウド、確認は手元のスマホ**という使い方を想定した変更である。移動中にレビューして承認だけ返す運用が成立しつつあることを示す材料になる。
- **承認ピッカーの再設計は、権限 UI の学習コストに直結する。** 承認画面が変わると、組織内の手順書やスクリーンショットが古くなる。アプリ更新のたびに手順書を見直す、という運用の必要性を説明する実例として使える。
- 記事化は見送った（スコア5）。モバイルアプリの定常更新で、業務フローや判断が変わる粒度ではない。Codex タスクリンク対応は週次ロールアップで Codex 側の文脈に含める方が読みやすい。
