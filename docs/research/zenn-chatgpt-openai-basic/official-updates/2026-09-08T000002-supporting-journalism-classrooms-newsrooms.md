# 2026-09-08 ジャーナリズム支援施策の拡大

## 公式内容の日本語要約

OpenAI は 2026-09-08、**ジャーナリズム領域への支援を教育段階まで拡張する施策**を発表した。ツール提供、トレーニング、パートナーシップ、知見共有、実務的な導入支援を組み合わせた多面的な取り組みと説明されている。

第一弾の相手は2校である。**CUNY Newmark J-School の Tow-Knight Center for Journalism Futures** と、**Northwestern 大学 Medill School の Knight Lab**。2026-2027 学年度に向けて、両校の希望する大学院生と教員へ **400 以上の ChatGPT Edu サブスクリプション**を提供する。

既存施策の延長という位置づけも明示されている。American Journalism Project との提携更新によりポートフォリオ内の 50 以上の報道機関が Enterprise ツールと API クレジットへアクセスできること、Lenfest Institute、WAN-IFRA、INMA との協業、NABJ / NAHJ / AAJA / NLGJA といった記者団体のカンファレンスでの研修実施、そして **OpenAI Academy for News Organizations** の拡充が挙げられている。今後さらに追加フェーズを準備中としている。

**製品面・機能面の変更を伴う発表ではない。** 提供されるのは既存の ChatGPT Edu と API クレジットであり、新機能・新モデル・料金改定のいずれも含まない。

## できるようになったこと

- 対象2校の大学院生・教員が **ChatGPT Edu を 400 席以上利用**できる（2026-2027 学年度）
- 製品仕様・API・料金の変更は**なし**

## 影響範囲

- 対象ユーザー: 対象2校のジャーナリズム系大学院生・教員
- 対象プラン: ChatGPT Edu（提供先限定）
- API / UI / 管理者機能: 該当なし

## 教材化メモ

記事化しない判断のため、ここに残す。**教材として使えるのは施策そのものではなく、「AI ベンダーが職能教育へ投資する構図」の方**である。ベンダーが教育課程に無償で入り込むことは、その職能における標準ツールの決定権に影響する。企業研修の設計を扱う教材で、ツール選定が「現場の比較検討」ではなく「学生時代に触ったツール」で決まっていく経路の実例として引ける。

ただし**速報記事にすると読者の実務が何も変わらない**。導入判断にも操作にも料金にも影響しないため、単独記事の価値は薄い。将来 OpenAI Academy for News Organizations の教材が一般公開された場合は、その時点で改めて扱う。
