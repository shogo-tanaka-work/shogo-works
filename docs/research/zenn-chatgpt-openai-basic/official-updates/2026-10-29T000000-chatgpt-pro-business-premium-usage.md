# 2026-10-29 Pro・Business Premium の Work / Codex 利用枠を拡大

## 公式内容の日本語要約

Pro 100 / Pro 500 は Work・Codex の枠が従来の2倍。9月29日案内の Pro 200 引き下げは取り消し、低い枠だった契約者は10月29日から2倍に。対象の Pro / Business 契約者はリンクした API 組織向けのプロモーション API クレジットを有効化できる（ChatGPT の利用クレジットとは別枠）。同日の release notes には Texting your dot（米国 Pro のベータ）もあるが対象は限定的。日付は release notes の見出し（October 29, 2026）による。
