# 2026-08-18 Pacing model development in an era of cyber-critical capabilities

## 公式内容の日本語要約

フロンティアモデルの監視・アラインメント・セキュリティを強化し、その進捗に合わせてモデル開発のペースを調整する、という方針表明。公式ページの説明文は「OpenAI is strengthening monitoring, alignment, and security for frontier AI models. See how new safeguards are guiding the pace of model development.」である。

製品・機能・API のいずれにも変更はない。
