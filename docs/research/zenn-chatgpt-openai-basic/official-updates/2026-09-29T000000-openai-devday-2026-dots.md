# 2026-09-29 DevDay 2026: 常時稼働エージェント dots

## 公式内容の日本語要約

OpenAI が年次開発者会議 DevDay 2026（サンフランシスコ Fort Mason、2026-09-29）で **dots** を発表した。20件超の発表のうち、消費者向けで最も大きい位置づけとされる。

dots は**常時稼働（always-on）の個人向けエージェント**である。従来のチャットが「聞かれたら答える」形だったのに対し、dots はタスクやプロジェクトを割り当てておくと**バックグラウンドで作業を継続する**。モデルは **GPT-6 Astra**、そして **dots 自身が専用のクラウドコンピュータを持つ**。

接触面が複数ある。ChatGPT のデスクトップアプリ・モバイルアプリ・Web に加え、**Slack と Microsoft Teams からも同じ dot に話しかけられる**。dot は経路によらず文脈を保持するため、Slack で続きを始めても経緯を説明し直す必要がない。

提供範囲は **Pro と Business Premium プランで1体目が追加費用なし**（対象市場のみ）。Enterprise（Edu / Healthcare を含む）はワークスペース管理者が有効化した時点で利用可能になる。

## できるようになったこと

- タスク・プロジェクトを割り当て、バックグラウンドで継続作業させる
- 専用クラウドコンピュータ上でエージェントを動かす
- ChatGPT / Slack / Microsoft Teams を跨いで同一文脈を維持する
- 他アプリとの接続を通じて作業を引き継ぐ

## 影響範囲

- 対象ユーザー: Pro / Business Premium（対象市場）。Enterprise は管理者の有効化後
- 対象プラン: 1体目は追加費用なし
- API / UI / 管理者機能: 管理者による有効化制御あり
