# 2026-10-26 GPT-6.1 Terra

## 公式内容の日本語要約

OpenAI が高速・低コスト帯の新モデル GPT-6.1 Terra を発表した（RSS pubDate 2026-10-26 00:00 GMT、Exa のライブ取得で本文日付 2026-10-26 を確認）。視覚推論とコンピューター操作、文章の自然さを強化した GPT-5.6 Terra の後継。標準 API 価格は入力 $1 / キャッシュ入力 $0.05 / 出力 $5 per 1M トークンで、公式は GPT-5.6 Terra と GPT-6.1 Sol より50%低いと説明している。

ChatGPT Work と Codex では Plus / Pro / Business / Enterprise / Edu に展開し、同じ利用枠で GPT-5.6 Terra より多くのタスクをこなせる。API は `gpt-6.1-terra`。UAE の推論レジデンシーは非対応。Preparedness Framework のサイバー領域で Critical 閾値に該当し、GPT-6 Astra の保護策を引き継ぐ。

ベンチマーク（公式値）: Terminal-Bench 4.0 で 50.3%（GPT-5.6 Terra は 21.5%）、低推論での誤り率は 53.6% から 16.7%。最も複雑なコーディングは引き続き Sol / Astra が適するとしている。
