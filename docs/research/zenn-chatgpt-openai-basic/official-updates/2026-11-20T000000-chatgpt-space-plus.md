# ChatGPT - Space が Plus に展開

## 公式内容の日本語要約

ChatGPT Space を 18歳以上の Plus へ世界展開。ページ・プレゼンを共同作成し、接続アプリに応じて自動更新。サイドバーでは Library を置き換える。共有ページを開くには Plus・Pro・Business・Enterprise と Space アクセスが必要で、Free は不可、公開リンクなし。日付は release notes の見出し（Updated: 6 hours ago）による。
