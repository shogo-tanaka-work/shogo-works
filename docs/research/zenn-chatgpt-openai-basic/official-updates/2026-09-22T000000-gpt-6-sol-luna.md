# 2026-09-22 GPT-6 Sol / GPT-6 Luna

## 公式内容の日本語要約

OpenAI は 2026-09-22、**GPT-6 Sol** と **GPT-6 Luna** を公開した。9月初旬に出た GPT-6 Astra と同系統の学習手法で作られた、より速く安いモデルである。位置づけは「Astra の到達点を、日常業務の規模・リズム・予算へ配るためのモデル」。Astra は引き続き最上位として残る。

**最大の変更は価格である。キャッシュと推論の効率改善分をそのまま価格へ反映し、GPT-5.6 系のプロモーション価格と比べて Sol / Luna とも API 価格を50%引き下げた。**

| モデル | 入力 | 出力 |
| --- | --- | --- |
| GPT-5.6 Sol → GPT-6 Sol | $4 → **$2** | $20 → **$10** |
| GPT-5.6 Luna → GPT-6 Luna | $0.20 → **$0.10** | $1.20 → **$0.50** |

（per 1M tokens。Luna は出力側が $1.20 → $0.50 で、下げ幅は58%）

ベンチマークでは、業務ワークフローを測る AutomationBench 1.0.6 で GPT-6 Sol（xhigh）が 33.2% / タスク単価 $0.27。公式は Claude Opus 5（max）の 26.9% を、**Opus 5 の9%のコスト**で上回ったと主張している。Agents' Last Exam V1 では Sol（max）が 56.4%。コーディングの DeepSWE v1.1 では Sol（max）が 68.8% で、Claude Fable 5（xhigh）の 69.9% と1.1ポイント差、タスク単価は約80%低いとしている。

事実性については、利用者が誤りを報告した実会話ベースの社内評価で、**GPT-6 Sol は前世代比で誤りが約半分**、Luna も高 effort で GPT-5.6 Sol 相当に達するとしている。

## できるようになったこと

- ChatGPT Work と Codex で、Plus / Pro / Business / Enterprise / Edu 向けに当日ロールアウト
- API で Sol / Luna とも利用可能
- Free / Go ユーザーはデスクトップアプリで GPT-6 Luna を試用できる
- 利用上限が引き上げられ、反復回数を増やせる

## 影響範囲

- 対象ユーザー: API 利用者、ChatGPT Work / Codex の有料プラン利用者、Free / Go（Luna のみ）
- 対象プラン: Plus / Pro / Business / Enterprise / Edu、および API 全般
- API / UI / 管理者機能: モデル指定と単価が変わる。既存アプリのコスト試算を作り直す必要がある
