# OpenAI - Perplexity and Intelligence

## 公式内容の日本語要約

OpenAI の Chief Scientist（Jakub Pachocki）による論考。モデル開発各社を比較し、共通の安全基準を作る指標として、事前学習の perplexity（クロスエントロピー損失）を使うことを提案している。第一歩として OpenAI 社内の事前学習の進捗（GPT-3.5 の log-perplexity 約0.99、GPT-4 約0.91、現行は0.8未満）を公開した。数学の未解決問題で成果が出始めた水準として約0.76にも触れる。取得は本文冒頭の約5,000字までで、後半（AI による事前学習研究への関与など）は未確認。

製品・API・プランの変更は含まず、利用者の操作や判断に影響しないため、スコア4で見送り。

## 教材化メモ

- 製品の更新ではなく研究・方針の論考。「モデルの進歩を測る指標は何か」を考える補助資料として、AI 概論の補足に使える程度。
- 数値は OpenAI 社内の評価データセット上のもので、他社との比較はできない点に注意する。
