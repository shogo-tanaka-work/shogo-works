# 2026-08-18 ChatGPT for Teens 提供開始

## 公式内容の日本語要約

OpenAI が 13〜17 歳向けの専用体験「ChatGPT for Teens」を公開しました。最大の特徴は**オプトインではないこと**です。年齢を 13〜17 歳と申告したアカウント、および OpenAI の年齢推定システムが 18 歳未満と判定したアカウントは、本人の操作なしに自動的にこの体験へ切り替わります。公式ヘルプは「あなたが有効なアカウントであれば ChatGPT が自動的に有効化する」と明記しています。

中身は「学習支援」と「保護」の二本立てです。学習側は Study Mode（誘導質問と段階的支援）を軸に、宿題を丸投げしようとする挙動を検知して Study Mode へ誘導する Responsible Homework Reminder、Quizzes、Learning Visualizations、そして本人または保護者が「この時間帯の新規チャットは既定で Study Mode」と決められる Study Hours が組み合わされています。保護側は自傷・摂食障害・暴力・危険行為・性的表現に関する制限が強化され、保護者への安全通知の対象に摂食障害関連の状況が追加されました。

保護者コントロールは任意のアカウント連携で有効化します。重要な設計として、**保護者は子どもの会話を読めません**。安全通知が発生した場合にのみ、支援に必要な最小限の情報が共有されます。Quiet hours による利用時間帯の制限も可能です。

提供範囲は 2026-08-18 から Free および個人向け有料プランのグローバル展開が開始されました。オーストラリアのみ完全提供は 2026-09-08 予定です。アカウント保有者が 18 歳以上と判定された時点で通常体験へ移行し、保護者連携も解除されますが、保護者コントロールや sensitive content の低減は後から再設定できます。

同日、OpenAI は教育団体 CodeAI との signature partnership も発表しました（`Partnering with CodeAI to prepare the first AI generation`）。AI そのものの提供ではなく「AI をどう理解し、疑い、使いこなすか」の教育を教員とともに設計する枠組みで、Teens 発表と一体の内容です。

## できるようになったこと

- 13〜17 歳アカウントおよび年齢推定で 18 歳未満と判定されたアカウントが、操作なしで Teens 体験へ自動移行
- Study Hours で本人または保護者が「新規チャットが既定で Study Mode になる時間帯」を設定
- Responsible Homework Reminder が宿題の丸投げを検知して段階的解法へ誘導
- 保護者への安全通知に摂食障害関連の状況を追加
- 18 歳到達時に通常体験へ自動移行（保護は任意で再設定可能）

## 影響範囲

- 対象ユーザー: 13〜17 歳と申告または年齢推定されたアカウント全般。および その保護者
- 対象プラン: Free および個人向け有料プラン（グローバル）。オーストラリアは 2026-09-08 完全提供予定
- API / UI / 管理者機能: 消費者向け UI。ChatGPT for Teachers（教育機関管理）とは別枠
