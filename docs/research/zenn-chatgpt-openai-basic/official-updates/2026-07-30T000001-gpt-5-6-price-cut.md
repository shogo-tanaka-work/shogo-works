# 2026-07-30 GPT-5.6 の価格改定

## 公式内容の日本語要約

OpenAI が GPT-5.6 ファミリーのうち2モデルの価格を引き下げた。

- **GPT-5.6 Luna（最速・最安）**: 入力 100万トークンあたり $1 → $0.20、出力 $6 → $1.20（約80%減）
- **GPT-5.6 Terra（中位）**: 入力 $2.50 → $2、出力 $15 → $12（約20%減）
- **GPT-5.6 Sol（最上位）**: 据え置き

GPT-5.6 ファミリーの初回リリースは 2026-07-09 で、そこから3週間での価格改定にあたる。

## できるようになったこと

- GPT-5.6 Luna / Terra を従来より低い単価で利用できる

## 影響範囲

- 対象ユーザー: OpenAI API 利用者
- 対象プラン: API 従量課金
- API / UI / 管理者機能: 価格のみ。API 仕様の変更はなし

## 教材化メモ

- 発表から3週間での大幅値下げは、モデル価格が短期で動くことの実例。教材に単価を直書きすると陳腐化が速いという注意の裏付けになる
- Luna の80%減という幅は、下位モデルの価格競争が激しいことを示す。「安いモデルで足りる作業を切り出す」というコスト設計の話に接続できる
- Sol が据え置きである点は、最上位モデルの価格には競争圧力がかかりにくいという構図の例
- 2026-07-31 に予告された Codex の GPT-5.4 退役の移行先が Terra / Luna であるため、退役と値下げをセットで扱える
