# 2026-08-04 Claude Code v2.1.222

## 公式内容の日本語要約

v2.1.221 に続くリリースで、内容はほぼ全てが修正と挙動変更です。中でも重いのが権限・分離まわりの 2 件です。

1 つ目は worktree 分離の穴です。worktree で隔離したセッションとそのサブエージェントが、メインチェックアウトに対して破壊的な git コマンドを実行できていました。分離は今後、全セッション種別でファイル編集と Bash の双方に適用されます。2 つ目は PreToolUse の auto-allow hook が、バックグラウンドエージェントのタスク（要約・compaction・リネーム）でツール制限を迂回していた問題です。

安全側の強化として、auto mode では `SendMessage` で他エージェントセッションへ送るメッセージも、送信前に permission classifier で評価されるようになりました。また `disable-model-invocation` が付いた skill を Claude が呼ぼうとしたときの拒否メッセージが変わり、ワークフローを自前で再現するのではなくユーザーに実行を依頼するよう指示されます。

運用面では Remote Control の自動起動設定が変わりました。repo 内の `.claude/settings.json` / `.claude/settings.local.json` からは**オンにできなくなり**（オフにするのは可能）、有効化は `/config` によるユーザースコープ設定のみになります。加えて **ultraplan 機能が削除**されました。

このほか、`/usage` が MCP サーバーへ使用量を過大に割り当てていた問題（呼び出し後の全ターンではなく、実際にツール結果を消費したリクエストだけを按分）、HTTPS プロキシ配下で起動時の接続チェックがハングしていた問題、`ANTHROPIC_BASE_URL` のゲートウェイでキープアライブが届いていてもストリームのアイドルタイムアウトが発火する問題、組織制限下で `model: opus` 系のサブエージェント別名が親モデルへ落ちていた問題などが修正されています。

## できるようになったこと

- worktree 分離がファイル編集と Bash の両方、全セッション種別に適用（メインチェックアウトへの破壊的 git 操作を防止）
- PreToolUse auto-allow hook のツール制限バイパスを修正（バックグラウンドタスク）
- auto mode で `SendMessage` の送信内容を permission classifier が事前評価
- Remote Control の自動起動は repo-local 設定からオンにできず、`/config` のユーザースコープのみ
- ultraplan 機能を削除
- `/usage` の MCP サーバー按分を実消費ベースに修正、`/usage-credits` の Team / Enterprise 誤表示を修正
- HTTPS プロキシ配下の起動時接続チェック、`ANTHROPIC_BASE_URL` ゲートウェイのアイドルタイムアウトを修正
- `/diff`・Remote Control のワークスペース diff・web セッションの差分表示が raw git blob を使用（diff driver / textconv を無視）

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。特に worktree 分離・hooks・Remote Control を運用に組み込んでいる組織
- 対象プラン: 全プラン（`/usage-credits` の修正は Team / Enterprise）
- API / UI / 管理者機能: CLI、hooks、`.claude/settings.json`、Remote Control、`/usage`
