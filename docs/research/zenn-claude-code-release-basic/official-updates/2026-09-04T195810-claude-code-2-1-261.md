# 2026-09-04 Claude Code 2.1.261

## 公式内容の日本語要約

管理・診断まわりの追加が中心のリリースである。`/status` と `claude doctor` に**組織ポリシー行**が表示されるようになり、どのポリシーが効いているかをその場で確認できる。`/skill-doctor` が追加され、使われていない Skill を洗い出せる。`bashOutputMaxChars` と `taskOutputMaxChars` の設定が入り、ツール出力の上限をコンテキスト消費に合わせて調整できるようになった。長いサブエージェント用プロンプトをファイルで渡す `--append-subagent-system-prompt-file` も追加されている。

修正は Remote Control 関連が多い。TLS 検査プロキシ配下でのイベントストリーム失敗、停止後にセッションが固まって見える問題、ターン開始前の Stop が SDK / クラウドセッションで無視される問題、teleport したセッションのアップロードなどが直っている。**権限・設定まわりでは、`enabledPlugins` で強制有効化したプラグインがクラウドセッションで破棄される問題と、フィーチャーフラグが旧バージョンの Claude Code にも適用されてしまう問題**が修正された。`rm` の安全確認が `rm -rf` の変種も捕まえるよう強化されている。

`/context` のトークン計数がローカル推定へ変更され、`/usage` と VS Code パネルで週次上限の行が落ちる問題も修正された。VS Code 側は MCP サーバー管理ダイアログ、セッションの可視性表示、権限プロンプトの折りたたみ、セッションメニューのアーカイブ機能が追加されている。

**本リリースはバージョン番号付きリリースのため、`selection-rubric.md`「日次リリース型ツールの扱い」により単独記事化しない（判定 D）。** 週次ロールアップでまとめる。

## できるようになったこと

- `/status` / `claude doctor` で組織ポリシーの適用状況を確認する
- `/skill-doctor` で未使用 Skill を洗い出す
- `bashOutputMaxChars` / `taskOutputMaxChars` でツール出力の上限を調整する
- `--append-subagent-system-prompt-file` で大きなサブエージェント用プロンプトを渡す

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。Remote Control とクラウドセッションの利用者は修正の影響が大きい
- 対象プラン: 全プラン。組織ポリシー行と managed settings は Enterprise / Team に効く
- API / UI / 管理者機能: CLI / VS Code 拡張 / 管理者設定

## 教材化メモ

`/skill-doctor` は「Skill を作りっぱなしにしない」運用の入口になる。Skill 運用教材があれば、棚卸しコマンドとして紹介できる。`bashOutputMaxChars` / `taskOutputMaxChars` は、長いコマンド出力でコンテキストを食い潰す事故への対処として、コスト管理の文脈で扱える。
