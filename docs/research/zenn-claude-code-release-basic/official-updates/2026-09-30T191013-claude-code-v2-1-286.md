# 2026-09-30 Claude Code v2.1.286

## 公式内容の日本語要約

Claude Code **v2.1.286** が公開された（2026-09-30T19:10:13Z）。**バージョン番号付きリリースのため、`selection-rubric.md` の「日次リリース型ツールの扱い」に従い判定D（見送り・週次ロールアップへ）とする。** 以下は追跡用の要点である。

**資格情報の露出に関する修正が集中している。** MCP のエラーメッセージが資格情報の値を露出していた問題、パーセントエンコードされた Bearer トークンがログ上で部分的にしかマスクされていなかった問題、秘匿値が不可視文字を含んだ状態でマスク済みログに現れていた問題、URL のパスワード伏せ字が特殊文字と IPv6 アドレスで失敗していた問題、秘匿値の伏せ字処理後にフィードバック用トランスクリプトへ不正な JSON 行が入る問題。**いずれも「ログ・トランスクリプトに資格情報が残る」系で、組織統制の観点では重要度が高い。**

**可用性・フォールバック。** 既定モデルが利用不可のとき全ターンが失敗していた問題を修正し、**1つ前のティアで再試行**するようになった。API リトライは**モデル呼び出しごとに1つの上限**へ変更。モデルのフォールバック通知に**コンテキストウィンドウの縮小**が表示される。

**権限・UI。** 複数のリクエストが重なったとき権限プロンプトに「2 of 5」の件数を表示。fetch / skill / ファイル読み取り / サンドボックス操作の権限プロンプトを改善。Bash・PowerShell・Monitor のプロンプトでコマンドをダッシュで囲んで表示。

**サブエージェント関連の修正が多い**（トランスクリプトの二重表示、ハンドバック時に agent 名ではなく生の task ID が出る、フォアグラウンドのサブエージェントでタスク追跡ツールが欠落、isolated worktree のサブエージェントが project CLAUDE.md を二重読み込み、Workflow tool のサブエージェントが接続停滞で再起動）。

**`--bare` の挙動変更**: 指定した MCP サーバーだけに接続し、バックグラウンドタスクを起動しなくなった。**プラグインのインストールが git / folder 由来の npm ソースを拒否**するようになった。

**VSCode 拡張**にブックマーク（応答の保存と閲覧）、回答付きの question card、オプションのプレビューが追加された。

## できるようになったこと

- 権限プロンプトの件数表示、フォールバック時のコンテキスト縮小表示
- 既定モデル不可時に1つ前のティアで再試行
- VSCode: ブックマーク、question card

## 影響範囲

- 対象ユーザー: Claude Code 全利用者（CLI / VSCode / クラウドセッション / Claude Tag）
- 判定: **見送り（週次ロールアップへ）**。バージョン番号付きリリースのため内容にかかわらず単独記事化しない

## 教材化メモ

- **資格情報のログ露出の修正が5件まとまって出た**という事実そのものが教材になる。**「ツールが秘匿値を扱う経路は想像より多い」**——エラーメッセージ、ログ、フィードバック用トランスクリプト、URL のパスワード部分、不可視文字。自社でログ設計をするときのチェックリストとして、そのまま流用できる。
- **「既定モデルが使えないと全ターン失敗」から「1つ前のティアで再試行」への変更**は、外部モデルに依存するシステムの可用性設計の型。**単一モデル指定は単一障害点である**という原則の具体例。
- **週次ロールアップでは、資格情報露出の修正群を「今週の要点」の冒頭に置く。** 対応はバージョン更新だけで済むが、更新を促す理由としては十分に強い。
