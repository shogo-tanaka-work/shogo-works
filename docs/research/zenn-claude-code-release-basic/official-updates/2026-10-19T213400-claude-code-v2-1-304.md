# 2026-10-19 Claude Code v2.1.304

## 公式内容の日本語要約

CHANGELOG 先頭の v2.1.304。追加は、mod の `tool.check` に `decider: "person"`（人だけが承認できる）と `e.isReadOnly`、プラグインが先に走って mod のフックを飛ばしたときのトランスクリプト表示、`/auto-mode-setup`（プロジェクトと直近のセッションを読んで auto mode に環境を教える。Bedrock / Vertex / Foundry / Claude apps gateway / テレメトリ無効セッションでも利用可）、`/claude-api managed-agents-secure`（Managed Agents の設定を公式セキュリティガイドと比較）、Pro / Max で非アクティブな会話を再開すると 5 時間枠を多く消費する場合の警告。

修正は多数: サンドボックス `denyRead` グロブの角括弧、マウントドライブや `/Volumes` 等の `rm -r` に安全確認が出ない問題、ヘッドレス実行がプラグインにより `--max-turns` を超えて続く問題、Remote Control、OpenTelemetry 設定、LLM ゲートウェイでの `context_management` エラーなど。

バージョンリリースのため単独記事にせず、週次ロールアップへ回す。
