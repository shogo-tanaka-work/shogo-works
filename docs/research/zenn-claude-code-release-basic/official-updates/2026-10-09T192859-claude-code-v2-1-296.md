# 2026-10-09 Claude Code v2.1.296

## 公式内容の日本語要約

バージョン番号付きリリースのため**単独記事化はせず**、週次ロールアップ（`weekly-ai-news-rollup`）へ送る。以下は追跡用の要点である。

**Added の主なもの。** `managed.policies[]` に `code` キーが入り、Claude Desktop の Code タブの `cli` 設定を適用できるようになった（`desktop` と並んで gateway モードを有効化する）。subagent の frontmatter と `--agents` 定義で `autoCompactWindow` が使えるようになり、サブエージェントだけメイン会話より早く auto-compact できる。`CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` で workflow エージェント全体を1モデルに固定できる（他の subagent は自分のモデルを維持）。`CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS` で 529（overloaded）リトライの最大バックオフを延ばせる。Read tool に `allow_large` が付いた。

**セキュリティ・権限まわりの修正。** 共有トランスクリプトとデバッグログのシークレット秘匿が、**値の無いキーの直後に続く値**（シェル文字列内の JSON を含む）も捕まえるようになった。Bash の権限チェックが、**`BASH_ARGV0` へ代入してから使うコマンド**を自動承認せず確認するようになった。cloud session が feature flag 未読込時に auto mode の Claude in Chrome チェックを飛ばす問題を修正。Windows の Git Bash で `rm -rf /c/Users/<name>` が bypass permissions モードでも確認を出すようになった。

**編集の破壊防止。** Edit / NotebookEdit が **非 UTF-8 ファイル（Windows-1252 / Shift-JIS / GBK）の編集を拒否**するようになった。従来は非 ASCII 文字を置き換えてしまっていた。**日本語環境では実害が出ていた挙動**である。

**価格の反映。** `/cost`、ステータスライン、`--max-budget-usd`、SDK のコスト計算が **Sonnet 5.5 のキャッシュ読み取りを $0.10 / 100万トークン**（従来 $0.20）で計算するようになった。2026-10-07 の値下げがツール側に入った形である。

**その他。** hooks（managed `PreToolUse` / `prompt` の `"continue": false` がターンを終わらせない、など）、MCP、teleport / セッション再開、Haiku 5.5 のトークンカウント、self-hosted runner、plugin / mod、Windows（PowerShell コマンドの許可ルールが約1KB → 32KB）、VS Code 拡張、Cloud sessions、Claude Tag、Code Review に多数の修正が入っている。MCP ツール説明の既定上限が 2,048 → 4,096 文字へ拡大した。

## できるようになったこと

- gateway 配下で Code タブの CLI 設定を managed policy から適用できる
- サブエージェント単位で auto-compact のタイミングを変えられる
- workflow エージェントのモデルを一括指定できる
- 529 リトライの待ち時間上限を環境変数で延ばせる

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。gateway / managed policy を使う組織、Windows・日本語環境の利用者
- 対象プラン: 全プラン
- API / UI / 管理者機能: CLI / 管理者設定 / VS Code 拡張 / Cloud sessions

## 教材化メモ

- **Shift-JIS 編集の拒否は、日本語環境の教材で必ず触れる価値がある。** 従来は非 ASCII を置き換えてファイルを壊していた。「エージェントにファイルを編集させる前に文字エンコーディングを確認する」という運用上の注意が、公式側の修正として裏付けられた形である。
- **`BASH_ARGV0` の権限バイパス修正は、権限チェックの穴が「変数経由の間接参照」で開く実例**として使える。許可リスト方式の限界を説明する素材になる。
- **`autoCompactWindow` のサブエージェント単位指定は、文脈管理の教材に組み込める。** サブエージェントは短命で文脈も小さいため、メイン会話と同じ閾値にする必要がない。
