# Claude Ship（PR のレビュー・修正・承認）ベータ

## 公式内容の日本語要約

Code Review（GA）に、PR Steward（CI 失敗・マージ競合・レビュー指摘への対応）と Claude Approvals（リポジトリ内ポリシーに沿った承認判断）の2エージェントをベータで追加。Claude Code の /ship コマンドで push・PR 作成・レビュー・指摘対応まで進められる。Team・Enterprise の GitHub リポジトリ対象。ZDR・HIPAA 構成・CMEK の組織は不可。トークン課金。
