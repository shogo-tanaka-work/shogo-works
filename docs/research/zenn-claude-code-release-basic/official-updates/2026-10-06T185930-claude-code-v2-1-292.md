# 2026-10-06 Claude Code v2.1.292

## 公式内容の日本語要約

約90項目を含む大きめのリリースである。**追加**は、`claude plugin install` への `--marketplace <source>` 指定、**Agent tool への `effort` パラメータ**、`CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS` 環境変数、mod が独自行を足せる `prompt.autocomplete` イベント、mod 向け `$.model.complete` のプロンプトキャッシュである。

**セキュリティ修正が明示されている。** 「Security: Fixed PreToolUse hook approvals and auto mode bypassing permission prompts」——**PreToolUse hook の承認と auto mode が権限プロンプトを迂回していた**問題の修正である。加えて、サンドボックス内コマンドが**ステージされたファイルのコピーを読めた**問題、managed sandbox の read-deny パスがプロジェクト権限を落とさなかった問題、macOS / Windows で notebook / PDF の読み取りが承認範囲外のファイルを返した問題、サーバー管理設定のオンディスクキャッシュが改竄されていた問題、`rm -rf` が 8.3 短縮名でホームフォルダ削除として扱われなかった問題も修正された。

その他の修正は、MCP サーバーのプロトコルバージョン交渉、128文字を超える MCP ツール名、`NO_PROXY` の無視、plan mode のセッション復帰、`/resume` 後に作成した scheduled task が発火しない問題、cloud session の権限再要求・通知の欠落・thinking 設定の忘却、プラグイン hooks worker の再起動時挙動、Claude Tag（Slack）と Code Review の各種修正など広範に及ぶ。

**本リリースはセキュリティ修正を含むが、バージョン番号付きリリースのため単独記事化しない規約を適用する。** 週次ロールアップの「今週の要点」冒頭で、更新が必要である旨を扱う。

## できるようになったこと

- `claude plugin install --marketplace <source>` でインストール元の marketplace を指定できる
- **Agent tool に `effort` パラメータ**を渡せる
- mod が `prompt.autocomplete` で補完候補を追加できる、`$.model.complete` でプロンプトキャッシュが効く
- 過負荷時のリトライ基準遅延を `CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS` で調整できる

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般（権限・サンドボックス周りの修正は全員に関係する）
- 対象プラン: 全般
- API / UI / 管理者機能: CLI、プラグイン / mod、cloud session、Claude Tag、Code Review

## 教材化メモ

- **バージョン番号付きリリースのため単独記事化しない（週次ロールアップへ）。セキュリティ修正を含んでいても同じ扱い。**
- **「PreToolUse hook の承認と auto mode が権限プロンプトを迂回していた」は、ハーネス設計の教材でそのまま使える。** 権限の確認をフックに委ねる設計は、**フック側の不具合が権限統制の穴になる**。「ガードレールを増やすほど安全」ではなく、**ガードレール自体が攻撃面になる**という論点の実例である。
- **Agent tool の `effort` パラメータは、サブエージェントのコスト設計を扱う教材の材料になる。** 委譲先ごとに推論量を変えられるなら、「調査は軽く、実装は重く」といった配分が書ける。
