# 2026-10-08 Claude Code v2.1.294

## 公式内容の日本語要約

小規模なリリースで、内容は2点である。

**修正（権限・安全性）**: 指示文として書かれた prompt hook と agent hook（例「〜のコマンドをブロックする」）が、**本来ブロックすべき操作を通してしまっていた**。これが修正された。

**改善**: Stop / SubagentStop に対する prompt hook のうち指示文として書かれたものの判定が、より慎重になった。結果として **Claude が早すぎるタイミングで停止しにくくなる**。

2点とも「自然言語で書かれた hook をどう解釈するか」に関する変更である。hook を正規表現やコマンドではなく指示文で書いている運用では、**これまでブロックされていなかった操作が今後ブロックされる**という挙動変化が起きうる。

## 影響範囲

- 対象ユーザー: Claude Code で prompt hook / agent hook を指示文で書いている利用者
- 対象プラン: Claude Code 全般
- API / UI / 管理者機能: CLI。権限制御の挙動が変わる修正を含む

## 教材化メモ

- **「自然言語で書いた制御は、解釈の精度に依存する」という実例として使える。** 同じ hook の記述が、バージョンによってブロックする / しないに分かれた。**決定的に止めたい操作は、指示文ではなくコマンドやパターンで書く**という設計判断の根拠になる。
- **権限を自然言語で書く運用のテスト方法を教える題材になる。** 「ブロックされるはずの操作を実際に試す」テストを hook 導入時に1回やる習慣がないと、通っていたことに気づけない。
