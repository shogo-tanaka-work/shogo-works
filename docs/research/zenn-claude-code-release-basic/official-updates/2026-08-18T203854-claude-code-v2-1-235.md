# 2026-08-18 Claude Code v2.1.235

## 公式内容の日本語要約

前日の `v2.1.234` に続く改善・修正中心のリリース。新機能は1点で、残りは修正と改善である。

**新設定 `spellcheck`** が追加された。任意設定で、有効にするとプロンプト入力中の綴り誤りに下線が付く。判定はローカルにインストール済みの `aspell` / `hunspell` / `ispell` を使う。外部サービスへ送らずローカル辞書で完結する形である。

**権限まわりの整合性が2点**改善された。権限ダイアログの表示文と「don't ask again」の対象範囲が、実際に付与される権限と常に一致するようになり、内容を完全に表示できない場合は「don't ask again」自体を出さない。また、権限プロンプトのコメント欄で Shift+Tab を押すと、欄を閉じる代わりに編集を承認しセッション全体の編集権限まで付与してしまう不具合が修正された。

**クラウドセッション実行時の負荷が下がった**。`/ultrareview` や `/autofix-pr` をバックグラウンドで動かしている間、イベントストリームを更新のたびに再走査・再描画していたのをやめ、メモリと CPU の使用を抑えている。

その他、macOS / Linux ネイティブビルドの内蔵 `grep` が病的なパターンでメモリを食い潰さず即座に失敗するようになった点、auto-compact が無効なときにコンテキスト上限エラーがその旨と `/config` を案内するようになった点、Vim モードで transcript 切り替え時に NORMAL モードとカーソル位置が保たれる点などが含まれる。

## できるようになったこと

- `spellcheck` 設定でプロンプト入力の綴り誤りにローカル辞書ベースの下線表示
- 権限ダイアログの表示と付与範囲が一致し、全内容を表示できない場合は「don't ask again」を出さない
- クラウドセッション（`/ultrareview` 等）のバックグラウンド実行時にメモリ / CPU 使用を削減
- コンテキスト上限エラーが auto-compact 無効を明示し `/config` を案内

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。spellcheck は `aspell` / `hunspell` / `ispell` を入れている環境
- 対象プラン: 記載なし
- API / UI / 管理者機能: CLI / TUI と VSCode 拡張の修正
