# 2026-10-26 Claude Code v2.1.311

## 公式内容の日本語要約

self-hosted-runner に `--hold-idle-file` と `--max-hold-min` を追加（ホストが残したプロセスを報告している間、アイドルセッションを維持）。Explanatory 出力スタイルのヒント追加。修正の中心は、非常に長いリスト項目を含む CLAUDE.md による起動時の長時間フリーズ、MCP リソース読み取り待ち中の中断不能、標準コンテキストで 200K 超過時の「1M context に credits が必要」停止（自動 compact して継続するように変更）、Write / Edit の最大5秒の停滞、サブエージェントが後から接続した MCP サーバーのツールを使えない問題、compaction 直後に古い MEMORY.md / CLAUDE.md が見える問題、`SubagentStop` フックの重複実行など。
