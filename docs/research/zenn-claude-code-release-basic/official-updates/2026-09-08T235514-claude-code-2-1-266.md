# 2026-09-08 Claude Code v2.1.266

## 公式内容の日本語要約

v2.1.266 は単一の回帰修正のみを含むリリースである。

**`CLAUDE_CODE_USE_GATEWAY` 環境変数が Cloud gateway サインインを強制していた回帰**が修正された。この回帰により、API キーやカスタムヘッダーと併用した場合に `Not signed in` で失敗する事象が起きていた。修正後、**この環境変数は単独では無視される**。利用者側の設定変更は不要と明記されている。

前バージョン v2.1.265 の公開から約3時間後のリリースであり、直近の変更で入り込んだ不具合への追従と読める。

## できるようになったこと

- `CLAUDE_CODE_USE_GATEWAY` を設定していても、**API キー / カスタムヘッダーでのサインインが失敗しなくなった**
- 同変数は**単独では無視される**（設定変更は不要）

## 影響範囲

- 対象ユーザー: `CLAUDE_CODE_USE_GATEWAY` を設定している環境の Claude Code 利用者
- 対象プラン: 記載なし
- API / UI / 管理者機能: CLI（認証）

## 教材化メモ

**単独記事にしない（バージョンリリース）。** 教材価値としては、**環境変数を「とりあえず設定しておく」運用の危うさ**を示す小さな実例になる。この変数は本来 gateway 利用時のためのものだが、設定されているだけで認証経路を強制していた。**設定が意図せず他の経路を潰す**という構図は、CI やコンテナで環境変数を継承させる設計を扱う教材で使える。

ただし影響範囲が限定的で、修正後は利用者の作業も発生しないため、単独記事の価値はない。週次ロールアップでは v2.1.265 の hotfix として1行に収める。
