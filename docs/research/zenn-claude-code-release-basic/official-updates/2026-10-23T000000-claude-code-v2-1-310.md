# Claude Code v2.1.310

## 公式内容の日本語要約

CHANGELOG の最新版。Bedrock・Vertex・Foundry 上、およびテレメトリや非必須通信を無効にした環境でも Monitor ツールとプラグインモニターが使えるようになった。一部のゲートウェイが拒否する beta 値や会話途中のシステムメッセージで失敗する問題は、再試行で回避する。`cleanupPeriodDays` が極端に大きい場合に最近のファイルが消える不具合、"Prompt is too long" 後のコンパクションの修正、シンボリックリンク先の表示、Windows の hook 抜け穴の修正を含む。Linux では `/sandbox` が Ubuntu の AppArmor 制限を案内する。

記事化判断: 見送り（週次ロールアップへ）。バージョン番号付きリリースのため。日付は CHANGELOG に無く、GitHub API は取得できなかったため date-only 扱い。
