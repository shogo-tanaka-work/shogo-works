# 2026-10-02 Claude Code v2.1.288

## 公式内容の日本語要約

Claude Code の **v2.1.288**（2026-10-02T20:19:57Z）がリリースされた。前日 v2.1.287 で導入された **mods**（TypeScript 関数で本体の挙動を書き換える仕組み）の周辺整備が中心である。

**主な変更:**

- **`$.ui.selection()` を mods へ追加** — フルスクリーンモードで最後に選択したテキストを返す。mod 側から「ユーザーが今どこを見ているか」を取れるようになった。
- **クラウドセッションへ組み込みの `gh api`** — GitHub CLI を含まないイメージのクラウドセッションでも `gh api` が使える。
- **Ctrl+C で消したプロンプトの復元** — 空のプロンプトで ↑ を押すと直前の入力が戻る。
- **MCP サーバーが追加の OAuth スコープを要求したときの再認証プロンプト** — 従来は失敗で止まっていた箇所。
- **`/code-review` に `--max-findings <n>|all`** — 報告する指摘件数を増減できる。

ほかに複数のバグ修正と改善が含まれる。

**本リリースはバージョン番号付きリリースであるため、`selection-rubric.md` の「日次リリース型ツールの扱い」により単独記事化しない（判定D）。** 週次ロールアップ（`weekly-ai-news-rollup`）でまとめる。

## できるようになったこと

- mod からユーザーの選択テキストを取得できる
- GitHub CLI 無しイメージのクラウドセッションで `gh api` を呼べる
- MCP サーバーのスコープ追加要求時に再認証できる
- `/code-review` の指摘件数を調整できる

## 影響範囲

- 対象ユーザー: Claude Code 利用者、mod / plugin 開発者
- 対象プラン: Claude Code 全般
- API / UI / 管理者機能: mods API、`/code-review`、クラウドセッション

## 教材化メモ

- **`$.ui.selection()` は「エージェントに視線情報を渡す」系の API** として位置づけられる。ユーザーが選択した範囲という文脈は、プロンプトへ明示的に書かせるより精度が高く、かつ安い。同種の設計（IDE 拡張、ブラウザ拡張）へ転用できる考え方である。
- **MCP の OAuth スコープ追加で再認証プロンプトが出るようになった**のは、「権限は後から増える」という前提が仕組み側に入った例。初回認可で全権限を要求する設計との対比として教材に使える。
- **`--max-findings` は「レビューの網羅性と可読性のトレードオフを利用者に開放した」変更**である。既定値を固定せずユーザーに選ばせる設計判断として説明できる。
