# 2026-10-05 Claude Code v2.1.290

## 公式内容の日本語要約

Claude Code の **v2.1.290** が 2026-10-05T23:33:17Z に公開された。前版 v2.1.289（2026-10-03T23:07:17Z、PR #466 で記録済み）から約2日ぶんで、**CHANGELOG 上では直近で最も分量の大きいセクション**になっている。

**mod / hook 周りの追加**が目立つ。mod の hook 結果へ **`serverToolUses`** が追加され、各種 hook に **`agentId`** と **`ceiling`** のフィールドが加わった。plugin のバリデーションも強化されている。

**CLI 側のコマンド追加**として **`claude attach`** と **`claude logs`**、および **managed agents のセットアップ**に関する機能が入った。

残りは広範な不定修正である。プロキシ環境、長時間セッション、画像の扱い、スケジュール済みタスク、権限チェック、フリーズ・速度低下・メモリ、Windows / macOS / Linux / WSL の各プラットフォーム固有の問題、VS Code 連携（スクリーンリーダー対応、設定ダイアログ、ファイル取り扱い）、クラウドセッション（作業中インジケータ、プロンプト候補）、Claude Tag（Slack）の fast mode・メモリアクセス・scheduled routine、`/code-review` の blocking comment ラベルと organization mode が挙げられている。

## できるようになったこと

- mod の hook 結果に `serverToolUses` が入る
- 各 hook に `agentId` / `ceiling` が追加
- `claude attach` / `claude logs` コマンドの追加、managed agents のセットアップ
- plugin バリデーションの強化
- 多数のプラットフォーム / 統合（VS Code / Slack / クラウドセッション）側の修正

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。mod / plugin 作者には hook のフィールド追加が直接関係する
- 対象プラン: Claude Code（全チャネル）
- API / UI / 管理者機能: CLI、hook / mod API、VS Code 拡張、Claude Tag（Slack）
