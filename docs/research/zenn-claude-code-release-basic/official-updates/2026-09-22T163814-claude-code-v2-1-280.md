# 2026-09-22 Claude Code v2.1.280

## 公式内容の日本語要約

Claude Code `v2.1.280` が 2026-09-22T16:38:14Z に公開された。**規模の大きいリリースで、変更点は100項目を超える。**

**モデル面の変更が中心である。** Claude Opus 5.5（`claude-opus-5-5`）が追加され、既定の Opus モデルになった（1M コンテキスト、$4 / $20 per Mtok、キャッシュ読み取り $0.20）。あわせて **Pro / Team Standard プランの既定モデルが Sonnet から Opus へ変わり**、Max / Team Premium / Enterprise と揃った。`/effort` が per-model になる前に保存された effort レベルは Opus 5.5 のような新モデルへ引き継がれず、各モデルの既定から始まる。

**セキュリティ関連の修正が複数ある。** シンボリックリンク経由の書き込みが、リンクのツリー内での見え方で判定されていた不具合を修正した。**書き込みが実際に着地する場所がプロンプトに表示され、`acceptEdits`・allow ルール・auto mode がツリー外へ着地する書き込みを承認しなくなった。** また、安全性チェックがレビューを拒否したときに auto mode が同じ操作を無限に再試行していた問題、回答が得られないときに無停止で拒否し続けていた問題（バックオフと10回での打ち切りを追加）も修正されている。プラグインマーケットプレイスについては、予約済みマーケットプレイス名を模した名前の追加を拒否し、既に追加済みなら読み込みを停止するよう変更された。

その他、`CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH` の追加、フルスクリーンモードのマウス対応拡大、VS Code 拡張への `/status` / `/sandbox` / `/chrome` / `/export` / `/skills` / `/plan` ダイアログ追加、Claude Code on the web でのルーティン・GitHub Enterprise Server トークン更新の修正などが含まれる。

## できるようになったこと

- Opus 5.5 を既定 Opus として利用できる
- MCP ツール説明の2,048文字上限を環境変数で変更できる
- VS Code 拡張から Status / Sandbox / Chrome / Export / Skills / Plan の各ダイアログを開ける

## 影響範囲

- 対象ユーザー: Claude Code の全利用者
- 対象プラン: **Pro / Team Standard は既定モデルが変わるため、想定と違う場合は明示設定が必要**
- API / UI / 管理者機能: シンボリックリンク書き込みの判定変更により、これまで通っていた許可ルールが通らなくなる可能性がある
