# 2026-08-17 Claude Code v2.1.234

## 公式内容の日本語要約

50項目超の変更を含む大型リリース。目玉は **claude.ai の利用上限がリセットされたときにセッションを自動で継続する**挙動が既定で入ったこと。`/config` の「Continue automatically at usage limit」で無効化できる。上限に当たって作業が止まり、リセット後に手動で再開していた運用が変わる。

セキュリティ面では、**Windows NT namespace パス（`\??\`）の拒否対象が拡大**した。v2.1.233 で塞いだ NTLM 認証情報の漏洩ベクトルについて、残っていた事前承認前のファイルアクセス経路（リモートファイル読み取り、セッション復元、CLAUDE.md の include、workflow スクリプト、ファイルアップロード）まで対象を広げている。あわせて MCP 診断が解決済みシークレットを表示していた問題（スコープ競合の警告は `${VAR}` 形式で表示、接続失敗の詳細はサーバーのオリジンのみ表示）、`strictKnownMarketplaces` の allowlist が SCP 形式の git ソースを取りこぼしていた問題が修正された。権限プレビューのマスキングが承認者からコマンドや宛先を隠してしまう問題も直っている。

運用面では **`/permissions` と `/add-dir` が作業中に開けるようになった**（ルール変更は現ターンの残りから有効）。`/goal` は回復不能なエラーでターンが落ちたとき自動解除され、バックグラウンドタスクで30分以上待たされると Claude が状況を確認しにいくようになった（`CLAUDE_CODE_GOAL_CHECKIN_MINUTES=0` で無効化）。

コスト面では、**組み込み `claude-api` skill の読み込みコストが約200k+トークンから約25kへ削減**された（参照ドキュメントを必要時のみ読み込む方式に変更）。

Remote Control 系も広く手が入り、effort の選択がスマホや claude.ai/code からターミナル/Desktop/VS Code ホストのセッションへ反映されるようになった。GitLab リモートと認証済み `glab` CLI がある repo では、フッターとステータスラインに MR バッジ（`!N`、draft/pending/green 状態付き）が出る。

## できるようになったこと

- 利用上限リセット時のセッション自動継続（既定 on、`/config` で off）
- `/permissions`・`/add-dir` を作業中に実行、`/autocompact`・`/theme`・`/help`・`/config`・`/advisor` をターン途中で開く
- GitLab MR バッジをフッター/ステータスラインに表示
- `CLAUDE_CODE_PROJECT_DIR_NAME` でプロジェクト別 transcript ディレクトリ名を短縮
- `selection:clear` キーバインドでアプリ内テキスト選択を解除
- `claude-api` skill の読み込みコストを約 1/8 に削減

## 影響範囲

- 対象ユーザー: Claude Code 全ユーザー（Remote Control / GitLab / Windows 利用者は追加の影響）
- 対象プラン: 記載なし（claude.ai 利用上限の自動継続は claude.ai 認証のセッション）
- API / UI / 管理者機能: CLI 挙動・セキュリティ境界・`/config` 設定に影響
