# 2026-11-16 Claude Code 2.1.326

## 公式内容の日本語要約

CHANGELOG の先頭に 2.1.326 が追加された（日付は CHANGELOG に無く、GitHub Releases API は 403 のため date-only 扱い）。agent teams 有効時にも Code Mode をオンにできるようになった。`--allowedTools` 等の値が不完全なルールのときの起動時警告、`managed-mcp.json` 追加時の MCP 停止理由の表示、`/status` へのプロバイダー・環境変数による機能無効化の行、OTEL の `host.name` / `host.id` 属性（`OTEL_RESOURCE_INCLUDE_HOST`）が追加された。修正は、Edit deny ルール下の `cp`、設定ファイル書き込み失敗時の警告、深いネスト設定のクラッシュ、サンドボックス（Linux の symlink / ロックファイル残り）、再開セッションの履歴欠落などが中心。

## 影響範囲

- 対象: Claude Code 全利用者。管理者向けの修正を含む。
