# 2026-08-06 Claude Code v2.1.223

## 公式内容の日本語要約

Claude Code v2.1.223 は、権限まわりのセキュリティ修正が中心のリリース。修正内容が具体的で、いずれも「承認ダイアログを回避される」種類の問題にあたる。

第一に、細工した Bash コマンドが自身の一部を権限チェックから隠せる問題を修正した。関連して、タブや不可視 Unicode を詰めたコマンドが承認ダイアログ上で一部を隠せる問題も塞いでいる。承認画面に表示された内容と実際に実行される内容が食い違いうる状態だったことになる。さらに、ワークフロースクリプトが動的 `import()` を使ってワークフローサンドボックス外のコードを実行できた問題、エージェント定義の `bypassPermissions` モードが組織の bypass 無効化ポリシーを無視していた問題も修正された。

管理機能では、`strictKnownMarketplaces` と `blockedMarketplaces` に所有者ワイルドカード（`"owner/*"`）を追加し、GitHub org 配下のマーケットプレイスリポジトリを一括で許可・禁止できるようになった。サーバー配信の管理設定がマシンローカルの `managed-settings.json` / MDM プロファイルの env ブロックを無効化していた問題も修正され、管理者 env はキー単位でマージされる。

コンテキスト制御では `CLAUDE_CODE_DISABLE_1M_CONTEXT` の対象が「固定リスト」から「1M ネイティブウィンドウを持つすべての Claude モデル」に拡張された。未知のモデル ID のセッションも想定ウィンドウ内に収めるよう auto-compact が働くようになり、戻したい場合は `CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1` を指定する。

コマンド体系では `/review` が `/code-review` のエイリアスになった。`/code-review` は現在の差分または PR（`/code-review <level> <pr#>`）をレビューし、深いクラウドレビューは `/code-review ultra`。effort level を省略すると前回指定した level を再利用する。

そのほか、ワークフローエージェント・フォークしたスキル・スラッシュコマンド・再開したバックグラウンドエージェントが要求したサブエージェントモデルが制限されている場合に警告を出すようになり、クラウドセッションでは `claude --teleport <session id>` でローカル継続する方法を示す `/teleport` ヒントが追加された。ゲートウェイのモデル検出が `vertex_ai/claude-*` や `bedrock/anthropic.claude-*` のようなプロバイダ接頭辞付き ID を隠していた問題も修正されている。

## できるようになったこと

- Bash 権限チェックの回避（コマンド一部の隠蔽、タブ・不可視 Unicode によるダイアログ偽装）を修正
- ワークフロースクリプトによる動的 `import()` でのサンドボックス外実行を修正
- エージェント定義の `bypassPermissions` が組織ポリシーを無視する問題を修正
- `strictKnownMarketplaces` / `blockedMarketplaces` で `"owner/*"` ワイルドカード指定が可能に
- 管理者 env がサーバー配信設定に潰されず、キー単位でマージされるように
- `CLAUDE_CODE_DISABLE_1M_CONTEXT` が 1M ネイティブ対応の全 Claude モデルに適用
- 未知モデル ID でも auto-compact が想定ウィンドウを維持（無効化は `CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1`）
- `/review` が `/code-review` のエイリアスに統合、level 省略時は前回値を再利用
- サブエージェントモデルが制限され親モデルで動く場合に警告表示
- クラウドセッションに `/teleport` ヒント（`claude --teleport <session id>`）
- プロバイダ接頭辞付きモデル ID がゲートウェイのモデル検出に出るよう修正

## 影響範囲

- 対象ユーザー: Claude Code の全ユーザー、特に組織で権限ポリシーを運用する管理者
- 対象プラン: 全プラン（管理設定は Enterprise 相当の管理機能）
- API / UI / 管理者機能: CLI コマンド体系 + 管理設定 + 環境変数
