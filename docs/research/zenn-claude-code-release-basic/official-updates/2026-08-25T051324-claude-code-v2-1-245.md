# 2026-08-25 Claude Code 2.1.245

## 公式内容の日本語要約

2.1.245 の公式記載は1項目のみ。**glibc 2.44 を採用している Linux ディストリビューション（Arch Linux、CachyOS、Fedora Rawhide が名指しされている）で、起動時にクラッシュする問題**を修正した。

前版 2.1.243（2026-08-24T23:40Z）の公開から約5時間半後に出ており、**特定環境で起動できない状態を解消するための緊急修正**と読める。該当ディストリビューションの利用者は、2.1.243 / 2.1.244 では Claude Code を起動できなかったことになる。

## できるようになったこと

- glibc 2.44 環境（Arch Linux / CachyOS / Fedora Rawhide 等）で Claude Code が起動する

## 影響範囲

- 対象ユーザー: glibc 2.44 を使う Linux ディストリビューションの利用者
- 対象プラン: 全プラン
- API / UI / 管理者機能: ランタイム（起動処理）

## 教材化メモ

- **「ローリングリリース系ディストリビューションを開発機に使うコスト」の実例**として使える。Arch / Fedora Rawhide は新しい glibc を先に取り込むため、ツール側の想定より先に進む。開発環境の選定を扱う教材で、「新しさ」には検証負担が伴うという話を、具体的な日付付きの事例として提示できる。
- **前版から5時間半で緊急修正が出た**という事実は、リリース速度の速いツールを業務に組み込むときの前提を説明する材料になる。**壊れるのも速いが直るのも速い**。逆に言えば、バージョンを固定せず自動更新している組織は、短時間の障害を踏む確率と、短時間で復旧する確率の両方を受け入れている。**バージョン固定の是非を「安全か危険か」ではなくトレードオフとして教える**題材になる。
