# 2026-07-24 Claude Code v2.1.219

## 公式内容の日本語要約

Claude Code v2.1.219は、同日発表のClaude Opus 5をデフォルトOpusモデルとして統合したほか、sandboxネットワーク制御、フック追加、headless streaming強化、subagentのネスト対応拡大など多数の機能を含む大型リリース。翌v2.1.220（2026-07-25T01:35:55Z）は「Bug fixes and reliability improvements」のみの軽微パッチで、本ファイルに併記する。

## できるようになったこと

- Claude Opus 5（`claude-opus-5`）を追加。新しいデフォルトOpusモデルとして採用（1M context、Fast modeは$10/$50/百万トークン）
- `sandbox.network.strictAllowlist` 設定を追加。sandbox化されたコマインドで許可リスト外ホストへのアクセスをプロンプトなしで拒否できる
- `DirectoryAdded` フックを追加。`/add-dir` またはSDKの `register_repo_root` でセッション中に新しい作業ディレクトリが登録された際に発火
- headless stream-jsonのinitイベントに `mcp_server_errors` を追加。`--mcp-config` で設定検証により除外されたMCPサーバーを一覧表示
- `workflowSizeGuideline` 設定キーを追加。Dynamic workflowのサイズガイドラインを任意の設定ファイルから指定可能に
- stream-jsonでネストしたsubagent転送に対応。depth-2以降で生成されたsubagentも `--forward-subagent-text` 指定時に表示されるように
- subagentのネスト生成がデフォルトでdepth 3まで対応（従来は1）。`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1` で無効化可能
- Dynamic workflowのデフォルトサイズガイドラインを「medium」（15エージェント未満推奨）に変更
- managed MCP allowlist/denylistの `${VAR}` 解決元を起動時環境変数とmanaged-settings envに変更
- Opus 4.7をFast modeから削除。`/fast` はOpus 5とOpus 4.8に適用

### 主なバグ修正

- `claude -p` のテキスト出力がミッドストリームAPIエラーで既に生成済みの回答を失う不具合を修正
- self-hosted runner再起動中に承認した権限がセッション再開時に失われる不具合を修正
- Vim mode: 空プロンプトで←キーを押した際にNORMAL modeからagent viewへ戻れるように修正
- スクリーンリーダーモードで毎キー入力ごとに行全体を読み上げていた不具合を修正

## 影響範囲

- 対象ユーザー: Claude Code全ユーザー、特にsandbox/フック/subagentを活用する開発者・エンタープライズ運用者
- 対象プラン: Opus 5利用にはClaude Code経由のClaude契約が必要
- API / UI / 管理者機能: sandbox設定・MCP設定・workflowサイズガイドラインなど管理者/上級者向け設定が中心

## 教材化メモ

- Opus 5統合は同日のAnthropic本体発表とセットで扱うと文脈が伝わりやすい。
- `sandbox.network.strictAllowlist` はセキュリティ強化系設定として、企業導入担当者向けの実務メモに向く。
- subagentネスト depth 3 対応は、複雑なマルチエージェントワークフローを組む開発者への影響が大きい。
