# 2026-09-29 Claude Code v2.1.285

## 公式内容の日本語要約

環境変数 **`CLAUDE_CODE_DISABLE_WEB_FETCH`** が追加され、WebFetch を組織として無効化できるようになった。あわせて **`claude --desktop`** が入った。

修正が広範囲に及ぶ。**プラグインのインストール不具合**、**MCP サーバーの扱い**、**artifact の公開時の競合**、セッション周り、VSCode 固有の問題、Claude Tag と Code Review 関連。**safeguard によるブロック時のエラーメッセージが改善**され、セッション再開の性能が上がっている。

前版 v2.1.284（09-28）が Sonnet 5.5 の既定採用・auto mode の全プラン既定化という大きな既定値変更だったのに対し、**本版は追随の修正が中心**である。

**バージョン番号付きリリースのため、`selection-rubric.md` の「日次リリース型ツールの扱い」に従い単独記事化しない。** 週次ロールアップで扱う。

## できるようになったこと

- `CLAUDE_CODE_DISABLE_WEB_FETCH` で WebFetch を無効化する
- `claude --desktop` を使う
- プラグイン導入・MCP・artifact 公開の不具合を回避する

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般
- 対象プラン: 全般
- API / UI / 管理者機能: **`CLAUDE_CODE_DISABLE_WEB_FETCH` は組織統制の材料になる**

## 教材化メモ

- **`CLAUDE_CODE_DISABLE_WEB_FETCH`** は、エージェントの外向き通信を環境変数1本で切れるという点で、統制の教材に使いやすい。9月に相次いだ OpenAI の misalignment 報告（DNS 経由の情報持ち出し）と並べると、**「エージェントが外部へ出る経路を、機能単位で落とせるか」**という点検項目として具体化できる。managed settings と組み合わせた統制の例として週次ロールアップで扱う。
- v2.1.284 の大きな既定値変更（Sonnet 5.5、auto mode）に対する**翌日の修正版**という形は、「既定値を変える更新の直後は追随修正が来る」という運用上の経験則の実例。社内標準バージョンを1版待つ判断の根拠になる。
