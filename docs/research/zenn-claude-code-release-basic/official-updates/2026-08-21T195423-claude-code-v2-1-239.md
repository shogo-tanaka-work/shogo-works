# 2026-08-22 Claude Code 2.1.239

## 公式内容の日本語要約

2026-08-21T19:54Z（JST 2026-08-22 04:54）リリース。本 CHANGELOG で60項目以上が並ぶ、直近では最大規模の版である。追加・変更・修正が広範に入っており、特にコスト計算・課金・エンタープライズ配布まわりの修正が重い。

**コスト計算**では、`/cost`・ステータスライン・`--max-budget-usd` の見積もりに、データレジデンシー（US-only inference）ワークスペースの 1.1 倍割増が反映されるようになった。これまでは割増分が見積もりに乗らず、実際の請求と表示がずれていたことになる。

**課金に直結する修正**として、レスポンスの `Content-Type` ヘッダーを削るプロキシ配下で Bedrock のストリーミングが壊れ、**毎ターンを非ストリーミングで再実行して API 課金が黙って倍になっていた**不具合が直った。Bedrock を企業プロキシ経由で使っている環境は影響範囲を確認する価値がある。加えて、SSO プロファイル＋`awsAuthRefresh` の構成で HTTPS プロキシ配下だと起動時にハングする問題も、認証情報の事前チェックが `HTTPS_PROXY` を尊重するようになって解消した。

**配布・運用面**では、claude.ai から同期されたプラグインが cloud セッションで `name@synced` として表示され、ローカルにインストールした同名プラグインを上書きしなくなった。Alpine/musl ビルドでは画像ペースト・クリップボード・音声キャプチャのネイティブアドオンが musl ビルドに差し替わり、実際に読み込めるようになっている。Bedrock / Vertex / Foundry など従来除外されていた構成でもフルスクリーンレンダラーの初回案内が出るようになった。

**セキュリティ寄りの修正**として、ログインコード欄などマスク入力の内容が Ctrl+Y で他所に貼り付けられたり、二重 Esc で消したときにプロンプト履歴へ保存されたりする問題が直っている。組織ポリシーで拒否されたリクエストが、拒否表示より先に再送されていた問題も修正された。

このほか JetBrains ターミナルでの Edit / Write の約5秒停止、WebFetch のキャッシュが15分ではなくセッション中ずっと保持されていた問題、Linux サンドボックスで `extensions.worktreeConfig` 設定のリポジトリのすべての git コマンドが壊れていた問題、`.worktreeinclude` の `**/` パターン、UTF-8 BOM 付き `.md` のエージェント/スキルが無視される問題、OpenTelemetry のトレース分断など、広範な修正が入っている。Windows でセッション横断メッセージング（`SendMessage` / `ListAgents`）が macOS / Linux と同等に使えるようになった。

## できるようになったこと

- データレジデンシーワークスペースの 1.1× 割増をコスト見積もりに反映
- `/claude-api upgrade` で Python プロジェクトを `anthropic` 0.x → 1.x へ移行
- cloud セッションで claude.ai 同期プラグインを `name@synced` として扱う（ローカル同名を上書きしない）
- Alpine/musl ビルドで画像ペースト・クリップボード・音声キャプチャが動作
- Windows でセッション横断メッセージングが利用可能に
- `keybindingFlavor: "readline"` が Bash の単語境界（Alt+F / Alt+D / Ctrl+Y）に一致
- `/goal` の長時間バックグラウンド作業チェックインが 30分 → 1時間 → 2時間へバックオフ

## 影響範囲

- 対象ユーザー: Claude Code 全ユーザー。特に Bedrock / Vertex / Foundry 経由、企業プロキシ配下、データレジデンシーワークスペース、Alpine/musl コンテナ、Windows 利用者
- 対象プラン: 全プラン（データレジデンシーは対象ワークスペースのみ）
- API / UI / 管理者機能: API 課金（Bedrock 二重課金修正）、CLI 表示、プラグイン配布、サンドボックス、OpenTelemetry すべてに及ぶ
