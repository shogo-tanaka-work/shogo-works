# 2026-11-04 Claude Code 2.1.318

## 公式内容の日本語要約

CHANGELOG は日付なしのため、公開日は観測日（2026-11-04）を date-only で記録。

主な追加: mod の $.model.fork に effort オプション、Claude apps gateway の mantle upstream で assume_role（別 AWS アカウント・開発者単位のコスト配賦）、claude auth status と claude -p JSON にログイン失効日（loginExpiresAt / credential_expires_at）、失効10日前からの stderr 警告。修正: --continue が会話を失う回帰（2.1.314 起因）、macOS の多数 Bash 実行時のメモリ増加、権限プロンプトへの誤入力、設定ファイル書き込み失敗の無言化。

バージョンリリースのため単独記事にせず、週次ロールアップで扱う。
