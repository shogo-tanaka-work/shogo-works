# 2026-08-26 Claude Code 2.1.247

## 公式内容の日本語要約

窓内の Claude Code リリースは 2.1.247 の1件（2.1.246 は前日サマリー済み）。

**追加**: セッションで問題が起きたときに Claude がフィードバック報告の下書きを作り、`/feedback` から確認・送信できる `SendFeedback` ツール（`feedbackDrafts` 設定でオフ可）。組織が独自のヒントを組み込みヒントと並べて巡回させるための `spinnerTipsOverride` 拡張（`{id, text, cooldownSessions, priority}` 形式、`tipsFile`、`label`）。Bash 権限プロンプトに auto mode への案内と「Yes, and switch to auto mode」のワンキー選択肢。既存プロジェクトの Claude API 支出をプロファイルし、キャッシュ・トークン衛生・バッチ・effort・モデル選択といったコスト要因を1つずつ計測しながら詰める `/claude-api cost-optimize`。`/claude-api` スキルの Admin API 対応（組織メンバー、招待、ワークスペース、API キー、レートリミットレポート、ワークロード ID フェデレーション、CMEK）。

**変更**: **Sonnet 5 の既定 auto-compact 窓が 1M コンテキスト全体になり**、1M 窓のセッションは約 934K ではなく **約 967K トークン**で自動圧縮されるようになった。クロスセッションのピアメッセージは既定で1行プレビューに畳まれる（Ctrl+O で展開）。ネットワーク/オートマウンタのパス、制御文字、先頭の不可視文字を含むリンク先はプレーンテキスト描画に変更。

**セキュリティ・堅牢化**: プラグインマーケットプレースの名前に制御文字・不可視文字が含まれる場合を拒否し、マーケットプレース由来のテキストをエスケープ安全に。Bash sandbox の後片付けが dotfile 管理（nix/home-manager、stow）の `~/.claude/settings.json` シンボリックリンクを削除する問題を修正。

**修正**: サブエージェントが初回呼び出しの 404 で落ちる問題（セッションのフォールバックモデル連鎖を使うようになり、親へ返るエラーに種別・ステータス・リクエスト ID・モデルが含まれる）。フックやバックグラウンドエージェントが大量のエラー出力を吐いて会話を溢れさせ "Prompt is too long" で行き詰まる問題。コンテナ再起動でクラウドセッションが無言になる問題（再開後に失われた作業を報告する）。ほか、キーボードレイアウト、`/compact`、`/rename`、`/install-github-app` など多数。

## できるようになったこと

- `/feedback` にフィードバック下書き（`SendFeedback` ツール）
- `/claude-api cost-optimize` で Claude API 支出を計測しながら最適化
- 組織独自のスピナーヒント配信（`spinnerTipsOverride`）
- Sonnet 5 の 1M 窓セッションで自動圧縮の発火が約 967K トークンへ後ろ倒し

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般、組織管理者、Claude API 開発者
- 対象プラン: Claude Code 利用者全般（Bedrock / Vertex / Foundry を含む）
- API / UI / 管理者機能: CLI（UI）+ 設定（`feedbackDrafts` / `spinnerTipsOverride`）+ 組み込みスキル

## 教材化メモ

- **`/claude-api cost-optimize` が「1つずつ計測しながら変える」と明示している**点は、AI コスト最適化の教え方としてそのまま使える。キャッシュ・トークン衛生・バッチ・effort・モデル選択を同時に触ると、どれが効いたか分からなくなる。**一度に1変数**という基本を、公式ツールが手順として持っている例。
- **auto-compact 窓の変更（934K → 967K）は「安全余裕をどこに取るか」の話**。長い窓を使い切る側に倒すと圧縮が減り文脈が保たれるが、圧縮の失敗余地は狭まる。設定値の背後にあるトレードオフを読む練習題材になる。
- **マーケットプレース名の制御文字・不可視文字を拒否する**修正は、プラグインエコシステムの供給側リスクの実例。ハーネスエンジニアリングのガードレール層で「拡張機能をどこまで信用するか」を扱うときの具体例に使える。
- 記事化は見送った（本数上限）。日次の Claude Code リリースとしては標準的な粒度で、同日の Claude in Chrome 一般提供・Codex v0.150.0 の方が読者への影響が大きいと判断した。
