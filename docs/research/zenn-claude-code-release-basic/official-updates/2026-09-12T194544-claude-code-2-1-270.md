# 2026-09-12 Claude Code v2.1.270

## 公式内容の日本語要約

前日の `v2.1.269` で入り込んだ回帰を1点だけ直すパッチリリース。CHANGELOG のエントリは1行のみである。

修正内容は、**セッションを一定時間動かし続けた後に、Bash の読み取り専用 git コマンドが想定外に権限確認を求めてくる**問題（`2.1.269` での回帰）。読み取り専用コマンドは既定で確認なしに実行される想定だが、長時間セッションでその判定が崩れていた。

機能追加・変更・非推奨化はなく、退役日や発効日の告知も含まれない。`2.1.269` を入れて長時間セッションで git コマンドの確認が増えたと感じていた環境は、このバージョンで解消する。

## できるようになったこと

- 長時間稼働セッションでも、Bash の読み取り専用 git コマンドが余分な権限確認を出さなくなった（`2.1.269` の回帰修正）

## 影響範囲

- 対象ユーザー: Claude Code の全ユーザー。特に1セッションを長く使い続ける運用
- 対象プラン: プラン差なし
- API / UI / 管理者機能: 権限判定の挙動のみ。設定項目の追加はない

## 教材化メモ

- **記事化しないため、ここに残す。** 単独の教材素材としての価値は薄いが、**「パッチの直後にパッチが出る」構造そのもの**は運用教材で使える。`2.1.269` は大型リリース（`claude plugin eval`、`/output-style` 等）で、その翌日に権限判定の回帰修正が出た。**大型リリース直後に更新すると回帰を踏む確率が上がる**という、バージョン運用の一般則の実例になる。
- 権限確認の増加は「仕様変更かと思って設定を触る」方向の誤対応を招きやすい。**まず CHANGELOG で回帰かどうかを確認する**という手順を、ツール運用の教材で明示する材料になる。
- 週次ロールアップでは `2.1.268` / `2.1.269` とまとめ、`2.1.270` は「`269` の回帰修正」という位置づけで1行に収めるのが妥当。
