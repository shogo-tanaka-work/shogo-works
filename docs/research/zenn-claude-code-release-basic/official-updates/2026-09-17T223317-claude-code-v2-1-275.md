# 2026-09-17 Claude Code v2.1.275

## 公式内容の日本語要約

Claude Code v2.1.275 が 2026-09-17T22:33:17Z に公開された。**大型のリリースで、追加・修正・改善が100項目を超える。** VS Code 拡張、Claude Tag（Slack）、Code Review の各面にも変更が入っている。

**セキュリティ関連の変更が3点ある。** (1) **npm ソースからインストールするプラグインを `npm pack --ignore-scripts` で取得し整合性検証するよう変更**。パッケージの install script が実行されなくなった。(2) **プラグイン / marketplace のメッセージ・ログ・`claude plugin marketplace list` が、git / ssh / marketplace URL に埋め込まれたパスワードやトークンを表示していた問題を修正**（VS Code の Manage plugins ダイアログ側も同様に修正）。(3) Claude apps gateway のサインインで、gateway が名乗ったアカウントを**保存前にユーザーが確認**し、`/status` に表示するよう変更。

**主な追加**: キュー済みメッセージを一括送信する send-now キー（ctrl+enter）。`otelHeadersHelper` 失敗時の起動警告。**claude.ai アカウントで有効なスキルとプラグインを、同じアカウントでサインインしたターミナルセッションへ同期**（`syncClaudeAiSkills: false` / `syncClaudeAiPlugins: false` でオプトアウト）。`/plugin install <plugin> --marketplace <source>`。

**主な変更**: スケジュール実行および「Run now」の routine 実行が、**編集可能な artifact へのデータ保存とページ再公開を確認なしで行う**ように変更（公開 artifact・初回公開・削除は従来どおり確認する）。Claude in Chrome の auto mode が、classifier 承認済み呼び出しについて拡張側のサイト別チェックを省略。

**修正の傾向**: 破損したトランスクリプト・メッセージエントリでの resume 失敗やクラッシュ、フルスクリーン UI の不具合、sandboxed Bash が zsh で失敗時に exit code 0 を返す問題、`/rewind` がバックアップを完全にコピーできないときにゼロ埋め・切り詰めファイルを復元する問題など。

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。プラグイン運用者、Claude Tag / VS Code 利用者
- 対象プラン: 該当なし
- API / UI / 管理者機能: CLI / VS Code / Claude Tag / Code Review。`syncClaudeAiSkills` / `syncClaudeAiPlugins` が追加

## 教材化メモ

- **記事化しない（`見送り（週次ロールアップへ）`）。** バージョン番号付きリリースは、**権限・サンドボックス・資格情報・セキュリティ修正を含んでいても**単独記事にしない規約（`selection-rubric.md`）による。本リリースはまさにその3種を含むが、規約どおり週次ロールアップへ送る。週次側では「今週の要点」冒頭で対応要否を明示する。
- 教材観点では **`npm pack --ignore-scripts` への変更が最も価値が高い**。**「プラグインをインストールする」という行為が、サードパーティのコードを自分の権限で実行することだった**という事実が、修正の形で可視化されている。サプライチェーンの話を具体例で始められる。
- **URL に埋め込んだ資格情報がログへ出ていた**件は、「秘密情報を URL に入れない」という基本則が守られなかったときに何が起きるかの実例。**ログ・エラーメッセージ・一覧表示という3経路すべてで漏れていた**点が、経路を全部塞ぐ難しさを示す。
- **claude.ai のスキル/プラグインが端末へ同期される**変更は、組織の統制観点で覚えておく。個人アカウントで有効化したものが手元の端末に降りてくる経路が増えた。オプトアウト設定名は変わりうるので、恒久教材には「同期の向きと止め方を確認する」とだけ残す。
