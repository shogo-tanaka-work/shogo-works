# 2026-08-04 Claude Code v2.1.221

## 公式内容の日本語要約

v2.1.220（バグ修正のみ）に続く大型リリース。セキュリティ修正、sandbox の認証情報保護、VSCode 拡張のUI追加、プラグイン運用まわりの挙動変更が同時に入っている。

セキュリティ面では、zsh の `[[ ]]` 正規表現条件文の中に隠したコマンドが Bash tool の権限チェックを迂回して実行できるバイパスを修正した。Windows の PowerShell 権限チェックでも、クォート文字を含むパスの扱いが誤っていた点を修正している。いずれも該当コマンドは今後 permission プロンプトが出る。

sandbox には認証情報ファイル向けの `mode: "mask"` が追加された。Linux / WSL では sandbox 内のコマンドがセンチネル値の複製（ファイル全体、または `extract` 正規表現で捕捉したスパンのみ）を読み、egress 時に sandbox proxy が実値へ差し替える。macOS ではファイルマスキングは `deny` にフォールバックする。

VSCode 拡張には Focus view が追加された。ツール実行のログを畳んでターンごとの要約と実行中インジケータだけを表示するチャットメニュー切り替えで、`Ctrl+Alt+F` または「Claude Code: Toggle Focus view」コマンドで切り替える。

運用系では、バックグラウンドセッションの既定挙動が「作業を保全するため commit と push を行い、必要な場合のみ draft PR を開き、CLAUDE.md の git 指示に従い、最後に成果物の所在を報告する」に変更された。`/plugin` からインストールしたプラグインは安全な場合に即時有効化され、`/reload-plugins` が不要になった。`/fork` で分岐したセッションは元のチェックアウトではなく自前の worktree を作る。

## できるようになったこと

- sandbox の認証情報ファイルを `mode: "mask"` でマスクし、実値を sandbox 内へ渡さずに外部通信だけ成立させられる（Linux / WSL）
- VSCode で Focus view によりツール実行ログを畳んだ表示に切り替えられる
- `claude plugin validate` が Claude Desktop の managed marketplace sync で弾かれる名前を事前警告する
- `claude-api` skill の `prompt-audit` サブコマンドで、旧モデル向けに書かれたプロンプト・ツール説明を監査できる
- `/status` がセッション種別（`interactive` / バックグラウンドの `attached` / `unattended`）を表示する
- Stats パネルが cache トークンを含めた集計（input / output / cache read / cache write の内訳）を表示する
- Google Vertex AI で Claude 4.5世代以降のモデルの tool search が再有効化された

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。特に sandbox / プラグイン / VSCode 拡張の利用者、Team・Enterprise 管理者
- 対象プラン: 全プラン（spend limit メッセージ修正は Team / Enterprise）
- API / UI / 管理者機能: CLI 挙動、VSCode 拡張UI、sandbox 設定スキーマ、Bedrock / Vertex 認証まわり
