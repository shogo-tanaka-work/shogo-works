# 2026-09-24 Claude Code v2.1.282

## 公式内容の日本語要約

2026-09-24T18:38:05Z に v2.1.282 が公開された。前版 v2.1.281（2026-09-23）から1日での小刻みなリリースで、**新機能より修正の比重が大きい**。

追加されたもののうち実務に効くのは3つ。1つ目は **`maxProseWidth` 設定**で、ターミナル上の散文の横幅に上限をかけられる。**表とコードブロックは全幅のまま維持される**ため、ワイドなターミナルでの可読性だけを改善できる。2つ目は**起動時通知**で、無視されているテレメトリ関連の環境変数を一覧表示する。設定したつもりで効いていない変数に気づける。3つ目は **`allowClaudeInChromeWithManagedMcp` 管理設定**で、管理された MCP 構成下で Claude in Chrome を許可するかを組織側で決められる。

修正側は範囲が広い。web search の結果復号の失敗、再開したセッションでのメッセージ再送、**スラッシュコマンド実行時に extended thinking が落ちる問題**、vim モードのカーソル位置の複数の不具合。加えて artifact の公開処理、`/ultrareview` の安定性、複数ダイアログでのキーボードナビゲーションが改善された。

**本リリースはバージョン番号付きリリースのため、`selection-rubric.md` の「日次リリース型ツールの扱い」に従い単独記事にしない。** 週次ロールアップ（`weekly-ai-news-rollup`）でまとめる。

## できるようになったこと

- `maxProseWidth` 設定で散文の横幅に上限を設定（表・コードは全幅を維持）
- 起動時に、無視されているテレメトリ関連の環境変数を通知
- `allowClaudeInChromeWithManagedMcp` 管理設定を追加
- 修正: web search 結果の復号失敗、再開セッションのメッセージ再送、スラッシュコマンド時の extended thinking 欠落、vim モードのカーソル位置
- 改善: artifact の公開、`/ultrareview` の安定性、各ダイアログのキーボードナビゲーション

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。管理設定部分は組織管理者
- 対象プラン: Claude Code を利用できる全プラン
- API / UI / 管理者機能: CLI 設定（`maxProseWidth`）、管理設定（`allowClaudeInChromeWithManagedMcp`）

## 教材化メモ

- **「設定したつもりで効いていない環境変数」を起動時に出す**という設計は、教材で扱う価値がある。CLI ツールの設定は静かに無視されると気づけない。起動時通知はその典型的な対処。
- `maxProseWidth` は**可読性と情報量のトレードオフを、要素の種類ごとに分けて解く**例。散文だけ折り返し、表とコードは全幅。一律に幅を決めない設計判断として説明できる。
