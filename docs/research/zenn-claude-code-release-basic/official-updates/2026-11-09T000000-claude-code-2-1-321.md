# 2026-11-09 Claude Code 2.1.321

## 公式内容の日本語要約

Fable 5.2（`claude-fable-5-2`）を既定の Fable モデルとして追加。`claude remote-control` に `--settings <file>` を追加。MCP OAuth のリフレッシュトークン等が別ホストへ送られる問題、読み取り専用 Bash がサンドボックス外で確認なしに動く問題、Bash 権限チェックが誤ったフォルダで書き込みを判定する問題、`cp`/`mv` の deny ルール未適用などを修正。ほか多数のバグ修正。
