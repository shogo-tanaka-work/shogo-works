# 2026-09-15 Claude Code v2.1.273

## 公式内容の日本語要約

Claude Code の `v2.1.273` が 2026-09-15T20:23:03Z に公開された。窓内で2版目にあたる。

**機能追加は3系統。**(1) **LLM ゲートウェイ向けのヒントヘッダー**が追加され、リクエストの分類とコンテキスト圧縮（compaction）の追跡ができるようになった。(2) **MCP サーバーの切断通知**と再接続処理が入った。(3) **セッションのフォーク**機能が追加された（Remote Control のセッションフォークを含む）。

**修正側は権限と認証に集中している。** Bash コマンドの権限判定、特に複合的なシェル構文に対するチェックの漏れが修正された。**Bedrock / Vertex / Foundry での 401 / 403 エラーが修正**され、資格情報に関するエラーメッセージが改善された。そのほか、skill の同期不具合、プロンプトキャッシュの問題、コンテキストメーターの計数誤り、ターミナル描画の不具合、artifact publishing とデータベース書き込みの信頼性、バックグラウンドタスク管理が修正されている。

**LLM ゲートウェイ向けヘッダーは、組織が自前のゲートウェイを挟んで Claude Code を運用する構成を前提にした追加**である。リクエストの分類ができるということは、ゲートウェイ側でコストや用途の可視化・制御が効くようになるという意味になる。

## できるようになったこと

- LLM ゲートウェイがリクエストの分類とコンテキスト圧縮を追跡できるヒントヘッダーを受け取れる
- MCP サーバーの切断を検知して通知し、再接続を試みる
- セッションをフォークして分岐させられる（Remote Control を含む）

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般、LLM ゲートウェイを運用する組織、Bedrock / Vertex / Foundry 経由の利用者
- 対象プラン: 全プラン
- API / UI / 管理者機能: ゲートウェイ向けヘッダー（インフラ）、MCP（連携）、セッション管理（UI）

## 教材化メモ

- **LLM ゲートウェイ向けヘッダーは、企業導入の観点で週次ロールアップの要点候補**である。エージェント CLI のコストが「誰が何に使ったか分からない」形で膨らむのは実務で頻出する問題で、ゲートウェイ側で分類できるようになるのは統制の前提が変わる。**コンテキスト圧縮の追跡ができる点も、コスト分析の粒度に直結する。**
- **Bedrock / Vertex / Foundry の 401 / 403 修正は、クラウド経由で Claude Code を使う組織に効く。** 資格情報エラーのメッセージ改善も含め、「動かないが理由が分からない」系のサポート負荷を下げる変更である。
- **Bash の権限判定、特に複合シェル構文のチェック漏れ修正は、`2.1.270` の権限判定回帰に続く同系統の修正**である。週次では「権限判定の修正が複数版にまたがって続いている」という流れで扱うと分かりやすい。
- セッションのフォークは、長い作業の分岐検証に効く。教材では「やり直しコストを下げる仕組み」として扱える。
