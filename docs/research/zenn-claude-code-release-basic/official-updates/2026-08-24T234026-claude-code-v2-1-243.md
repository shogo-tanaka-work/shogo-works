# 2026-08-24 Claude Code 2.1.243

## 公式内容の日本語要約

Claude Code 2.1.243 が 2026-08-24T23:40:26Z に公開された。前2版（2.1.240 / 2.1.241）が `Bug fixes and reliability improvements` の1行だけだったのに対し、本版は**組織運用に効く設定が4つまとめて入った**まとまりの大きいリリースである。

追加された主な設定は次の4点。**`modelPicker`** は `/model` の選択リストを、順序とラベル付きで組織側が定義できる設定で、Vertex / Bedrock 形式の ID 表記も受け付ける。既定のラインナップに追加する形でも、置き換える形でも使える。**`promptCacheTtl` / `subagentPromptCacheTtl`** は、API キー利用者およびクラウドプロバイダー利用者が、メイン会話のプロンプトキャッシュを1時間に保ちつつサブエージェントは5分に据え置く、といった使い分けを可能にする。**`modelPricing`** は managed setting で、組織の契約単価と割引率を `/cost`・ステータスライン・テレメトリのコスト表示に反映させる。定価ベースの表示から契約実勢へ変わる。

認証面では **`/login` に「Anthropic Console アカウントでサインイン」という鍵レスの選択肢が追加**された（公式表記では recommended）。API キーの発行を許可していない組織でもサインインできるようにするための導線である。

可視性の改善も複数入った。`/usage` に **Loops の内訳**（ループ単位の実行回数・総トークン・1回あたりトークン・最終実行）が追加され、暴走したり冗長になっている `/loop` タスクを見つけやすくなった。`/status` には、上位の managed source が有効なため適用されなかった managed settings ソースを列挙する `Skipped sources` 行と、Claude Code on the web 向けの GitHub 接続状態の行が追加された。`/mcp` と `/plugins` では、組織が認証を管理している claude.ai コネクタに `managed` マーカーが付く。`/tasks` とエージェント詳細ダイアログには、各サブエージェントが動いたモデルと effort level が表示されるようになった。

修正では、**非対話（`-p`）／SDK セッションでリモート MCP サーバーが切断後に復帰しない不具合**が直り、自動再接続または失敗としての報告が行われるようになった。デスクトップアプリ起点の MCP サインインが client ID metadata document 対応サーバー（例: Linear）で `Invalid redirect URI` になる問題、サーバー側の一時的な無効化がキャッシュされ auto mode が起動時に使えなくなる問題、API 過負荷時に auto mode のツール呼び出しが約1分待たされた末に `temporarily unavailable` で拒否される問題も修正された。`/resume` が直近50セッションしか出さなかった制限もスクロール読み込みで解消している。

## できるようになったこと

- `modelPicker` 設定で `/model` の選択リストを順序・ラベル付きで定義できる（Vertex / Bedrock の ID 表記も可）
- `promptCacheTtl` / `subagentPromptCacheTtl` でメイン会話とサブエージェントのプロンプトキャッシュ TTL を分けられる
- `modelPricing` managed setting で、契約単価・割引率を `/cost`・ステータスライン・テレメトリに反映できる
- `/login` → Anthropic Console の鍵レスサインインが選べる（API キーを許可しない組織向け）
- `/usage` に Loops 内訳、`/status` に `Skipped sources` と GitHub 接続状態、`/mcp` `/plugins` に `managed` マーカー、`/tasks` にサブエージェントのモデルと effort level
- 非対話 / SDK セッションのリモート MCP 再接続、auto mode の起動時不可・過負荷時拒否、`/resume` の50件制限などを修正

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。`modelPricing` と `Skipped sources` は managed settings を運用する組織向け
- 対象プラン: `/status` の GitHub 接続表示は Pro / Max 向けの記載。他はプラン限定の明記なし
- API / UI / 管理者機能: 管理者向け設定（`modelPricing`・`modelPicker`・managed settings の可視化）と認証導線の追加を含む
