# 2026-10-01 Claude Code v2.1.287

## 公式内容の日本語要約

CHANGELOG の記載は次のとおり。

- **Claude Mods を追加**。プラグインがより深い挙動を変更できるようになった（詳細は 2026-10-01 の公式ブログ。本メモと対になる `2026-10-01T000000-claude-code-mods.md` を参照）。
- **You should know を追加**。組み込みの mod で、**側で動くサブエージェントが見落としを指摘する**。`/plugin enable cc-plugin-you-should-know@builtin` で有効化（テレメトリ有効のファーストパーティセッション向け）。
- agents ビューに **`n:<text>` フィルタ**を追加。セッション名とタスクに一致し、折りたたまれたセクション内の一致も表示、Enter で最初の一致を開く。
- OpenTelemetry の `user_prompt` イベントに **`prompt_text` を追加**。ドット付きキーを入れ子にするバックエンド向けの `prompt` の複製で、**`prompt` を落としている / マスクしている箇所では `prompt_text` も同様に扱う必要がある**（anthropics/claude-code#70763）。
- **MCP サーバーからの URL プロンプト**に対応（2025-11-25 プロトコル。サインインなど）。**このアップデート後に接続できなくなったサーバーには MCP 設定へ `"bareElicitationCapability": true` を追加する。**

## できるようになったこと

- mods によるプラグインからの深い挙動変更
- `You should know` による見落ち指摘（オプトイン）
- agents ビューの名前・タスク検索
- MCP サーバーの URL プロンプト（サインイン等）

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般
- 対象プラン: 全プラン
- API / UI / 管理者機能: **OTel で `prompt` をマスクしている組織は `prompt_text` の扱いを追加で決める必要がある**。MCP サーバーが接続不能になった場合は設定追加が必要

## 教材化メモ

- **テレメトリに「同じ内容の別キー」が増えたときのマスキング漏れ**。`prompt` を伏せていても `prompt_text` を伏せ忘れればプロンプト本文が外部へ出る。**マスキングをキー名の列挙で実装している場合、アップデートで静かに穴が開く**典型例。対策はキー名の allowlist 方式へ寄せること。
- **後方互換を壊す変更に設定フラグで逃げ道を用意する**やり方（`bareElicitationCapability`）。アップデート後に接続不能という症状と原因の距離が遠いため、**リリースノートを読まないと解決できない**種類の変更である。
- 本リリースはバージョン番号付きのため単独記事化しない（週次ロールアップ対象）。ただし mods は公式ブログの独立発表として別に記事化した。
