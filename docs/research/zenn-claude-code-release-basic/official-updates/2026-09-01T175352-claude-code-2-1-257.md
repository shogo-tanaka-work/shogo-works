# 2026-09-01 Claude Code 2.1.257

## 公式内容の日本語要約

**同日に公開された Claude Fable 5.1（`claude-fable-5-1`、1M コンテキスト）を、既定の Fable モデルとして採用した。** モデル発表とクライアント側の対応が同日に揃った形である。

セキュリティ面では **Containment Escape ルール**が auto mode に追加された。**クラウドのメタデータ資格情報の取得を自動承認の対象から外す**もので、クラウド上で動くエージェントが インスタンスメタデータ経由で資格情報を取りに行く経路を、自動承認では通さないという制御である。

権限まわりではもう1つ、**作業ディレクトリ外のファイルを初めて読む前に、1回だけ確認プロンプトを出す**挙動が入った。

利便性の変更として、`/effort` に **`s` パラメータ**が加わり、セッション限りの effort 変更ができるようになった（`/model` と同じ考え方）。時刻表示の書式カスタマイズ（12時間 / 24時間 / UTC / strftime）にも対応。`/model` のピッカーに **gateway 側から供給されるモデル説明**が表示されるようになった。`/doctor` は古いサンドボックスマスクファイルを警告する。

バグ修正は、`.claude/` フォルダを起動後に作成した場合の設定読み込み遅延、agent view の dispatch セッションが誤った権限モードを継承する問題、`claude agents` での Ctrl+G のリバインド、npm 更新中のバックグラウンドセッション起動失敗、応答ストリーミング中のスピナー停止、バックグラウンドセッション状態ファイルの詳細重複、Completed ビューの並び順など。

## できるようになったこと

- 既定の Fable モデルが Claude Fable 5.1 に
- `/effort s` でセッション限りの effort 変更
- 時刻表示の書式カスタマイズ
- `/model` ピッカーに gateway 供給のモデル説明が出る

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般
- API / UI / 管理者機能: **auto mode の自動承認範囲が狭まる**（Containment Escape）。作業ディレクトリ外の初回読み取りに確認が入る

## 教材化メモ

- **モデル公開とクライアント既定値の切り替えが同日**という点は、運用者にとっては「意図せず新モデルに乗る」ことを意味する。既定値の変更は、明示的に固定していない限り自動で降ってくる——**バージョン固定の要否を判断する材料**になる。
- **Containment Escape**（クラウドメタデータ資格情報の取得を自動承認しない）は、エージェントをクラウド上で動かす際の典型的な攻撃経路への対処。**「エージェントが動く場所」自体が権限境界になる**という理解が要る。
