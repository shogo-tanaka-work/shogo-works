# 2026-08-25 Claude Code 2.1.246

## 公式内容の日本語要約

2.1.246 は、直近では最大級の変更量を持つリリースで、権限・プラグイン・表示・メモリの各領域に手が入っている。

権限まわりで最も重要なのは、**サブコマンドの前にワイルドカードを置いた Bash allow ルール**（例 `Bash(git * main)`）に対して**起動時警告が出るようになった**点である。公式の説明によれば、この書き方は**サブコマンドの前に挿入されたオプションにもマッチしてしまう**。つまり意図より広い範囲を許可している設定が、すでに現場に存在しうる。あわせて `/permissions` に **Auto mode タブ**が追加され、auto mode の classifier ルールを閲覧・編集できるようになった。**末尾に `&&` や `||` がぶら下がった不正なコマンドは、常に承認を要求する**よう修正されている。

セキュリティ面の修正が2件ある。**第三者ゲートウェイ（`ANTHROPIC_BASE_URL`）向けに設定した API キーが、Anthropic 宛のテレメトリ・メトリクス要求に載って送信されていた不具合**が修正され、資格情報は自分のホストにのみ送られるようになった。また `apiKeyHelper` が短命 JWT を返す構成で、アイドル後の最初のプロンプトで API エラーが見えていた問題も直り、期限切れトークンは送信前に更新され、401/403 は静かにリトライされる。

メモリと表示の改善も大きい。フルスクリーンおよび Ctrl+O のトランスクリプト表示で、**セッション長に比例してメモリが増えていた問題**（各行がトランスクリプト全体のツールルックアップの完全なコピーを保持していた）が修正された。base64 のような**極端に長い1行を含む diff でトランスクリプトが極端に遅くなる問題**も、行を切り詰めてマーカー表示する形で解消している。

`/cd` は挙動が変わり、**移動先のプロジェクト設定・hooks・`.mcp.json` サーバー（通常の承認プロンプト経由）・skills・agents が、`--resume` を待たずに移動直後から有効**になる。サブエージェントは `maxTurns` に達した場合、完了したように見せるのではなく**出力を「部分的」と明示して返し、`SendMessage` で継続できるヒントを添える**ようになった。非対話セッション（`-p`、SDK、クラウドセッション）は、サーバーエラーや接続断で途中終了した応答を**自動的に継続**する。

このほか、プラグイン関連の修正が多数（プラグインキャッシュの SHA 名ディレクトリ重複、`<plugin>:` 接頭辞の二重表示、BOM 付き `plugin.json`、`/reload-plugins` が `skills/*/SKILL.md` 形式のスキルを0件と報告する問題など）、`claude agents` のセッション表示、テーマ・キーバインド関連の修正が含まれる。

## できるようになったこと

- サブコマンド前ワイルドカードの Bash allow ルールに起動時警告
- `/permissions` の Auto mode タブで classifier ルールを閲覧・編集
- ターン終了時に完了時刻を表示（例 `✻ Sautéed for 23s · done 6:05 PM`）
- `/cd` 後、移動先の設定・hooks・MCP・skills・agents が即時反映
- サブエージェントの `maxTurns` 到達時に「部分的」と明示して返す
- 非対話セッションが中断された応答を自動継続

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。とくに Bash allow ルールを managed settings で配っている組織
- 対象プラン: 全プラン。第三者ゲートウェイ（`ANTHROPIC_BASE_URL`）利用者は資格情報送信の修正が該当
- API / UI / 管理者機能: 権限設定・プラグイン・テレメトリ
