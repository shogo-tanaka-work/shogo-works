# 2026-08-20 Claude Code 2.1.237

## 公式内容の日本語要約

Claude Code 2.1.237 が 2026-08-20T00:54Z（JST 09:54）にリリースされた。変更は2件と小規模だが、いずれも影響範囲が明確である。

**LLM ゲートウェイまたはカスタム base URL を使うセッションでプロンプトキャッシュが効いていなかった問題が修正された。** 社内プロキシや LiteLLM 系のゲートウェイ経由で Claude Code を使っている組織では、キャッシュが効かないぶん入力トークンを都度フルで送っていたことになる。修正後はキャッシュが効くため、同じ使い方でもコストと応答時間が下がる方向に変わる。

**組み込みの出力スタイルとして `Concise` が追加された。** 前置きを省きつつ、網羅性は維持する方針のスタイルである。既存のカスタム出力スタイルを自前で書いていた場合、標準スタイルで代替できるかを見直す余地がある。

## できるようになったこと

- LLM ゲートウェイ / カスタム base URL 経由のセッションでプロンプトキャッシュが機能
- 組み込み出力スタイル `Concise`（前置きを省略しつつ網羅性は維持）

## 影響範囲

- 対象ユーザー: Claude Code 利用者。特にゲートウェイ経由で利用している組織
- 対象プラン: 全プラン
- API / UI / 管理者機能: CLI（設定・課金への間接影響あり）
