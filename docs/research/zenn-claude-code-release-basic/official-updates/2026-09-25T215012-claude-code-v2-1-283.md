# 2026-09-25 Claude Code v2.1.283

## 公式内容の日本語要約

Claude Code の **v2.1.283** が 2026-09-25T21:50:12Z に公開された。前版は v2.1.282（2026-09-24T18:38:05Z）。

追加されたものは3点。**リクエストのグルーピング用の gateway hint ヘッダー**、**モデルの可用性を制御する managed settings（管理設定）**、**MCP ツールの出力のログ記録**である。

修正は SDK のセッション内ツール呼び出し、MCP の進捗通知、stdio サーバーのクリーンアップに入った。ほかにプラグインの検証強化、モデルピッカーの表示不具合、vim モードのカーソル位置、権限ダイアログのアクセシビリティを含む多数の UI 修正が含まれる。
