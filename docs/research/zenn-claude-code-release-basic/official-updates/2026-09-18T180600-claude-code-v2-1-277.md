# 2026-09-18 Claude Code v2.1.277

## 公式内容の日本語要約

**約100項目が入った大型リリース**である。本メモでは運用判断に効くものだけを拾う。

**AGENTS.md 対応が入った。** CLAUDE.md が無いプロジェクトでは **Claude Code が AGENTS.md を読む**ようになり、どちらを読むかは `/config` の「Project instructions」で変更できる。**Bedrock / Vertex / Foundry ではまだ利用できない。** 本リポジトリのように CLAUDE.md と AGENTS.md を同じ実体へのシンボリックリンクで運用している構成には影響しないが、**片方しか置いていないリポジトリの挙動が変わる。**

**ゲートウェイ／プロキシまわりが2つ増えた。** `CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1` は、外向き通信が forward proxy だけという Claude apps ゲートウェイ向けで、**名前解決をローカルで行わずホスト名をそのままプロキシへ渡す。** あわせて、ゲートウェイの upstream に任意の `headers:` マップを付けて、プロバイダの手前に自前のプロキシを置く構成へ静的ヘッダを送れるようになった。

**サブエージェント出力の扱いが変わった。** サブエージェントの結果は、**サブエージェント出力であることを示すヘッダの下にインデントして**メインエージェントへ渡るようになり、**結果の中のテキストがセッション自身の指示として通らない**ようにした。Bedrock / Vertex / Foundry ではワークフロースクリプトが計算した `agent()` プロンプトも、スクリプト由来のテキストとして枠付けされる。**プロンプトインジェクションの経路を1つ塞ぐ変更**である。

**削除が2つある。** 非推奨だった **TaskOutput ツールが削除**され、バックグラウンドタスクの出力は Read で読む形になった（`taskOutputMaxChars` と `TASK_MAX_OUTPUT_LENGTH` は無効化）。`claude -p` の外部起動時に走っていた Haiku の自動タイトル生成も削除された。

そのほか、`claude -p` / Agent SDK が内部エラー後に無応答でハングする問題、`--resume` を含む「text content blocks must be non-empty」でのリクエスト全失敗、`sandbox.excludedCommands` の glob が**複合 Bash コマンド全体をサンドボックスから外していた**問題（現在は全パートが一致した場合のみ）など、**権限・サンドボックス・資格情報まわりの修正が多数含まれる。**

## できるようになったこと

- CLAUDE.md の無いプロジェクトで AGENTS.md をプロジェクト指示として読める
- forward proxy が唯一の外向き経路であるゲートウェイ構成に対応（`CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1`）
- ゲートウェイ upstream へ静的ヘッダを送れる（`headers:`）
- サブエージェント結果が指示として解釈されない形で受け渡される

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。特にゲートウェイ経由の企業構成、AGENTS.md 運用のリポジトリ、SDK / headless 利用者
- 対象プラン: プラン非依存（AGENTS.md は Bedrock / Vertex / Foundry で未対応）
- API / UI / 管理者機能: プロジェクト指示の読み込み、ゲートウェイ設定、サンドボックス、プラグイン管理、VS Code / Web / Claude Tag

## 教材化メモ

**単独記事にしない（バージョンリリースのため規約により週次ロールアップへ）。** ただし週次で扱うときの主題は **AGENTS.md 対応**にする。

**AGENTS.md は「エージェント横断の共通規約ファイル」への収束の話である。** 本リポジトリが CLAUDE.md / AGENTS.md / `.claude` をすべて `.agents/` へのシンボリックリンクにしているのは、**ツールごとに正本が分かれるのを避けるため**だった。公式が AGENTS.md を読むようになったことで、**シンボリックリンクによる回避策が要らなくなる方向**へ一歩進んだ。ハーネスエンジニアリング教材の「正本を1か所にする」節へ、実装が追いついた例として置ける。

**サブエージェント出力の枠付けは、セキュリティ教材の実例として強い。** 「エージェントの出力を別のエージェントの入力に入れる」構造は、**信頼境界がコードではなくテキストの中にある**。ヘッダとインデントで枠を付けるという対処は素朴に見えるが、**構造で塞ぐ**という原則の実装そのものである。Cloudflare の guardrails 教材と同じ原則で束ねられる。

**TaskOutput の削除は「非推奨は本当に消える」の実例。** 非推奨のまま使い続けた設定（`taskOutputMaxChars`）が無効化される形なので、**設定ファイルに書いてあるのに効かない**という状態が発生する。棚卸しの動機づけに使える。
