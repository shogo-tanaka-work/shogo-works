# 2026-08-27 Claude Code v2.1.248

## 公式内容の日本語要約

日次パッチとしては珍しく、**権限・資格情報・課金の3方向に踏み込んだ**リリース。

**`--restricted`（または `CLAUDE_CODE_RESTRICTED=1`）を追加**。コマンドやコードを実行する組み込みツールと `WebFetch` を（`--tools` で明示指定しない限り）取り除き、ファイル操作は作業ディレクトリ内に限定し、**`bypassPermissions` を拒否し、ユーザー／プロジェクト／ローカルの設定ファイルをすべて無視する**。設定ファイルを無視するという点が重要で、実行環境側の設定で権限を緩められない。

**セキュリティ修正**: `/ultrareview` とローカル起点のクラウドセッションが、**未コミットの `prod.env` 形式ファイルや `*.tfvars`、資格情報ファイルのエディタ swap / 一時 / バックアップ（`key.pem.tmp`、`id_rsa.swo` 等）をアップロードしていた**問題を修正。これらは手元に留まるようになった。

**`/usage-credits` を追加**。AWS Marketplace 経由課金の Enterprise、セルフサーブ Enterprise、Enterprise トライアルの各組織で、メンバーが管理者に上限引き上げを申請できる。あわせて、この機能が使えない組織（`DISABLE_EXTRA_USAGE_COMMAND` で非表示など）に対してレート制限メッセージが `/usage-credits` を案内していた不具合も修正された。

そのほか、エージェント frontmatter の `experimental.cacheTtl`（`"5m"` / `"1h"`）、`claude self-hosted-runner --client-label`、サーバー管理設定の読み込み失敗を `/doctor` と `/status` に出す診断、`/web-setup` で GitHub CLI トークンに `workflow` スコープが無い場合の警告、Bedrock / Vertex / Foundry およびテレメトリ無効時のセッション間メッセージング（`SendMessage` / `ListAgents`）対応が入った。

長時間セッションで OAuth トークン更新後にツール定義が再描画され、**1時間に1回程度プロンプトキャッシュを取りこぼしていた**（拡張思考の文脈も失われていた）不具合も修正されている。Workflow ツールの説明は約5.7k トークンから約1k トークンへ削減され、スクリプト記述のリファレンスは `workflow-authoring` スキルへ分離された。

## できるようになったこと

- `--restricted` / `CLAUDE_CODE_RESTRICTED=1` による制限モード（実行系ツールと WebFetch を除去、作業ディレクトリ外のファイル操作を禁止、`bypassPermissions` 拒否、設定ファイル無視）
- `/usage-credits` による上限引き上げ申請（対象 Enterprise 組織）
- エージェント単位のプロンプトキャッシュ TTL 指定（`experimental.cacheTtl`）
- Bedrock / Vertex / Foundry・テレメトリ無効環境でのセッション間メッセージング

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。特に CI / 共有環境で実行する運用、Enterprise 管理者
- 対象プラン: 全プラン（`/usage-credits` は対象 Enterprise 組織のみ）
- API / UI / 管理者機能: CLI フラグ・環境変数・スラッシュコマンド・管理設定の診断
