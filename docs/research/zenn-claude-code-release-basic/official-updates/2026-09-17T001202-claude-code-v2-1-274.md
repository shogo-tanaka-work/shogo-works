# 2026-09-17 Claude Code v2.1.274

## 公式内容の日本語要約

Claude Code v2.1.274 が 2026-09-17T00:12:02Z に公開された。**運用の安定性まわりの追加と修正が中心**である。

**追加**: メモリ使用量が危機的になったときの可視警告（解放手順と安全な再起動の案内つき）。`CLAUDE_CODE_MCP_STARTUP_WAIT_MS` による、非対話の初回ターンが MCP サーバー接続を待つ上限の設定（`0` で待たない）。OpenTelemetry の `claude_code.llm_request` スパンへの `effort` 属性追加。`claude_code.managed_settings_resolved` OTel イベント（managed settings のソースとポリシーヘルパー状態。`OTEL_LOG_MANAGED_SETTINGS=1` で秘匿設定とダイジェスト）。Claude apps gateway の `store.connect_timeout_seconds`。Claude Desktop / Cowork が gateway 経由で送るテレメトリへの `enduser.sub`（IdP subject）追加。フルスクリーンでの折り畳まれたチームメイト / エージェントメッセージのクリック展開。

**修正**: 「unexpected tool_use_id」400 エラーの無限リトライで詰まる問題（破損トランスクリプトが可能な範囲で自己修復し、それ以外は `/rewind` を案内する明示エラーでループを終わらせる）。`http` 設定の MCP サーバーが legacy HTTP+SSE しか話せない場合に 422 等で接続失敗する問題。Streamable HTTP の MCP ツール呼び出しが、サーバー別 `timeout` を長く設定しても約5分でタイムアウトする問題。403 insufficient_scope が「サインイン期限切れ」と誤報告される問題（不足権限を明示し `/mcp` 再認証へ誘導）。hook 駆動セッション（`/goal` 実行中など）が再圧縮後の溢れで compaction せず「Prompt is too long」で終わる問題。compaction 済みセッションの再開で `/goal` が失われる問題。`claude agents` が自動更新の再起動後に各種フラグを失う問題。

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。特に MCP サーバー運用者、OTel でテレメトリを取っている組織
- 対象プラン: 該当なし
- API / UI / 管理者機能: CLI。`CLAUDE_CODE_MCP_STARTUP_WAIT_MS` と gateway 設定が追加
