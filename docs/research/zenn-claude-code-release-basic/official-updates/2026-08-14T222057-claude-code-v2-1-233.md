# 2026-08-14 Claude Code v2.1.233

## 公式内容の日本語要約

**Todo / タスク追跡ツールが新しいモデルで使えなくなった。**TaskCreate / TaskGet / TaskUpdate / TaskList と TodoWrite が、Opus 4.8、Sonnet 5、Fable 5、Mythos 5 およびそれ以降のモデルでは提供されなくなった。`CLAUDE_CODE_ENABLE_TODO_TOOLS=1` を設定すると戻せる。既存のワークフローが黙って変わる種類の変更である。

**前バージョンの権限変更が一部 revert された。**v2.1.232 で入った Bash の権限変更のうち、Windows の Cygwin 形式シンボリックリンクに関するものと、入力リダイレクト（`< file`）に関するものが巻き戻された。公式は「より狭い範囲の版を後のリリースで戻す」としている。あわせて、Windows で auto mode が通常の `cd <dir> && <command> > file` のような Bash コマンドで繰り返し手動承認を求める v2.1.232 の退行も修正された。

**新たなセキュリティ修正が1件入った。**Windows のパスを NT デバイスプレフィックス（`\??\`）で綴ると UNC パス検証を回避できた問題が修正され、NTLM 認証情報の漏洩ベクトルが塞がれた。

機能追加としては、`--worktree` フラグと `claude agents` ビューが GitLab のマージリクエスト URL に対応した（MR は `!N` として表示される）。Anthropic 上流のアプリゲートウェイに `forward_user_identity` 設定（オプトイン）が加わり、サインイン中のユーザー identity をヘッダーとして送ることで、ゲートウェイの背後のプロキシがユーザー単位に支出を割り当てられる。Linux では Bash ツールのコマンドに対するメモリ cgroup 対応（`CLAUDE_CODE_TOOL_MEMORY_LIMIT`、オプトイン）が入り、暴走したビルドがセッションを止めなくなった。`CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS` で WebFetch のセッション URL キャッシュ TTL を設定できる（既定の15分は変更なし）。

修正では、権限プロンプト待ちの間に環境が停止したときクラウドセッションが失われた扱いになる問題、固定タイムアウトで長時間ストリームを切るサーバー（サーバーレスホスト等）に対して MCP v2 接続が subscriptions/listen ストリームを開き続ける問題、Claude Desktop / VS Code 配下で権限プロンプト時に Notification フックが発火しない問題、サンドボックス有効時に Linux のアイドルセッションが CPU コアを1つ占有し続ける問題などが直った。

その他、`claude self-hosted-runner` のセッション開始が速くなり（作業ツリーを書き換えずにセッションブランチを作成、サーバー往復2回が起動を待たせなくなった）、アプリゲートウェイの 400 / 413 エラーが上流（Vertex、Foundry、Claude Platform on AWS）自身のメッセージを運ぶようになった。print モードでは、Claude Code が認識しないモデル ID へリクエストが出ると stderr に `[claude-code:unrecognized_model]` が出力される（`modelOverrides` で対応付けると消える）。

## できるようになったこと

- `--worktree` と `claude agents` ビューで GitLab のマージリクエスト URL を扱える
- `forward_user_identity` でゲートウェイ背後のプロキシがユーザー単位に支出を割り当てられる
- `CLAUDE_CODE_TOOL_MEMORY_LIMIT` で Bash コマンドのメモリを cgroup 制限できる（Linux）
- `CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS` で WebFetch のキャッシュ TTL を調整できる

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。Windows 利用者、セルフホストランナー運用者、Linux でのサンドボックス利用者への影響が大きい
- 対象プラン: 記載なし（バージョン更新）
- API / UI / 管理者機能: CLI、アプリゲートウェイ設定、環境変数（`CLAUDE_CODE_ENABLE_TODO_TOOLS`、`CLAUDE_CODE_TOOL_MEMORY_LIMIT`、`CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS`）
