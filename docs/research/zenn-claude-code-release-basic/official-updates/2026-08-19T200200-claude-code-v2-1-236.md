# 2026-08-19 Claude Code 2.1.236

## 公式内容の日本語要約

Claude Code 2.1.236 が 2026-08-19T20:02Z（JST 2026-08-20 05:02）にリリースされました。前版 2.1.235 の翌日で、追加は3件、残りは修正と改善です。

**既定モデルの外部指定**として `ANTHROPIC_DEFAULT_MODEL` 環境変数が追加されました。これまで既定モデルは設定ファイルか `/model` での選択に依存していましたが、環境変数で与えられるようになったため、チームや CI ごとに配布する環境で既定を揃えられます。

**セッション横断の `SendMessage` に `notify_when_idle`** が追加されました。別セッションがアイドル状態になったときに通知を受け取れます。複数セッションを並行させる運用で、相手の完了を待つためのポーリングが要らなくなります。

**macOS のサンドボックス**で、ワイルドカードを使った read-deny ルールの扱いが改善されました。読み取り拒否の指定が意図どおりに効くようになる、権限設計側の修正です。

このほか `auto` モードの改善が複数入りました。Monitor の allow ルールの扱いが強化され、複数のクラウドプロバイダー上での `auto` モードの挙動が改善されています。`/usage` の表示は Team / Enterprise メンバー向けに変更され、`/goal` のアイドルセッション判定タイミング、`/model` ピッカーのハイライト挙動、slash コマンドのエラー処理も変わりました。print / SDK モードでの SIGTERM の扱いが変更されている点は、CI やスクリプトから呼ぶ側に影響します。

修正はディレクトリ削除後のクリップボードコピーとバックグラウンド処理、フルスクリーンレンダラーのフォールバック、`/model` ピッカーの描画、`SendMessage` の閉じタグ不正、サブプロセス失敗時の未処理 Promise 拒否、ターミナルリサイズ後のフルスクリーン表示、managed-settings の承認プロンプトのタイミング、tmux でのターミナルタブタイトルの跳ね、git status チェックの設定処理など広範囲です。VSCode ではトランスクリプトのスクリーンリーダー対応が入りました。

## できるようになったこと

- `ANTHROPIC_DEFAULT_MODEL` で既定モデルを環境変数から指定
- セッション横断 `SendMessage` の `notify_when_idle` でアイドル通知を受け取り
- macOS サンドボックスのワイルドカード read-deny ルールが正しく適用される
- `auto` モードが Monitor の allow ルールを扱えるようになり、複数クラウドプロバイダー上でも改善
- VSCode でトランスクリプトのスクリーンリーダー対応

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。特に CI / SDK から呼ぶ利用者（SIGTERM 挙動変更）、macOS でサンドボックス設定を書いている管理者、複数セッション並行運用者
- 対象プラン: 全プラン。`/usage` 表示の変更は Team / Enterprise メンバー向け
- API / UI / 管理者機能: 環境変数と managed-settings まわりの変更を含むため、配布設定を持つ組織は確認対象
