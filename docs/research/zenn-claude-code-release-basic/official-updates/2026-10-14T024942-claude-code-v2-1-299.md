# 2026-10-14 Claude Code v2.1.299

## 公式内容の日本語要約

**アイドル圧縮（idle compaction）が入った。** 200K トークンを超える会話を約54分放置すると、**1時間のプロンプトキャッシュが切れる前に圧縮する。** `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` で 200K の下限を変更でき、settings.json の `"idleCompaction": false` で無効化する（どちらも v2.1.290 以降が必要）。**キャッシュの寿命に合わせて自動で動く挙動が増えた**点が運用上の変化である。

**`CLAUDE_CODE_DISABLE_FILE_MENTIONS` が追加された。** `@` でファイルを指定したとき、**内容そのものではなくパスだけを渡し、Claude は自分のファイルツールで読む。** 文脈へ一括投入する既定の挙動を止められる。

**agent view に `/effort` と `/fast` が入り、新しいセッションの開始値を設定できる。** mod 向けには `$.prompt.media`（managed settings 経由で導入された mod の `prompt.submit` フックが添付画像・文書のバイト列を読める）、`$.session.identity()`、`Text` の `size` / `weight` / `mono` / `tabular`、`Box` の名前付き spacing（`xs`〜`xl`）が追加された（`bold` は `weight` に置き換えて非推奨）。

**セキュリティ・正しさに関わる修正が複数ある。** plan mode が `PreToolUse` / `tool.check` フックで許可された書き込みを実行しなくなった。`mcp__<server>` の deny / ask ルールが、正規化後のサーバー名に二重アンダースコアを含む場合にも適用されるようになった。**Write が Windows-1252 / Shift-JIS / GBK / UTF-16BE のファイルを黙って UTF-8 へ変換するのを拒否するようになった**（日本語環境では効く修正である）。Read は BOM 付き UTF-16LE を正しく扱う。

**スケジュール関連の修正も入っている。** `ScheduleWakeup` が Agent SDK / IDE / `claude remote-control` セッションでバックグラウンドタスク実行中にも発火する。**スケジュール済みタスクが、夏時間終了時の重複する1時間に再発火・早発火しなくなった。**

その他、`claude self-hosted-runner orchestrator` の `--shutdown-drain-sec`、`claude plugin eval` の `--disallow-tools` と `disallowed_tools`、`session.append` mod フックの `queue` door、`/usage` の警告追加（max effort / workflows / always-on context / 大きなツール結果）、Claude Desktop の Code タブでの `CLAUDE_CODE_ATTRIBUTION_HEADER=0` 対応、Claude in Slack のキャンバス削除。

## できるようになったこと

- 長時間アイドルの会話がキャッシュ失効前に自動圧縮される（下限と無効化を設定可能）
- `@` メンションでファイル内容を文脈へ入れず、パスのみを渡せる
- agent view から新規セッションの effort / fast を設定できる
- MCP の deny / ask ルールが二重アンダースコアを含むサーバー名でも効く
- 非 UTF-8 ファイルの意図しない変換が起きない

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。mod 開発者と self-hosted runner 運用者に追加 API あり
- 対象プラン: 記載なし
- API / UI / 管理者機能: CLI、settings.json、環境変数、mod API、VS Code / Slack 連携

## 教材化メモ

- **単独記事にしない（判定D）。** バージョン番号付きリリースのため、規約どおり週次ロールアップへ回す。セキュリティ・権限関連の修正を含むが、**この2ツールはほぼ毎回含むため中身で判定しない。**
- **アイドル圧縮は「キャッシュの寿命が UX を決める」例として教材価値が高い。** 54分という数字は1時間のプロンプトキャッシュから逆算されている。**課金構造が機能設計に出てくる**典型例で、週次ロールアップの要点に向く。
- **Shift-JIS の黙示変換を拒否する修正は、日本語環境向けの注意点としてそのまま使える。** 既存の挙動で壊れていたファイルがあり得るため、**過去の変換を疑う必要がある**という形で伝える。
