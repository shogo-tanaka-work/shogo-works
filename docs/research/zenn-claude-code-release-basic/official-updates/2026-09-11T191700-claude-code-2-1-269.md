# 2026-09-11 Claude Code v2.1.269

## 公式内容の日本語要約

Claude Code の **v2.1.269** が公開されました（前バージョン 2.1.268 は 09-10T20:30Z）。

新機能の中心は **`claude plugin eval`** です。プラグインの eval スイートを Claude Code に対して実行し、**再現可能な JSON および HTML レポート** を出力します。プラグイン開発の品質検証を、手元の試行ではなく回帰可能な形へ移す機能です。

**`/output-style [name]`** も追加されました。セッションをまたいで output style の一覧表示と切り替えができます。

Bash ツールの編集について、**`bashEditDiffEnabled`** によるファイル差分表示が加わりました。Bash 経由の編集が何を変えたかを差分で確認できます。

運用面では **OpenTelemetry メトリクスへのリポジトリ属性タグ付け**（`OTEL_METRICS_INCLUDE_REPOSITORY`）と、**LLM ゲートウェイのモデル探索タイムアウト延長**（`CLAUDE_CODE_GATEWAY_MODEL_DISCOVERY_TIMEOUT_MS`）が追加されています。

修正は、プロンプトキャッシュの無効化、ターミナル互換性、権限ルール、MCP サーバーの再接続、再開セッションのトランスクリプトなど複数にわたります。

## できるようになったこと

- `claude plugin eval` によるプラグイン eval スイートの実行と JSON / HTML レポート出力
- `/output-style [name]` での output style の一覧・切り替え（セッション横断）
- `bashEditDiffEnabled` による Bash ツール編集のファイル差分表示
- `OTEL_METRICS_INCLUDE_REPOSITORY` でのリポジトリ属性付きメトリクス
- `CLAUDE_CODE_GATEWAY_MODEL_DISCOVERY_TIMEOUT_MS` によるゲートウェイ探索タイムアウト延長

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般（プラグイン開発者への影響が大きい）
- 対象プラン: 記載なし
- API / UI / 管理者機能: CLI / 設定・環境変数
