# 2026-09-01 Claude Code 週次上限プロモーションの延長

教材化メモ: src/content/ai-news-notes/claude-code/weekly-limits-promotion-extended.mdx

## 公式内容の日本語要約

**8/28 から日次サマリーで「保留（公式未確認）」として持ち越していた、Claude Code の週次利用上限の扱いが確定した。**

公式ヘルプセンター記事が更新され（取得時の表示は `Updated today`）、**期間が「2026-05-13 から 2026-09-13 まで」に書き換えられた。** 記事には「We've extended this promotion. Increased weekly limits now run through September 13, 2026.」と明記されている。

内容は従来どおりで、**週次の利用上限が標準の +50%**。5時間ごとの利用上限には適用されない。対象は Pro / Max / Team および旧来のシート課金型 Enterprise プランで、Free と従量課金型 Enterprise は対象外。**2026-09-13 を過ぎると標準水準に戻り、課金内容の変更はない。**

**重要な点として、公式記事には「09-14 から恒久 +25%」という記載は存在しない。** 前日までのサマリーで保留にしていた X 投稿ベースの情報は、**本日時点でも公式面からの裏付けが取れていない。** 公式が明示しているのは「09-13 までの +50%、その後は標準水準へ復帰」だけである。`anthropic.com/news` と `claude.com/blog` にも、恒久増枠に関する告知は出ていない。

**当初の期限は 2026-08-31 23:59 PT（= 2026-09-01 15:59 JST）だった。** つまり、期限当日に延長が発表された形になる。前日のサマリーで「次回実行時には期限を過ぎているため最優先で確定させる」としていた項目が、これで解消された。

## できるようになったこと

- 週次上限 +50% の適用期間が **2026-09-13 まで**（従来は 2026-08-31）に延長された
- 対象プラン利用者は、追加の申請や設定なしで延長の恩恵を受ける

## 影響範囲

- 対象ユーザー: Claude Code の Pro / Max / Team / 旧シート課金型 Enterprise
- 対象外: Free、従量課金型 Enterprise
- 対象プラン: 週次上限のみ。5時間ごとの上限は対象外
- API / UI / 管理者機能: 設定変更は不要。**2026-09-13 経過後に標準水準へ戻る点だけが運用上の論点**
