# 2026-10-31T01:01:00Z Claude Code v2.1.316

## 公式内容の日本語要約

`CLAUDE_CODE_DISABLE_ULTRATHINK`（ultrathink キーワードを無効化）、`CLAUDE_CODE_SUBAGENT_EFFORT`（サブエージェントの effort 指定）、`CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP` を追加。Claude apps gateway にグループ共有の月額予算（`pooled_budget`）、`managed.policy_mode: layered`、Bedrock の `guardrail.input_tagging` を追加。**Opus 4.8 の fast mode を 2026-10-30 付で非推奨化し、2026-11-30 に削除（削除後は fast mode のリクエストがエラーになり、通常の Opus 4.8 にはフォールバックしない。Opus 5.5 への移行を案内）。** macOS/Linux で終了時にシェルコマンドが残る問題、Bash ツールのエイリアス・SHELLOPTS 関連、PowerShell フックの exit code 2 などを修正。
