# 2026-08-21 Claude Code 2.1.239

## 公式内容の日本語要約

Claude Code 2.1.239 が 2026-08-21T19:54Z（JST 2026-08-22 04:54）にリリースされた。前版 2.1.238 の約23時間後で、変更点は60項目を超える。大半は修正だが、コスト表示・移行支援・プラットフォーム対応に実務上の意味がある追加が含まれる。

**コスト見積もりにデータレジデンシー分のプレミアムが反映されるようになった。** US-only inference を使うデータレジデンシー構成のワークスペースでは、実際の課金に 1.1倍のプレミアムが乗る。これまで Claude Code 内の見積もりはその係数を含んでいなかったため、表示額と請求額がずれていた。データ所在地の制約で US-only を選んでいる組織にとっては、見積もりの前提が変わる変更である。

**`/claude-api upgrade` が追加された。** Python プロジェクトを `anthropic` 0.x から 1.x へ移行するコマンドで、SDK のメジャーバージョン移行を Claude Code 側から実行できる。

**Windows でセッション横断メッセージングが利用可能になった。** これまで macOS / Linux に限られていた機能で、`SendMessage` による複数セッションの連携が Windows でも組める。あわせて `ListAgents` が自セッションの名前を返すようになり、稼働中のチームメイトも一覧に出るようになった。

**Bedrock / Vertex / Foundry など、これまで対象外だった構成でもフルスクリーンレンダラーの案内が出るようになった。** Alpine / musl ビルドでは画像ペースト・クリップボード・音声キャプチャのアドオンが読み込まれるようになり、ビルド種別による機能差が縮んだ。クラウドセッションでは claude.ai から同期されたプラグインが `name@synced` として表示される。

修正側では、HTTPS プロキシ配下で Bedrock と SSO プロファイルを併用したときの起動ハング、プロキシが Content-Type を落とす環境での Bedrock ストリーミング、`WebFetch` が期限切れページをセッション中ずっとメモリに保持する問題、会話が約64KBを超えるとカスタムセッションタイトルが `/resume` から消える問題などが直っている。JetBrains IDE のターミナルで Edit / Write が約5秒止まる問題、`PreToolUse` フックで遅延したツール実行が OpenTelemetry のトレースを分断する問題も対象に含まれる。

## できるようになったこと

- データレジデンシー構成（US-only inference）のコスト見積もりに 1.1倍プレミアムが反映される
- `/claude-api upgrade` で Python プロジェクトを `anthropic` 0.x → 1.x へ移行
- Windows でセッション横断メッセージングが利用可能に
- `ListAgents` が自セッション名と稼働中のチームメイトを返す
- Alpine / musl ビルドで画像ペースト・クリップボード・音声キャプチャが動作
- クラウドセッションで claude.ai 同期プラグインが `name@synced` 表示に
- 月次上限到達時のメッセージにセッション／週次上限のリセット時刻が出る

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般、特にデータレジデンシー構成の組織、Windows 利用者、Bedrock / Vertex / Foundry 経由の利用者
- 対象プラン: 全プラン（データレジデンシーは該当ワークスペースのみ）
- API / UI / 管理者機能: CLI / コスト表示 / プロキシ・ゲートウェイ経由の接続 / OpenTelemetry
