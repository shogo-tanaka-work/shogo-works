# 2026-09-10 Claude Code v2.1.268

## 公式内容の日本語要約

**バージョン番号付きリリースのため、単独記事化はしない（`見送り（週次ロールアップへ）`）。** 内容で判定しない規定に従う。以下は週次ロールアップ向けの抽出である。

**本リリースは秘密情報の露出修正が2件ある。** `plugin/marketplace` のエラー表示が資格情報を含んでいた問題、および **MCP・プラグインのサーバー詳細が secrets を露出していた**問題が修正された。どちらも「ログやエラー画面に認証情報が出る」系であり、**共有画面・CI ログ・バグ報告を経由して漏れる**経路になる。週次で扱う際は冒頭に置く。

権限まわりも複数ある。**シンボリックリンク先ディレクトリで権限ルールが正しく適用されていなかった**問題の修正、空のアクセス制御リストと public address リクエストに対する起動時警告の追加、`WebFetch` の deny ルールのスコープ変更。

ゲートウェイ運用向けの追加が目立つ。**Claude apps のゲートウェイ価格設定**（クライアント間のレート整合）、**`gatewayInternalNetworks` 設定**（内部ゲートウェイからのログイン許可）、`claude auth status --json` への `configDirectory` 追加。

その他の挙動変更として、**`WebFetch` が無期限にハングしなくなり 300 秒で失敗**するようになった。**アイドル状態のセッションで CPU 使用率が高止まりする問題**、**組織既定モデルへ無言で切り替わる問題**も修正されている。プラグインコマンドに `--json` フラグが追加された。

VSCode 拡張、Claude Code on the web、Claude Tag、Code Review にも多数の修正が入っている。

## できるようになったこと

- `gatewayInternalNetworks` による内部ゲートウェイログイン
- `--remove-session-state` によるセッション状態の削除
- プラグインコマンドの `--json` 出力
- 空のアクセス制御リストに対する起動時警告

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般（特にゲートウェイ経由の組織利用）
- 対象プラン: 全プラン
- API / UI / 管理者機能: CLI / 拡張 / 管理設定
