# 2026-10-07 Claude Code v2.1.293

## 公式内容の日本語要約

Claude Code の v2.1.293 が公開された。CHANGELOG と releases の記載から、主な内容は次のとおり。

**モデル既定値の変更**: Anthropic API 上の既定 Haiku モデルとして **Claude Haiku 5.5 を採用**した。同日に公開された Haiku 5.5（`claude-haiku-5-5`）が、Claude Code 内のサブエージェントや軽量処理に回る側の既定になったということである。

**API 追加**: サブエージェントのステータスライン payload に `agentType` を追加。`$.tool.register` に `isDeferred` を追加。いずれも mod / プラグイン側から、動いているサブエージェントの種類と、ツールが遅延登録されたかどうかを判別できるようにするもの。

**修正**: コンテキストの compaction、メモリリーク、キューに入れたメッセージの消失、サインアウト時の挙動に関する複数の不具合を修正。加えて、以前の変更2件を revert している。

直前の v2.1.292（2026-10-06）は `claude plugin install` の `--marketplace` オプション、Agent tool の `effort` パラメータ、mod のモデル呼び出しへのプロンプトキャッシュ、および UNC パス読み取りとプロキシ処理のセキュリティ修正を含んでいた。v2.1.291（同日）はそのリグレッション修正だった。

## できるようになったこと

- Claude Code 内の Haiku 系処理が Haiku 5.5 の速度・価格で動く
- mod から `agentType` と `isDeferred` を参照できる

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般（既定モデルが変わる）
- 対象プラン: Claude Code 全プラン
- API / UI / 管理者機能: CLI、mod / プラグイン API

## 教材化メモ

- **「既定モデルが静かに変わる」ことの扱いが教材価値の中心である。** Haiku 5.5 は Haiku 4.5 とトークナイザが違い、同じ文章が約30%多いトークンになる。**既定が切り替わると、利用量の見え方が変わる。** Claude Code の消費を測っている組織には、バージョン更新日を跨いだ比較が成立しなくなる期間が出る。測定の基準日をリリース単位で持つという運用を、この例で教えられる。
- **バージョン番号付きリリースなので単独記事にはしない。** 判定 D（週次ロールアップへ）。`selection-rubric.md` の「日次リリース型ツールの扱い」に従い、タイトルにバージョン番号が付くリリースは内容にかかわらず単独記事化しない。既定モデルの変更という実質的な内容を含むが、**中身で判定すると版数の羅列に戻るため、機械的な線を維持する。** 週次ロールアップの「今週の要点」で、既定 Haiku モデルの切り替えに触れる。
