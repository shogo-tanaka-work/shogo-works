# 2026-10-06 Claude Code v2.1.291

## 公式内容の日本語要約

CHANGELOG の記載は2件のみで、いずれもリグレッション修正である。**2.1.290 で cloud session が権限プロンプトへの回答を落とすことがあった問題**と、**2.1.288 でセッション終了時に最後のメッセージが失われることがあった問題**を修正した。

新機能・仕様変更は含まれない。**前日（2.1.290）で入った cloud session 周りの変更を即日で追い直す形の緊急修正**であり、クラウド実行を常用している場合は更新した方がよい。

## できるようになったこと

- cloud session で権限プロンプトの回答が落ちなくなった（2.1.290 のリグレッション）
- セッション終了時に最後のメッセージが失われなくなった（2.1.288 のリグレッション）

## 影響範囲

- 対象ユーザー: Claude Code 利用者（特に cloud session 利用者）
- 対象プラン: 全般
- API / UI / 管理者機能: CLI

## 教材化メモ

- **バージョン番号付きリリースのため単独記事化しない（週次ロールアップへ）。**
- **2.1.290 → 2.1.291 が同日内の修正である点は、「最新版に即座に上げる運用」の是非を扱う教材の実例になる。** クラウド実行で権限プロンプトの回答が落ちるのは、自律実行を止める種類の不具合である。**常用環境では1〜2版待つ**という運用判断の具体例として使える。
