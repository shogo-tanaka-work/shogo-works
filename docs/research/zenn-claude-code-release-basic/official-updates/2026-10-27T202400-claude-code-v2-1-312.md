# 2026-10-27 Claude Code v2.1.312

## 公式内容の日本語要約

Claude apps gateway に `oidc.user_id_claim` を追加し、`sub` 以外の id_token クレーム（Microsoft Entra ID の `oid` など）で利用者を識別できるようにした。fullscreen では、キュー済みメッセージの「to send now」表示をクリックして即送信できる。

修正は、VS Code 拡張でサインイン後に managed settings が取得されなくなる問題、巨大な CLAUDE.md を先頭だけ読んで上書きする問題（Write は全文読込か in-place 編集を促す）、Bash の `cd` 後に skills が見つからない問題、`claude -p` が無出力になる問題、PDF 読込の失敗など多数。

変更点として、Bedrock / Vertex / Foundry / Mantle で未知のモデル名（カスタムデプロイ名など）に短い system prompt を使うようにし（`CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0` で従来動作）、拒否後の自動モデル切替も未知モデル名に拡張した（`CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1` で無効化）。使用上限の表示は「5-hour limit」に変更。prompt / agent hooks はセッションあたり同時24件までに制限された。

記事化判断: 見送り（週次ロールアップへ）。バージョンリリースのため機械的に判定D。

## 影響範囲

- 対象ユーザー: Claude Code 利用者、Bedrock / Vertex / Foundry 経由の管理者
