# 2026-08-28 Claude Code 2.1.251

## 公式内容の日本語要約

Claude Code の大型リリース。100項目を超える変更が入っている。

**Added** の主なものは、**`PreModelSwitch` / `PostModelSwitch` フックイベント**（モデル切替をブロック・確認・注記できる）、**フォアグラウンドのサブエージェントのツール呼び出しと結果を Remote Control クライアントへライブ配信**、`/usage` への **Spend limit バー**と `rate_limits.spend_limit` ステータス項目、`/cost` への**セッション単位のプロンプトキャッシュ行**（ヒット率・ミス・再キャッシュされたトークン・warm/cold）、`claude --help` への `attach` / `logs` / `stop` / `respawn` / `rm` の追加である。

**Fixed** はセキュリティ系が目立つ。**ファイルツール（Read / Write / Edit）が、権限チェック後に作業ディレクトリ内で差し替えられたシンボリックリンクを辿り、承認済みの場所の外を読み書きできた問題**を修正。**マーケットプレイスエントリで宣言されたプラグインコマンドがプラグインディレクトリの外を指せた問題**（パストラバーサルとして拒否するよう変更）。**プロジェクト設定から詳細ベータトレーシングや生 API ボディのログを有効化できた問題。** **Grep / Glob がシンボリックリンク経由の検索パスに `Read(...)` の deny ルールを適用していなかった問題。** ほかに Opus 5 で effort=xhigh/max かつ thinking 無効時にリクエストが失敗する問題など、70件超の修正が並ぶ。

**Changed** では、**サンドボックスの TLS 終端・自前プロキシ経由のルーティング・資格情報注入・サンドボックス分離の弱体化を行うサーバー管理設定に、適用前の承認を必須化**した。`ANTHROPIC_CUSTOM_HEADERS` も、資格情報・組織／テナント・ルーティング・API 挙動に関わるヘッダーを設定する場合は承認が要る。`CLAUDE_CODE_SUBAGENT_MODEL` は上書きではなく既定値の設定に変わり、`/effort` はモデルごとに既定値を保存するようになった。**seat 型 Enterprise 契約の既定モデルが Opus 5 に変更**された。

## できるようになったこと

- モデル切替をフックで制御できる（`PreModelSwitch` / `PostModelSwitch`）
- `/cost` でセッション単位のプロンプトキャッシュ効率を確認できる
- `/usage` で Spend limit を確認できる

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。特にサーバー管理設定を配布している組織
- 対象プラン: 全般（seat 型 Enterprise は既定モデルが Opus 5 へ）
- API / UI / 管理者機能: 管理設定の承認要件が広がるため、配布済み設定の再承認が発生しうる

## 教材化メモ

- **「権限チェックの後に対象が差し替わる」タイプの脆弱性**（TOCTOU）が、シンボリックリンク経由で複数箇所（ファイルツール、Grep/Glob の deny ルール、プラグインコマンドのパス）に出ている。**チェックした対象と実際に操作する対象が同一であることを保証する**という原則を、実物の修正リストで説明できる良い教材。
- **「設定ファイルが権限を弱められる」問題の扱い方**として、サーバー管理設定のうち危険なもの（TLS 終端・プロキシ・資格情報注入・サンドボックス弱体化）だけ承認を必須にした設計は参考になる。**全部承認にすると形骸化し、全部素通しにすると危ない**という中間解の実例。
- 本リリースはバージョン番号付きのため単独記事にはしない。セキュリティ修正を含むが、この2ツールはほぼ毎回含むため、週次ロールアップの「今週の要点」冒頭で対応要否を明示する扱いとする。
