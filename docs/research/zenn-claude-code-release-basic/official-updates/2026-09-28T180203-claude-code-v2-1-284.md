# 2026-09-28 Claude Code v2.1.284

## 公式内容の日本語要約

**Claude Sonnet 5.5（`claude-sonnet-5-5`）が Anthropic API 上の既定 Sonnet モデルとして追加された。** 1M コンテキスト、$2/$10 per MTok、キャッシュ読み出し $0.20/MTok。

**権限周りの変更が2件ある。** 1つは auto mode のプロンプトに **「Yes, but ask again next time」**（作業ディレクトリ外の読み取りを1回だけ許可し、次回は再度確認する）が追加された。もう1つは**対話ターミナルと VS Code のセッションが、permission mode 未設定なら全プラン・全プロバイダーで auto mode で起動するようになった**（`permissions.defaultMode` は従来どおり優先）。

**課金可視化**として、`/usage` とステータスラインに Claude apps gateway の支出上限が**金額で表示**される（例: "$271.40 / $500.00 spent this month"）。ステータスラインの `rate_limits.spend_limit` に `used_usd` / `limit_usd` / `period` が追加。

**管理設定・セキュリティ関連の修正**が複数含まれる。`ANTHROPIC_FOUNDRY_RESOURCE` が検証なしに Foundry エンドポイントのホストへ補間されていた問題の修正、managed settings の `allowManagedPermissionRulesOnly` 下でプラグインが `allowed-tools` により自分のツールを自己承認できていた問題の修正、プロジェクト外から `.claude/rules` へシンボリックリンクされたルールが承認プロンプトなしにスキップされていた問題の修正、`MEMORY.md` と recall メモ内の不可視文字・擬似マークアップの無害化。

その他、`/mcp reconnect all` の追加、Ultracode を `/effort` 内の独立トグルへ変更、圧縮後も残る "Prompt is too long" の再圧縮対応、VS Code / Claude Tag / Code Review 側の多数の修正。

## できるようになったこと

- Sonnet 5.5 を既定 Sonnet として利用（1M コンテキスト）
- auto mode の「今回だけ許可、次回も確認」選択
- `/usage` とステータスラインでの支出金額表示
- `/mcp reconnect all` による失敗した MCP サーバーの一括再接続

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般、managed settings を使う組織
- 対象プラン: 全プラン（auto mode 既定化は全プラン・全プロバイダー）
- API / UI / 管理者機能: 既定モデル、既定 permission mode、managed settings の権限検証

## 教材化メモ

- **バージョンリリース扱いのため単独記事にしていない**（`selection-rubric.md` の「日次リリース型ツールの扱い」）。**auto mode の全プラン既定化と Sonnet 5.5 既定化は週次ロールアップの冒頭で扱う。**
- **セキュリティ修正が4件含まれる**点は週次ロールアップの「今週の要点」で明示する必要がある。特に managed settings 下でのプラグイン自己承認と、`.claude` シンボリックリンク経由のルール読み込みは、組織で配布している設定の見直しにつながる。
- Sonnet 5.5 そのものは Claude（Anthropic）側の発表として単独記事化した（src/content/ai-news/claude/sonnet-5-5-default-breaking-changes.md）。
