# 2026-09-01 Claude Code 2.1.258

## 公式内容の日本語要約

**2.1.255 で入った回帰により macOS 12（Monterey）で Claude Code が起動しなくなっていた問題を修正した。** 同日中に 2.1.257 → 2.1.258 と2本が出ており、後者は回帰修正が主眼である。

もう1つの修正は、**リモートセッションとスケジュールセッション**で、権限承認の再送に失敗した後に `user messages must have non-empty content` エラーが発生する問題。

新規要素として、**`CLAUDE_CODE_SUBAGENT_MODEL_FORCE` 環境変数**が追加された。サブエージェントに適用するモデルを一貫させるためのもので、サブエージェントが親と異なるモデルで走ることを防げる。

2.1.257 で入った項目（Containment Escape ルール、`/effort` のセッション限り指定、`/doctor` の古いサンドボックスマスク警告、作業ディレクトリ外の初回読み取り確認、`/model` ピッカーの gateway 供給説明）も本リリースの CHANGELOG に併記されている。

バックグラウンドセッションまわりの修正も継続している。npm 自己更新中の起動失敗（macOS）と Windows のデーモンロック、削除済みディレクトリからのバックグラウンドセッションのエラー報告改善、Completed ビューの完了時刻順ソートなど。

## できるようになったこと

- macOS 12（Monterey）で再び起動できる
- `CLAUDE_CODE_SUBAGENT_MODEL_FORCE` でサブエージェントのモデルを固定できる

## 影響範囲

- 対象ユーザー: **macOS 12 利用者は 2.1.255〜2.1.257 で起動不能だった可能性がある**。本リリースで解消
- API / UI / 管理者機能: サブエージェントのモデル制御が環境変数で可能に

## 教材化メモ

- **2.1.255 の回帰が 2.1.258 まで残った**という事実は、日次リリース型ツールの現実的なリスクを示す。**最新版へ自動更新する運用は、回帰を最短で踏む運用でもある。** 一方で修正も速い——どちらを取るかは、業務の停止許容度で決める話になる。
- **`CLAUDE_CODE_SUBAGENT_MODEL_FORCE` は、コスト管理の観点で価値がある。** サブエージェントが高価なモデルで走ると、親の指定だけ見ていては費用が読めない。**「どのプロセスがどのモデルを使うか」を明示的に固定できることは、予算統制の前提**である。
- 記事化は見送り（判定D・バージョン番号付きリリースのため週次ロールアップへ）。
