# 2026-08-20 Claude Code 2.1.238

## 公式内容の日本語要約

Claude Code 2.1.238 が 2026-08-20T20:33Z（JST 2026-08-21 05:33）にリリースされた。同日 2本目のリリースで、前版 2.1.237 の約20時間後にあたる。

**`keybindingFlavor` 設定が追加**され、Readline 形式の `Ctrl+W` 挙動を選べるようになった。ターミナル操作の癖が既存のシェル操作と揃う。

**プラグインマーケットプレースが `headersHelper` に対応**した。HTTP ヘッダーを発行できるため、認証が必要な社内マーケットプレースをホストする構成が取りやすくなる。プラグイン配布を社内に閉じたい組織に効く変更である。

**`claude self-hosted-runner --defer-shutdown-max-min` が追加**され、セルフホストランナーを猶予付きで停止できるようになった。実行中のジョブを打ち切らずに落とす運用ができる。

**長時間の対話セッションでメモリが無制限に増える問題が修正された。** 1日中同じセッションを開いたまま使う運用では、これまで再起動でしのぐしかなかった可能性がある。あわせて、**セッション途中でカスタム出力スタイルが既定に戻ってしまう問題**も修正された。

このほか MCP サーバー、Remote Control、権限プロンプト、ターミナル処理まわりに複数の修正が入っている。

## できるようになったこと

- `keybindingFlavor` 設定で Readline 形式の `Ctrl+W` 挙動を選択
- プラグインマーケットプレースが `headersHelper` で HTTP ヘッダーを発行（認証付き社内マーケットプレース）
- `claude self-hosted-runner --defer-shutdown-max-min` による猶予付きシャットダウン
- 長時間セッションのメモリ増加とカスタム出力スタイルの巻き戻りを修正

## 影響範囲

- 対象ユーザー: Claude Code 利用者、セルフホストランナー運用者、プラグイン配布側
- 対象プラン: 全プラン
- API / UI / 管理者機能: CLI / プラグイン配布 / セルフホスト運用
