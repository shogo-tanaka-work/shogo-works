# 2026-09-14 Claude Code v2.1.271

## 公式内容の日本語要約

Claude Code の `2.1.271` が 2026-09-14T22:12:54Z に公開された。前版 `2.1.270`（09-12T19:45Z）から2日ぶりで、Added 8件・Fixed 約40件・Improved 8件という構成である。**Fixed の比率が高く、うち Bash の権限判定に関する修正が4件まとまっている。**

追加分で実務に効くのは3点である。1点目は **Bash / PowerShell / Monitor に対するコマンド単位の `allowed_domains`**（auto モード + サンドボックス時）。コマンドが必要とするホストをそのコマンドと一緒に承認し、**そのコマンドに限って開ける**。他のホストは拒否される。2点目は **`modelPricing` 管理設定と Claude apps gateway の `pricing` ブロックで 1 を超える `multiplier`（最大10）を許容**したこと。社内チャージバックで上乗せレートを使う用途向けである。3点目は **agent frontmatter と `--agents` JSON への `omitClaudeMd`** で、カスタム / プラグインのサブエージェントを user / project / local の CLAUDE.md なしで走らせられる（managed policy ファイルは引き続き読み込まれる）。

その他、**Remote セッション（クラウド・セルフホストランナー）での fast mode 対応**、`/config` パネルのマウス操作、`claude self-hosted-runner --drain-marker-file`、`claude plugin install` / `update` の `--accept-command <sha256>` が入った。

修正側では、**組織ポリシーのキャッシュが account / organization / API キー切り替え後も再利用される**問題、**読めない・パースできない enterprise `managed-mcp.json` が無視されていた**問題（今後は MCP の排他制御を維持して起動時に警告する）、`ANTHROPIC_UNIX_SOCKET` 経由のサードパーティローカルプロキシで組織ポリシー取得が拒否される問題が直った。**いずれも企業の統制設定が意図せず外れる形の不具合である。**

## できるようになったこと

- auto モード + サンドボックスで、**コマンド単位に許可ホストを絞る**（`allowed_domains`）
- サブエージェントを **CLAUDE.md 非読み込みで起動**する（`omitClaudeMd`）
- `modelPricing` / gateway `pricing` で **1 超〜10 倍の multiplier** を設定する
- Remote セッションで **fast mode を使う**（組織が許可する場合）
- `claude plugin install` / `update` で **直前の `--json` 表示と同一のコマンドだけを承認**する（`--accept-command`）

## 影響範囲

- 対象ユーザー: Claude Code 利用者全般。**`allowed_domains` と `managed-mcp.json` 修正は企業管理者に直接関係する**
- 対象プラン: 記載なし（`modelPricing` / `managed-mcp.json` / 組織ポリシーは managed settings 前提）
- API / UI / 管理者機能: CLI・管理設定・サンドボックス・MCP・権限判定にまたがる

## 教材化メモ

**単独記事にはしないが、週次ロールアップでの扱いを決めておく。** この版の要点は「統制設定が外れる方向の不具合修正」が4系統（組織ポリシーのキャッシュ、ポリシー読み込み後のツール一覧更新、`managed-mcp.json`、`ANTHROPIC_UNIX_SOCKET` 経由のポリシー取得）まとまっている点である。**管理者が設定したはずの制限が効いていなかった期間がある**という読み方になるため、週次では「要点」の冒頭に置く。

**`allowed_domains` のコマンド単位化は、サンドボックス設計の考え方が一段進んだ例として使える。** 「セッション単位でホストを開ける」から「コマンドと一緒に審査して、そのコマンドにだけ開ける」への移行であり、最小権限の粒度を下げる一般則の実例になる。

**`omitClaudeMd` は取り扱い注意。** サブエージェントを CLAUDE.md なしで走らせられるのは便利だが、**プロジェクト規約を読まないエージェントを増やす設定**でもある。managed policy は残る点と合わせて説明しないと、ガバナンス上の誤解を招く。
