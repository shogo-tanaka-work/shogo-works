# 2026-09-10 Gemini in Google Sheets の Android 対応

## 公式内容の日本語要約

Web 版で提供されていた **Gemini in Google Sheets が Android 端末でも使える**ようになった。スプレッドシートを開いて **Gemini のスパークアイコンをタップ**すると、データについて質問し、分析的な示唆を得て、グラフを作成できる。「Summarize this table」「Analyze for insights」といった推奨プロンプトが用意される。

**公式が明示的に制限を書いている点が重要である。** モバイル版の機能は**データ分析と示唆の取得に絞られており、複雑な編集・書式設定・数式生成は Web 版を使う必要がある。** つまり「Web 版がそのまま手元に来た」わけではない。

管理者向けの個別設定は無く、ドメイン / OU 単位の Gemini for Google Workspace の有効化設定に従う。エンドユーザーには既定で提供される。

ロールアウトは Rapid Release / Scheduled Release 両ドメインで **2026-09-09 開始、最大15日で可視化**。

## できるようになったこと

- Android の Google Sheets から Gemini にデータについて質問できる
- 分析的な示唆の取得とグラフ作成ができる
- 推奨プロンプトから開始できる
- （制限）複雑な編集・書式設定・数式生成は Web 版のみ

## 影響範囲

- 対象ユーザー: Android で Sheets を使うユーザー
- 対象プラン: Business Standard / Plus、Enterprise Standard / Plus、Google AI Pro for Education、Google AI Pro / Ultra
- API / UI / 管理者機能: UI（モバイル）
