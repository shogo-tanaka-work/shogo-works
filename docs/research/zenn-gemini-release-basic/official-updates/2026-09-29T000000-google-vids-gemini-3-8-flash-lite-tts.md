# 2026-09-29 Google Vids の TTS が Gemini 3.8 Flash Lite へ

## 公式内容の日本語要約

Google Vids のナレーション生成（TTS）エンジンが **Gemini 3.8 Flash Lite TTS** へ更新された。改善点として公式が挙げるのは、**文のつながりの改善、自然な間の取り方、文脈を踏まえた強調**で、いわゆるロボット的な抑揚が減るとされる。**音声生成の速度も向上**している。

展開は**即日**で、**Rapid Release と Scheduled Release の両ドメイン**、**大半の Google Workspace エディション**、加えて**個人向け（Consumer）と教育（Education）プラン**が対象。段階的ロールアウトではなく一斉適用である。

09-23 の「Gemini Omni で Google Vids の HD 動画生成」に続く、**Vids まわりの連続した強化**の一環と読める。

## できるようになったこと

- Google Vids でより自然な抑揚のナレーションを生成する
- 音声生成をより短時間で終える

## 影響範囲

- 対象ユーザー: Google Vids 利用者
- 対象プラン: 大半の Workspace エディション、Consumer、Education
- API / UI / 管理者機能: 管理者の操作不要（即日・全ドメイン）

## 教材化メモ

- **社内研修動画・マニュアル動画の内製**という具体的な用途に直結する。ナレーターを立てずに動画教材を作る導線として、Workspace 契約済みの企業には追加コストなしで効く。
- 「TTS の品質が実用水準を超えたかどうか」は**実際に聞いて判断する**しかない領域なので、教材では**比較試聴の手順**として扱うのが妥当。
- 単独では読者の判断を変える度合いが小さく、**Workspace の AI 機能をまとめる回の1項目**として扱う。
