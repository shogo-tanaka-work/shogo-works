# 2026-10-22 Google Vault が Gemini in Workspace の絞り込みエクスポートに対応

## 公式内容の日本語要約

Vault の eDiscovery で、Gmail・Drive・Docs・Sheets・Slides・Meet の Gemini in Workspace の会話を、対象者（最大5,000人の組織部門を含む）と期間で絞って JSON エクスポートできる。保持ルールと訴訟ホールドは今後対応、Vault API は UI 提供から14日以内。Rapid / Scheduled Release で提供中。
