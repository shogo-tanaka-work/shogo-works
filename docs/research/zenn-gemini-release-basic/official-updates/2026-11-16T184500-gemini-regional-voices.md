# 2026-11-16 Gemini アプリに66の地域別ボイス

## 公式内容の日本語要約

Google I/O で予告した地域方言ボイスが Android / iOS の Gemini アプリで展開開始。米・英・インド英語、ヒンディー語、ブラジルポルトガル語、インドネシア語、韓国語など66種。Gemini Live の3点メニューまたはアプリ設定から選択でき、選んだ声はアプリ全体（Live、チャットの読み上げ）に反映される。日本語向けの言及は無し。

## 影響範囲

- 対象: Gemini アプリ（Android / iOS）。
