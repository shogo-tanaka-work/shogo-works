# 2026-09-30 Google Vids の字幕スタイル設定

## 公式内容の日本語要約

Google Vids で、動画の字幕（captions）の見た目をカスタマイズできるようになった。Workspace Updates Blog の個別ポストとして 2026-09-30 に公開されている。

前日（2026-09-29）の **Gemini 3.8 Flash Lite TTS によるナレーション音声の更新**と合わせて、**Vids の「動画を自力で仕上げる」側の機能が連続して強化されている**流れにある。

## できるようになったこと

- Google Vids の字幕スタイル（見た目）のカスタマイズ

## 影響範囲

- 対象ユーザー: Google Vids 利用者
- 判定: **記事化は見送り（スコア不足 5点）**。読者の判断を変える度合いが小さい

## 教材化メモ

- **社内動画教材の内製という文脈では、字幕スタイルは軽視できない要素である。** アクセシビリティ（視認性）と、ブランドガイドラインへの適合の両方に関わる。「機能としては小さいが、内製の実務では毎回詰まる箇所」という性格の更新。
- **Vids の強化が連続している点**（09-29 の TTS 更新 → 09-30 の字幕スタイル）は、Workspace の AI 機能をまとめて扱う回の素材として蓄積する。個別では弱いが、**「研修動画を Workspace 内で完結させる」という線で束ねると教材になる。**
