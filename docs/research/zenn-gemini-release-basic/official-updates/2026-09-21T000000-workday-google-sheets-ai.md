# 2026-09-21 Workday for Google Sheets

## 公式内容の日本語要約

Google は 2026-09-21、Workspace Updates Blog で **Workday Adaptive Planning と Google Sheets を接続する Marketplace アドオン「Workday for Google Sheets」**を告知した。財務アナリストが計画データをシステム間で手動転記することなく、**動的なレポート作成とアドホックな差異分析（variance analysis）**を Sheets 上で行えるようにするものである。

**AI 機能の提供元は Workday 側である点に注意が必要**である。本アドオンは Google Workspace Marketplace 経由で配布されるサードパーティ製で、Gemini の機能拡張ではない。Workspace Updates Blog は Google 自社の Gemini 更新と、こうした Marketplace パートナーの告知を同じ面で扱う。

提供条件は **Workday Adaptive Planning のライセンスが別途必要**である。ロールアウトは Rapid Release / Scheduled Release ドメインともに告知時点で提供済み（段階的ロールアウトの待機期間なし）。対象は全 Google Workspace 顧客、Workspace Individual 契約者、および個人 Google アカウント利用者とされている。

## できるようになったこと

- Workday Adaptive Planning の計画データを Google Sheets へ手動エクスポートせずに取り込める
- Sheets 上で差異分析やレポート作成を、元データへの接続を保ったまま行える

## 影響範囲

- 対象ユーザー: Workday Adaptive Planning を使っている財務・経営企画部門
- 対象プラン: 全 Workspace 顧客 + Workspace Individual + 個人アカウント。ただし **Workday Adaptive Planning ライセンスが前提**
- API / UI / 管理者機能: Google Workspace Marketplace アドオンの追加

## 教材化メモ

- **「Workspace で AI が使える」という話を、提供元で切り分ける**教材になる。Gemini（Google 自社）、Marketplace アドオン（サードパーティ）、API 連携は、契約・データの流れ先・管理者統制のすべてが異なる。本件は2つ目にあたり、Workday のライセンスが別に要る。
- **前提ライセンスのある機能告知を読むときの型**として使える。「全顧客が対象」と書かれていても、実際に使えるのは前提製品を契約している組織だけ。告知の対象範囲と実際の適用範囲は一致しない。
- 単独記事にはしない。対象が Workday Adaptive Planning 利用企業に限定され、読者層（中小企業の AI 導入・副業層）との重なりが薄いため。
