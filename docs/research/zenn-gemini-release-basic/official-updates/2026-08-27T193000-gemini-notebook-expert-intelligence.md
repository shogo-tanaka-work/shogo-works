# 2026-08-27 Gemini Notebook の Expert Intelligence

## 公式内容の日本語要約

Google が **Expert Intelligence** を Gemini Notebook で公開した。Google Play ブックスで購入した電子書籍を Notebook のソースとして直接追加し、**その本に基づいた回答**を得られる。

対象は **10万冊超**。参加出版社に Bloomsbury、De Gruyter Brill、Johns Hopkins University Press、Macmillan Publishers、O'Reilly Media、Penguin Random House。加えて Steven Pinker、Michael Pollan、Jennifer Wallace ら **15名以上のベストセラー著者**と組み、補助資料付きの「Featured Notebooks」を用意した。

本を追加すると、質問への回答がその本を根拠に生成されるほか、**インフォグラフィック、音声概要、クイズ**の生成にも使える。自分の資料や他のソースと組み合わせた横断分析も可能。

米国ユーザーには無料の電子書籍がプロモーションとして提供される。今後は **Gemini アプリと検索の AI Mode** への展開、およびサブスクリプション・調査レポート・教科書といったソース種別の追加が予定されている。

## できるようになったこと

- Google Play ブックスの購入済み電子書籍を Gemini Notebook のソースに追加
- 書籍を根拠にした回答・インフォグラフィック・音声概要・クイズの生成
- 著者監修の Featured Notebooks の利用

## 影響範囲

- 対象ユーザー: Gemini Notebook 利用者（Google Play ブックスの購入書籍を持つ人）
- 対象プラン: 公式に明記なし。無料電子書籍のプロモーションは米国ユーザー向け
- API / UI / 管理者機能: Gemini Notebook の UI（ソース追加）

## 教材化メモ

- **「AI に何を読ませるか」がライセンス問題として整理され始めた**事例。出版社と正式に組み、購入済みの本を根拠にする形にしたことで、権利処理と体験の両立を図っている。社内文書 RAG の設計を説明するとき、**ソースの正当性をどう担保するか**という論点の外部例として使える。
- **「購入した本を AI に読ませる」体験は、社内ナレッジ RAG の縮小版**として教えやすい。ソース追加 → 根拠付き回答 → 別形式（音声・クイズ）への変換、という流れは、社内での使い方の説明にそのまま流用できる。
- 記事化は見送った（本数上限・スコア7）。米国中心のプロモーションで、日本の読者が今すぐ使える範囲が限定的。**Gemini アプリと AI Mode へ展開された時点で拾い直す価値がある**。
