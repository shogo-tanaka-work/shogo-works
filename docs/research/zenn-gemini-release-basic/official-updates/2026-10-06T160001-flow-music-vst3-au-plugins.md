# 2026-10-06 Google Flow Music のプラグイン書き出し

## 公式内容の日本語要約

Google が **Google Flow Music** の「Spaces」機能で作ったカスタム音楽ツールを、**DAW 向けのプラグイン（VST3 / AU）として書き出せる**ようにしたと発表した。

公式が使う「vibe code」は、**自然言語で楽器やエフェクトを作ること**を指す。コーディング経験は不要で、アーティスト・プロデューサー・ソングライターが自分のワークフローに合わせたツールを作れるとしている。書き出し形式は **VST3 と AU（Audio Units）**で、プロ向け DAW から読み込める。

**価格、提供地域、提供開始日は本文に記載がない。** 公開日（2026-10-06）以外の日付情報は示されていない。

## できるようになったこと

- 自然言語で作った楽器・エフェクトを **VST3 / AU プラグイン**として書き出せる
- 作ったツールを DAW のワークフローへ持ち込める

## 影響範囲

- 対象ユーザー: 音楽制作者（Flow Music の利用者）
- 対象プラン: 不明（公式に記載なし）
- API / UI / 管理者機能: UI（Flow Music の Spaces）
