# 2026-09-23 Google Vids × Gemini Omni 1.1 Flash

## 公式内容の日本語要約

Google は 2026-09-23、**Google Vids で Gemini Omni 1.1 Flash を利用できるようにした**と発表した。Workspace Updates 側は機能面、blog.google 側は提供範囲の拡大を扱っており、実質的に同じ更新の2面である。

**機能面は3点。** (1) **シーン延長の品質向上** — 生成済みクリップを長くする際に、視覚的な文脈・照明・登場人物の見た目・環境の一貫性を保つ。Omni 1.1 はキャラクターと音声の一貫性が大きく改善したとされる。(2) **尺の厳密な指定** — 生成クリップの長さを正確に指定でき、ナレーションやストーリーに合わせられる。(3) **1080p フル HD 生成とアップスケール** — 新規シーンを 1080p で生成できるほか、既存の AI クリップを 1080p へアップスケールしてタイムライン上で他の素材と揃えられる。

**提供範囲は個人アカウントまで広がった。** blog.google 側のポストは「Google アカウントまたは Google Workspace アカウントを持つ誰もが、Omni 1.1 を使って無料で動画を生成できる」としている。テンプレートから組み立てる導線もあり、`vids.new` から開始する。**AI 生成クリップにはデジタル透かしが入る。**

ロールアウトは Rapid Release / Scheduled Release とも 2026-09-23 開始で、機能が見えるまで1〜3日。**管理者向けの制御項目はない。** 対象エディションは Business Starter / Standard / Plus、Enterprise Starter / Standard / Plus、Education Plus、個人 Google アカウントおよび Google AI Pro / Ultra、Enterprise Essentials / Essentials Plus、非営利、Individual、教育向けアドオン（Google AI Pro for Education、Teaching and Learning）、AI Expanded Access（このアドオン保有者は Vids での Omni 利用上限が高い）。

## できるようになったこと

- Google Vids で Gemini Omni 1.1 Flash を使える
- 生成シーンを一貫性を保ったまま延長できる
- 生成クリップの尺を正確に指定できる
- 1080p フル HD で生成、または既存 AI クリップを 1080p へアップスケールできる
- 個人 Google アカウントでも無料で動画生成を開始できる（`vids.new`）

## 影響範囲

- 対象ユーザー: Google アカウントまたは Workspace アカウント保有者
- 対象プラン: Business Starter / Standard / Plus、Enterprise Starter / Standard / Plus、Education Plus、個人アカウント、Google AI Pro / Ultra、Enterprise Essentials / Essentials Plus、非営利、Individual、教育向けアドオン、AI Expanded Access（上限が高い）
- API / UI / 管理者機能: **管理者制御なし。** 組織側で個別にオフにする設定は用意されていない
