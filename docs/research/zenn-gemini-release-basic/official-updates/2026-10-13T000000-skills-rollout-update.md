# 2026-10-13 skills のロールアウト更新

## 公式内容の日本語要約

Google は 2026-10-13、**2026-09-30 に告知した skills のロールアウト状況を更新**した。**2つの提供面で結果が分かれた。**

**Gemini アプリ側は予定どおり開始した。** 公式は「skills in the Gemini app are starting to roll out today, with an expected completion by mid-November」と記している。対象は**全 Google Workspace 顧客と個人の Google アカウント**で、**年齢制限はなく全年齢**が利用できる。**管理コントロールは存在しない**（公式は "There are no admin controls for skills in the Gemini app." と明記）。今後数週間のうちに、Gemini アプリの skills の共有機能と Google Drive 連携が追加される予定で、開始時に Workspace Updates ブログで告知される。

**Workspace 側は延期された。** 公式は「those rollouts are slightly delayed」と記し、Rapid Release / Scheduled Release の両ドメインについて **"Delayed until further notice"** とした。**9月30日の告知で示していた日程は両方とも無効になった**（Rapid Release は 2026-10-12 完了予定、Scheduled Release は 2026-10-19 開始予定）。更新後の日程は確定しだい共有するとしている。

**Workspace 側の対象エディション**は Business Starter / Standard / Plus、Enterprise Starter / Standard / Plus、教育向けアドオン（Google AI Pro for Education）、AI Expanded Access。**18歳以上限定**で、**管理者による有効・無効の切り替えが可能**（詳細はヘルプセンター）。

## できるようになったこと

- Gemini アプリで skills が使い始められる（段階的、11月中旬完了見込み）
- Workspace 側の skills を待つ組織は、当初日程が無効になったことを前提に棚卸し計画を組み直せる

## 影響範囲

- 対象ユーザー: Gemini アプリ利用者（全年齢・全 Workspace 顧客・個人アカウント）、Workspace の skills を待つ管理者
- 対象プラン: Gemini アプリは全対象。Workspace は Business / Enterprise 各 Starter・Standard・Plus、Google AI Pro for Education、AI Expanded Access
- API / UI / 管理者機能: Gemini アプリ側は管理コントロールなし。Workspace 側は管理コンソールに設定あり（提供は延期）
