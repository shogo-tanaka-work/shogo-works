# 2026-08-12 Gemini の connected apps 拡大

## 公式内容の日本語要約

Made by Google 2026 に合わせて、Gemini アプリに接続できる外部サービスが拡大された。今後数週間かけて順次ロールアウトされる。

カテゴリと対象サービスは次の通り。生産性・クリエイティブは Granola、Otter.ai、Wix（会議の要約、Web サイト編集）。ローカル・エンタメは Fever、GetYourGuide、Localiza、OpenTable（英国）、Ticketmaster（体験予約、レンタカー、レストラン予約、チケット検索）。音楽は iHeartRadio と Pandora。住まい・健康・生活は Angi、Thumbtack、Zocdoc（業者探し、医師の予約）。

Gemini 側で使いたいサービスをオンにすることで、計画・作成・タスク処理を1か所で進められる、というのが公式の説明である。

日本のユーザーにとって実用範囲に入るものは限られる。OpenTable は英国限定と明記されており、Angi / Thumbtack / Zocdoc / Localiza は米国・中南米中心のサービスである。業務文脈で意味を持つのは Granola と Otter.ai（会議記録）、Wix（サイト編集）あたりに絞られる。

## できるようになったこと

- Granola / Otter.ai の会議記録を Gemini から参照して要約できる
- Wix のサイト編集を Gemini 経由で指示できる
- 予約・チケット・音楽ストリーミング系サービスを Gemini から操作できる（多くは地域限定）

## 影響範囲

- 対象ユーザー: Gemini アプリ利用者
- 対象プラン: 明記なし（Gemini アプリの connected apps 設定）
- API / UI / 管理者機能: Gemini アプリの接続済みアプリ設定

## 教材化メモ

- 「AI アシスタントに外部サービスを接続する」設計の実例として、MCP / connectors を扱う教材の比較材料になる。Gemini の connected apps はユーザーが個別にオンにする明示的オプトイン方式で、この点は組織導入時のガバナンス設計と結びつけて説明できる。
- 地域限定が多いため、教材で具体名を挙げる場合は「日本で使えるか」を必ず添える。読者が試して使えないと教材の信頼を落とす。
