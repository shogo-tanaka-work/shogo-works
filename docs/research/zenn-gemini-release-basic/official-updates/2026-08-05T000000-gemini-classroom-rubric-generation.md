# 2026-08-05 Gemini による Classroom ルーブリック生成

## 公式内容の日本語要約

Google Workspace Updates で、Google Classroom の課題作成フロー内で Gemini がルーブリック（評価基準表）を生成できるようになったことが告知された。教員は課題作成の途中で、その課題の文脈を使ってそのまま利用できるルーブリックを即座に生成できる。

これまでは課題を作ったあとで別途ルーブリックを用意する流れだったため、作成フローへの統合が今回の変更点にあたる。対象は 18 歳以上のユーザーに限定され、ロールアウトは 2026-08-05 開始。

前日（2026-08-04）に告知された「Gemini in Google Classroom の全年齢拡大」とは別件で、こちらは年齢制限が付いている点に注意が必要。

## できるようになったこと

- 課題作成フローの中で、課題の文脈を使ったルーブリックを Gemini が生成できる
- 生成されたルーブリックはそのまま Classroom で利用できる形式

## 影響範囲

- 対象ユーザー: Google Classroom の教員（18 歳以上）
- 対象プラン: Workspace for Education（Gemini 対応エディション）
- API / UI / 管理者機能: Classroom UI（課題作成画面）

## 教材化メモ

- 教育機関向けの限定的な更新のため速報記事化はしない。ただし「評価基準を先に AI で言語化してから作業を作る」という順序は、教育以外の業務（レビュー基準、品質チェックリスト）にも転用できる考え方として、教材の応用例に使える。
- 年齢制限の有無が機能ごとに異なる点は、Workspace の教育向け機能を扱う際の注意事項として記録しておく。
