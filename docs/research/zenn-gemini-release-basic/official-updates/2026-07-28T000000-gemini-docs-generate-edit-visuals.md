# 2026-07-28 Google Docs の Gemini でビジュアルを生成・編集

## 公式内容の日本語要約

Google Docs の Gemini から、ドキュメント内で直接ビジュアル（画像・図表・インフォグラフィック）を生成・編集できるようになった。自然言語プロンプトで複数のビジュアルをまとめて作成でき、アスペクト比の変更などの編集も同じ画面内で完結する。

- ロールアウト: Rapid Release / Scheduled Release の両ドメイン向けに 2026-07-28 から段階的展開（機能反映まで最大15日）
- 対象エディション: Business Standard / Plus、Enterprise Standard / Plus、Education Plus、Google AI Pro / Ultra（個人向け）、Google AI Pro for Education
- 管理者設定: 「Gemini for Workspace in Drive」の有効化が前提。デフォルトで有効だがアクセス管理は可能
- エンドユーザー設定: 「Workspace smart features」の有効化が必要

## できるようになったこと

- Docs から離れずに画像・図表・インフォグラフィックを生成できる
- 自然言語プロンプトで複数のビジュアルを一括生成できる
- 生成後にアスペクト比変更などの編集ができる

## 影響範囲

- 対象ユーザー: 上記エディションの Google Docs 利用者
- 対象プラン: Business Standard/Plus、Enterprise Standard/Plus、Education Plus、Google AI Pro/Ultra、Google AI Pro for Education
- API / UI / 管理者機能: Docs の Gemini サイドパネル / 挿入UI、管理コンソールの「Gemini for Workspace in Drive」設定、ユーザー側の smart features 設定

## 教材化メモ

- Workspace 教材の「資料作成」章に、外部の画像生成ツールを経由しないワークフローとして追加候補。
- 管理者設定（Drive 側の Gemini 有効化）とユーザー設定（smart features）の二段構えは、Workspace の AI 機能に共通する前提として教材で一度まとめて説明する価値がある。
