# 2026-10-16 Gemini Notebook に学習向け3機能

## 公式内容の日本語要約

Google は Gemini Notebook の学習活用を紹介する公式ポストの中で、**「最近3つの新機能を公開した」**として次を挙げた。形式は Tips 記事だが、**新機能の告知を含む。**

1. **Short Video Overviews** — 概念を説明する**約60秒の動画**を生成する。すばやく見る、あるいは共有する用途。
2. **Interactive Learning Overviews** — 手持ちの資料を**段階を追って進む対話型の解説**にする。**Reports の下**に置かれ、要約と studio の出力を組み合わせる。
3. **クイズ形式の拡張** — **短答・複数選択・穴埋め**が追加された。

あわせて既存機能としてフラッシュカードと、ノートブックに自分の成績についてフィードバックを求める使い方が紹介されているが、**これらは新規として扱われていない。**

**提供範囲の記載が無い点に注意が必要である。** このポストは製品告知ではなく活用 Tips の体裁であり、**対象プラン、Workspace エディション、ロールアウト日程、管理者コントロールのいずれも書かれていない。** Workspace 側での提供条件を確認するには、Workspace Updates Blog 側の個別ポストを待つ必要がある。

## できるようになったこと

- 資料から60秒程度の解説動画（Short Video Overviews）を生成できる
- 段階を追う対話型の解説（Interactive Learning Overviews）を Reports 配下で作れる
- クイズに短答・複数選択・穴埋めの形式が加わった

## 影響範囲

- 対象ユーザー: Gemini Notebook 利用者（学習用途、研修教材作成）
- 対象プラン: **公式ポストに記載なし。** Workspace エディション条件・ロールアウト日程・管理者コントロールも未記載
- API / UI / 管理者機能: UI 側の機能追加。Interactive Learning Overviews は Reports 配下
