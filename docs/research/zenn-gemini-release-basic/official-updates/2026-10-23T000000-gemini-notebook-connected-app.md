# 2026-10-23 Gemini Notebook が連携アプリに

Gemini Notebook が Gemini アプリの Connected App になった。`@Gemini Notebook` でノートブックの作成・編集・削除、ソースの追加・更新・削除、一覧、内容に基づく質問ができる。管理者設定は既定で有効、EEA は利用者側の既定がオフ。Rapid Release / Scheduled Release で提供中。
