# 2026-09-10 Gemini アプリの Windows 版

## 公式内容の日本語要約

Google が **Gemini アプリの Windows 版**を公開した。**Windows 10 / 11 向けに、本日から全世界で提供**される。ダウンロードは `gemini.google/desktop`（macOS 版の `gemini.google/mac` とは別ドメイン）。

中核は**起動方法**である。**`Alt + Space` を押すと、作業中のウィンドウの上に Gemini が重なって表示される。** 公式が挙げる用途は「ドキュメントの事実確認」「プレゼンのタイトル案出し」で、**アプリを切り替えずにその場で済ませて元の作業へ戻る**という設計思想が明示されている。

アプリ内からは、ドラフトの推敲、長文ドキュメントの要約、アイデア出し、画像・動画の生成が行える。**Gmail と Google Drive の情報を参照**でき、複数ステップの作業は **Gemini Spark**（公式が "24/7 personal AI agent" と呼ぶエージェント）へ引き渡せる。

公式は「PC の動作を遅くしない軽量な常駐」であることを強調している。また「Windows 版はこれが始まりで、ネイティブなデスクトップ機能は順次追加する」としており、**macOS 版にある一部機能（音声入力など）は現時点では未搭載**である。Spark の提供国制限（EEA / ナイジェリア / スイス / 英国が対象外という既存のドキュメント記載）が Windows でも同じかは、公式ポストに記載がない。

執筆者は Erin Pettigrew（Director of Product Management, Gemini App）。

## できるようになったこと

- Windows 10 / 11 に Gemini アプリをインストールできる（全世界、本日から）
- `Alt + Space` で作業中の画面の上に Gemini を呼び出せる
- Gmail / Google Drive の情報を参照して要約・下書きができる
- 複数ステップの作業を Gemini Spark へ引き渡せる
- 画像・動画をデスクトップから生成できる

## 影響範囲

- 対象ユーザー: Windows 10 / 11 ユーザー（全世界）
- 対象プラン: 公式ポストにプラン別の明記なし。Spark / 動画生成は既存のプラン・地域制限に従う可能性
- API / UI / 管理者機能: UI（デスクトップアプリ）
