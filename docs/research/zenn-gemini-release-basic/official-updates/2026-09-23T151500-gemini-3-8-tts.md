# 2026-09-23 Gemini 3.8 Flash TTS / Flash-Lite TTS

## 公式内容の日本語要約

Google は 2026-09-23、Gemini ファミリーに **2つの新しい text-to-speech モデル**を追加した。**Gemini 3.8 Flash TTS** と **Gemini 3.8 Flash-Lite TTS** で、いずれも同日からロールアウトが始まっている。提供面は Google AI Studio、Gemini API、Gemini Enterprise、Gemini Notebook、Google Vids。

**Flash TTS は創作方向の深い制御を担う。** 自然言語のプロンプトから新しい声をゼロから設計でき、ゲーム、没入型オーディオブック、ポッドキャスト、インタラクティブメディア向けのキャラクターボイスを作れる。演技の指示、テンポ、方言の切り替え、あいづち（backchanneling）を**行単位（line by line）で指示できる**のが従来のプリセット選択との差である。報道によれば用意済みの声は2,000種以上あり、**30秒の音声サンプルから声を再現する機能**も持つ。この場合は声の持ち主による口頭の同意録音を提出させ、参照話者と一致するかをシステム側で確認してから作成する、という同意チェックが入る。

**Flash-Lite TTS は大量処理とコスト効率に振った版。** 大量の吹き替え、音声コンテンツの量産、表現力のあるボイスエージェント向けで、トーン・テンポ・ニュアンスの細かい制御は保持する。

Google はこの発表を「静的なプリセットから、動的なクリエイティブスタジオへの転換」と表現している。Gemini 3.8 ファミリーは今月初めに公開されており、TTS はその系列への追加に当たる。

## できるようになったこと

- 自然言語プロンプトから新規の声をデザインできる（Flash TTS）
- 演技の指示・テンポ・方言・あいづちを行単位で指定できる
- 30秒の音声サンプルから声を再現できる（口頭同意の録音と話者一致チェックが必要）
- 大量吹き替え・ボイスエージェント向けのコスト効率版（Flash-Lite TTS）を選べる
- Google AI Studio / Gemini API / Gemini Enterprise / Gemini Notebook / Google Vids から利用できる

## 影響範囲

- 対象ユーザー: Gemini API / AI Studio の開発者、Gemini Enterprise・Notebook・Vids の利用者
- 対象プラン: 提供面ごとに異なる（API は従量課金、Vids / Notebook は各エディションの提供範囲に従う）
- API / UI / 管理者機能: Gemini API に新モデルID が追加。音声再現は同意確認フローを伴う
