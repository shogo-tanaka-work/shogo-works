# 2026-07-31 July's Gemini Drop

## 公式内容の日本語要約

Gemini アプリの月次まとめ「Gemini Drop」の7月版。6項目が挙げられている。

1. **macOS の音声機能**: Mac 上のどのアクティブウィンドウでも Gemini に話しかけ、テキストの口述、内容の変換、ビジュアルの生成ができる（2026-07-29 に個別発表済み）
2. **Gemini Spark のグローバル展開**: 世界中で利用可能になり、ノートパソコンを閉じた後も24時間稼働してタスクを進められる。ただし EEA、英国、スイス、ナイジェリアでは提供されない
3. **新しい Flash モデル**: Gemini 3.6 Flash と Gemini 3.5 Flash-Lite が、推論の改善と速度向上を提供
4. **アバター機能**: 毎回自分の写真をアップロードしなくても、アバターを使って自分が写った画像を作れる
5. **アプリ連携**: Dropbox、Zillow Rentals、Viator を Gemini に接続し、1つのプロンプトで各サービスをまたいだ作業ができる
6. **パーソナライズ画像生成**: ユーザーの興味・嗜好に基づいた画像を生成できる（米国のユーザー向け）

個別のプラン要件はこのページには明記されていない。詳細は Gemini Drops Hub を参照する形になっている。

## できるようになったこと

- Gemini Spark がグローバルで利用可能に（EEA / 英国 / スイス / ナイジェリアを除く）
- アバターを使った自分入り画像の生成（毎回の写真アップロードが不要）
- Dropbox / Zillow Rentals / Viator との連携
- 興味・嗜好に基づくパーソナライズ画像生成（米国）
- Gemini 3.6 Flash / Gemini 3.5 Flash-Lite の提供
- macOS の音声機能（個別発表は 2026-07-29）

## 影響範囲

- 対象ユーザー: Gemini アプリ利用者
- 対象プラン: 個別のプラン要件はページ上に明記なし。Spark の提供国拡大は Google AI Pro 加入者向け（2026-07-30 の Spark 発表側に記載）
- API / UI / 管理者機能: Gemini アプリ UI
- 地域制限: Spark は EEA / 英国 / スイス / ナイジェリアで提供なし。パーソナライズ画像生成は米国のみ
