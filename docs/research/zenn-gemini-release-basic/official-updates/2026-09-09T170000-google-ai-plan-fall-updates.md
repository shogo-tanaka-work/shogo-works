# 2026-09-09 Google AI プランの秋アップデート

## 公式内容の日本語要約

Google は 2026-09-09、Google AI プラン（AI Plus / Pro / Ultra）の更新をまとめて告知した。個々の機能解説ではなく、**プラン別に何が使えるようになったかを5点の箇条書きで並べた告知**である。

内容は次のとおり。**(1) 音声入力**を Gmail / Docs / Keep で使い、文書作成・受信トレイ検索・メモ取りができる（Gmail と Keep は AI Plus / Pro / Ultra、Docs は AI Pro / Ultra）。**(2) Google Pics を Google Workspace で利用**し、ポスターや SNS 投稿の作成、デジタルイラストの編集ができる（AI Pro / Ultra）。**(3) Sheets canvas** でスプレッドシートをプロンプト1つで対話的な「ミニアプリ」に変換できる（AI Pro / Ultra）。**(4) Gemini Spark が Google Chrome および Google Photos と接続**され、Web 上の用事の処理、写真編集、アルバムのキュレーションを代行する（米国の AI Pro / Ultra）。**(5) 適格な大学生**は世界中で Google AI プランを1年間無償で利用できる。

**本文は各項目1文程度で、機能ごとの詳細ページは示されていない。** 提供条件（プラン・地域）だけが明記されている構造である。

## できるようになったこと

- Gmail / Docs / Keep で音声入力による作成・検索ができる
- Google Pics を Workspace 内で使える
- Sheets canvas でスプレッドシートを対話的ミニアプリ化できる
- Gemini Spark が Chrome / Google Photos と連携する（米国のみ）
- 適格な大学生が Google AI プランを1年間無償で使える

## 影響範囲

- 対象ユーザー: Google AI プラン（AI Plus / Pro / Ultra）のコンシューマー利用者。Spark 連携は米国限定
- 対象プラン: 項目ごとに AI Plus / Pro / Ultra で差がある
- API / UI / 管理者機能: UI のみ。API・管理者機能への言及なし
