# 2026-11-10 Workspace の Gemini 関連更新（まとめ）

## 公式内容の日本語要約

- **Gemini in Gmail の拡大（11-10）**: AI Overview の会話要約と「Help me write（非パーソナライズ）」を、18歳以上の全 Workspace ユーザーへ拡大。既定で ON、管理者は Gemini 機能を無効化可能
- **Google Chat の会議調整（11-10）**: 5人以内の会話で会議の意図を Gemini が検出し、候補3枠・参加者・タイトルを1クリックで登録。英語・Web 版のみ、Business / Enterprise Standard・Plus 等が対象
- **Workspace Studio「Wait until」（11-09）**: フローを日時または最大14日の待機で一時停止して再開できる
- **Chat の番号付き・入れ子リスト（11-11）**: 最大5階層。記事化対象外

## 影響範囲

- 対象: Workspace 管理者・利用者。Gmail 拡大は既定 ON のため管理者の確認が要る
