# 2026-09-17 Gemini Notebook の学習向け機能

## 公式内容の日本語要約

**前日窓（2026-09-17）の取りこぼしを追補したものである。** 同日の Workspace Updates からは3件（Workspace Studio、Notebooks in Gemini の組織展開、Expert Intelligence）を記録済みだが、**本件は記録から漏れていた**。2026-09-18 の Weekly Recap で存在を確認し、個別ポストを取得した。

**Gemini Notebook に学習向けの5機能が入った。** 展開は **2026-09-15 から extended rollout**（最長15日以上かかりうる形）で、Rapid Release / Scheduled Release の両ドメインが対象である。

**(1) 音声レコーダー（モバイル）** — Android / iOS アプリで講義や思いつきをその場で録音し、**録ったものがソースとして統合され、引用できる**。

**(2) ノートブックとのリアルタイム会話** — **18歳以上**の利用者が、**約100言語**でノートブックと会話できる。**応答はソース資料に接地される**。モバイルアプリで提供。

**(3) インタラクティブな学習オーバービュー** — Reports 配下に置かれ、要約に**クイズ・フラッシュカード・マインドマップ**を組み合わせる。

**(4) 試験対策の強化** — クイズ形式に**記述式・多肢選択・穴埋め**が加わり、**クイズやフラッシュカードの成績を振り返るチャット**が付いた。設問はカスタマイズできる。

**(5) 短尺の動画オーバービュー** — **約60秒**、**80言語以上**の教育動画を生成でき、クラスメイトと共有できる。複雑な概念にはアニメーションが付く。

**提供範囲は広い。** すべての Google Workspace 顧客、Workspace Individual 契約者、**個人の Google アカウント利用者**が対象である。**管理者は Gemini Notebook 設定の On / Off で制御**し、**エンドユーザー側の設定は不要**。機能が有効なグループ・組織部門に対して提供される。

## できるようになったこと

- モバイルで録音し、その音声をそのままノートブックのソースとして引用できる
- 約100言語でノートブックと音声会話でき、回答がソースに接地される（18歳以上）
- 要約からクイズ・フラッシュカード・マインドマップまでを1つの学習オーバービューで扱える
- 記述式・多肢選択・穴埋めのクイズを作り、成績をチャットで振り返れる
- 80言語以上で約60秒の動画オーバービューを生成・共有できる

## 影響範囲

- 対象ユーザー: 全 Workspace 顧客、Workspace Individual、個人 Google アカウント
- 対象プラン: 上記すべて（管理者が Gemini Notebook 設定で On / Off）
- API / UI / 管理者機能: モバイルアプリ（録音・会話）、Reports 配下の学習オーバービュー、管理コンソールの Gemini Notebook 設定
