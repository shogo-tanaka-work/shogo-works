# 2026-09-15 Gemini 3.8 Live / 3.8 Live Extended Thinking

## 公式内容の日本語要約

Google は 2026-09-15、**音声対話向けの2モデル、Gemini 3.8 Live と Gemini 3.8 Live Extended Thinking** を発表しました。公式は「これまでで最も高度な live dialogue モデル」と位置づけています。

**2モデルの役割は分かれています。3.8 Live は規模とコスト効率を重視**し、会話の知性・流暢な対話・視覚的グラウンディングを組み合わせた汎用型です。**3.8 Live Extended Thinking は高難度タスク向け**で、知性と多段推論を強化しています。

**今回の中核は「話しながら処理する」点です。** 公式および開発者向けポストは、モデルが**会話の流れを保ったままツール呼び出しや API 呼び出しをバックグラウンドで実行**できると説明しています。従来の音声アシスタントで生じていた「処理のために音声出力が止まる」という待ちを取り除く設計です。

**ベンチマークでは 3.8 Live Extended Thinking が Artificial Analysis の Speech-to-Speech リーダーボードで1位**とされています。

**提供経路は4系統です。** 開発者向けは Gemini API と Google AI Studio（Live API 経由）。企業向けは Gemini で private preview、Gemini Enterprise for Customer Experience と Google Workspace 法人顧客向けは「coming soon」。一般利用者向けは Gemini Live、および Workspace の Docs（Google AI Pro / Ultra 契約者）と Gmail / Keep（全 Google AI 契約者）です。

**価格は音声入力 $0.005/分、音声出力 $0.018/分**です。

開発者向けポストでは、先月公開済みの **Gemini 3.5 Transcribe**（85言語以上、WER はストリーミング 4.0% / 非ストリーミング 2.6%）と併せて、音声プロダクト構築の組み合わせとして提示されています。

## できるようになったこと

- **会話を中断せずにツール / API 呼び出しを実行**できる音声モデル
- **3.8 Live**: スケールとコスト効率重視。視覚的グラウンディング対応
- **3.8 Live Extended Thinking**: 多段推論強化。Speech-to-Speech リーダーボード1位
- **Live API 価格**: 音声入力 $0.005/分、音声出力 $0.018/分
- 提供: Gemini API / AI Studio、Gemini Live、Workspace の Docs / Gmail / Keep
- 企業向けは private preview、Gemini Enterprise CX と Workspace 法人は coming soon

## 影響範囲

- 対象ユーザー: 開発者（API / AI Studio）、一般利用者（Gemini Live）、Google AI 契約者（Gmail / Keep）、Google AI Pro / Ultra（Docs）
- 対象プラン: 企業向けは private preview 段階。**Workspace 法人顧客は未提供（coming soon）**
- API / UI / 管理者機能: **API 追加（Live API）とモデル選択肢の追加**。価格は分課金
- 注意: **Workspace 法人での提供時期は公式に明示されていない**
