# 2026-09-22 Gemini Study notebooks の Workspace 展開

## 公式内容の日本語要約

Google は 2026-09-22、Gemini の **Study notebooks** を Google Workspace アカウント（学校用・職場用）でも利用できるようにしたと告知した。これまで個人アカウント向けに提供されていた機能の、組織アカウントへの展開である。

**Study notebooks は、Gemini を「対話型・適応型の学習プラットフォーム」として使うための機能である。** 手持ちの資料をアップロードすると、**学習目標に合わせた個別のレッスンを生成し、進捗を追跡し、理解度を測る。** 単に資料を要約するのではなく、学習のセッションとして組み立てる点が従来のノートブック機能との違いである。

使い方は、Gemini の左サイドバーから notebook を作成し、講義資料や業務資料を投入する。進捗ダッシュボードで到達度を確認する。

管理者は Gemini アプリ設定と Gemini Notebook 設定から有効化し、**グループまたは組織部門（OU）単位でアクセスを制御できる。**

ロールアウトは 2026-09-17 開始の段階的ロールアウト（機能の可視化まで最大15日）。対象は全 Google Workspace 顧客と Workspace Individual 加入者のうち **EEA 域外**で、EEA のユーザーには数週間後に提供される。

## できるようになったこと

- 学校・職場の Workspace アカウントで Study notebooks を作成できる
- 学習目標に沿った個別レッスンの生成と進捗追跡ができる
- 管理者がグループ / OU 単位で提供範囲を制御できる

## 影響範囲

- 対象ユーザー: Google Workspace 利用者、Workspace Individual 加入者（EEA 域外が先行）
- 対象プラン: 全 Google Workspace 顧客
- API / UI / 管理者機能: 管理者側の有効化設定あり。公開日（2026-09-22）よりロールアウト開始（2026-09-17）が先行しているため `rollout_date` を併記する
