# 2026-09-15 Gmail 検索の AI Overviews が全世界展開

## 公式内容の日本語要約

Google は 2026-09-15、**Gmail 検索の AI Overviews** を全世界へ拡大したと発表した。Gmail の検索バーに自然言語で質問すると、個々のメールを開かずに要約と回答が返る機能である。

これまでは **米国在住・英語設定のユーザーに限定**されていた。今回の変更で、**英語設定の有料プラン契約者であれば世界中で利用できる**ようになった。言語要件は残っており、**Gmail の言語設定が英語であることが条件**である。

ロールアウトは3系統。**Rapid Release ドメインは 2026-09-03 から段階展開（表示まで最大15日）**、**Scheduled Release ドメインは 2026-09-21 から全面展開（表示まで1〜3日）**、個人 Google アカウントは 2026-09-03 から段階展開。

対象は Business（Starter / Standard / Plus）、Enterprise（Starter / Standard / Plus）、消費者向けの Google AI Plus / Pro / Ultra、Frontline Plus、Google AI Pro for Education、AI Expanded Access アドオン。

**除外地域が明記されている。個人アカウントについては EEA / 英国 / スイス / 日本では利用できない。** 日本の個人ユーザーは対象外である一方、日本の Workspace 有料テナントは英語設定であれば対象に入る、という非対称な構造になっている。

## できるようになったこと

- 英語設定の有料プラン契約者が、世界中で Gmail 検索の AI 要約を使える
- 自然言語の質問に対し、個別メールを開かずに要約と回答を得られる

## 影響範囲

- 対象ユーザー: 英語設定の Gmail 利用者（有料プラン）
- 対象プラン: Business / Enterprise 各 Starter・Standard・Plus、Google AI Plus / Pro / Ultra、Frontline Plus、教育向けアドオン
- 除外: 個人アカウントの EEA / 英国 / スイス / **日本**
- API / UI / 管理者機能: Gmail 検索（UI）
