# 2026-10-06 Trello for Google Workspace

## 公式内容の日本語要約

**Google Chat のメッセージとメールから Trello カードを作成できる**アプリ「Trello for Google Workspace」が公開された。従来の「Trello for Gmail」を置き換えるもので、**既存の Trello for Gmail 利用者は再インストールなしで継続できる。**

対象は **Google Workspace の全顧客と個人 Google アカウント**で、Trello アカウントが別途必要である。ロールアウトは **2026-10-06 時点で Rapid Release / Scheduled Release の両ドメインへ即時適用**済みである。

導入は Google Workspace Marketplace から。**管理者が組織を代表してインストールできる**ほか、管理者が許可していればエンドユーザー個別のインストールも可能である。利用するには Chat のスペースまたは DM にアプリを追加し、サインインを済ませる。

**本発表に Gemini / AI 要素の言及はない。**

## できるようになったこと

- Google Chat の会話から Trello カードを直接作成できる
- Gmail 向けアプリが Workspace 全体向けに置き換わった（既存利用者は再インストール不要）

## 影響範囲

- 対象ユーザー: Google Workspace 全顧客と個人 Google アカウント（Trello アカウントが必要）
- 対象プラン: 全エディション
- API / UI / 管理者機能: UI（Chat アプリ）＋ 管理者機能（Marketplace 配布）
