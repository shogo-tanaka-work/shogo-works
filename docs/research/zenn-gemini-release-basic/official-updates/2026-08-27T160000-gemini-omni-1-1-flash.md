# 2026-08-27 Gemini Omni 1.1 Flash

## 公式内容の日本語要約

Google が動画生成モデル **Gemini Omni 1.1 Flash**（モデル ID `gemini-omni-1.1-flash`）を開発者向けに公開した。Google I/O で初出したモデルの更新版で、焦点は「生成できること」ではなく**制御できること**に移っている。

**シーン延長（Scene Extension）**: 従来は直前の1秒しか参照できなかったのに対し、**最大10秒ぶんの文脈**を解析して延長できるようになった。10秒単位で継ぎ足し、**合計40秒**まで伸ばせる。視覚的な一貫性と物語の連続性が保たれる。

**始点／終点フレームの指定**: 開始フレームと終了フレームを与えると、その間の動画を生成する。トランジション、複雑なカメラワーク、シームレスなループが作れる。

**360p ドラフトモード**: 標準の 720p に比べ**最大60%高速・コストは3分の1**でプレビューを生成。試行錯誤のコストを下げる。

**4K アップスケール**: 1080p または 4K の仕上げ出力に対応。

**動画リファレンス**: 最大3秒の動画を入力として与え、視覚的な文脈とキャラクターの一貫性を保つ。

提供面は **Google AI Studio**（直接利用）、**Gemini Enterprise Agent Platform**（Agent Platform API）、**Google Flow**（AI Plus / Pro / Ultra 加入者）。Gemini アプリでもシーン延長が Plus / Pro / Ultra 加入者向けに全世界で利用できる。価格表は公式ページに掲載されている。

## できるようになったこと

- 10秒単位・合計40秒までのシーン延長（直前10秒の文脈を参照）
- 始点・終点フレームを指定した中間生成
- 360p ドラフト（最大60%高速・コスト1/3）→ 720p / 1080p / 4K の解像度ワークフロー
- 最大3秒の動画リファレンスによるキャラクター一貫性の維持

## 影響範囲

- 対象ユーザー: 開発者（AI Studio / Agent Platform API）、Google Flow 利用者、Gemini アプリ利用者
- 対象プラン: Flow は AI Plus / Pro / Ultra。Gemini アプリのシーン延長は Plus / Pro / Ultra
- API / UI / 管理者機能: Gemini API（AI Studio）、Gemini Enterprise Agent Platform、Google Flow、Gemini アプリ
