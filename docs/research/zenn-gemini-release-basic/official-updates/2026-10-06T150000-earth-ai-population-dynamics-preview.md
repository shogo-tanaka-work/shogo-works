# 2026-10-06 Google Earth AI の公衆衛生向け提供

## 公式内容の日本語要約

Google が **Google Earth AI** を公衆衛生領域へ展開する発表を出した。衛星画像、人流データ、基盤モデルを組み合わせ、感染症のアウトブレイク予測やリスク人口の特定を支援するとしている。

提供面での新規性は3点である。(1) **Population Dynamics Insights が Google Maps Platform で Preview 提供**となり、商用利用可能な地理空間埋め込みデータセットとして使える。(2) 対象組織は **Google Public Programs を通じて Google Earth クレジットを無償で申請**できる。(3) **PDFM（Population Dynamics Foundation Model）への無償アクセスを、一部ユースケースについて申請**できる。

研究プロトタイプとして、会話形式で空間を地図化する **Geospatial Reasoning エージェント**と、自律的に疾病を予測する **planetary prediction engine** の2つが紹介されている。

事例として、コンゴ民主共和国でのエボラ対応で **48 の曝露集落と 45,500 人超のリスク人口を特定**し、通常数週間かかる作業を短縮したとしている。他に心血管疾患の予測、予防接種の追跡、デング熱の予測、コレラのホットスポット特定への適用例が挙げられている。

## できるようになったこと

- **Population Dynamics Insights を Google Maps Platform から Preview で利用**できる（商用可）
- 対象組織が Google Earth クレジットと PDFM アクセスを無償で申請できる

## 影響範囲

- 対象ユーザー: 公衆衛生機関、研究機関、地理空間データを扱う開発者
- 対象プラン: Google Maps Platform（Preview）、Public Programs 経由の無償クレジット
- API / UI / 管理者機能: API / データセット（Maps Platform）

## 教材化メモ

- **AIニュース記事化は見送った（スコア5）。** 製品発表としての実体はあるが、**Gemini / Workspace ではなく Google Maps Platform の地理空間領域**であり、本サイトの `gemini` カテゴリで扱うと読者の期待とずれる。用途も公衆衛生に特化しており、一般企業・副業読者の実務と接点が薄い。
- **「基盤モデルが地理空間へ広がっている」という流れは、AI 活用の裾野を説明する教材で1行触れる価値がある。** 言語・画像の次に、**位置情報と人流が埋め込み空間へ入ってきた**という整理ができる。
- **事例の数字（48集落・45,500人を数週間→短時間）は、AI 導入効果を語るときの「公式が出した具体値」として引用できる。** ただし**自社ケースへの外挿はできない**ことを必ず添える。
