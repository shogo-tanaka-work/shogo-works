# 2026-07-29 Gemini for macOS の自然言語音声操作

## 公式内容の日本語要約

Google が macOS 版 Gemini アプリに音声操作機能を追加した。Fn キーの長押しでデスクトップ上のどのウィンドウからでも音声モードを起動し、話しかけられる。

既定では「インテリジェント音声入力（intelligent dictation）」として動作する。話した内容を整形済みのテキストに変換し、「えー」「あのー」といったフィラーを自動的に除去し、文中の言い直しも拾って修正したうえで、カーソル位置へそのまま挿入する。

設定で Gemini の推論を有効にすると、画面のコンテキストとローカルファイルの情報を使った操作までできる。デスクトップ上の文書やファイルの要約、選択したテキストのトーン調整を伴う書き換え、音声指示による画像の生成・編集などが対象。公式ページでは「これらの獣医の書類を読んで、犬の病歴をペットホテル宛のメールにまとめて」「このメモを冒頭に TL;DR を付けたエグゼクティブサマリーにして」といった例が挙げられている。

提供は 2026-07-29 に macOS 版 Gemini アプリの全ユーザーへグローバル展開。言語は当初英語のみで、他言語は今後対応予定。配布は `gemini.google/mac/`。

## できるようになったこと

- Fn キー長押しで、任意のアプリのウィンドウから Gemini の音声モードを起動できる
- フィラー除去・言い直し補正込みの整形済みテキストをカーソル位置に直接入力できる
- 推論を有効にすると、画面上の内容とローカルファイルを踏まえた要約・書き換え・画像生成/編集を音声で指示できる

## 影響範囲

- 対象ユーザー: macOS 版 Gemini アプリの全ユーザー（グローバル展開）
- 対象プラン: 特定プラン限定の記載なし
- API / UI / 管理者機能: デスクトップアプリ UI。推論の有効化はアプリ設定
- 言語: 英語のみ（他言語は今後）

## 教材化メモ

- 「OS 全体で使える音声入力 + 画面認識」は Apple Intelligence と正面から重なる領域。プラットフォーム標準機能とサードパーティアプリの競合という切り口で説明できる
- インテリジェント音声入力は「音声入力の精度」ではなく「整形して挿入する」ことが本質。単純な文字起こしとの違いを教材で明確にしたい
- ローカルファイルを読ませる前提の機能なので、業務端末での利用範囲の線引き（何を読ませてよいか）が実運用の論点になる
- 英語のみの段階なので、日本語ユーザー向け教材では「今すぐ使える機能」としては扱えない
