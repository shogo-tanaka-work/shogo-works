# 2026-10-06 EmbeddingGemma 2

## 公式内容の日本語要約

Google が **EmbeddingGemma 2** を公開した。**テキスト、コード、画像、動画、音声を1つの共有埋め込み空間に載せる**マルチモーダル埋め込みモデルで、**端末上（オンデバイス）での検索・検索拡張生成を想定している。**

パラメータ数は **7.4億（740M）**で、テキスト専用なら **2.7億（270M）**まで落とせるモジュラー構成を持つ。ライセンスは **Apache 2.0** で商用利用に制約が少ない。コンテキスト長は **8,000 トークン**で、公式の換算では**音声約5.5分、画像29枚、動画58フレーム**に相当する。量子化時のメモリ要件は、Pixel 11 Pro でテキスト専用 **191MB**、フルマルチモーダル **567MB** とされている。

ベンチマークは **MTEB Code で 78.68**、MAEB でも結果を出しており、公式は「**1B 未満のマルチモーダル埋め込みモデルの中で先頭**」と表現している。一部ではより大きい競合モデルを上回るとしている。

配布は **Hugging Face と Kaggle** で、**Gemini Enterprise Agent Platform の Model Garden** にも追加予定である。デプロイは MediaPipe、LiteRT、transformers.js などの推論フレームワークに対応する。想定用途はオンデバイスのセマンティック検索、RAG パイプライン、コードのインデックス、メディアライブラリの整理、プライバシー優先のアプリケーションである。

## できるようになったこと

- **テキスト・コード・画像・動画・音声を別々のモデルなしに1つの埋め込み空間へ**載せられる
- **モバイル端末上で動く規模（量子化で 191MB〜567MB）**でマルチモーダル検索を実装できる
- **Apache 2.0** のため商用製品に組み込める

## 影響範囲

- 対象ユーザー: RAG / 検索を実装する開発者、オンデバイス AI を扱う開発者
- 対象プラン: オープンウェイト（Hugging Face / Kaggle）、Gemini Enterprise Agent Platform Model Garden は追加予定
- API / UI / 管理者機能: モデルウェイト配布（API ではない）
