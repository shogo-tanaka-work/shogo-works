# 2026-11-11 Sheets canvas を単独リンクとして公開

## 公式内容の日本語要約

Gemini で表データをダッシュボード・かんばん・カレンダー等のミニアプリにする Sheets canvas を、元スプレッドシートを共有せずに独自リンクで公開できるようになった。リンクは閲覧のみで、スプレッドシートとは別に公開範囲を設定できる。ソース更新のたびに自動再公開するか、現時点の静的ビューとして公開するかを選べる。

## できるようになったこと

- キャンバスのツールバーのアイコンから「Publish canvas」を選んで公開。リンクのコピー、公開範囲の変更、公開停止も同じ場所
- 公開できるのは編集権限を持つキャンバスのみ。現時点は Web 版 Sheets
- 管理者向けの新設定はなく、既存の「ウェブに公開」（Drive の共有設定）に従う
