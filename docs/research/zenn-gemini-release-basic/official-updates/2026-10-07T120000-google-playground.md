# 2026-10-07 Google Playground

## 公式内容の日本語要約

Google が **Playground** を公開した。ブラウザ上で会話しながらカスタムゲームを作り、遊び、共有できる実験的プラットフォームである。

白紙のキャンバスまたはスタータープロンプトから始め、プロンプトを打って即座にテストする。物理挙動、ルール、キャラクター、環境は「こう変えて」と頼むことで変更できる。完成したゲームは非公開のまま、リンク共有、または Playground の Explore ギャラリーへ公開のいずれかを選べる。ゲームはスマホ・ノート PC のブラウザで動く。一部ジャンルではリーダーボードとマルチプレイに対応し、Play Games プロフィールでハンドル取得・お気に入り・クリエイターのフォローができる。

**提供は 2026-10-07 開始、米国の18歳以上限定**（`playground.google`）。**作成側のアクセスは Google AI サブスクリプションに応じた段階的ロールアウト**で、ティアの内訳は発表に記載がない。他国への展開も言及されていない。

公式は「early experiment」と明示しており、機能は変わり得る。プロ水準のメカニクスと 3D 機能を加える **Unity Spark は未提供**で、テスト中・クローズドベータ予定とされる。公開されたゲームは Community Guidelines に沿った安全性スクリーニングとユーザー通報の対象になる。駆動モデルの名称は示されていない。

## できるようになったこと

- プロンプトだけでブラウザゲームを作成・公開・共有できる（米国18歳以上）

## 影響範囲

- 対象ユーザー: 米国の18歳以上の一般利用者
- 対象プラン: Google AI サブスクリプションに応じた段階的提供（内訳は非公開）
- API / UI / 管理者機能: Web（`playground.google`）
