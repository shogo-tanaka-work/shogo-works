# 2026-07-28 Google Docs の Gemini コメントワークフロー支援

## 公式内容の日本語要約

Google Docs のコメント（レビュー）フローを Gemini が支援する機能が4つ追加された。

1. コメント内容の要約と、コメントに対する質問応答
2. 新規コメントの自動挿入（Gemini がレビュー観点でコメントを付ける）
3. コメントスレッドへの返信案の生成
4. 受け取ったフィードバックに基づくドキュメント編集案の提示

- ロールアウト: 2026-07-28 から段階的展開（機能反映まで最大15日）
- 対象エディション: Business Standard / Plus、Enterprise Standard / Plus、Education Plus、Google AI Pro / Ultra（個人向け）、Education アドオン、AI Expanded Access
- 管理者設定: 「Gemini for Workspace in Drive」の有効化が必要
- エンドユーザー設定: 「Workspace smart features」の有効化が必要

## できるようになったこと

- 大量のコメントが付いたドキュメントで、コメント全体の論点を要約して把握できる
- レビュー観点のコメントを Gemini に付けさせられる
- コメントへの返信文案を生成できる
- フィードバックを反映した本文編集案を受け取れる

## 影響範囲

- 対象ユーザー: 上記エディションの Google Docs 利用者（特にレビュー・共同編集を伴う業務）
- 対象プラン: Business Standard/Plus、Enterprise Standard/Plus、Education Plus、Google AI Pro/Ultra ほか
- API / UI / 管理者機能: Docs のコメントUI、管理コンソールの「Gemini for Workspace in Drive」設定、ユーザー側の smart features 設定
