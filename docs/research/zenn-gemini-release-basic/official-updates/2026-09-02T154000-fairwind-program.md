# 2026-09-02 Fairwind Program

## 公式内容の日本語要約

Google が **Fairwind Program** を発表した。「政府と信頼されたパートナーが自社のサイバー防御ツールを使うための限定アクセスプログラム」と説明されている。同日発表の **Gemini 3.8 Flash Cyber** を提供する枠組みで、Cyber 版が一般提供されない代わりの導線にあたる。

優先される対象は3種類。**政府機関と国家サイバー当局、重要インフラ事業者（医療・通信・エネルギー・金融）、そして中核となるテクノロジープラットフォーム**である。全世界で **650 を超えるパートナーが参加**しているとしている。

提供物は **Gemini 3.8 Flash Cyber と CodeMender**（脆弱性修正に特化したツール）の組み合わせで、従来は数週間かかった修正作業に対し「検証済みでデプロイ可能なパッチを数分で生成できる」と位置づけている。

参加には運用面の厳格な基準が課される。**社内でアクセスできるチームを限定すること、多要素認証による保護を実装すること**が条件として挙げられている。プログラムページは `deepmind.google/fairwind-program` に用意されているが、**公式ポスト側に明示的な申込手順や詳細な適格要件の記載はない**。

## できるようになったこと

- 政府・重要インフラ・中核プラットフォーム事業者が、**Gemini 3.8 Flash Cyber と CodeMender** を限定提供で利用できる
- 脆弱性の発見から**検証済みパッチの生成まで**を数分単位で回す運用が視野に入る
- 参加には**アクセス範囲の限定と多要素認証**が要件

## 影響範囲

- 対象ユーザー: 政府機関、国家サイバー当局、重要インフラ事業者、中核テクノロジープラットフォーム。**一般企業・個人は対象外**
- 対象プラン: プログラム参加（限定アクセス）
- API / UI / 管理者機能: プログラム参加組織向けのモデル・ツール提供

## 教材化メモ

- **「強い能力を作ったうえで、配布先を絞る」という設計**が、2026年9月時点で複数社に共通して現れている。OpenAI は Astra の攻撃的サイバー能力を Daybreak Blue の審査済み防御側に限定し、Google は Cyber 版を Fairwind に限定した。**能力の公開と配布の分離**という考え方は、AI の提供設計を語るときの共通語彙になりつつある。
- **一般読者が「使えない発表」をどう読むか**の教材になる。使えないから無関係、ではない。**攻撃側の能力も同じ速度で上がっている**という前提の共有、そして自社が使う商用セキュリティ製品の背後で何が動き始めるかの予告として読める。
- **「アクセスできるチームを限定する」「多要素認証を必須にする」が提供条件になっている**点は、強い道具を渡す側が受け手の運用体制を問うという構図。社内で強力な AI ツールを配るときの内製ルールの参考になる。
