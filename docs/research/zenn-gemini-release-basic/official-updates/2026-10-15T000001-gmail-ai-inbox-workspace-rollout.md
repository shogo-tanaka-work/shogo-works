# 2026-10-15 Gmail の AI Inbox が有料 Workspace ユーザーへ展開

## 公式内容の日本語要約

**AI Inbox は、優先度の高いメールに追いつくための Gmail の機能である。** 2026年に先に Gmail（コンシューマー側）で提供され、今回**有料 Workspace ユーザーへ拡大された。**

**構成は2つである。**

- **Suggested to-dos（やることの候補）**: メールスレッドから**アクションアイテム・成果物・期限**を抽出する。
- **Topics to catch up on（追いつくべき話題）**: 主要なスレッドを要約する。**決定事項や状況の変化**を含む。

**展開スケジュールはドメイン種別で分かれている。**

- **Rapid Release ドメイン**: 段階的展開は **2026-10-12 開始**。表示まで最大15日。
- **Scheduled Release ドメイン**: 段階的展開は **2026-10-26 開始**。表示まで最大15日。
- **Starter と Education エディション**: 展開は「今後数か月（coming months）」の予定。

**対象エディションは次のとおり。** Business: Starter / Standard / Plus、Enterprise: Starter / Standard / Plus、Education: AI Pro for Education、その他: Frontline Plus。

**管理者コントロールが無い点が要点である。** 公式は **"There is no admin control for this feature."** と明記している。利用者は Gmail のデスクトップクライアントまたはモバイルアプリのメニューから使う。

**提供範囲に制限がある。** 現時点では**米国の、言語設定が EN-US のユーザーのみ**である。

**公式表記に不整合がある。** Starter と Education は対象エディション一覧に載っている一方、注記では後から展開するとされている。**この2エディションの展開時期は公式上あいまいである。**

## できるようになったこと

- Gmail がメールスレッドからアクションアイテム・成果物・期限を抽出して提示する
- 主要スレッドの決定事項や状況変化が要約として表示される
- デスクトップとモバイルの両方から参照できる

## 影響範囲

- 対象ユーザー: 有料 Workspace（Business / Enterprise / Education AI Pro / Frontline Plus）の Gmail 利用者
- 対象プラン: 上記のとおり。Starter / Education は時期が未確定
- API / UI / 管理者機能: Gmail デスクトップ / モバイル UI。**管理者コントロールは提供されない**
- 制限: 米国・EN-US 設定のみ。表示まで最大15日
