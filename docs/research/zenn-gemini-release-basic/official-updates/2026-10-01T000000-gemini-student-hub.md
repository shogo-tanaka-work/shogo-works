# 2026-10-01 Gemini student hub

## 公式内容の日本語要約

Gemini アプリに、学習向けのツールを1か所へまとめた **student hub** が追加された。ハブからは「**学習ノート（study notebook）の開始、単語カード（flashcards）の作成、練習クイズ（practice quiz）の受験**」などが行え、**学習ツールは今後も追加**されるとしている。

**対象は、年齢を問わず Google Workspace for Education の全ユーザー、および個人の Google アカウント保有者（全世界）。** ただし **EEA（欧州経済領域）は対象外**である。

**2026-10-01 にローンチし、Rapid Release / Scheduled Release の両ドメインで即日利用可能**。

管理者は Workspace 管理コンソールの**既存の生成AI 設定**でアクセスを管理する。**エンドユーザー側の個別設定は無く**、`gemini.google.com/students` にアクセスするか、Gemini アプリのメニューで Students を選ぶだけで使える。

## できるようになったこと

- 学習ノート / 単語カード / 練習クイズへ1か所からアクセス
- Workspace for Education と個人アカウントの双方で利用（EEA 除く）

## 影響範囲

- 対象ユーザー: Workspace for Education 全ユーザー、個人 Google アカウント。**EEA は対象外**
- 対象プラン: 追加費用の記載なし
- API / UI / 管理者機能: 既存の生成AI 設定で管理。エンドユーザー設定なし
