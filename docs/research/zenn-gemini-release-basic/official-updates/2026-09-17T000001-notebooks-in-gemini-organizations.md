# 2026-09-17 Notebooks in Gemini の組織向け提供

教材化メモ: src/content/ai-news-notes/gemini/notebooks-in-gemini-organizations.mdx

## 公式内容の日本語要約

Google は 2026-09-17、**Notebooks in Gemini** を学校と組織へ提供拡大したと発表した。2026-04 に個人ユーザー向けに announce された「プロジェクトや会話をトピック単位で整理する専用スペース」が、**あらゆる年齢の学生・教育者・ビジネス利用者**に開放される。

公式が挙げる使い方は3つ。**学生**は科目ごとの教材を1つのノートブックへ入れ、Gemini を「その科目を把握した学習相手」にして練習問題の生成や難所の平易化に使う。**教育者**はカリキュラム基準・評価ルーブリック・授業テンプレートを入れ、基準に沿った課題や差別化教材、個別フィードバックを生成する。**ビジネス利用者**は製品情報・案件詳細・調査レポート・戦略メモを入れ、要点の統合と成果物の下書きに使う。

**Gemini アプリと Gemini Notebook という2つのツールが接続される点**が公式の強調点。ノートブックに授業メモを入れて Gemini Notebook で Cinematic Video Overview を作り、翌日 Gemini アプリから同じノートブックを開いて同じ素材で学習ガイドを作る、といった往復ができる。

**管理者設定は既定 ON。** Gemini App と Gemini Notebook のアクセス設定で制御され、**両方が ON のグループ / OU のユーザー**が使える。エンドユーザー側の設定は不要で、Gemini アプリの左パネルから「New notebook」で開始する。**ソースは1ノートブックあたり最大10件。**

**ロールアウトは 2026-09-14 開始**（Rapid / Scheduled Release とも段階展開、機能が見えるまで最大15日）。

## できるようになったこと

- 学校・組織アカウントで Notebooks in Gemini が使えるようになった
- Gemini アプリと Gemini Notebook で同じノートブックを行き来できる

## 影響範囲

- 対象ユーザー: 全 Google Workspace 顧客、Workspace Individual 加入者（**EEA を除く**）、および個人 Google アカウント（全世界）
- 対象プラン: 上記。Gemini と Gemini Notebook の両方が ON である必要がある
- API / UI / 管理者機能: **既定 ON のため、止めたい組織は明示的に OFF にする作業が発生する**
