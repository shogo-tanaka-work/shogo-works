# 2026-10-28 Gemini アプリに immersive explorations

## 公式内容の日本語要約

Gemini アプリで、題材を階層的に掘り下げる対話型の immersive explorations が使えるようになった。Gemini student hub と gemini.google.com/immersive-explorations から利用でき、管理者・ユーザーの設定項目はない。英語・インドネシア語・ヒンディー語・ブラジルポルトガル語・フランス語・簡体字中国語に対応し、他言語は英語のみ。音声ナレーションは今後追加予定。なお同日、Sheets のピボットテーブルにコンパクト形式（Excel インポートの互換性向上を含む）が追加された（ロールアウトは 2026-10-22 開始）。

## 影響範囲

- 対象: 全 Workspace 顧客、個人アカウント。日本語は未対応（英語のみ）

教材化メモ: 記事化しない（スコア不足 5）。日本語が未対応で、日本の読者の使い方は変わらない。
