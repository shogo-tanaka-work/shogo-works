# 2026-09-02 Google Vids のドキュメント→動画サマリー生成

## 公式内容の日本語要約

Google Vids に、**静的なドキュメントを動画サマリーへ変換する機能**が追加された。Google ドキュメント、PDF、Word ファイルを取り込むと、AI が台本を生成し、ナレーションを付け、対応するビジュアルを作成する。

想定用途として公式が挙げているのは、**研修資料のキャッチアップ、議事録、長いドキュメントのレビュー**である。テキストが多く読むのに時間がかかる資料を、視聴で追える形に変えることが狙いになる。

ロールアウトは2段階。**Rapid Release ドメインは即日利用可能**、**Scheduled Release ドメインは 2026-09-05 から段階的**で、機能が見えるまで最大15日かかる。

対象エディションは広い。**Business Starter / Standard / Plus、Enterprise Starter / Standard / Plus、Education Plus、Google AI Plus / Pro / Ultra（一般向け）、非営利団体**、および Education アドオン（Google AI Pro for Education、Teaching and Learning）である。

**管理者制御もエンドユーザー設定も存在しない。** `vids.new` から利用する。

## できるようになったこと

- Google ドキュメント / PDF / Word ファイルを **動画サマリーへ変換**
- **台本・ナレーション・ビジュアルを自動生成**
- Rapid Release は即日、Scheduled Release は 2026-09-05 から

## 影響範囲

- 対象ユーザー: 上記エディションの Workspace 利用者と、Google AI Plus / Pro / Ultra の一般ユーザー
- 対象プラン: Business / Enterprise / Education Plus / 非営利 / Google AI Plus 以上
- API / UI / 管理者機能: **管理者制御なし、ユーザー設定なし**
