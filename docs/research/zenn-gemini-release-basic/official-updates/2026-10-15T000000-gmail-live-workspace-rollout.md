# 2026-10-15 Gmail Live が有料 Workspace ユーザーへ展開

## 公式内容の日本語要約

**Gmail Live は、Gmail の音声検索機能である。** Android と iOS の Google Workspace 利用者が対象で、**最新の Gemini モデル**を使い、受信トレイについて音声で聞いた質問に**低遅延で、読み上げて答える。**

**各ターンでメールのソースカードが表示される。** 答えの根拠になったメッセージをその場で開けるため、**読み上げられた内容を自分で確認できる。** 音声（voice）は利用者が好みのものを選べる。

**開始方法は Gmail の検索バーの Live エントリポイントをタップする。** 初回はマイクへのアクセス許可を求められる。

**展開は 2026-10-15 開始で、Rapid Release と Scheduled Release の両ドメインが対象である。** 段階的な展開で、**表示されるまで最大15日かかる。**

**対象エディションは広い。**

- **Business**: Starter / Standard / Plus
- **Enterprise**: Starter / Standard / Plus
- **Frontline**: Plus
- **Nonprofits**: Google Workspace for Nonprofits
- **アドオン**: Gemini Business、Gemini Enterprise、AI Expanded Access、AI Ultra Access
- **教育向けアドオン**: Google AI Pro for Education
- **コンシューマー**: Google AI Plus / Pro / Ultra

**管理者の扱いが要点である。** Gemini in Workspace のアクセスがある組織では**既定でオン**である。既存の smart features とパーソナライゼーション設定を尊重し、管理者は Gemini 機能を利用者単位でオン・オフできる。

**提供範囲に制限がある。** 現時点では**米国の、言語設定が英語（米国）のユーザーのみ**である。

## できるようになったこと

- Gmail の検索バーから音声セッションを開始し、受信トレイの内容を音声で質問できる
- 回答が読み上げられ、各ターンで根拠となったメールをソースカードから開ける
- 読み上げの音声を利用者が選べる

## 影響範囲

- 対象ユーザー: Android / iOS の Gmail 利用者（Workspace 有料エディションおよび対象アドオン、コンシューマーの AI Plus / Pro / Ultra）
- 対象プラン: 上記エディション一覧のとおり。**既定オン**
- API / UI / 管理者機能: Gmail モバイルアプリ UI（検索バーの Live）、管理コンソールの Gemini 機能オン・オフ
- 制限: 米国・英語（米国）設定のみ。表示まで最大15日
