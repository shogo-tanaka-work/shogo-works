# 2026-09-09 Gemini が Workspace 横断のオーケストレーターになる

## 公式内容の日本語要約

Google は 2026-09-09、**Workspace Intelligence を使って Gemini が Workspace 横断の「インテリジェント・オーケストレーター」として動く**ようになったと発表した。Google Chat、Drive、Docs、Slides、Gmail のいずれで作業していても、そこから他アプリにまたがるタスクを Gemini に投げられる。

これまでは、各アプリの中に入って、そのアプリの Gemini に依頼する必要があった。今回の変更は、**作業中のアプリを離れずに、別アプリの成果物を作らせる**という点が新しい。

公式が挙げる用途は5つ。**(1) コンテンツ作成** — 任意のアプリから書式付きの Docs / Sheets / Slides を生成し Drive へ保存する。**(2) リサーチ** — フォルダやスレッドを横断してデータを統合し、出典付きの要約レポートにする。**(3) メール下書き** — 会議メモやドキュメントを元にメールを作成し、そのまま送信もできる。**(4) 会議設定** — 空き時間を探し、カレンダーの衝突をチャット上で解消する。**(5) タスク管理** — ToDo やリマインダーを作り、Google Tasks へ反映する。

ロールアウトは **Rapid Release / Scheduled Release の両ドメインで 2026-09-02 に開始**、最大15日の段階展開のため **2026-09-17 前後に完了見込み**。現時点では **英語のみ**で、他言語は今後対応。

## できるようになったこと

- Chat / Drive / Docs / Slides / Gmail のどこからでも Gemini に横断タスクを依頼できる
- 書式付きの Docs / Sheets / Slides を生成し Drive へ保存できる
- フォルダ・スレッド横断でリサーチし、出典付き要約レポートを作れる
- 会議メモやドキュメントからメールを下書きし、直接送信できる
- 空き時間探索とカレンダー衝突の解消をチャット上で行える
- ToDo・リマインダーを Google Tasks へ反映できる

## 影響範囲

- 対象ユーザー: Workspace のエンドユーザー全般（英語環境）
- 対象プラン: Business Standard / Plus、Enterprise Standard / Plus、Google AI Pro / Ultra（コンシューマー）、Frontline Plus（会議設定のみ）、Education アドオン
- API / UI / 管理者機能: UI（各アプリ内 Gemini）。段階展開 2026-09-02 開始 → 2026-09-17 前後完了見込み
