# 2026-09-23 Gemini の Connected Apps 拡大

## 公式内容の日本語要約

Google は 2026-09-23、**Gemini アプリの Connected Apps に新しい一群のサービスを追加**し、同日からロールアウトを開始した。タブを行き来せずに、プロジェクト管理、クリエイティブ制作、生活まわりの手続きを Gemini の会話の中で扱えるようにする、という位置付けである。

追加されたサービスは3カテゴリに分かれる。**Productivity** は Airtable、Linear、monday.com、PandaDoc、Wispr AI、Zoho。プロジェクト管理、データベースの整理、音声でのメモ取りなどが対象になる。**Creativity** は Adobe、Picsart、Squarespace、Webflow。ビジュアルアセットの制作やサイト構築を会話から扱える。**Lifestyle** は apartments.com（物件検索）、Experian（信用情報の確認）、Peloton（ワークアウト計画）、SeatGeek（イベントチケット）。

利用開始は Gemini の設定から対象アプリを接続するか、チャット内で `@` メンションするか、直接依頼するかのいずれか。

この拡大は、同じ週に Workspace 側で発表された **Gemini in Google Workspace の MCP 連携**（Asana / Atlassian Rovo / HubSpot / Intuit Mailchimp / Intuit QuickBooks / Monday / Salesforce、2026-09-18 の Weekly Recap 掲載）と方向が一致する。個人向けの Gemini アプリと業務向けの Workspace の両方で、外部 SaaS を会話から直接叩ける面が広がっている。

## できるようになったこと

- Gemini アプリから Airtable / Linear / monday.com / PandaDoc / Wispr AI / Zoho を操作できる
- Adobe / Picsart / Squarespace / Webflow をクリエイティブ作業の中から呼び出せる
- apartments.com / Experian / Peloton / SeatGeek を生活まわりのタスクで使える
- 設定からの接続、または `@` メンションで会話に持ち込める

## 影響範囲

- 対象ユーザー: Gemini アプリ利用者（2026-09-23 からロールアウト開始）
- 対象プラン: 公式ポストにプラン別の記載なし
- API / UI / 管理者機能: Gemini の設定画面に接続先が追加。`@` メンションで呼び出す導線
