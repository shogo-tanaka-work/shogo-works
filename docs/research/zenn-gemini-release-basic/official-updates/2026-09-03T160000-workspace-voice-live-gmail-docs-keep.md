# 2026-09-03 Gmail / Docs / Keep への音声機能追加

## 公式内容の日本語要約

Google が、**Gemini の音声モデル（Gemini Audio models、Gemini 3.5 Live 統合）を用いた3つの音声機能**を Workspace 製品へ追加すると発表した。いずれも「話しかけて作業を進める」形式で、タイピングを前提としない操作系である。

**Gmail Live** は、受信トレイに対する会話型の検索。公式例は「**What's my flight's gate number?**（自分のフライトのゲート番号は？）」のように尋ねるだけで情報を引き出せる、というもの。キーワード検索ではなく、質問の形で必要な情報へ到達する。

**Docs Live** は、ハンズフリーの執筆支援。リアルタイムの会話を通じて「**構造化された、文脈を踏まえた文書をその場で組み立てる**」。特徴的なのは参照範囲で、**Gmail、Drive、Chat、および Web から詳細を引いてくる**点が明記されている。文書作成の入力元が、開いている文書の中だけに閉じない。

**Keep Live** は、話した内容を整理されたメモへ変換する。公式表現では「**アイデアを捉え、構造化し、整理された実行可能なメモへ洗練する**」。

**提供対象はプランによって分かれる。**

- **Gmail Live と Keep Live**: **Google AI Plus / Pro / Ultra** の加入者
- **Docs Live**: **Pro / Ultra** のみ
- **Google Workspace のビジネス顧客向けは「coming soon」**

ロールアウトは公開時点（2026-09-03）の**「今週」から開始**。言語や地域の制約については、当該ポストに明示がない。

## できるようになったこと

- Gmail で、受信トレイの内容を音声の質問で検索できる（Gmail Live）
- Docs で、会話しながら構造化文書を作成でき、Gmail / Drive / Chat / Web から情報を引ける（Docs Live）
- Keep で、話した内容を整理済みのメモへ変換できる（Keep Live）

## 影響範囲

- 対象ユーザー: Google AI Plus / Pro / Ultra の個人加入者。Workspace ビジネス顧客は「近日提供」
- 対象プラン: Gmail Live・Keep Live は AI Plus / Pro / Ultra、Docs Live は Pro / Ultra
- API / UI / 管理者機能: 各製品の UI に音声操作が入る。管理者向け統制の記載は当該ポストになし（Workspace 展開時に別途告知される見込み）
