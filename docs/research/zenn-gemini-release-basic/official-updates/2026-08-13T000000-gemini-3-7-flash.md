# 2026-08-13 Gemini 3.7 Flash

## 公式内容の日本語要約

Google が Flash 系列の新モデル **Gemini 3.7 Flash** を公開した。位置づけは「コーディングとエージェント向けの、これまでで最も賢い実用モデル」。**Gemini 3.6 Flash のわずか3週間後**のリリースで、開発者フィードバックとアルゴリズム面の改良が反映されている。

ベンチマークでは 3.6 Flash からの伸びが明確である。FrontierCode 1.1 Main が **43.6%（3.6 Flash は 34.4%）**、DeepSWE v1.1 が **65.3%（同 49.0%）**。Web 開発では WebDev Arena の Elo が **1588（同 1538）**。文書処理を測る GDP.pdf は **34.0%（同 22.0%）**、実業務ワークフローを測る AutomationBench は **30.4%（同 17.0%）** と、いずれも大きく改善している。

UI 生成では、スクリーンショット・画像・デザインシステムのいずれを参照入力としても、デザインへの追随度が高いとされる。

開発者体験の面では、行き詰まりへの適応、意図の確認、指示追従の忠実さが向上し、多段の計画立案とツール呼び出しにより多くの労力を割くとされている。手動での監督と再試行が減る方向である。

**価格が重要**である。年末までの導入価格として **入力 $0.75 / 1M トークン、出力 $3.75 / 1M トークン**。公式は「3.6 Flash の当初価格の半額」としている。導入価格は **2026-12-31 で終了**する。

Google AI Pro / Ultra の加入者が160か国以上で使える Gemini Spark も、同日から 3.7 Flash を使うようになった。CBRN とサイバー領域の悪用に対する安全策が更新された状態で出荷されている。

**本エントリは前窓（2026-08-14 の巡回）で取りこぼしたものである。**当該巡回では `blog.google` の Gemini ページを確認したが、Gemini App 面の最新記事（connected apps、2026-08-12）だけを見て「窓内の新規なし」と判定していた。同ページには Gemini Models 面のセクションが別にあり、そこに 3.7 Flash が掲載されていた。

## できるようになったこと

- コーディング・エージェント用途で 3.6 Flash から大幅に改善したモデルを使える
- 導入価格 $0.75 / $3.75（1M トークン、入力 / 出力）で 2026-12-31 まで利用できる
- Gemini Spark が 3.7 Flash で動くようになった（160か国以上、Google AI Pro / Ultra）

## 影響範囲

- 対象ユーザー: Gemini API 利用者、Gemini Spark 利用者
- 対象プラン: API は従量課金（導入価格は 2026-12-31 まで）。Spark は Google AI Pro / Ultra
- API / UI / 管理者機能: Gemini API のモデル指定、Gemini Spark
