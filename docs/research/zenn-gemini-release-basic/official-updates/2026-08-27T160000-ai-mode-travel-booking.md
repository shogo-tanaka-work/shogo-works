# 2026-08-27 検索 AI Mode の旅行機能

## 公式内容の日本語要約

Google 検索の **AI Mode** に、旅行の計画から予約までを完結させる3機能が追加された。

**航空券の価格追跡**: AI Mode に運賃の監視を頼むと、価格が変動したときにメールで通知される。**300を超える航空会社・旅行パートナー**のデータを参照し、**180以上の国と地域**で利用できる。

**ポイント・マイル表示**: 航空券とホテルの必要マイル数／ポイント数を、ロイヤルティプログラムの単位で表示する。初期対応は Alaska Airlines、American Airlines、Choice Hotels、Hilton、Wyndham。Accor、Flying Blue、Hyatt、LATAM、Lufthansa Group が「数週間以内」に追加予定。

**ホテル予約**: AI Mode 内でホテルを探し、そのまま予約まで完了できる。決済は Google Pay。**米国・英語でロールアウト開始**で、今後数週間かけて拡大する。パートナーに Booking.com、Expedia、Marriott ほか。

なお、公式ページの注記により**欧州のユーザーには一部制限がある**。

## できるようになったこと

- AI Mode 内での航空券価格の監視とメール通知（180以上の国と地域）
- マイル／ポイント建てでの必要数表示
- AI Mode 内でのホテル検索から予約・決済までの完結（米国・英語から）

## 影響範囲

- 対象ユーザー: Google 検索の AI Mode 利用者
- 対象プラン: 検索の AI Mode（公式に有料プラン限定の記載なし）。ホテル予約は米国・英語から段階提供
- API / UI / 管理者機能: Google 検索の UI

## 教材化メモ

- **検索が「探す場所」から「やり終える場所」へ移った**具体例。予約と決済まで内包した時点で、比較サイト・OTA のトラフィック構造が変わる。**AI が入口を握ると、その下流のビジネスモデルが再編される**という話の実例として、SEO / LLMO の教材に接続できる。
- 一方で、**日本の読者はまだ使えない**（ホテル予約は米国・英語から）。「海外で先に出た機能が日本に来るまでのラグ」をどう扱うかは、情報発信の実務判断として教材にできる。今すぐ使えない機能を紹介する価値は、**構造の変化を先に理解しておくこと**にある。
