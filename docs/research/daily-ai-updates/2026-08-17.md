### Claude Code の公式ガイダンスを速報化しなかった理由

速報記事の枠（要約 / 何が変わったか / 業務インパクト / 副業・個人活用視点）に載せると、**「何が変わったか」節に書くことがない**。無理に速報化すると、読者が「Claude Code に新機能が入った」と誤読する。

内容の価値自体は高い。公式が数値（出力は入力の約5倍、キャッシュ読み出しは入力の 0.1 倍、プロンプトキャッシュは約1時間で失効）を明示しており、`/clear`・`/compact`・`/context`・@-mention・effort の設定タイミングという具体的な操作まで示している。したがって **B判定（Knowledge へ最小反映）** とし、`src/content/knowledge/ai-tools/claude-code/daily-operations.mdx` への追記を別タスクとして残す。
