**本数上限（最大10本）には達していない。** スコア6点以上が8件で、**全件を記事化した。** **`見送り（本数上限）` は0件、`見送り（週次ロールアップへ）` は4件、`見送り（スコア不足）` は3件、`見送り（対象外）` は4件、`見送り（既出・未マージPR）` は1件。** **Claude Code / Codex の例外枠（1回2本まで）は1本使用（Codex 1 / Claude Code 0）。**

**記事8本のツール内訳は ChatGPT・OpenAI 7 / Codex 1 で、極端に OpenAI へ偏っている。** 通常であれば偏りを是正するところだが、**本日は OpenAI の年次開発者会議当日であり、窓内更新16件のうち11件が OpenAI 関連という実態を反映した結果**である。**他ツールで6点以上に達した候補は1件も無く**、枠を空けるために OpenAI の記事を削る判断はしなかった（`selection-rubric.md` はスコア6点未満の記事化を禁じており、逆に6点以上を本数調整のために落とす規定は無い）。

**DevDay の発表を7本に分割した判断について。** 1本の大型記事にまとめる案も検討したが、**(1) 対象読者が異なる**（dots とプラン変更は利用者、Agents API と plugin extensions は開発者、Private Intelligence は情シス・法務）、**(2) 期限付きの告知（Pro 200 減枠、2026-10-30）が他の発表に埋もれる**、**(3) 上限10本に対して余裕がある**——の3点から分割した。`selection-rubric.md` は「本数を絞る前に記事を薄くしない」としており、**逆に言えば枠があるうちは分割して厚みを保つ方が規約の趣旨に合う。**
