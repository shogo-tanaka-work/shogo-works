**本日は Cloudflare Birthday Week 2026 の一日である。** 窓内の更新18件のうち **10件が Cloudflare** に集中した。総論記事「The Internet has a second audience」が発表群の索引になっており、**「インターネットには第2の観客（AI エージェント）がおり、全リクエストの半分以上を占める」**という整理のもとに、可視化（AI Crawl Control / BotBase）・制御（Web Bot Auth）・**課金（Pay Per Use / Monetization Gateway）**の3層で製品を並べている。

**発表群を貫く方向は1つである。「エージェントを排除する対象から、支払い能力のある顧客として扱う」への転換である。** HTTP 402 は仕様に20年以上ありながら使われてこなかったが、**顧客が画面を見ない相手になった瞬間に実用的になった**。Monetization Gateway はこれを x402（Coinbase の Facilitator、Base チェーン上の USDC）で実装し、**Cloudflare 自身が AI Gateway の Machine Payments で本番利用している**。

**同時に、エージェントへ渡す実行環境の側も刷新された。** Containers は**起動中央値 648ms（従来4秒強から約6.2倍）**、ファイルシステムのスナップショット（パブリックベータ）、実行時のイメージ選択（`durable_object` スケジューリングポリシー）。Sandbox SDK 1.0 では**外向き通信を Worker 側で代行して資格情報をサンドボックスへ渡さない**構成が可能になった。**旧 `Container` / 旧 `Sandbox` クラスと Sandbox SDK 0.x は 2026-12-31 でメンテナンス終了**という期限付きである。
