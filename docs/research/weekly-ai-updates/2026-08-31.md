## 補足メモ

- **未マージの日次 PR の確認**: 着手前に open な日次 PR を洗い出した。**open は1本（PR #382 / `feat/daily-ai-update-2026-08-31`）**。内容は 2026-08-31 の日次サマリー1ファイルのみで、**窓内の更新0件・記事化0本**のため、ロールアップの再掲リスクは無い。同 PR の日次サマリー本文も参照し、Claude Code / Codex とも窓内の新規 stable リリースが無いことを確認済み。他の日（08-25 〜 08-30）の日次サマリーはすべて `main` にマージ済みで参照できた。**参照できなかった日はない。**
- **日次パイプラインの欠測**: `docs/research/daily-ai-updates/` に **2026-08-24 のファイルが存在しない**（08-23 の次が 08-25）。窓の初日にあたるため、**08-24 に公開された更新のうち、08-25 のサマリーが拾っていないものは本ロールアップでも拾えていない**可能性がある。SKILL の規定どおり**欠測分の遡り調査は行わない**（窓が二重になるため）。なお 08-25 のサマリーは Claude Code 2.1.241（08-23T00:52Z 公開）を「どの実行にも覆われていない期間の分」として明示的に拾っており、この前後の取りこぼしは限定的と見られる。
- **セキュリティ修正の告知面**: 今週のロールアップ対象には、Claude Code 2.1.251 の**シンボリックリンク経由の権限回避（TOCTOU）修正**と 2.1.248 の**資格情報ファイルのクラウド送信修正**、Codex 0.151.0 の**権限変更後に古い Guardian 分類が承認してしまう問題の修正**が含まれる。`selection-rubric.md` の方針により日次では単独記事にしないため、**週次ロールアップが唯一の告知面**である。両記事とも「今週の要点」の冒頭でこれを最初に書いた。
