- **今週は「MCP の権限統制」が3製品で同時に動いた。** GitHub Copilot はグローバル既定ポリシーの対象に **MCP servers in Copilot** を含め（10-22、本日展開完了）、使用状況メトリクスで **MCP サーバーを名前付きで集計**できるようにした（10-22）。Microsoft Copilot は Cowork に **MCP 経由の federated コネクタ**（利用者自身の権限を使う）を追加した（10-21）。n8n は 2.45.0 で **MCP ツール権限の全面見直し**を入れた（10-20）。**MCP が「つながるか」から「誰に何を許すか」へ移った週である。** 日次では別ツールの別告知として散るため、週次でまとめて見ることで初めて見える並行性であり、**本 Skill の存在意義がそのまま出た形**である。
