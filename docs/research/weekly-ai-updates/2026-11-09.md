  - **AI Search の課金開始: 2026-12-01（残り22日）**。日次 #533 で記事化済み（Cloudflare）。本週次の対象外
- **退役告知の3つの型が同じ週に揃った。** ①**止まる**（Claude Code の Opus 4.8 fast mode、11-30）、②**代替が自動で有効になる**（GitHub Copilot の3モデル、11-16）、③**自動で流れるが設定が下位へ変わる**（xAI の `grok-imagine-image-quality` → `-2.0-low`、11-02 発効）。③は**エラーにならずに出力の質が変わる**ため最も気づきにくい。教材化メモに対比として記録した
- **利用者側の対応が必要な変更（ロールアップ以外）**
  - **n8n 2.47.0 / 3.1.0 の送信リクエストガードの既定ブロック IP レンジ拡張**。内部ネットワーク宛てのリクエストを行うワークフローは止まりうる。プロジェクトスコープの適用追加（フォルダ一覧、MCP インスタンスコンテキスト）も権限が狭まる方向
  - **Dify 1.19.0 のアップグレード要件**。Docker Compose 2.35.0 以降が必須、アプリパッケージが v2 固定（**古いインポーターは拒否しうるため、インポート先を先に上げる**）、ローリング更新ではトレースキューを `ops_trace_v2` へ分離し**旧キューを purge しない**
  - **GitHub Copilot の使用状況メトリクスの読み方**。`null` は false / 0 ではなく「データなし」、テレメトリ欠落と旧バージョンの2カウントは**重複しうるので合算しない**、ローカル BYOK は**下限値**、新フィールドは遡及適用されない。impact dashboard の計測追加も遡及しないため、変更日を跨いだ時系列の比較は誤読を生む
- **統制上の論点として記録しておくもの**（いずれも記事化はしていない）
  - **Copilot の JetBrains Air 統合**は、Air 側の governance / analytics に Copilot 利用が出ず、**Air 内から Copilot の支出上限を設定できない**。課金は Copilot 側、実行と可視化は IDE ベンダー側に分かれる
  - **Cursor Build Live Apps** は、社内システム接続用のシークレットを Cursor 側へ預ける構造で、**チーム管理者はシークレットを閲覧できる**
  - **M365 Copilot Cowork のローカル Edge 利用**は、利用者がサインイン済みのサイトを AI が操作する。資格情報・Cookie・セッショントークンは端末に留まると明記されているが、**操作の権限は利用者と同じ**
  - **assisted tool approval（Copilot、オプトイン）** は、2026-10-26 GA の assisted permissions と同系列で、**承認の判定自体を LLM に委ねる**層が各ツールへ広がっている
