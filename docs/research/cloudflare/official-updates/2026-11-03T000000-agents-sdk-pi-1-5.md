# 2026-11-03 Agents SDK が Pi 1.5 に対応（保存書き込み削減・session API 変更）

## 公式内容の日本語要約

Agents SDK v0.33.0 が PiHarness を Pi 1.5 へ更新。ストリーミング中のストレージ書き込みを一括化し（SQLite で長文回答 約27倍・並列ツール 約5.7倍の削減）、2,048 セッションのベンチで 1 harness あたり 88→459 run/秒、500KB のツール呼び出しのストリームも低メモリ化した。一方で session.events() は session.watch() に置換、retry() と parked ステータスは削除。Pi 1.5 で動かした会話は Pi 1.4 で読めず、ロールバック不可。新 API は session.continue()、defaults.maxTurns、code mode から browserTool 呼び出し。既定設定ではクラッシュ時に最大約1秒分のストリーム途中経過を失い得る。
