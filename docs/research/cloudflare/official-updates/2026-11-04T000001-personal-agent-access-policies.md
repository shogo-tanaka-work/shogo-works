# 2026-11-04 Bots: 主要な Personal Agent ごとのアクセス制御（Account Abuse Protection の AI assistant 可視化を併記）

## 公式内容の日本語要約

「Configure AI bot policies」が「AI Crawler and Agent access policies」に改名され、主要な Personal Agent を個別に Allow / Block on pages with ads / Block できる。Security Analytics に Personal Assistants カテゴリと、どのエージェントが来ているかのウィジェットを追加（blog 11-04）。11-03 には Account Abuse Protection（early access）がログイン・サインアップ時の AI assistant とその対象アカウントを表示する更新も出ている。製品面は Bots / セキュリティ寄りで、AI エージェント対応という点でのみ対象。
