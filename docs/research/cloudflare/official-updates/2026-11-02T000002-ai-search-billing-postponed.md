# 2026-11-02 AI Search の課金開始が12月1日に延期、既定の同期間隔は24時間に

## 公式内容の日本語要約

AI Search の課金開始が 2026-11-01 から 2026-12-01 へ1か月延期された。料金と含まれる使用量は変更なし。12月1日より前の利用は課金されない。あわせて AI Search インスタンスの既定の同期間隔が 6 時間から 24 時間に変わる。15 分〜24 時間の範囲で従来どおり選べる（設定画面または API の `sync_interval`）。

## 影響範囲

- 対象: AI Search 利用者
