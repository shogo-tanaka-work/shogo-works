# 2026-10-30T14:23:43Z Cloudflare services for private origins が一般提供

## 公式内容の日本語要約

プロキシ有効な A / AAAA レコードをプライベート IP に向け、Cloudflare One の接続（IPsec・GRE・CNI・Tunnel・Mesh）経由で公開トラフィックを非公開オリジンへ届ける。WAF・Bot 管理・レート制限・キャッシュ・Workers が公開オリジンと同様に使える。Private Origins の entitlement はアカウントチームが有効化する必要があり、Argo Smart Routing と Dedicated CDN Egress IP は非対応。プライベート間通信は2027年初頭にクローズドベータ予定。
