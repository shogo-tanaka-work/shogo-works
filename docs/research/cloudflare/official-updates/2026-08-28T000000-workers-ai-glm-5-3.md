# 2026-08-28 Workers AI に Z.ai GLM-5.3

## 公式内容の日本語要約

Cloudflare Workers AI に **Z.ai GLM-5.3**（モデル ID `@cf/zai-org/glm-5.3`）が追加された。Z.ai のフラッグシップの**エージェント型コーディングモデル**で、長時間・ツール駆動の開発ワークフロー向けと説明されている。推論（reasoning）と function calling に対応する。

**コンテキストウィンドウは 100万トークン**。価格は **入力 100万トークンあたり 1.40 ドル、キャッシュ済み入力 0.26 ドル、出力 4.40 ドル**。

公式が掲げるベンチマークは、Terminal Bench 2.1 が 88.2、Terminal Bench 3.0 が 28.3、DeepSWE が 66.9、FrontierSWE が 78.1。

利用には **Workers Paid プラン、または AI Gateway のプリペイドクレジット**が必要。アクセス経路は Workers AI binding、REST API、OpenAI 互換エンドポイント、AI Gateway の4通り。

なお、同系列の軽量版 **GLM-5.3 Flash** は 08-26 に Workers AI へ追加済みで、AI Search 側での対応は changelog 上 **2026-08-30 付**（本日の窓外）で告知されている。

## できるようになったこと

- Workers AI 上で **GLM-5.3** をエージェント型コーディング用途に呼び出せる（コンテキスト100万トークン、function calling 対応）
- OpenAI 互換エンドポイント経由で既存クライアントからも利用できる

## 影響範囲

- 対象ユーザー: Workers AI / AI Gateway の利用者
- 対象プラン: **Workers Paid** または AI Gateway プリペイドクレジット
- API / UI / 管理者機能: Workers AI binding、REST API、OpenAI 互換エンドポイント、AI Gateway

## 教材化メモ

- 記事化しないため、この節を残す（本数上限による見送り、スコア7）。**「エージェント型コーディングモデルをエッジの推論基盤から使う」**構成は、モデル提供元の API を直接叩く構成との比較教材になる。ゲートウェイ側でキャッシュ・レート制御・ログを一元化できる代わりに、モデルの追加は基盤側の対応待ちになる。
- **キャッシュ済み入力が通常入力の約1/5（0.26 ドル対 1.40 ドル）**という価格差は、プロンプトキャッシュ設計の効き方を数字で示す材料になる。長いシステムプロンプトを持つエージェントほど差が出る。
- ベンチマーク数値は公式掲載値をそのまま記録している。Terminal Bench は 2.1 と 3.0 で数値の水準が大きく違うため、**版が異なるベンチマークの数値を横並びにしない**という注意点の実例にできる。
