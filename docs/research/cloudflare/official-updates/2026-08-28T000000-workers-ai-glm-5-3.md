# 2026-08-28 Workers AI に GLM-5.3

## 公式内容の日本語要約

Cloudflare は 2026-08-28、**Z.ai の GLM-5.3 を Workers AI で提供開始**した。モデル ID は `@cf/zai-org/glm-5.3`、**コンテキストウィンドウは 1M トークン**である。

**価格は前世代（GLM-5.2）と同額**に据え置かれた。入力 100万トークンあたり **$1.40**、キャッシュ済み入力 **$0.26**、出力 **$4.40**。

Cloudflare が引用しているベンチマークは、コーディングとエージェント系で伸びが大きい。**Terminal Bench 2.1 が 81.0 → 88.2**、**Terminal Bench 3.0 が 4.6 → 28.3**、**DeepSWE が 46.2 → 66.9**、**FrontierSWE が 67.5 → 78.1**、**SWE-Marathon が 19.4 → 42.5**。Z.ai 自身は社内の Z.ai Code Bench で **GLM-5.2 比 50% の改善**としている。

## できるようになったこと

- Workers AI 上で `@cf/zai-org/glm-5.3` を呼び出せる
- 1M トークンのコンテキストを、前世代と同じ単価で使える

## 影響範囲

- 対象ユーザー: Workers AI 利用者、Cloudflare 上でエージェント／コーディング支援を組む開発者
- 対象プラン: Workers AI の従量課金
- API / UI / 管理者機能: モデル ID 指定で利用可能
