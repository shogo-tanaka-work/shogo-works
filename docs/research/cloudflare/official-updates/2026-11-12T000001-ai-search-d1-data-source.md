# 2026-11-12 AI Search が D1 をデータソースに対応（beta）

## 公式内容の日本語要約

AI Search が D1 データベースをソースにでき、指定した読み取り専用クエリの各行を1ドキュメントとして索引化する。定期同期で追加・変更・削除を反映する。ダッシュボード、REST API、Workers バインディングから作成できる。
