# 2026-09-08 Miniflare v5

## 公式内容の日本語要約

Cloudflare は 2026-09-08、**Miniflare v5** を公開した。Miniflare は `wrangler dev`、Cloudflare Vite プラグイン、`@cloudflare/vitest-plugin` の背後で Workers のローカル実行を担うライブラリである。今回のリリースは、**次世代の CLI（`cf` CLI）に向けた土台の整理**という位置づけで、内部構造の刷新が中心である。

設定面では、**設定の形が `cloudflare.config.ts`（Cloudflare のプログラマティック設定形式）に揃えられた**。あわせて非推奨 API とレガシーオプション（D1 alpha バインディング等）が削除され、`wrappedBindings` のような内部 API も不要となり撤去された。

機能面では、**組み込みのモジュール探索が削除**され、モジュールグラフの解決は上位ツール側の責務になった。ローカル専用ルートは `/cdn-cgi` 配下から **`/cdn-cgi/local` 配下へ移動**した。永続化オプションはリソースごとの設定をやめ、**共有のルートオプションへ統合**された。

**Wrangler や Vite プラグイン経由で使っている大多数の開発者に必要な対応はない**と公式に明記されている。移行期限の提示もない。直接 Miniflare を API として利用しているケースだけが影響を受ける。

## できるようになったこと

- 設定の形が **`cloudflare.config.ts` と一致**した
- 永続化オプションが**共有ルートオプションへ統合**された
- ローカル専用ルートが **`/cdn-cgi/local`** へ移動した
- 非推奨 API・レガシーオプション（D1 alpha バインディング等）が削除された
- 次世代 **`cf` CLI** の基盤が整った

## 影響範囲

- 対象ユーザー: Workers 開発者。ただし **Wrangler / Vite プラグイン / vitest プラグイン経由の利用者は対応不要**
- 対象プラン: 記載なし（開発ツール）
- API / UI / 管理者機能: ローカル開発ツール（Miniflare の公開 API）
