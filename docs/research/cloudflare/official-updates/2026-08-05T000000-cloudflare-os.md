# 2026-08-05 Cloudflare OS

## 公式内容の日本語要約

Cloudflare が、社内業務向けに AI エージェントとカスタムアプリを配置するためのオープンソースプラットフォーム「Cloudflare OS」を公開した。同社が自社の働き方を作り替えるために内製したものを、そのまま OSS として出す形になっている。

中核はブラウザからアクセスする「エージェントワークスペース」で、社内の文脈とスキルを与えた状態でエージェントを動かす。ドキュメント、スライド、スプレッドシート、さらにはカスタムアプリの生成に対応し、定型作業は決定論的なワークフローとして固定できる。「コードで確実に処理する部分」と「AI の判断に任せる部分」を混在させる設計になっている。

アクセス制御は「Gatekeepers」と呼ぶ、サービスごとの Worker が担う。エージェントは**アクセス権ゼロの状態から始まり**、必要なリソースを都度申請する。認証情報は生成されたコードから隔離され、アクセスポリシーは参照したリソースを追跡して意図しない共有を防ぐ。

生成されるアプリはフルスタックの Workers で、クライアント側のブラウザ UI とサーバー側（SQLite を持つ Durable Object Facets）で構成される。作ったアプリはそのまま共有することも、他人が独立したコピーを作れる「ブループリント」として共有することもできる。

モデルは AI Gateway 経由で任意のものを接続でき、チーム・ワークスペース単位でコストと予算を管理できる。GitHub 上でスターターリポジトリとともに OSS 公開されており、記事中に個別の価格提示はない（デプロイ先は Cloudflare のインフラ）。想定利用者は「社内の全員」で、非エンジニアからエンジニアまでを対象としている。

## できるようになったこと

- 社内文脈を持つエージェントワークスペースをブラウザから利用できる
- ドキュメント / スライド / スプレッドシート / カスタムアプリを生成できる
- 定型作業を決定論的ワークフローとして固定できる
- Gatekeepers によりエージェントを「権限ゼロ起点 + 都度申請」で運用できる
- 生成アプリを Workers + Durable Object Facets(SQLite) としてデプロイできる
- アプリをブループリントとして配布し、各自が独立コピーを持てる
- AI Gateway 経由で任意モデルを接続し、チーム単位で予算管理できる

## 影響範囲

- 対象ユーザー: Cloudflare アカウントを持つ組織（非エンジニアを含む全社員を想定）
- 対象プラン: OSS として GitHub 公開。デプロイ先の Cloudflare 利用料に依存
- API / UI / 管理者機能: ブラウザ UI + Workers デプロイ + 管理者向けアクセスポリシー
