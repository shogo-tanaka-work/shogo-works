# 2026-09-28 EmDash 1.0

## 公式内容の日本語要約

**EmDash 1.0 は Astro 上に構築された無償・オープンソースの CMS** で、開発者・編集者・**AI エージェント**が協働してサイトを作り運用することを想定している。**ライセンスは MIT**、175名超のコミュニティ貢献者。**即日本番利用可能**で、デプロイ先は Cloudflare Workers / Node.js 環境 / 自前ホスティング。

**プラグインレジストリが分散型である。** 「開発者が自分のアイデンティティやリリースの所有権を中央マーケットプレイスへ渡さずに公開できる」設計で、サイト運営側は権限境界が明示された状態でプラグインを探して導入する。**プラグインはシステムへ無制限にアクセスするのではなく、隔離されたサンドボックス内で動作する**——従来型 CMS のセキュリティ課題に対する回答として位置づけられている。

**エージェント向けワークフローとして API / CLI / MCP サーバーを内蔵**し、AI アシスタントがコンテンツとサイト運用を管理できる。

## 影響範囲

- 対象ユーザー: Astro でサイトを作っている開発者、CMS を選定中の制作者
- 対象プラン: OSS（MIT）。Workers へデプロイする場合は Workers の通常課金
- API / UI / 管理者機能: CMS 本体、プラグイン権限モデル、MCP サーバー

## 教材化メモ

- **単独記事は見送り（スコア5）。** 当サイト自身が Astro 製であり関心は高いが、**AI ニュースとしての読者価値は CMS 選定の文脈に限られる**。Knowledge 側で Astro / サイト構築を扱う回に参照するのが適切。
- **プラグインをサンドボックスで動かす設計**は、WordPress 系のプラグイン起因の事故と対比する教材になる。「プラグインに全権を渡さない」という前提の置き方。
- **分散型レジストリ**は、中央マーケットプレイスへの依存（アカウント停止・審査方針の変更）というリスクの話に繋げられる。
