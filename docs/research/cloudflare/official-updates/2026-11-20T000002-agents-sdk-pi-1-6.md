# Agents SDK - Pi 1.6 対応

## 公式内容の日本語要約

Agents SDK v0.34.0 が PiHarness を Pi 1.6 へ更新。ツールが人の返答・期限・別セッションを待つ間、Durable Object を起こしたままにせず休止できる（park / harness.signal()）。subagent 待ちの notify、beforeTool での承認ゲート、既存履歴からのセッション開始（init）、中断時にキュー入力を残す onAbort: "keep"、接続断の再試行改善。
