# 2026-11-09 Markdown for Agents GA

## 公式内容の日本語要約

Markdown for Agents が GA。ダッシュボード（Agent Readiness > Markdown for Agents）に Analytics（変換結果、推定トークン削減、上位ページ・UA、失敗理由）、Logs（サンプルイベント）、Playground（HTML との比較）を追加。GraphQL Analytics API の `markdownForAgentsAdaptiveGroups` で同じ集計を取得でき、Traces に `markdown_conversion` スパンが出る。件数はサンプル重み付き推定、トークン削減はバイト数ベースの推定。
