# 2026-09-30 Sandbox SDK 1.0

## 公式内容の日本語要約

Cloudflare は **Sandbox SDK 1.0** を公開した。サンドボックス用コンテナを、**自分で定義した Durable Object クラスから直接管理できる**ようになった。

Durable Object 側が制御できるようになったのは次の範囲である。**イメージとサイズの決定** — サンドボックス起動ごとに異なるイメージ・インスタンスサイズを選べ、デプロイ時に既存コンテナを再起動させない。**スナップショット** — サンドボックスを保存して後から復元（パブリックベータ）。**ライフサイクル管理** — タスク完了・ユーザーの活動状況などを基準に終了タイミングを開発者が決める。**コマンド実行** — 入出力のストリーミング、シグナル処理、ブラウザからのターミナル接続。**プレビューのホスティング** — サンドボックスのポートプレビューに独自ホスト名と認証を付与。**安全なネットワーク** — 外向きリクエストを Worker 側のコードで処理し、資格情報とバインディングを保護する。**エージェント統合** — AI エージェントを同じ Durable Object 内で動かし、サンドボックスのコマンド実行をツールとして渡せる。

**移行。** 既存の Sandbox SDK 0.x アプリは動作し続け、**バグ修正とセキュリティ修正は 2026-12-31 まで提供**される。段階移行と一括移行の両方に対応した移行ガイドが用意されている。

## できるようになったこと

- 自前の Durable Object クラスからサンドボックスのイメージ・サイズ・寿命を制御
- ポートプレビューへの独自ホスト名と認証
- 外向き通信を Worker 側へ寄せ、資格情報をサンドボックスへ渡さない構成
- 同一 Durable Object 内でエージェントを動かし、サンドボックス操作をツールとして提供

## 影響範囲

- 対象ユーザー: Sandbox SDK / Containers の利用者
- **期限: 0.x 系へのバグ・セキュリティ修正は 2026-12-31 まで**
