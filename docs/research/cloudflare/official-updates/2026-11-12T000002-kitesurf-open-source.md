# 2026-11-12 Kitesurf がオープンソース化

## 公式内容の日本語要約

エージェント向けブラウザエンジン Kitesurf が Apache 2.0 で公開された。Workers 上で動き、CDP 対応で Puppeteer 等から接続できる。自前デプロイには Dynamic Workers（Workers Paid）が必要で、組み込みの認証は無い。実験段階。
