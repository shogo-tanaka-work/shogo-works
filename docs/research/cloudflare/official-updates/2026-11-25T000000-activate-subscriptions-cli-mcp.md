# 2026-11-25 Cloudflare CLI と MCP からサブスクリプションを有効化

## 公式内容の日本語要約

これまで OAuth セッションを使う cf CLI と MCP サーバーはサブスクリプションを作れず、製品の有効化にダッシュボードでの決済が必要だった。今後は CLI と MCP から Workers Paid などを有効化できる。スコア 5（1/1/1/0/2）で見送り。

## 教材化メモ

エージェントに課金を伴う操作を任せるときの権限設計の題材。恒久教材化は不要。
