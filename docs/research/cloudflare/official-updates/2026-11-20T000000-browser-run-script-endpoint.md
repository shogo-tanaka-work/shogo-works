# Browser Run - /script で任意のブラウザスクリプトを実行

## 公式内容の日本語要約

Playwright / Puppeteer / CDP の関数を API 1回で実行できる /script を追加。隔離 Worker で実行され、Worker のデプロイ不要。/script/ 系で既存セッションへ追加実行、env.BROWSER.script()、Script Studio も提供。セッションは自動で閉じない。
