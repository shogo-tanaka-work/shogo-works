# 2026-08-18 Codex rust-v0.148.0

## 公式内容の日本語要約

`rust-v0.147.0` からの stable リリース。`## New Features` に6項目が並び、TUI の操作性、セッション管理、モデル提供元の3方向にまたがる。

**セッションの持ち出しと再利用**が中心的な変更である。TUI の会話を `/export` で Markdown としてクリップボードまたはファイルへ書き出せるようになった。加えて `codex exec fork` でセッションを分岐でき、resume picker からセッションのアーカイブと復元ができる。TUI 初期化中でもプロンプトを書き始められ、resume / fork の進捗が起動中に表示される。

**Amazon Bedrock Runtime が組み込みプロバイダとして追加**された。AWS profile / region の指定と GPT-5.6 のルーティングに対応する。自前で環境変数を組む必要がなくなり、AWS 上でモデル利用を集約している組織が Codex をそのまま載せられる。

**Hooks が非同期実行と MCP tool 呼び出しに対応**した（#37533、#38705）。従来の同期コマンド実行だけでなく、hook から MCP tool を叩けるため、Codex の実行前後に外部システムを絡めた処理を挟める。

`/status`、status line、ターミナルタイトルに**推定スレッドクレジットまたはコストが表示**される（対象ワークスペースのみ）。Bug Fixes では、sandbox が Linux / Windows で拒否パスや読めないパスに対し fail closed になった点が運用上重要である。

## できるようになったこと

- TUI 会話を `/export` で Markdown 出力（クリップボード / ファイル）
- `codex exec fork` によるセッション分岐、resume picker からのアーカイブ / 復元
- Amazon Bedrock Runtime を組み込みプロバイダとして利用（AWS profile / region / GPT-5.6 ルーティング）
- Hooks の非同期実行と、hook からの MCP tool 呼び出し
- `/status` / status line / ターミナルタイトルでの推定コスト表示

## 影響範囲

- 対象ユーザー: Codex CLI 利用者、AWS 上でモデル利用を集約している組織
- 対象プラン: コスト表示は対象ワークスペースのみ
- API / UI / 管理者機能: CLI・TUI の変更。sandbox は拒否パスに対し fail closed へ
