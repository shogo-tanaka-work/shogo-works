# 2026-09-04 OpenAI Codex 0.153.4

## 公式内容の日本語要約

Astra 対応ホットフィックスの4本目である。**バンドルのモデルピッカーで Astra が表示されるよう修正され、あわせてモデルが明示設定されていない場合の「バンドル既定モデル」が Astra になった**（#42874）。設定ファイルでモデルを固定していない利用者は、更新後に使われるモデルが変わることになる。

もう1件は、Astra の非同期の確認質問に関するガイダンスを**そのツールがセッションで利用可能なときだけ**適用するよう限定した修正である（#42878）。0.153.3 の修正の追い込みにあたる。

**バージョン番号付きリリースのため単独記事化しない（判定 D）。** ただし**既定モデルの変更は利用者に無断で挙動が変わる種類の差分**であり、週次ロールアップの「今週の要点」で明示すべき項目として引き継ぐ。

## できるようになったこと

- バンドルのモデルピッカーで Astra が見えるようになった
- モデル未設定時の既定が Astra になった

## 影響範囲

- 対象ユーザー: Codex CLI 利用者全般
- 対象プラン: Codex 利用者全般。**モデルを明示設定していない環境は既定が変わる**
- API / UI / 管理者機能: CLI のモデル選択

## 教材化メモ

「既定モデルが更新で変わる」ケースの実例として使える。CLI 系ツールの運用教材では、コスト・挙動の再現性を担保するために**モデルを設定ファイルで固定しておく**という指針を、この事例とセットで示せる。
