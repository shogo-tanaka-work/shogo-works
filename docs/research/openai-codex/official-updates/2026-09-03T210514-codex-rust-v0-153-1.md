# 2026-09-03 OpenAI Codex rust-v0.153.1

## 公式内容の日本語要約

Codex の stable **`rust-v0.153.1`** が公開された。**バージョン番号付きリリースのため単独記事にはしない**（週次ロールアップへ）。

新機能は1点のみである。

- **`GPT-6-Astra` を API 経由で設定できるようにした。既定モデルは変更せず、モデルピッカーにも表示しない。**

**同日（2026-09-03）の GPT-6 Astra 公開に対する、クライアント側の受け入れ準備にあたる。** 「既定を変えずピッカーにも出さない」という形は、**限定提供中のモデルを、設定を書ける利用者だけが先に使えるようにする**典型的な段階的展開である。Astra 本体の提供が「限定された組織 → 数日で全有料プラン・API」と告知されている点と整合する。

## できるようになったこと

- 設定ファイル / API 指定経由で `GPT-6-Astra` を Codex のモデルとして指定できる（アクセス権がある場合）

## 影響範囲

- 対象ユーザー: GPT-6 Astra へのアクセス権を持つ Codex 利用者
- 対象プラン: Astra が提供されている範囲に依存
- API / UI / 管理者機能: **既定モデルの変更なし。モデルピッカーへの表示もなし**

## 教材化メモ

- **「既定は変えず、ピッカーにも出さず、設定でだけ使える」**という出し方は、**段階的ロールアウトの実装パターン**として教材にしやすい。新モデルへの一斉切り替えは、性能・価格・挙動のいずれかで必ず誰かを壊す。**受け入れ側の準備を先に配り、切り替えは後から**という順序は、機能フラグの運用そのもの。
- クライアント（Codex）とモデル（Astra）が**同日にリリースされている**点も実務的。**新モデルを使うには、モデル側の提供だけでなくクライアント側の対応バージョンが要る**——この二段構えを見落とすと「アクセス権はあるのに使えない」という切り分けで詰まる。
