# 2026-08-26 Codex v0.150.0（stable）

## 公式内容の日本語要約

Codex の stable リリース v0.150.0。窓内の stable はこの1件で、alpha は `rust-v0.151.0-alpha.1`（19:56Z）、`alpha.2`（21:36Z）、`alpha.3`（23:08Z）の3件。

新機能の中心は**タスク間の参照**。`@` メンションで他の Codex タスクを参照でき、エージェントにタスクの読み取り・作成・メッセージ送信を依頼できる（#40308, #40315）。複数タスクを跨いだ作業の受け渡しが、コピペではなく参照で成立するようになった。

**`Interrupt` フックが追加**された（#40511）。トップレベルのターンが中断されたときにコマンドまたは MCP ハンドラを実行できる。中断時の後始末（一時ファイル削除、ロック解放、通知）をフックとして定義できる。

そのほか UI 面では、`/copy` が「応答全体 / 個別のコードブロック / 引用」を選べるピッカーになり（#39997）、名前のないターミナルタスクに説明的なタイトルが自動で付き `/rename` が編集可能な候補を出す（#40492, #40495）。Markdown リンクが対応ターミナルでクリック可能なラベルとして表示される（URL は保持、#40471）。権限モードを巡回するショートカットのバインドと、Vim モードでの `.`（直前の編集の繰り返し）にも対応（#39873, #40521）。

バグ修正では**セキュリティ関連が目立つ**。**未信頼プロジェクトがプロジェクト階層の `AGENTS.md` の指示を供給しなくなり、管理者の deny-read ルールが効くようになった**（#39837, #40004）。app-server 診断のクレデンシャル秘匿も改善（プロバイダー・認証更新・アテステーションを含む、#39993）。ほかに、リモート MCP のベアラートークン参照と必須サーバー起動の修正（#39926, #39952, #39979）、Unicode パス下での Windows sandbox 設定と起動エイリアスの修正（#39971, #40570）、デタッチプロセスによる Unix シャットダウンハングの防止（#40460）、Amazon Bedrock モデルでの会話圧縮とマルチエージェント互換性の修正（#39804, #39825）。

## できるようになったこと

- `@` で他の Codex タスクを参照し、読み取り・作成・メッセージ送信を依頼できる
- `Interrupt` フックで中断時の処理を定義できる
- `/copy` の選択的コピー、ターミナルタスクの自動タイトル、クリック可能な Markdown リンク
- 未信頼プロジェクトの `AGENTS.md` が指示として読み込まれなくなった（管理 deny-read ルールも有効化）

## 影響範囲

- 対象ユーザー: Codex CLI 利用者、フックや MCP を運用しているチーム、管理者
- 対象プラン: Codex 利用者全般
- API / UI / 管理者機能: CLI（UI）+ フック機構 + 管理設定（deny-read ルール）
