# Codex CLI 0.164.0

## 公式内容の日本語要約

stable の 0.164.0。新機能は、番号付き10スロットの `/presets`（プロンプトとスラッシュコマンドの保存）、`/model` と `/permissions` のインライン引数、Kitty / Sixel 対応端末での画像プレビュー、企業向け MCP 接続の Codex アカウント権限による認証、リモート Bash でのクレデンシャルのマスク、Amazon Bedrock セットアップウィザードの既定有効化。
