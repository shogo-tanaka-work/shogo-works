# 2026-08-05 Codex rust-v0.146.1

## 公式内容の日本語要約

Codex の stable リリース `rust-v0.146.1`。内容は 1 件のバックポートのみで、cyber 対応モデル（サイバーセキュリティ能力を持つモデル）に対する自動レビューの既定値を、より安全側に変更するもの（#37057）。あわせてターミナル UI 上で権限の変更内容を説明するようになった。

`rust-v0.146.0`（2026-07-29）へのバックポートであり、新機能の追加はない。窓内には alpha が 5 件（`rust-v0.147.0-alpha.10` / `alpha.11` / `alpha.12` / `alpha.13` / `alpha.6.5`）出ているが、SKILL ルールに従い件数のみ記録する。

## できるようになったこと

- cyber 対応モデル利用時の自動レビュー既定値が安全側に変更された
- 権限変更の内容がターミナル UI 上で説明されるようになった

## 影響範囲

- 対象ユーザー: Codex CLI の stable 利用者
- 対象プラン: 全プラン
- API / UI / 管理者機能: CLI の既定動作 + ターミナル表示

## 教材化メモ

- 「モデルの能力が上がると既定の安全設定を締める」という運用は、Claude Code の権限修正（v2.1.223）と同じ日に並んだ。ベンダー横断の傾向として教材で並べられる。
- パッチ単体では教材価値が薄い。Codex の権限・レビュー設定を扱う節で、既定値は版によって変わりうるという注意書きの実例として参照する。
