# 2026-09-30 Codex 0.159.2（stable）

## 公式内容の日本語要約

修正のみの小規模リリース。**Codex がバックグラウンドプロセスやサンドボックス化されたコマンドを起動する際、Windows でコンソール窓が明滅する問題**を抑制した。

0.159.0 で入った「Windows の余計なコンソール窓」対応の追撃にあたる。**Windows 環境での体感品質に限った修正**で、機能追加・既定値変更・セキュリティ修正は含まれない。

## できるようになったこと

- Windows でバックグラウンド実行時の画面の明滅が減る

## 影響範囲

- 対象ユーザー: Windows の Codex 利用者
- 対象プラン: 全般
- API / UI / 管理者機能: なし

- 単体では教材価値が薄い。**0.159.0 → 0.159.2 の3日足らずで同じ領域を2回直している**点だけ、週次ロールアップで「Windows 対応が継続中」として1行に畳むのが妥当。
