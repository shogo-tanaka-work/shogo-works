# 2026-10-01 Codex 0.160.0（stable）

## 公式内容の日本語要約

**New Features**

- agent command center で**古いタスクをキーボード操作可能な「Show more」で辿れる**ようになった。
- Linux X11 のローカルターミナル（対応環境）で、**フルスクリーン時に transcript のテキスト選択と中クリック貼り付け**ができる。
- **ポリシーが許す場合、プロジェクト外でもワークスペース既定でセッションを開始**でき、再開時に保存済みの権限を復元する。
- **Guardian review のオプトイン機能を追加**。以前のユーザー指示を取得し、**エージェント間の引き継ぎ（handoff）の文脈を含める**。

**Bug Fixes**

- 未送信のキューメッセージが再接続後に再開されるようになり、**送信の重複を避ける**。
- ターミナル UI が provider / reasoning-summary / verbosity の設定を保持し、resume と fork の履歴で正しいセッションを表示。
- **Windows のサンドボックスでの PowerShell フォールバックと長いパスの権限問題**を修正。バックグラウンドヘルパーによる不要なコンソール窓を抑制。
- サブエージェントが起動中の環境を保持し、設定または準備失敗を受け取れるようにした。
- 接続設定・ログ中の SQLite の停止を修正し、初期化エラーをタイムアウトとして隠さず表面化。
- 明示的な provider のモデルカタログに、非対応の同梱モデルや更新失敗後の古いエントリが混ざらないよう修正。

**Documentation**: provider の資格情報が設定済みストレージバックエンドをどう使うか、`env_key` が API キーの環境変数をどう特定するかを明確化。

**Chores**: プラグインのマニフェスト解析をキャッシュし、リモートプラグイン取得の HTTP 接続を再利用。未使用のログ DB 領域をバックグラウンドで回収。

## できるようになったこと

- Guardian review でエージェント引き継ぎの文脈を含めたレビュー（オプトイン）
- プロジェクト外でのセッション開始（ポリシー許可時）
- agent command center での古いタスク参照

## 影響範囲

- 対象ユーザー: Codex CLI 利用者
- 対象プラン: 記載なし
- API / UI / 管理者機能: **「ポリシーが許す場合」の挙動変更があるため、組織でワークスペース外の実行を制限している場合はポリシー設定を確認する**

## 教材化メモ

- **「エージェント間の引き継ぎ文脈をレビューに含める」**という発想。複数エージェントで分担すると、後段のエージェントは前段の意図を知らないまま作業する。**引き継ぎの情報落ちをレビュー工程で補う**という設計で、人間のチーム運営でも同じ構造の対処になる。
- **初期化エラーをタイムアウトとして隠さない**という修正方針。原因の違う失敗を同じ症状に丸めると、調査が無駄に長引く。**エラーを握りつぶさない**という本リポジトリの規約と同じ論点。
