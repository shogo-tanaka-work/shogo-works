# 2026-09-04 OpenAI Codex 0.153.3

## 公式内容の日本語要約

GPT-6 Astra 対応のホットフィックスである。**Amazon Bedrock のモデルピッカーに GPT-6-Astra が追加**された（Mantle と Runtime の global / US ルート向け、#42805）。Bedrock 経由で Codex を使っている組織が、Astra を選択肢として見られるようになる。

もう1件は Astra の非同期の確認質問（asynchronous clarification questions）に関するガイダンス修正で、サポートされているツールを使い、そのツールがテキストのみを受け付けることを認識させる内容である（#42809）。0.153.1 / 0.153.2 に続く Astra 受け入れ対応の3本目にあたる。

**バージョン番号付きリリースのため単独記事化しない（判定 D）。** ただし Bedrock 側での Astra 提供は、`0.153.4` の「バンドル既定モデル化」とあわせて週次ロールアップで扱う価値がある。

## できるようになったこと

- Amazon Bedrock 経由の Codex で GPT-6-Astra をモデルピッカーから選ぶ

## 影響範囲

- 対象ユーザー: Codex CLI 利用者、特に Amazon Bedrock 経由で使う組織
- 対象プラン: Codex 利用者全般
- API / UI / 管理者機能: CLI のモデルピッカー

## 教材化メモ

Codex を Bedrock 経由で使う構成は、AWS 側にログと課金を寄せたい企業で採用される。モデル追加が CLI 側のリリースに乗るという流れ自体が、「Bedrock 提供＝即座に手元で選べる、ではない」ことの実例になる。
