# 2026-09-01 Codex CLI 0.152.0

## 公式内容の日本語要約

安定版 `rust-v0.152.0` が公開された（前 stable は 08-29 の `rust-v0.151.0`）。

**Vim 風の検索が入った。** `/` と `?` によるパターン検索で、TUI 内をエディタと同じ操作感で移動できる。

**レート制限バナーが操作可能になった。** 従来は上限に達した旨を表示するだけだったが、その場で取れる選択肢を提示する形に変わった。

MCP まわりが2点。**MCP サーバー名がパッケージ形式の命名規則に対応**した。そして、**個々のツールごとに出力トークンの上限を設定できる**ようになった。後者は、饒舌な MCP ツールが1つ混ざるだけでコンテキストを食い潰す問題への対処である。

## できるようになったこと

- `/` と `?` による Vim 風のパターン検索
- レート制限到達時に、バナーから次の操作を選べる
- MCP サーバー名にパッケージ形式の命名を使える
- MCP のツール単位で出力トークン上限を設定できる

## 影響範囲

- 対象ユーザー: Codex CLI 利用者
- API / UI / 管理者機能: TUI 操作と MCP 設定。**ツール別の出力上限はコンテキスト消費の制御手段として実務価値が高い**

## 教材化メモ

- **MCP のツール別出力上限**は、エージェント設計の一般論として重要。**MCP ツールの出力はモデルのコンテキストへ直接入るため、1つの饒舌なツールが全体の効率を壊す。** 「上限をツール単位で持てる」という設計は、**コンテキストを共有資源として管理する**という発想の表れである。自作 MCP サーバーを設計する側にも、出力量の設計責任があるという話につながる。
- **レート制限バナーを「表示」から「操作」へ変えた**のは小さいが良い設計変更。エラー表示で終わらせず、その場で次の行動を提示する——**行き止まりを作らない UI** の実例として使える。
