# 2026-10-27 Codex CLI 0.165.0（rust-v0.165.0）

## 公式内容の日本語要約

新機能は、組み込みの Google Cloud Vertex AI プロバイダー（`model_provider = "gcp"`）、モデルカタログへの GPT-6.1 Terra 追加、セッションピッカーのリポジトリフィルタとエージェントコマンドセンターのディレクトリ別グルーピング、app-server API の実験的 attached thread forks、会話中の reasoning effort 変更の既定有効化、新規プロファイルでの memory v2 既定化（外部エージェントのメモリ取り込み対応）。

修正は、TUI の承認レビュアー既定値の反映、実行設定が不正なときの設定編集、リモート MCP ツール要求のキャンセル、Plan モード切替後にキュー済みメッセージが作業を再開する問題、モデル未検出時のリトライ停止、marketplace URL 検証で Git が許可パターンと別ホストへ接続し得る隙間の修正。

記事化判断: 見送り（週次ロールアップへ）。バージョンリリースのため機械的に判定D。
