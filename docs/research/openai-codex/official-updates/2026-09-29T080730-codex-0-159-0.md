# 2026-09-29 Codex 0.159.0（stable）

## 公式内容の日本語要約

新機能。**instant interrupt** をオプトインで有効にでき、モデルの応答中や code-mode の長い処理中でも新しい入力で軌道修正できる。**新規セッションのウェルカム画面**が整理され、利用中と利用後に tips が出る。**警告ビューア**は閉じると既読を自動で消し、`k` キーで残せる。**提案されたプランを検討しながら会話履歴をスクロール**できるようになった。Mermaid のネイティブ描画がエッジ種別・ラベル・ノードのグループ化へ対応。app-server クライアントがスレッド履歴を指定位置からページングできる。

修正。**Windows で MCP サーバー・code-mode ホスト・パイプコマンドが余計なコンソール窓を出す問題**に対処（制約の強いランチャーでは埋め込み実行へフォールバック）。転記コピーが Markdown の表・書式・意味のある空白を保つように。空セッションがタスク切替時に下書きを保持。ChatGPT サインインでブラウザが確実に開くように。

**セキュリティ**: 承認済みコマンドでも明示的なファイルシステム拒否を維持し、**書き込み可能ルート配下で `.aws` ディレクトリを既定保護**。ネットワーク有効サンドボックスの macOS TLS アクセス修正。

Chores: 自動フォローアップ提案と `tui.prompt_suggestions` 設定を廃止。同梱の `plugin-creator` skill を配布から除外。

## できるようになったこと

- 応答中の即時割り込みで軌道修正する
- プラン検討中に履歴をスクロールする
- `.aws` を既定で保護する

## 影響範囲

- 対象ユーザー: Codex CLI 利用者（特に Windows / macOS サンドボックス）
- 対象プラン: 全般
- API / UI / 管理者機能: `tui.prompt_suggestions` 設定の廃止は設定ファイルの棚卸しが必要

## 教材化メモ

- **`.aws` の既定保護**は、前日の 0.158.0 の「昇格権限に対するターミナル入力承認の既定有効化」と同じ方向の変更である。**資格情報ディレクトリを既定で守る**という設計が、この2ツールで連続して入っている点は、エージェント権限設計の教材で「ベンダー側の既定値が動いている」実例として使える。
- **instant interrupt** は「エージェントを止める手段」の話で、9月に相次いだ misalignment 報告（人間の中止指示が効かなかった事例）と並べると、**割り込み可能性を製品機能として実装する**流れが読める。
- 設定項目の**廃止**（`tui.prompt_suggestions`）は、CLI ツールを社内標準に据えるときの保守コストの実例。
