- detached な memory リクエストのターンメタデータで `thread_source` を `memory_consolidation` に設定（#40186）
- 画像 compaction のバックポートを、アノテーション以前のリリース向けに調整

## できるようになったこと

- `codex exec --thread-source <SOURCE>` でスレッドの発生源を分類でき、fork 先にも伝播する
- リモート compaction 時に画像がバジェット計算へ含まれるようになった
- memory consolidation 由来のリクエストがターンメタデータ上で識別できる
