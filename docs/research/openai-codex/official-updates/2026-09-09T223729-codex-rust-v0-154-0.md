# 2026-09-09 OpenAI Codex 0.154.0（stable）

## 公式内容の日本語要約

`0.154.0` は、09-04 の `0.153.4` 以来の stable リリース。前日まで alpha.8 まで進んでいた `0.154.0` 系が安定版として公開された。

新機能の筆頭は **GPT-6 Astra のモデルピッカーおよび Amazon Bedrock カタログへの追加**。同日 OpenAI が公式ポストで告知した Astra の提供開始（ChatGPT Work / Codex / API）と連動している。

作業環境まわりでは、**実験的な worktree サポート**が入り、新規セッションやフォークしたセッション用に分離チェックアウトを作れるようになった。並行作業時に作業ツリーを汚さない運用が CLI 側で扱えるようになる。また、**作業を止めずにインラインで質問へ回答**できるようになり、提示された選択肢から選ぶか自由入力ができる。

**Windows セッションがバックグラウンドの Codex サーバーを共有**できるようになり、デーモンのライフサイクルコマンドと管理された更新が提供される。Vim 編集は replace モードの undo と Escape の扱いが改善。`/copy` はステータス出力や個別のセッションフィールドをコピーでき、リッチテキストアプリへの貼り付けで書式が保たれる。

修正では**認可（authorization）まわりが目立つ**。MCP 接続が OAuth トークンのリフレッシュを協調して行い、失敗時にログインチャレンジを提示する。起動時に**信頼が確立する前のワークスペース制御下ヘルパーを実行しない**よう変更。リモートの resume / fork が保存済み権限を維持し、**新しい指示によって無効化された承認を自動承認レビューが拒否する**ようになった。

Chores として、**非推奨だった `codex mcp-server` エントリポイントが削除**された。移行が済んでいない環境では動かなくなる。

## できるようになったこと

- モデルピッカーと Amazon Bedrock カタログで GPT-6 Astra を選択できる
- 実験的 worktree で新規・フォークセッション用の分離チェックアウトを作れる
- 作業継続中にインラインで質問へ回答できる（選択肢または自由入力）
- Windows でバックグラウンド Codex サーバーを共有し、デーモンをコマンド管理できる
- `/copy` でステータス出力・個別セッションフィールドをコピーできる
- 既存セッションが新規インストールしたプラグインツールを認識し、外部でのアップグレード / ロールバック後に skills と hooks を再読込する

## 影響範囲

- 対象ユーザー: Codex CLI 利用者全般。特に Windows 利用者と MCP / プラグイン運用者
- 対象プラン: 記載なし
- API / UI / 管理者機能: CLI 全般。**`codex mcp-server` エントリポイントは削除済み**

## 教材化メモ

- **`codex mcp-server` の削除は、非推奨から削除までのリードタイムを追う実例として教材化できる。** 非推奨化の告知時点で棚卸ししていた環境は影響を受けず、放置していた環境はここで壊れる。「deprecated と書かれた時点が対応の開始点」という原則の裏付けになる。
- **「信頼が確立する前にワークスペース制御下のヘルパーを実行しない」修正**は、AI エージェントのサプライチェーン設計の教材素材。リポジトリに置かれた設定ファイルが、信頼判断より先に実行権を得ていたという構図で、`.envrc` や git hooks と同じ論点である。
- **「新しい指示によって無効化された承認を拒否する」**という修正は、エージェントの承認モデルを説明する際に効く。承認は「その時点の文脈に紐づく」ものであって、一度出した承認が後続の別の指示にまで及ぶわけではない。ハーネス設計の教材で扱う価値がある。
- **worktree サポートの実験的導入**は、本リポジトリの `branch-management.md` が定める「worktree は例外手段」という方針と突き合わせて読める。ツール側が支援を始めても、運用方針としては並行作業が必要なときだけ使う判断は変わらない。
- 本リリースは**バージョン番号付きのため単独記事化しない**（`selection-rubric.md` の「日次リリース型ツールの扱い」）。GPT-6 Astra 対応は、OpenAI 側の提供開始記事で触れる。
