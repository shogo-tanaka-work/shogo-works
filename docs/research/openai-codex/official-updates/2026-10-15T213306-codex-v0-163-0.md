# 2026-10-15 Codex CLI 0.163.0（stable）

## 公式内容の日本語要約

**stable の `rust-v0.163.0` が公開された。** 直前の stable は `0.162.1`（10-09）で、**stable の間隔は6日**である。窓内には **alpha が1件**（`0.163.0-alpha.10.2`、10-15）あり、規約どおり詳細ファイルは作らない。

**公式 changelog（`learn.chatgpt.com/docs/changelog`）に挙がっている主な追加は次のとおり。**

**`/config` パネルが検索できるようになった。** 設定項目を名前で探せる。設定が増えたツールで「どこにあるか分からない」状態を減らす変更である。

**ターンの途中でステアリングできるようになった。** 実行中に**フォローアップメッセージを送って方向を変えられる。** 従来は1ターンが終わるまで待つか中断するかだったため、**長いタスクの軌道修正のコストが下がる。**

**リーダーキーが設定可能になった（既定は `Ctrl+X`）。** キーバインドの衝突を避けられる。

**`/daemon` からバックグラウンドサーバーを再起動できるようになった。** 従来はプロセスを外から落とす必要があった操作が、CLI 内で済む。

**読み取り専用ツールの呼び出しが並列化された。** 複数ファイルの読み取りや検索が同時に走るため、**調査フェーズの待ち時間が短くなる。**

**Daybreak が対象アカウントで既定オンになった。** 対象は "eligible accounts" とされている。

**多数のバグ修正と内部変更が併せて入っている。**

## できるようになったこと

- `/config` を検索して設定項目を探せる
- 実行中のターンにフォローアップを送って方向を変えられる
- リーダーキーを変更できる（既定 `Ctrl+X`）
- `/daemon` からバックグラウンドサーバーを再起動できる
- 読み取り専用ツールが並列で走る
- 対象アカウントで Daybreak が既定で有効になる

## 影響範囲

- 対象ユーザー: Codex CLI 利用者全般。Daybreak は "eligible accounts" のみ
- 対象プラン: Daybreak の対象条件は公式に明示なし
- API / UI / 管理者機能: CLI（TUI、`/config`、`/daemon`、キーバインド、ツール実行）

## 教材化メモ

- **単独記事にしない（判定D）。** バージョン番号付きリリースのため規約どおり週次ロールアップへ回す。
- **「ターン中のステアリング」は週次ロールアップの要点に向く。** エージェントに長いタスクを投げる運用では、**途中で止めて作り直すコストが最大の無駄**になる。走らせたまま方向を変えられる設計は、Claude Code 側の類似機能と並べて比較できる。
- **読み取り専用ツールの並列実行は、ツール設計の教材に使える。** 「副作用がないものは並列化できる」という線引きは、**自作ツールやスキルを書くときの原則**としてそのまま一般化できる。
- **`/config` の検索可能化は、設定項目の増えすぎという問題の表れとして扱う。** 機能追加の副作用が UI 側に出てくる例である。
- **Daybreak の既定オンは対象条件が不明なため、断定しない。** "eligible accounts" のまま記録し、条件が公式に出たら更新する。
