# 2026-09-22 OpenAI Codex 0.156.0

## 公式内容の日本語要約

Codex の stable 版 `0.156.0` が 2026-09-22T19:53:19Z に公開された。**2026-09-18 の `0.155.1` 以来の stable で、`0.156.0` 系は alpha.3〜alpha.17 を積み上げたのち stable 化した。**

新機能は6点である。`/tui` で次回起動時のフルスクリーンUIを選べるようになり、トランスクリプト検索・マウス選択・右クリックコピーが使える。**音声会話が既定で有効**になり、F8 でトグル、`/voice settings` でピッカーを開く。Linux と Windows 向けにはオーディオランタイムが同梱される。`/usage` 分析ダッシュボードでアカウント利用状況・トークン総量・プラグインとスキルの稼働状況を見られる。agent command center からタスクを状態で絞り込み、worktree セッションを作れるようになり、**worktree サポートが既定で有効**になった。ターミナルテーマが6種追加され、Mermaid 図と表示数式が応答内で描画される。`/daemon` でローカルのバックグラウンドサーバーを更新でき、`--no-daemon` で迂回できる。

**バグ修正にサンドボックス関連が含まれる。** Windows の受信接続、Linux / macOS の特権ソケット、読み取り専用 macOS ファイルハンドル経由の書き込みという3つの隔離の穴を塞いだ。その他、ターン失敗・中断・サブエージェント完了イベント時のストリーム応答とプランの保持、tmux / SSH でのクリップボード転送、プロキシ経由のログイン回復、OAuth discovery が 503 を返したときの MCP 資格情報更新などが修正されている。

同期間の alpha は8件（`0.157.0-alpha.3`〜`alpha.10`、2026-09-22T01:46:59Z〜22:16:12Z）。規約により alpha は件数のみ記録する。

## できるようになったこと

- `/tui` でフルスクリーンUI、`/usage` で利用分析、`/daemon` でローカルサーバー更新
- 音声会話と worktree サポートが既定で有効
- Mermaid 図・数式の応答内表示、ターミナルテーマ6種の追加

## 影響範囲

- 対象ユーザー: Codex CLI 利用者
- 対象プラン: 記載なし（CLI 全般）
- API / UI / 管理者機能: **音声会話と worktree が既定 ON になるため、既定値前提の運用は確認が必要**。非推奨の `friendly` / `pragmatic` パーソナリティ設定は応答スタイルを選ばなくなった旨がドキュメントで明確化された

## 教材化メモ

- **`selection-rubric.md` の「日次リリース型ツールの扱い」により判定 D。** タイトルにバージョン番号が付く stable リリースのため、サンドボックス隔離の修正を含んでいても単独記事にせず、週次ロールアップへ送る。
