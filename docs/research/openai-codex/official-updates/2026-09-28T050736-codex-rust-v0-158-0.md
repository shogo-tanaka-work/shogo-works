# 2026-09-28 Codex 0.158.0（rust-v0.158.0）

## 公式内容の日本語要約

**stable の `rust-v0.158.0` が公開された。** 前回の stable は 2026-09-26 の 0.157.1 で、窓内の stable はこの1本。

**New Features**

- フルスクリーン TUI で **copy-on-select と右クリック貼り付けを設定可能**に
- **OAuth クライアントシークレットを事前登録した MCP サーバー**に対応
- **exec-server の WebSocket 接続を bearer token で保護**
- 画像生成で**透過背景を明示的に要求**できる
- **昇格した権限に対するターミナル入力の承認が既定で有効**に

**Bug Fixes**

- Windows のサンドボックスが標準パスおよび大きなポリシーで失敗する問題を修正
- Linux のサンドボックス起動を、入れ子の書き込み可能ルートがある場合に改善
- macOS のシステムパスのエイリアスを patch 操作で認識
- 新しいユーザー入力が来たときに承認レビューを再試行
- Mermaid 図で引用符付きラベルとアンパサンドを正しく描画

**窓内の alpha は5本**である。`0.160.0-alpha.3`（09-29T01:43:23Z）、`0.160.0-alpha.2`（09-28T20:04:01Z）、`rust-v0.160.0-alpha.1`（09-28T04:01:43Z）、`0.159.0-alpha.13`（09-28T15:32:49Z）、`0.159.0-alpha.12`（09-28T03:27:03Z）。`source-catalog.md` の規約どおり **alpha は件数のみ計上し、詳細ファイルは作成しない**。

## できるようになったこと

- フルスクリーン TUI の copy-on-select / 右クリック貼り付け設定
- OAuth クライアントシークレット事前登録型 MCP サーバーの利用
- exec-server WebSocket の bearer token 保護
- 透過背景の画像生成

## 影響範囲

- 対象ユーザー: Codex CLI 利用者、MCP サーバーを自前運用している開発者
- 対象プラン: CLI（ChatGPT プランに従う）
- API / UI / 管理者機能: サンドボックス、承認フロー、MCP 認証

## 教材化メモ

- **バージョンリリース扱いのため単独記事にしていない**（`selection-rubric.md` の「日次リリース型ツールの扱い」）。**「昇格権限のターミナル入力承認が既定有効」は既定値の変更であり、週次ロールアップで明示する。**
- **Windows / Linux / macOS の3プラットフォームでサンドボックス修正が同時に入っている**点は、サンドボックス実装の難しさの教材になる。
- exec-server の bearer token 保護は、**ローカルで立てた実行サーバーが無認証だった期間があった**ことを示す。自前運用の境界設計の話に繋げられる。
