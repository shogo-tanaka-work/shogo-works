# 2026-09-25 Codex CLI 0.157.0（stable）

## 公式内容の日本語要約

OpenAI Codex の stable **0.157.0** が 2026-09-25T02:32:43Z に公開された。公式 changelog（`learn.chatgpt.com/docs/changelog`）にも 2026-09-25 付で掲載されている。

主な内容は次のとおり。**GPT-6 Sol と Luna を追加し、Amazon Bedrock 経由でも使えるようにした。** **フルスクリーンの transcript を既定にし、Shift クリックでのテキスト選択範囲拡張に対応。** 対話セッションのうち条件を満たすものでは**背景サーバーを自動起動**する。**会話の fork（`F` ショートカット）**に対応し、fork 時に下書きが保持される。**`/import` コマンドがリモートおよびローカルの background-server セッションで使えるようになった。** ターミナル描画では Unicode の箇条書き記号と数式記法の扱いが改善された。

同日には patch の **rust-v0.157.1**（2026-09-25T23:41:41Z）も出ている（別メモ）。
