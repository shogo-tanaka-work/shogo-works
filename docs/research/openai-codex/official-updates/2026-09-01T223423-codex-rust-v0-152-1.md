# 2026-09-01 Codex CLI 0.152.1

## 公式内容の日本語要約

`rust-v0.152.0` の当日中のパッチ。**Guardian の承認レビューが、モデルのメタデータ経由で提供される Node REPL ポリシーを正しく尊重するようになった**というバグ修正1点である。

Guardian は Codex の承認・レビュー機構で、実行しようとする操作を承認対象とするかどうかを判定する。**そのポリシーがモデルメタデータ経由で渡される場合に、Node REPL に関する指定が無視されていた**のを修正した形になる。

**同日に stable が2本（0.152.0 と 0.152.1）出ている**点は、リリース頻度の高さを示す。窓内には alpha も4本（`rust-v0.153.0-alpha.1` 〜 `alpha.4`）が出ている。

## できるようになったこと

- （バグ修正のみ）Guardian の承認判定が Node REPL ポリシーを正しく適用する

## 影響範囲

- 対象ユーザー: Codex CLI 利用者のうち、Node REPL を含むワークフローで Guardian の承認制御を使っている環境
- API / UI / 管理者機能: 承認判定の正確性。**ポリシーが意図どおり効いていなかった期間があった点は、統制の観点では確認事項**

## 教材化メモ

- **「ポリシーが設定されていたのに効いていなかった」タイプの不具合**は、統制の信頼性を考えるうえで重要な事例。設定した側は効いていると信じるため、**不具合が是正されるまで誰も気づかない。** 統制は「設定したか」ではなく「実際に効いているか」を検証しないと担保できない——という一般則の具体例になる。
- **同日に stable が2本出る**という頻度は、Claude Code と並ぶ日次リリース型ツールの特徴。**「最新に追随する」運用が現実的かどうか**を判断する材料になる。
