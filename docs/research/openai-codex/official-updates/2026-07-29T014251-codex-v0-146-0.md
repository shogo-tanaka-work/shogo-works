# 2026-07-29 Codex CLI 0.146.0（stable）

## 公式内容の日本語要約

Codex CLI の stable 版 0.146.0 がリリースされた。会話管理とプラグイン基盤に大きめの追加が入っている。

会話管理では、`/new` や `/clear` で新しいセッションに名前を付けられるようになり、重要なスレッドのピン留め、サイド会話を閉じずに切り替える操作に対応した。スレッドの fork も強化され、ページング付きの履歴を持つ fork と、スレッド一覧に出ない一時 fork が使える。

プラグイン側では Agent Plugins のマニフェストをサポートし、ワークスペース単位でのプラグイン公開に対応した。さらにプラグインマーケットプレイスとして Amazon Bedrock と Claude Code が追加されている。実行環境面では app-server がリモートの Code Mode ホストへ WebSocket 接続できるようになり、互換のあるカスタムモデルプロバイダーでも単体の Web 検索が使えるようになった。スキル周りでは、実行環境（executor）が提供するスキルの発見と、それに紐づくリソースの安全な読み取りに対応した。

修正面ではプロキシ対応の徹底（認証、プラグインダウンロード、MCP 認可、リモート実行、WebSocket、リダイレクト、LM Studio 接続）、MCP 接続と Apps ツールの構成変更時の追随、中断・リプレイ・インポート・fork をまたいだ状態保持が挙がっている。運用面では、リリース成果物とチャネルメタデータの配布が OpenAI ホストのインフラ（GitHub はフォールバック）に切り替わり、エンタープライズプランの認識とアプリ内更新の管理者制御が追加された。

## できるようになったこと

- `/new` / `/clear` での新規セッション命名、スレッドのピン留め、サイド会話の維持切り替え
- ページング付き履歴を伴うスレッド fork、および一覧に出ない一時 fork
- Agent Plugins マニフェストのサポートとワークスペース単位のプラグイン公開
- プラグインマーケットプレイスに Amazon Bedrock と Claude Code を追加
- app-server からリモート Code Mode ホストへの WebSocket 接続
- 互換カスタムモデルプロバイダーでの単体 Web 検索
- executor 提供スキルの発見と関連リソースの安全な読み取り
- エンタープライズプラン認識と、アプリ内更新に対する管理者制御
- リリース配布を OpenAI ホストのインフラへ移行（GitHub はフォールバック）

## 影響範囲

- 対象ユーザー: Codex CLI 利用者全般。プラグイン開発者、エンタープライズ管理者への影響が大きい
- 対象プラン: CLI 共通。エンタープライズ向けの管理者制御は該当プランのみ
- API / UI / 管理者機能: CLI / app-server / プラグイン基盤 / 管理者制御の全域

## 教材化メモ

- 「セッションを名前付きで並行運用する」という使い方は、Claude Code のセッション運用と対比して教材化できる。1本の長い会話ではなく、目的ごとにスレッドを分けてピン留めする運用へ寄っている
- プラグインマーケットプレイスに Claude Code / Amazon Bedrock が入った点は、ツール間の相互運用が「移行」ではなく「共存」方向に進んでいる例として使える
- プロキシ対応の網羅的な修正は、社内ネットワーク配下での導入トラブルシューティング教材の材料になる
