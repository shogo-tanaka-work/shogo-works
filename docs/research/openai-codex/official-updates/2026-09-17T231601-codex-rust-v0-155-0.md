# 2026-09-17 Codex rust-v0.155.0（stable）

## 公式内容の日本語要約

OpenAI Codex の **`rust-v0.155.0` が 2026-09-17T23:16:01Z に stable として公開された。** 直前の 2026-09-17T23:14 にリリースページ上のタグが立ち、その約8分後に `rust-v0.156.0-alpha.1`（23:24:42Z）が続いている。

**本件の観測上の要点は「stable 化が9日ぶりに起きたこと」である。** 前日（2026-09-17）のサマリーは「`rust-v0.155.0` の stable 化は8日目も起きていない」と記録していた。窓内で alpha が **`alpha.15`（01:21Z）/ `alpha.16`（04:34Z）/ `alpha.17`（21:16Z）/ `alpha.18`（22:37Z）** と4件出たあと、stable へ到達した。**枝番付き採番（前日観測の `alpha.2.5` / `alpha.2.6`）と通常の `alpha.N` 系列が並行していた期間は、これで解消した。**

**New Features**: 対応ビルドでの**実験的な `/voice` 会話**（ライブ文字起こしとマイク操作）。TUI のステータス行に**推論サマリーをライブ表示**（完了時刻と併記）。agents overview での**タスクの非表示・アーカイブ・削除**。対応 macOS での **MCP リクエストの Touch ID 検証**。**デーモン更新スケジュールの設定可能化**と、再起動後の保存済みスレッドの自動復旧。Amazon Bedrock 連携向けに、**設定したコマンドから AWS の資格情報を取得**する機能。

**Bug Fixes**: compaction 失敗時に受理済みプロンプトを保持。tmux のリサイズ処理。トランスクリプトのビューポート復元。MCP OAuth トークン更新時の案内改善。**アカウント切り替え時にキャッシュ済みセッションとモデルカタログを正しく無効化**。**Windows のサンドボックスを資格情報露出に対して強化**。

## 影響範囲

- 対象ユーザー: Codex CLI 利用者全般。macOS の MCP 利用者、Bedrock 経由の利用者、Windows 利用者
- 対象プラン: 該当なし
- API / UI / 管理者機能: CLI / TUI / デーモン / MCP
