# 2026-11-13 Codex rust-v0.168.0

## 記録の経緯

## 公式内容の日本語要約

**新機能**

- Sessions → Model providers でモデルプロバイダーを一覧し、新規チャットの既定を選べる。
- `features.tui_workspace` を有効にすると、メインチャットの横にサイド会話を表示できる。区切りをドラッグしてペインを広げられ、`leader z` でフォーカス中のペインを拡大できる。
- 音声対応モデルを使うとき録音を添付できる。却下が確定した録音は以降のターンでスキップされ、クリップ長を使って短い録音をコンテキストに残しやすくする。
- `features.image_generation_animation` を有効にすると、アニメーション GIF の生成・編集ができる（フレーム数とタイミングの指定が任意）。
- フルスクリーンの Codex が、Ghostty と Kitty の tmux で `allow-passthrough all` 設定時に画像プレビューとペットを表示する。
- `tui.notification_method = "osc777"` でターミナル通知を使える。**承認通知はコマンドプレビューを長く表示し、ターミナル入力の要求とネットワークアクセスの要求を区別する。**

**修正**

- ローカル TUI の履歴と resume ピッカーが、新規作成スレッドをサインイン中の ChatGPT アカウントで絞り込む。
- 新規チャットの既定を変更した後も、開いているチャットと再開したチャットは保存されたモデルプロバイダーを使う。
- ツール呼び出しで中断された返信を1つの Markdown メッセージとして描画し、会話の再生時に reasoning summary を復元する。
- 最終トランスクリプト保存中、または長時間実行チャットへ戻った直後に送った steering メッセージが、実行中のターンへ届く。
- ファジーファイル検索でファイル名一致の重みを上げた。
- **Windows でアイドル状態のローカル MCP サーバーが、Codex の他の処理のファイルシステム I/O を塞がなくなった。**

**その他**

- `features.multi_agent` を明示設定していると警告が出る。サブエージェントのツールを無効化する設定は `agents.enabled` へ移った。
- app-server リファレンスに、モデルプロバイダーの一覧、カスタムゲートウェイの作成、ゲートウェイ / Bedrock / GCP 設定の更新を追記。
