# 2026-08-20 Codex CLI 0.149.0（stable）

## 公式内容の日本語要約

OpenAI Codex の stable リリース `rust-v0.149.0` が 2026-08-20T21:04Z（JST 2026-08-21 06:04）に公開された。前 stable は 2026-08-18 の `0.148.0`。npm では `@openai/codex@0.149.0`。

**新機能の中心は `codex agents` ダッシュボード**である。タスクの検索、開始、オープン、リネーム、停止を対話的に行える。これまで複数タスクの状態把握はセッションを渡り歩く必要があったが、一覧から操作できるようになった。

**`codex queue`** が追加され、既存のローカル / リモートセッションへメッセージを送れる。あわせてキュー投入したメッセージが**アイドル状態のセッションを確実に起こす**よう修正され、セッション名の重複解決も改善された。

**TUI セッション内の作業ディレクトリ操作**として `/cd`、`/pwd`、`/cwd` が追加された。セッションを閉じずにディレクトリを移動できる。

**`codex doctor` の診断範囲が拡大**し、エンドポイント保護、ネットワーク / プロキシの失敗、デスクトップアプリの状態、アップデート接続性を診断するようになった。

**SDK 利用者は CLI の設定オーバーライドを厳密に渡せるようになり、reasoning effort に `max` / `ultra` を選択できる**ようになった。Vim 編集は文字置換と `cw` / `c$` / `cc` などの change motion に対応範囲が広がった。

修正では、スレッドの resume / fork 時に権限プロファイルが正しく復元されるようになった点、サブエージェント活動の重複表示と通知ルーティングの改善、WebRTC Realtime のサイドバンド接続がトランスポート喪失後に再接続する点、TUI スレッド再生バッファに上限を設けてメモリ肥大を防いだ点が実務に効く。ドキュメントでは、外部コントリビューションは PR ではなく issue と設計議論を通すべきこと、secure devcontainer における **DNS エクスフィルトレーションのリスクと信頼境界の限界**が明文化された。

窓内の alpha は `rust-v0.149.0-alpha.3` / `.4` / `.7`、`rust-v0.150.0-alpha.1` の4件を確認した（`.5` / `.6` は Releases 一覧に出ていない）。

## できるようになったこと

- `codex agents` でタスクの検索・開始・オープン・リネーム・停止を対話的に操作
- `codex queue` で既存のローカル / リモートセッションへメッセージ送信
- TUI 内で `/cd`、`/pwd`、`/cwd` による作業ディレクトリ操作
- `codex doctor` がエンドポイント保護・プロキシ・デスクトップ状態・更新接続性を診断
- SDK から CLI 設定を厳密にオーバーライド、reasoning effort に `max` / `ultra`

## 影響範囲

- 対象ユーザー: Codex CLI / SDK 利用者
- 対象プラン: 全プラン（CLI）
- API / UI / 管理者機能: CLI / TUI / SDK
