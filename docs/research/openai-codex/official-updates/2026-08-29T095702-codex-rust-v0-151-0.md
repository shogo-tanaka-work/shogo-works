# 2026-08-29 Codex CLI 0.151.0

## 公式内容の日本語要約

Codex の stable リリース `rust-v0.151.0` が 2026-08-29T09:57:02Z に公開された。窓内の stable は本件1件のみである。

**New Features** は3点。**任意（optional）MCP サーバーからのツール探索に、設定可能な猶予期間（grace period）が入った。** 起動が遅い MCP サーバーのツールが取りこぼされる問題への対処である。**拡張（extensions）が、MCP のツール実行結果をモデルへ渡す前に検査・置換できる**ようになった。**プラグインカタログがリポジトリ単位の設定を統合し、不正なプロジェクトマーケットプレイスを、正常なプラグインを隠さずに報告する**ようになった。

**Bug Fixes** は6点で、権限とサンドボックスまわりが中心である。**復元した権限プロファイルが TUI のターンをまたいで保持されるようになり、`/cd` がサンドボックス制限を弱められないよう修正された。** モデル切り替え・フォールバック時にツールの可用性と reasoning effort が正しく保たれるようになった。**リモートサンドボックスの強制が、実行側の実際のホームディレクトリ・OS・パス規約を使うよう改善された。** app-server 応答で MCP のツール／リソースエラーの構造が保たれるようになり、**ネストしたサブエージェントのトークン使用量がルートの goal 予算に算入される**ようになった。**権限状態が変わった後に古い Guardian の分類が動作を承認してしまう問題**も修正された。

Chores として、エスカレートされた stdin レビューとリモート executor の MCP 探索にテレメトリが追加された。

窓内の alpha は `rust-v0.151.0-alpha.7.1 / 8 / 9 / 10 / 11 / 12 / 7.2` と `rust-v0.152.0-alpha.1 / 2` の計9件である。

## できるようになったこと

- 任意 MCP サーバーのツール探索に設定可能な猶予期間を設定できる
- 拡張から MCP ツール結果を検査・置換できる
- プラグインカタログがリポジトリ単位設定を統合し、不正なマーケットプレイスを個別に報告する

## 影響範囲

- 対象ユーザー: Codex CLI 利用者（特に MCP サーバーと拡張を運用しているチーム）
- 対象プラン: CLI 全般
- API / UI / 管理者機能: 権限プロファイル・サンドボックス強制・Guardian 分類まわりの挙動が変わる

## 教材化メモ

- **「古い判定結果が権限変更後も効いてしまう」バグ**（stale Guardian classifications）は、認可設計の教材としてそのまま使える。判定をキャッシュすると速いが、**権限状態の変化でキャッシュを無効化する経路を設計しないと、権限を絞ったのに効かない**という事故になる。RBAC やフィーチャーフラグの実装でも同じ形の欠陥が出る。
- **`/cd` がサンドボックス制限を弱められた**という修正は、「境界を決める操作」と「境界の中で動く操作」を混ぜると破れる、という具体例。作業ディレクトリ変更が権限境界を動かしてよいかは、設計時に明示的に決めるべき論点である。
- **拡張が MCP のツール結果をモデルへ渡す前に書き換えられる**のは、実務では強力だが両刃である。マスキングや整形に使えば有用だが、**第三者製の拡張がモデルの入力を静かに書き換えられる**ということでもある。MCP の信頼境界を説明する題材になる。
- **ネストしたサブエージェントのトークンがルート予算に算入されるようになった**点は、エージェント運用のコスト管理として重要。子エージェントが予算外だった状態は、階層が深いほど実コストが見えなくなる。**予算はツリー全体で1つ**という原則を教えられる。
