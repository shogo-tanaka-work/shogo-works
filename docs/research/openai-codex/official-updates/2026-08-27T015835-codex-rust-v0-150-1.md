# 2026-08-27 OpenAI Codex rust-v0.150.1

## 公式内容の日本語要約

前日の stable リリース `rust-v0.150.0` に対するパッチ。公式リリースノートの本文は Bug Fixes 1件のみである。

**リモート compaction（会話圧縮）が、保持している画像をトークン予算に既定で算入するようになり、必要に応じて古い画像から間引くようになった**（#41003）。従来はテキストだけを予算計算の対象にしていたため、画像を多く含む長いセッションで実際の消費が予算を超え、圧縮後も文脈が想定より膨らむ状態が起こりえた。この修正は後続バージョンからの backport（@rhan-oai）である。

破壊的変更、権限・サンドボックス・資格情報の扱いの変更、料金や上限の変更、新しいコマンドやモードの追加は含まれない。**利用者の操作手順は変わらない**。

窓内には alpha リリースも複数出ている（`rust-v0.151.0-alpha.3` 〜 `alpha.7`、および `rust-v0.150.0-alpha.12.2`）。運用ルールどおり alpha は詳細ファイル化せず、日次サマリーで件数のみ記録する。

## できるようになったこと

- 画像を含む長いセッションで、リモート compaction のトークン予算計算が実態に合うようになった

## 影響範囲

- 対象ユーザー: Codex CLI 利用者のうち、画像を多く扱う長時間セッションを回している層
- 対象プラン: 全プラン共通（CLI のバージョン更新）
- API / UI / 管理者機能: CLI 内部の圧縮処理のみ。設定・コマンド体系に変更なし

## 教材化メモ

- **「トークン予算の計算対象に何が入っているか」を疑う視点**の実例。マルチモーダルなセッションでは、テキストだけを数えている実装が実際の消費とずれる。自作のエージェント実装でも同じ落とし穴が起きうる。
- 記事化は見送った（`selection-rubric.md` の「日次リリース型ツールの扱い」）。破壊的変更・権限・セキュリティ・料金・操作フローのいずれにも当たらない通常のバグ修正であるため、週次ロールアップ（`weekly-ai-news-rollup`）でまとめる。
