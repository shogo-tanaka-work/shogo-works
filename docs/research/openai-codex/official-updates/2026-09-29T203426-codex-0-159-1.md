# 2026-09-29 Codex 0.159.1（stable）

## 公式内容の日本語要約

**バンドルカタログ、および Amazon Bedrock Mantle / Runtime カタログの既定モデルを GPT-6.1 Sol に変更**した、というのが本リリースの実質的な唯一の内容である（PR #49323 リリース準備、#49342 Bedrock カタログの backport）。

**DevDay 2026（同日）で発表された GPT-6.1 Sol が、その日のうちに Codex の既定モデルへ入った**ことになる。GPT-6.1 Sol は公式説明で「エージェント型コーディング、コンピュータ操作、専門業務で GPT-6 Astra にほぼ並び、Astra の標準入出力単価の5分の1」とされるモデルである。

**既定モデルの変更であるため、モデルを明示指定していない利用者は自動的に切り替わる。**

## できるようになったこと

- Codex の既定モデルとして GPT-6.1 Sol を使う
- Bedrock 経由でも同じ既定を得る

## 影響範囲

- 対象ユーザー: Codex 利用者全般、Bedrock 経由の利用者
- 対象プラン: 全般
- API / UI / 管理者機能: **既定が変わるため、出力傾向・単価の前提が動く**

## 教材化メモ

- **発表当日に既定モデルが差し替わる**という速度そのものが教材になる。「モデルを固定しない運用では、ベンダーの発表日が自社の挙動変化日になる」。
- 既定モデルの明示固定（pin）を推奨する根拠として引用できる実例。**評価済みのモデルで動かし続けたい業務は、モデル名を明示的に指定する**という運用ルールの必要性を、1リリースで説明できる。
