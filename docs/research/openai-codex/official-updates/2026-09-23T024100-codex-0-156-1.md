# 2026-09-23 Codex 0.156.1（stable）

## 公式内容の日本語要約

Codex の stable リリース `0.156.1` が 2026-09-23 02:41 UTC に公開された。内容は1点で、**モデルピッカーに GPT-6 Sol と GPT-6 Luna を追加**し、レート制限に達したときのプロンプトから **Luna を推奨**する形にしたもの。前日の `0.156.0`（2026-09-22、音声会話と worktree サポートの既定有効化を含む大型版）に対するフォローアップに当たる。

GPT-6 Sol / Luna は 2026-09-22 に OpenAI が公開したモデルで、API 価格は GPT-5.6 系のプロモーション価格比で半額（Sol が入力 $2 / 出力 $10、Luna が入力 $0.10 / 出力 $0.50）。レート制限時に Luna を勧める設計は、上限に当たった利用者を安価なモデルへ誘導して作業を止めない意図と読める。

**alpha は同日に8本出ている。** `0.158.0-alpha.2` から `alpha.6`（13:07 / 17:07 / 18:36 / 22:10 / 23:41 UTC）、`0.157.0-alpha.11`（04:50 UTC）、`0.155.0-alpha.16.3` / `16.4`（03:41 / 19:55 UTC）。`source-catalog.md` の規約どおり alpha は件数のみの言及にとどめ、詳細ファイル化しない。

**バージョン番号が付いたリリースのため、`selection-rubric.md` の「日次リリース型ツールの扱い」に従い単独記事化はしない。** 判定 D とし、週次ロールアップへ送る。

## できるようになったこと

- モデルピッカーから GPT-6 Sol / GPT-6 Luna を選べる
- レート制限に達したときのプロンプトが Luna を推奨する

## 影響範囲

- 対象ユーザー: Codex CLI 利用者
- 対象プラン: 全プラン（利用可能モデルはアカウントの権限に従う）
- API / UI / 管理者機能: TUI のモデルピッカーとレート制限バナーの挙動

## 教材化メモ

- **「上限に当たったら安いモデルへ誘導する」というUI設計**は、コスト設計の教材で扱う価値がある。利用者から見れば作業が止まらないが、モデルが変わったことに気づかないまま出力品質が変わる可能性もある。切り替わりを認識できる運用にしておく、という注意点とセットで教えたい。
- **stable の直後にフォローアップ stable が出る**パターン（0.156.0 → 0.156.1 が翌日）は、バージョン固定運用の判断材料。日次で上げるか、週単位でまとめて上げるかを決める根拠として使える。
