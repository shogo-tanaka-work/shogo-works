# 2026-08-18 OpenAI Codex 0.148.0（stable）

## 公式内容の日本語要約

Codex の stable 版 0.148.0 がリリースされました。機能追加が多く、単なるパッチではありません。

**会話のエクスポート**: `/export` で TUI の会話全体を Markdown として出力できるようになりました。出力先はクリップボードまたはファイルを選べます。作業ログを議事録や引き継ぎ資料へ転記する手作業が減ります。

**セッション操作**: `codex exec fork` でセッションを分岐できるようになりました。加えて TUI の resume picker からセッションのアーカイブと復元が可能です。1 本の長い会話を分岐させて別案を試す、終わった作業を一覧から片付ける、といった運用ができます。

**起動時の待ち時間**: TUI の初期化中にプロンプトを下書きできるようになりました。resume と fork の進捗も起動中に表示されます。

**コスト可視化**: 対象ワークスペースで、推定スレッドクレジットまたはコストが `/status`、ステータスライン、ターミナルタイトルに表示されます。

**プロバイダー**: Amazon Bedrock Runtime が組み込みプロバイダーとして追加されました。AWS プロファイル、リージョン、GPT-5.6 のルーティングに対応します。AWS 上で完結させたい組織にとって導入経路が 1 つ増えます。

**Hooks**: Hooks がコマンドを非同期で実行でき、MCP ツールを呼び出せるようになりました。既存 Hooks 機能の派生改善ですが、フックから外部ツールを叩けるようになった点は自動化の設計自体を変えます。

バグ修正はモデル切替と設定の永続化、セッション再開時のディレクトリ・ポリシー復元、一時的な障害を跨いだプロバイダー再接続、ターミナル入力と認証フロー、CRLF や折り返し行の描画、プラットフォーム横断のサンドボックスアクセス制限など広範です。ドキュメント面では bundled skill-creator ガイドが整理され、未完了の TODO プレースホルダを検証で弾くようになりました。

なお同 stable の後、2026-08-19T00:57:19Z に alpha `rust-v0.149.0-alpha.1` が出ています（本レポートでは件数のみ計上）。

## できるようになったこと

- `/export` で TUI 会話全体を Markdown 出力（クリップボード / ファイル）
- `codex exec fork` でセッション分岐、TUI からセッションのアーカイブ・復元
- TUI 初期化中のプロンプト下書き、resume / fork の進捗表示
- `/status` ・ステータスライン・ターミナルタイトルに推定クレジット / コスト表示
- Amazon Bedrock Runtime を組み込みプロバイダーとして利用（AWS プロファイル / リージョン / GPT-5.6 ルーティング）
- Hooks の非同期コマンド実行と MCP ツール呼び出し

## 影響範囲

- 対象ユーザー: Codex CLI / TUI 利用者全般。特に AWS 上で完結させたい組織、Hooks で自動化を組んでいる利用者
- 対象プラン: stable チャネル利用者。コスト表示は「eligible workspaces」限定
- API / UI / 管理者機能: CLI / TUI。プロバイダー設定は管理者側の判断事項
