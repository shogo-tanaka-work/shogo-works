# 2026-07-28 Cursor Start（インド向け新プラン）

## 公式内容の日本語要約

Cursorがインドの開発者向けに、月額₹649の新プラン「Cursor Start」を発表した。Grok 4.5（最も高性能なモデルと位置付け）とComposer（価格効率重視のコーディングモデル）へのアクセスを含み、常時稼働のクラウドエージェント、リモート操作対応のCursor for iOSアクセス、UPI決済に対応する。既存の無料プランユーザーはダッシュボードからアップグレード可能、新規ユーザーは `cursor.com/signup` のオンボーディング時にStartプランを選択できる。月額自動更新。

## できるようになったこと

- インド在住ユーザーが₹649/月の現地価格でCursorの主要機能（Grok 4.5、Composer、クラウドエージェント、iOSリモート操作）を利用できる
- UPI決済でのサブスクリプション支払いができる

## 影響範囲

- 対象ユーザー: インド在住の開発者（新規/既存無料ユーザー）
- 対象プラン: Cursor Start（新設、地域限定プラン）
- API / UI / 管理者機能: 該当なし（課金プラン・決済手段の追加）
