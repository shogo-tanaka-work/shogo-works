# 2026-08-14 Cursor が SpaceX に買収完了

## 公式内容の日本語要約

Cursor が公式ブログで、**SpaceX による買収が完了した**ことを発表した。2026-04 に公表した SpaceXAI とのモデル学習パートナーシップから始まった一連の手続きが、これで完結した形である。

Cursor 側の説明では、買収の狙いは計算資源である。**世界最大規模の GPU 群にアクセスできる**ようになり、より強力かつ運用コストの低いモデルを作れるとしている。その結果として「より高性能なモデルをより低コストで顧客に提供できる」と述べている。2026-08-12 にリリースした **Grok 4.6** が、その協業の初期成果だと位置づけられている。

製品の方向性については「取り組む仕事は変わらない」とし、野心的なアイデアを持つ人がコードを書く時間を減らし、より難しい問題に時間を使えるようにする、という従来の目標を維持すると説明している。

**公式ブログは製品・料金・プラン・データの取り扱い・既存契約の扱いについて一切言及していない**。移行スケジュールや、既存の Enterprise 契約が SpaceX 側へどう承継されるかも記載がない。

取引条件は SpaceX の SEC 提出書類（Form 8-K）で確認できる。

- 発効日: **2026-08-14**
- 形態: **全株式（all-stock）取引**、Anysphere, Inc. は SpaceX の完全子会社となる
- 対価: SpaceX Class A 普通株 **389,289,254 株**（Cursor の株式価値 600億ドル相当）
- 既存の RSU / ストックオプションは SpaceX 側の RSU 約 29,128,326 単位、オプション約 44,365,047 単位へ引き継ぎ
- 合併契約自体は 2026-06-16 締結

## できるようになったこと

- 機能面の変更はない。**企業としての所有構造が変わった**発表である
- Cursor は SpaceX の AI 部門（SpaceXAI）配下のプロダクトとなった
- SpaceX の GPU 資源を前提にしたモデル開発・提供が公式方針になった

## 影響範囲

- 対象ユーザー: Cursor の全利用者（個人・Business・Enterprise）
- 対象プラン: 記載なし。料金・プランの変更告知はない
- API / UI / 管理者機能: 変更告知なし
- **未開示の論点**: データの取り扱い方針、プライバシーポリシー・DPA の改定有無、既存 Enterprise 契約の承継、サブプロセッサ一覧の変更
