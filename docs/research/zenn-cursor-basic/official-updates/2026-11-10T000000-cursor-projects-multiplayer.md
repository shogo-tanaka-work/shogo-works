# 2026-11-10 Cursor Projects のマルチプレイヤー化

## 公式内容の日本語要約

9月に導入した Projects（1人のコーディネーター経由で複数エージェントを指揮する仕組み）が**マルチプレイヤー**になった。Project にチームメイトを招くと、各自のエージェントも含めて計画・実装・リリースを一緒に進められる。

- **共有タスクボード**: 誰が何をしているか、各自のエージェントが何に取り組んでいるか、各タスクの背後の PR を一覧で見られる。
- **共有コンテキスト**: 各メンバーは自分のコーディネーターとワーカーエージェントとの1対1チャット（ローカルコンテキスト）を持ちつつ、その上に要件ドキュメント・図・技術仕様・モックアップを置く共有層が載る。1つのチャットでの決定が Project 内の全エージェントから参照できる。新メンバーを招くとコンテキストが構成済みの状態で渡る。
- **エージェント間通信**: 別のメンバーのエージェント同士が調整する。例として、1人がレビュー機能を足しつつ別の1人が同じページを再デザインしている場合、両方のコーディネーターが重複を早期に検知して同期する。スキーマ変更と読み取り側の作業順を事前に合わせてコンフリクトを避ける、なども挙げられている。
- 公式の運用例として、オンコール輪番を共有 Project で回しており、引き継ぎ時に後任のコーディネーターが進行中の作業・未対応の課題・引き継ぎが必要なインシデントとメモ・監視対象のチャンネルや Linear ボードを把握していたとしている。

**提供形態**: 本日より Cursor の全ユーザーへベータ提供。左ナビから Project を作り、チームメイトを招く。

## 影響範囲

- 対象ユーザー: Cursor 全ユーザー（ベータ）
- 対象プラン: 公式はプラン制限を明示していない
- UI: 左ナビから Project 作成・招待
