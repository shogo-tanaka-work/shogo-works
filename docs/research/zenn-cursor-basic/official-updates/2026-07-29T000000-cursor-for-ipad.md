# 2026-07-29 Cursor for iPad

## 公式内容の日本語要約

Cursor の iPad アプリが有料全プランで提供開始された。大画面向けに最適化したレイアウトで、レビューをチャットの横に並べたまま作業でき、ファイル差分は省略なしで表示される。サイドバーのチャットをピン留めでき、複数エージェントの進行を並べて監視できる。

新たに「Inbox」が追加され、プロジェクトの進捗、未処理の項目、レビュー待ちのプルリクエストを一箇所で追える。レビュー画面はプルリクエストのワークフロー全体を対象にし、コメント、チェック、承認、レビュアー指定までモバイルアプリ内で完結する。

あわせて Bitbucket と Azure DevOps リポジトリへの対応、1セッションで生成された複数 PR の扱い（最新の1件だけでなく全件にアクセス可能）、アプリ内でのチーム切り替え、Apple Pencil によるスクリーンショットへのマークアップ注釈に対応した。

配布は App Store（ID: 6767085653）。詳細は Cursor の mobile ドキュメント。

## できるようになったこと

- iPad の大画面向けレイアウト（レビューとチャットの並列表示、完全な差分表示、チャットのピン留め）
- Inbox による進捗・未処理項目・レビュー待ち PR の一覧
- コメント / チェック / 承認 / レビュアー指定まで含む PR ワークフローのモバイル完結
- Bitbucket、Azure DevOps リポジトリ対応
- 1セッションで生成された複数 PR すべてへのアクセス
- アプリ内でのチーム切り替え
- Apple Pencil でのスクリーンショット注釈

## 影響範囲

- 対象ユーザー: Cursor の有料プラン契約者
- 対象プラン: 有料全プラン
- API / UI / 管理者機能: iPad アプリ UI。リポジトリ連携先の拡大（Bitbucket / Azure DevOps）

## 教材化メモ

- 「クラウドエージェントに投げて、移動中にレビューする」という運用の実例。エージェント前提の開発フローでは、手元の実行環境よりレビュー導線の方が重要になるという論点に接続できる
- PR レビューがモバイルで完結する点は、レビュー待ちがボトルネックになっているチームへの現実的な効果として説明しやすい
- Bitbucket / Azure DevOps 対応は、GitHub 以外を使う企業での採用可否に直結する前提条件
