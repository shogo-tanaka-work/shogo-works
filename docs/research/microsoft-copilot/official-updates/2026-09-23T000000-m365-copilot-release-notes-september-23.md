# 2026-09-23 Microsoft Copilot release notes

## 公式内容の日本語要約

主ソースの release notes に **2026-09-23 の見出し**が追加された。本文冒頭は **「Updates released between August 26, 2026, and September 22, 2026」**で、規約どおり**隔週で約4週間ぶんをまとめた公開**である（前回は 08-25 で 08-11〜08-25 が対象）。

**Microsoft 365 Copilot App** — **Copilot Cowork への作業の委任**（必要な成果を記述すると、Cowork が文脈を集めて複数ツールを横断して結果を返す）。**ビジョン機能**（音声セッション中にデスクトップ画面の内容とモバイルのカメラ映像を解析）。**Copilot Notebooks の新デザイン**（関連するチャット・出力・参照を持続的な作業空間へ整理）。**CarPlay 対応。**

**Microsoft 365 管理センター** — **ライセンス申請の専用ページ**が新設。Copilot のライセンス申請を集約し、並べ替え・絞り込み・一括操作に対応する。

**Microsoft 365 Copilot** — メール添付が検索結果でクリック可能な pill 表示に。Outlook メールの検索結果に「Sort by」（日付の昇順・降順）。建物・会議室・デスクのプロファイルカード。**トピックやキーワードから会議を検索**（本文・チャット・文字起こしを対象、直近2か月）。**Planner Agent chat**（自然言語での Q&A、タスク検出、プラン内でのタスク管理）。

**Excel** — Copilot の応答から変更箇所へ直接移動（新しいシート・テーブル・範囲・オブジェクトをハイライト）。**Show Changes ペインで Copilot による編集・提案を帰属表示。**

## できるようになったこと

- Copilot Cowork へ複数ツール横断の作業を委任
- 音声セッション中にデスクトップ画面とモバイルカメラの内容を解析
- 管理センターの専用ページで Copilot ライセンス申請を集約管理
- Excel の Show Changes で Copilot の編集を帰属表示
- 会議をトピック・キーワードで検索（直近2か月、本文・チャット・文字起こし対象）

## 影響範囲

- 対象ユーザー: Microsoft Copilot の利用者と Microsoft 365 管理者
- 対象プラン: release notes 記載の各機能の対象に従う
- API / UI / 管理者機能: 管理センターのライセンス申請ページが新設

## 教材化メモ

- **ビジョン機能（画面とカメラの解析）は、情シス審査の論点が変わる類の追加**である。テキスト入力の統制を整えても、**画面に映っているものが解析対象になる**なら、機微情報の扱いは別の設計が要る。
- **Excel の Show Changes での帰属表示**は地味だが実務で効く。**どのセルを AI が編集したかが残る**のは、レビュー・監査の前提が変わる。表計算を業務の正本にしている組織では、これが導入の可否を分ける。
- **release notes が隔週・約4週間ぶんまとめ**である点を毎回記録する。**週次巡回でも取りこぼしは起きないが、公開日と機能の実際の提供日は一致しない。** 「いつから使えるか」を release notes だけで判断しない。
