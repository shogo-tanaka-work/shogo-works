# 2026-09-04 GPT-6 Astra が Microsoft Copilot で提供開始

## 公式内容の日本語要約

OpenAI の **GPT-6 Astra** が Microsoft Copilot で提供開始になった（著者 Bas Brekelmans）。公式の表現は「**GPT-6 Astra は本日より Copilot Cowork と Copilot Studio へロールアウト**」。

**同日 2026-09-04 に GitHub Copilot でも GA**（Pro+ / Max / Business / Enterprise）となっており、**Codex `0.153.4`（2026-09-04）ではバンドル既定モデルが Astra に変わっている。** 同一日に3経路で Astra が前進した形である。

## できるようになったこと

- Copilot Cowork と Copilot Studio で GPT-6 Astra を利用する

## 影響範囲

- 対象ユーザー: Copilot Cowork / Copilot Studio の利用者
- 対象プラン: 個別ポスト本文未取得のため未確定
- API / UI / 管理者機能: Copilot Cowork、Copilot Studio

## 教材化メモ

- **同一モデルが同じ日に3つの経路（Microsoft Copilot / GitHub Copilot / Codex）へ入り、うち1つでは既定になった**——これが今週いちばん見落としやすい形の変化である。個別に見ればどれも「新モデルが使えるようになった」だが、**組織全体で見ると、同じ週に複数のツールの挙動が同時に動いた**ことになる。
- **Copilot Studio へ載る**という点は統制上重要。Studio で作られたエージェントは業務プロセスに埋め込まれるため、**基盤モデルの変更が業務の挙動変更として現れる。** モデル追加の告知を「開発者向けの話」として流すと、この経路を見落とす。
