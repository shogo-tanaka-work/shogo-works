# 2026-09-01 Claude Fable 5.1 が Microsoft Copilot で提供開始

## 公式内容の日本語要約

Anthropic の **Claude Fable 5.1** が Microsoft Copilot で提供開始になった（著者 Bas Brekelmans）。

`source-catalog.md` が指摘するとおり、**モデル追加告知は release notes ではなく Tech Community blog 側に出る**という構造が、今回も踏襲されている。

**同日に GitHub Copilot でも GA になり、Claude Code 2.1.257 でも既定 Fable モデルとして採用された。** モデル公開と主要クライアント3面への搭載が同日に揃っている。

## できるようになったこと

- Microsoft Copilot で Claude Fable 5.1 を利用する

- 対象プラン: 個別ポスト本文未取得のため未確定
