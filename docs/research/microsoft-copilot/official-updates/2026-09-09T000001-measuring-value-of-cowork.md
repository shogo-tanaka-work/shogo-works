## 教材化メモ

- **同じ週に GitHub Copilot も利用状況メトリクスを拡張している**（VS Code Agents ウィンドウの追加）。**ベンダー側が揃って「効果測定」を主題に置き始めた**のは、導入フェーズが「入れるかどうか」から「入れた結果を説明できるかどうか」へ移ったことの表れと読める。AI 導入支援の提案資料で、この同時性は論拠として使える。
- ただし**測定の主導権はベンダー側にある**点は注意が要る。ベンダーが定義した「完了した仕事」の指標は、契約更新を支える方向へ寄る。**社内で独自の指標を持っておく**という助言とセットで扱う。
