# 2026-08-25 Microsoft 365 Copilot リリースノート

## 公式内容の日本語要約

主ソースは隔週公開で、今回の見出しは **2026-08-25**、本文が示す対象期間は **2026-08-11 〜 2026-08-25** である。前回の見出し 2026-08-11 の続きにあたり、公開間隔は想定どおり（隔週）。

製品別の主な内容は次のとおり。

- **Excel**: Copilot による Python 編集
- **Microsoft 365 管理センター**: ハイブリッドデバイス向けの Organizational Messages
- **Microsoft 365 Copilot**: Viva Engage のプライベートコンテンツ対応、Copilot Notebooks の UX 刷新、チャットの改善
- **OneNote**: Copilot Notebooks で Teams 会議を扱えるように
- **Outlook**: Copilot によるスケジューリング、会議準備
- **PowerPoint**: メールの参照、スライドのライブ解説
- **Word**: Read Aloud 中の音声 Q&A、**Sonnet 5 モデルの利用**

**Word で Sonnet 5 が使えるようになった**点は、`source-catalog.md` が注意している「モデル追加告知」に当たる。従来はモデル追加が Tech Community blog 側に先行して出ることが多かったが、今回は release notes 側に載っている。

Tech Community blog 側は**窓内（2026-08-24〜08-31）の新規投稿なし**（最新は 2026-08-13 の Copilot Notebooks の Markdown / プレーンテキスト / リッチテキスト対応）。

## できるようになったこと

- Word の Copilot で Sonnet 5 を使える
- Excel で Copilot による Python 編集ができる
- Outlook でスケジューリング・会議準備を Copilot に任せられる

## 影響範囲

- 対象ユーザー: Microsoft 365 Copilot の利用者と管理者
- 対象プラン: Microsoft 365 Copilot（製品ごとに提供範囲が異なる）
- API / UI / 管理者機能: 各 Office アプリ UI + 管理センター

## 教材化メモ

- **Word に Sonnet 5 が入った**ことで、「Microsoft の Copilot は OpenAI のモデル」という前提が実務でも崩れている。M365 Copilot は GPT / Claude を併用する構成で、**どのモデルがどのアプリで動くかは製品側の都合で変わる**。ベンダーとモデルを1対1で覚えている読者向けに、更新の必要な箇所である。
- **隔週公開の release notes を日次で見ても大半が「更新なし」になる**という週次移管の判断が、今回も妥当だったことの記録。今回も窓内の公開は1回だけである。
