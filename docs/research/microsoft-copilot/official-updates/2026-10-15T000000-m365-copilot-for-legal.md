# 2026-10-15 Microsoft Copilot for legal

## 公式内容の日本語要約

**Microsoft Copilot に法務向けの機能群が入った。** 既存の Legal Agent を土台に、**20以上の法務スキル**とパートナー製プラグインを加えたもので、公式は法務スキルが「**世界中の Microsoft Copilot 顧客に一般提供**」であると述べている。**パートナープラグインは告知日から Microsoft plugin registry 経由で順次提供**される。プラン階層・ライセンス要件は記載がない。

**スキルは7領域である。** 起案（承認済みの先例から契約書・メモを作り、Word で編集可能なプレースホルダーを置く）、レビューと交渉（playbook と突き合わせ、**承認後にのみ適用される tracked edits を提案**）、義務の抽出（コミットメント・期限・トリガーを抽出し、関連契約を追跡）、リサーチ（資料の比較、欠落の指摘、構造化されたガイダンス化）、案件業務（時系列の作成、重要日付の抽出、議事録・決議書への変換）、Cowork（契約・メール・会議・ファイルを横断する多段タスク）、Work IQ（案件・基準などの組織文脈への接続）。

**パートナープラグインの領域は、リーガルリサーチ、文書・案件管理、契約と電子署名、リーガル AI、e-discovery。** 名前が挙がっているのは Bloomberg Law、iManage、Docusign、Harvey、Relativity である。

公式は、4月の Frontier リリース以降 **1,800人超の利用者が約10万件の編集を生成し、提案の約7割を採用した**と報告している（Microsoft 提供の数値）。

**日付は3つ。** 2026-10-15 に法務スキルが GA、パートナープラグインの提供開始。**2026-10 中に、定義語をたどる新しい Word 体験がプレビュー**へ。**2026-10-22 に Copilot in Word のウェビナー**（Microsoft Discovery Sessions カタログから登録）。

管理者の設定手順は列挙されていない。公式は「Copilot for legal を始める」サポート記事を案内し、既存の保護（enterprise data protection、ユーザー権限と秘密度ラベルの尊重、プロンプト・文書を基盤モデルの学習に使わないこと）を述べている。

## できるようになったこと

- 承認済み先例からの起案、playbook 突き合わせ、義務抽出、案件の時系列作成などを法務スキルとして使える
- Bloomberg Law / iManage / Docusign / Harvey / Relativity などのパートナープラグインを plugin registry から導入できる

## 影響範囲

- 対象ユーザー: Microsoft Copilot 顧客（世界中、GA）
- 対象プラン: 記載なし
- API / UI / 管理者機能: Copilot / Word の UI、Microsoft plugin registry

## 教材化メモ

- **「職種特化の Copilot」が製品として出てきた**点が本質。汎用アシスタントではなく、**先例・playbook・義務といった業務語彙をそのままスキル名にしている**。業種別・職種別のエージェント設計を考える題材になる。
- **tracked edits が承認後にのみ適用される設計**は、法務という領域での必須要件がそのまま UI 制約になった例。**「提案と適用を分ける」**という一般原則の具体例として使える。
- **採用率7割という数値の読み方**も教材になる。3割は却下されており、**人のレビュー工程を外せない**ことを示す数値である。ベンダー提供の数値であることも含めて扱う。
- プラン・ライセンス要件が書かれていないため、**導入コストの見積りができない**。問い合わせが必要な段階という整理になる。
