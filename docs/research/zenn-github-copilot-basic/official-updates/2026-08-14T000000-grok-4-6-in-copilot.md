# 2026-08-14 Grok 4.6 in GitHub Copilot

## 公式内容の日本語要約

GitHub Copilot で **Grok 4.6** が使えるようになった。対象は Copilot Pro、Pro+、Max、Business、Enterprise の各 SKU。

**Business と Enterprise ではポリシーが既定でオフ**で、管理者が明示的に有効化する必要がある。前日の Gemini 3.7 Flash（2026-08-13）と同じ扱いで、GitHub Copilot における新モデル追加の定着したパターンである。

課金は従量課金のもとでプロバイダーの表示価格が適用される。倍率は本告知には明示されていない。

利用できる面は Visual Studio Code、Visual Studio、Copilot CLI、GitHub Copilot cloud agent、GitHub Copilot アプリ、JetBrains、Xcode、Eclipse。

Grok 4.6 自体は 2026-08-12 に SpaceXAI が公開したフラッグシップモデルで、500k コンテキストと長時間稼働エージェント向けの設計を持つ。速報記事は `src/content/ai-news/xai-grok/grok-4-6.mdx`。

## できるようになったこと

- Copilot Pro / Pro+ / Max / Business / Enterprise で Grok 4.6 を選択できる
- 8つの面（VS Code、Visual Studio、CLI、cloud agent、Copilot アプリ、JetBrains、Xcode、Eclipse）で利用できる

## 影響範囲

- 対象ユーザー: GitHub Copilot 利用者
- 対象プラン: Pro / Pro+ / Max / Business / Enterprise。**Business / Enterprise は既定オフ**
- API / UI / 管理者機能: 各 IDE のモデルピッカー、Copilot 設定のモデルポリシー（管理者）

## 教材化メモ

- **3日間で2モデルが追加され、どちらも Business / Enterprise は既定オフ**（Gemini 3.7 Flash が 08-13、Grok 4.6 が 08-14）。個別モデルの話ではなく運用の型であることが、短期間の実例で示せる。`github-copilot/gemini-3-7-flash` の教材化メモで整理した「新モデル追加時の判断フロー」の必要性を、この頻度が裏づける。
- 追加のたびに管理者が個別判断する運用は、この頻度では回らない。**判断基準と棚卸しの周期を先に決める**という結論へ導く材料として使う。
- xAI 側の Grok 4.6 記事（`xai-grok/grok-4-6`）とセットで扱うと、「モデルが出る」と「使っているツールで選べるようになる」の間に2日のずれがあることを示せる。ベンダー発表と実利用可能時期は別、という一般則の実例。
