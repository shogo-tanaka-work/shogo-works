# 2026-09-10 MAI-Code-1-Flash の廃止

## 公式内容の日本語要約

**`MAI-Code-1-Flash` が GitHub Copilot の全体験から廃止された。** 対象は Copilot Chat、インライン編集、ask / agent モード、コード補完のすべてである。

**発効日は告知と同じ 2026-09-10 で、予告期間が無い。** 代替として公式が案内しているのは **`MAI-Code-1.1-Flash`** である。

利用者・組織側で廃止モデルを取り除く作業は不要で、自動的に退役する。ただし **Copilot Enterprise の管理者は、代替モデルをモデルポリシーで有効化する必要がある場合がある。** GitHub Enterprise 顧客は、懸念がある場合にアカウントマネージャーへ連絡するよう案内されている。

`source-catalog.md` に記録のとおり、`MAI-Code-1-Flash` は「2026年9月に廃止」と以前から予告されていた枠であり、**予告そのものは存在したが、具体的な発効日の告知は当日だった**という構図である。

## できるようになったこと

- （機能追加なし。モデルの退役）

## 影響範囲

- 対象ユーザー: GitHub Copilot 利用者全般、Copilot Enterprise / Business の管理者
- 対象プラン: 全プラン（Copilot Chat / インライン編集 / ask / agent / コード補完）
- API / UI / 管理者機能: モデルポリシー（管理者側で代替モデルの有効化が要る場合がある）

## 教材化メモ

- **予告期間ゼロの廃止が、2週連続で発生している。** 前週（週次サマリー 2026-09-07）では 08-31 告知・09-01 発効の6モデル廃止があった。今週は告知と発効が同日である。**「廃止は事前に予告されるもの」という前提が、この製品では成立していない。**
- **週次確認ソースであるため、検知は発効から4日後になった。** これは巡回頻度の設計上のトレードオフとして、前週に続き2回目の記録である。**期限つき告知に限っては、週次では事後検知になりうる**という事実が積み上がってきている。
- **バージョン番号ではなくモデル名で退役が来る**点も、Claude Code / Codex 型の「版数の羅列」とは別種の追跡が要ることを示す。モデル名を設定ファイルへ直書きしている環境は、退役のたびに壊れる。
- 記事化はしない（週次確認ソースの更新。週次サマリーの「期限のあるもの」で扱う）。
