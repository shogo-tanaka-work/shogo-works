# 2026-07-30 GitHub Copilot in VS Code 2026年7月版

## 公式内容の日本語要約

VS Code の v1.127 から v1.131 までの7月リリースにおける Copilot 関連の変更をまとめた changelog。

**Agents window の刷新**: public preview の agents window が再設計され、エディタパネルと共有タブバーによってチャットの横でコードをレビューできるようになった。差分レビューが高速化し、エージェントの種類をまたいだ Git worktree のサポート、セッションのグルーピングと並べ替えによるセッション管理の改善が入っている。

**マルチチャットセッション**: Claude 利用時に、1つのエージェントセッション内で複数の関連する会話を保持できるようになった。元の会話の履歴を保ったまま「peer chat へ fork」して別のアプローチを並行して探索できる。

**Vision とモデルアクセス**: Copilot Vision が一般提供（GA）になり、画像と PDF を貼り付け・ドラッグ・コンテキストメニュー経由でチャットへ追加できる。BYOK（Bring-Your-Own-Key）モデルが Agents window 内でも使えるようになり、エディタ以外でもモデルの選択肢が広がった。

**ターミナルとアクセシビリティ**: チャット、エディタ、ターミナルの各インターフェースで音声入力（dictation）に対応。ターミナルのスクリーンリーダー機能も改善された。OS レベルのキーボードショートカットから、VS Code がバックグラウンドで動作している状態でもコマンドを起動できる。

## できるようになったこと

- Agents window の再設計（チャット横でのコードレビュー、共有タブバー、高速な差分レビュー）
- エージェント種別をまたぐ Git worktree サポート、セッションのグルーピングと並べ替え
- Claude 利用時のマルチチャットセッションと peer chat への fork
- Copilot Vision が GA（画像・PDF をチャットへ追加）
- BYOK モデルを Agents window 内で利用可能
- チャット / エディタ / ターミナルでの音声入力
- ターミナルのスクリーンリーダー改善
- OS レベルショートカットからバックグラウンドの VS Code コマンドを起動

## 影響範囲

- 対象ユーザー: VS Code で Copilot を使う利用者
- 対象プラン: changelog に個別プランの記載なし（Agents window は public preview）
- API / UI / 管理者機能: VS Code UI

## 教材化メモ

- 「チャットの横でレビューする」レイアウトは、エージェント運用でレビュー導線が主役になることの表れ。Cursor for iPad（2026-07-29）と同じ方向の変化として並べて説明できる
- peer chat への fork は、Codex 0.146.0 のスレッド fork と同型の機能。ツール横断で「会話を分岐させて方針を比較する」操作が標準化しつつある
- Copilot Vision の GA は、スクリーンショットや PDF 仕様書を投げる使い方を正式に教材化できるタイミング
- BYOK が Agents window に広がった点は、モデル調達を自前で行う構成の説明に使える
