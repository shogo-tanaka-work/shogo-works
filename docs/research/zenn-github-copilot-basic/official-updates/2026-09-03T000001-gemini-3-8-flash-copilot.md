# 2026-09-03 Gemini 3.8 Flash が GitHub Copilot で利用可能に

## 公式内容の日本語要約

Google の **Gemini 3.8 Flash** が GitHub Copilot で使えるようになった。同週の weekly releases（2026-09-04）によれば、**Copilot Pro / Pro+ / Max / Business / Enterprise へロールアウト中**である。

**同日 2026-09-03 の廃止予告と対になっている。** Gemini 3.5 Flash と Gemini 3.6 Flash が 2026-10-02 に廃止され、公式が示す代替が本モデルである。つまり本告知は、**廃止予告の移行先を先に用意した**という位置づけになる。

## できるようになったこと

- Copilot Pro / Pro+ / Max / Business / Enterprise で Gemini 3.8 Flash を選ぶ

## 影響範囲

- 対象ユーザー: GitHub Copilot 利用者全般（Pro を含む）
- 対象プラン: Pro / Pro+ / Max / Business / Enterprise
- API / UI / 管理者機能: モデルピッカー、Copilot settings のモデルポリシー

## 教材化メモ

- **廃止予告と移行先の提供が同日に出ている**という段取りは、ベンダー側の作法として素直である。前項の Claude Opus 4.7 のケース（示された移行先が1か月で廃止対象になった）と対照させると、**「移行先が出てから廃止を告知する」ことと「移行先が長生きする」ことは別問題**だと分かる。
- Flash 系は 3.5 / 3.6 / 3.7 / 3.8 と短周期で更新されている。**世代交代の速いモデル系列を既定に据えると、移行作業が定常業務になる**。モデル選定では性能だけでなく**改廃の周期**を見る、という指針の裏づけに使える。
