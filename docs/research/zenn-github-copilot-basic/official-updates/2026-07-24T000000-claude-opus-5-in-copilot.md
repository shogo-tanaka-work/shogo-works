# 2026-07-24 Claude Opus 5 in GitHub Copilot

## 公式内容の日本語要約

AnthropicがClaude Opus 5を発表した同日、GitHub CopilotでもClaude Opus 5が利用可能になった。複雑で長時間実行が必要なコーディングタスク（慎重な推論、効果的なツール利用、複数ステップにわたる確実な実行）向けに設計されたモデルとして提供される。初期テストでは自律的なコード変更、リグレッション検証、複数ツールの協調が必要なタスクを含むagentic codingワークフローで高いパフォーマンスを示し、対象を絞った変更・検証・複雑タスクでの不要な実行オーバーヘッド削減に特に効果的だったとしている。高リスクなサイバー関連コンテンツへの安全対策も強化されており、一部のサイバー関連・セキュリティ関連リクエストがブロックされる場合がある。

## できるようになったこと

- Copilot Pro+、Max、Business、Enterpriseユーザーが Claude Opus 5 を選択可能
- Copilot Enterprise / Business のプラン管理者は Copilot 設定で Claude Opus 5 ポリシーを有効化する必要あり

## 影響範囲

- 対象ユーザー: GitHub Copilot Pro+ / Max / Business / Enterprise ユーザー
- 対象プラン: Pro+、Max、Business、Enterprise（Freeプランは対象外）
- API / UI / 管理者機能: Business/Enterpriseは管理者によるポリシー有効化が必須

## 教材化メモ

- Claude Opus 5発表から即日でGitHub Copilotに統合された点は、Anthropicと主要開発者プラットフォームの連携スピードを示す事例として教材価値がある。
- 管理者によるポリシー有効化が必要な点は、企業導入担当者向けの実務チェックリストに含めやすい。
