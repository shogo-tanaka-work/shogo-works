# 2026-10-26 GitHub Copilot で GPT-6.1 Terra が GA

## 公式内容の日本語要約

OpenAI の GPT-6.1 Terra が GitHub Copilot で一般提供になった。日常的な agentic コーディングとターミナル作業向けで、GPT-6.1 Sol より低コスト。公式の初期テストでは、ターミナル作業と C# のタスクを GPT-5.6 Terra より明確に多く解けたとしている。課金はプロバイダーのリスト価格に基づく usage-based billing。

対象は Copilot Pro / Pro+ / Max / Business / Enterprise。VS Code、Visual Studio、Copilot CLI、Copilot cloud agent、Copilot app、github.com、GitHub Mobile（iOS / Android）、JetBrains、Xcode、Eclipse のモデルピッカーから選べる。ロールアウトは段階的。

Business / Enterprise の管理者は Copilot 設定のモデルポリシーでアクセスを管理する。**default model enablement 配下では、管理者がグローバル既定を切っているか当該モデルを明示的に無効化していない限り、新規モデルは自動で有効になる。**

## 影響範囲

- 対象ユーザー: Copilot 有料プラン全般
- 管理者: 新規モデルの自動有効化が既定。モデルポリシーで個別制御が必要

## 教材化メモ

記事化しない（週次ソースの巡回記録）。2026-10-22 に GA したグローバル既定ポリシーの帰結が、最初の新規モデル追加で具体化した例である。「新しいモデルは黙って増える」のが既定だと理解していないと、統制側の棚卸しが追いつかない。
