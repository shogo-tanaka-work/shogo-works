# 2026-09-29 GitHub Copilot に GPT-6.1 Sol が GA

## 公式内容の日本語要約

OpenAI の **GPT-6.1 Sol** が GitHub Copilot で一般提供になった。ロールアウトは段階的で、公式も「まだ見えない場合は後で確認」と案内している。

対象は **Copilot Pro+ / Max / Business / Enterprise**。Sonnet 5.5（前日 GA、Pro を含む）と違い、**Pro は対象外**である。

クライアントは VS Code、Visual Studio、Copilot CLI、GitHub Copilot coding agent、GitHub Copilot app、github.com、GitHub Mobile（iOS / Android）、JetBrains IDEs、Xcode、Eclipse。

課金は **provider list pricing の usage-based billing**。

管理者の扱いは Sonnet 5.5 と同じで、**既定ポリシーでは新モデルが自動的に有効**になる。全体既定を切っているか、当該モデルを明示的に無効化している場合のみ入らない。

既定モデルになるかどうかは changelog に記載がない。

## できるようになったこと

- Pro+ 以上で GPT-6.1 Sol を選択
- coding agent を含む10クライアントから利用

## 影響範囲

- 対象ユーザー: Copilot Pro+ / Max / Business / Enterprise の利用者
- 対象プラン: **Pro は対象外**
- API / UI / 管理者機能: model policy（既定で自動有効）

## 教材化メモ

- **同じ週に出た2モデルで対象プランが違う**（Sonnet 5.5 は Pro から、GPT-6.1 Sol は Pro+ から）。「最新モデルが使えるか」はプラン表の静的な比較では決まらず、モデルごとに違う。社内で「Copilot のどのプランを買うか」を決めるとき、モデル単位の対象表を自前で持たないと判断できない。
- **OpenAI 本体の発表（DevDay 2026、09-29）と同日に Copilot へ入った。** Codex も同日 0.159.1 で既定モデルを GPT-6.1 Sol へ切り替えている。ベンダー発表日と自社の挙動変化日が一致する構造が、週をまたいで繰り返されている。
