# 2026-08-12 Agent Plugins 1.0

## 公式内容の日本語要約

GitHub が Agent Plugins 1.0 への対応を VS Code、Copilot CLI、GitHub Copilot SDK、GitHub Copilot アプリで GA にした。全 Copilot プランが対象である。

Agent Plugins 1.0 は 2026-08-06 に公開されたオープン標準で、エージェント向けのスキルと MCP サーバーを1つのインストール可能なプラグインとしてパッケージ化する仕様である。AWS、Anysphere（Cursor）、Microsoft、OpenAI、Vercel、Google が支持を表明している。特定ベンダーに依存しない形で「一度作れば複数のエージェントクライアントで動く」ことを目的としている。

従来は複数のエージェントへプラグインを配布しようとすると、クライアントごとに別のマニフェストとディレクトリ構成を維持する必要があった。1.0 では `plugin.json` に `$schema` フィールドを追加し、スキルを `skills/` 配下、MCP 設定を `mcp.json` に置く標準構成へ揃える。Copilot 固有のコンポーネントは `com.github.copilot/` ディレクトリに入れ、他のクライアントはこれを無視する。

既存の GitHub Copilot プラグインとは完全な後方互換があり、移行作業は不要である。Awesome Copilot マーケットプレイスからのインストールにも対応する。

企業ガバナンスの面では、Copilot Business / Enterprise の顧客が既存の `managed-settings.json` でプラグインの可用性を管理できる。Agent Plugins 用に別建てのポリシーを用意する必要はない。

## できるようになったこと

- 標準構成のプラグインを1つ作れば、VS Code / Copilot CLI / Copilot SDK / Copilot アプリで共通に使える
- スキルと MCP サーバーを1パッケージにまとめて配布できる
- Awesome Copilot マーケットプレイスからプラグインをインストールできる
- Copilot 固有部分を `com.github.copilot/` に隔離し、他クライアントとの互換を保てる
- Business / Enterprise は既存の `managed-settings.json` でプラグインの可否を統制できる

## 影響範囲

- 対象ユーザー: GitHub Copilot 利用者全般、プラグイン作者
- 対象プラン: 全 Copilot プラン。ガバナンス機能は Business / Enterprise
- API / UI / 管理者機能: VS Code / CLI / SDK / アプリ、`managed-settings.json`（管理者）
