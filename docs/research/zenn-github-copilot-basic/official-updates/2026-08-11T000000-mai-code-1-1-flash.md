# 2026-08-11 MAI-Code-1.1-Flash の提供開始

## 公式内容の日本語要約

Microsoft の小型コーディングモデル MAI-Code-1.1-Flash が GitHub Copilot でロールアウトを開始した。画像を理解できるネイティブの vision 機能を持ち、公式はコード品質、指示追従、ツール利用、性能のいずれも改善したとしている。

価格面の変化が大きい。前世代の MAI-Code-1-Flash と比べて表示価格が 73% 低く、公式は軽量なコーディング作業向けのコスト効率の高い選択肢と位置づけている。年額契約の利用者にはプレミアムリクエスト乗数 0.25 倍が適用され、従量課金ではプロバイダーの表示レートで請求される。

提供範囲はプランで分かれる。Free / Student は自動選択の対象としてのみ利用でき、モデルを手動で選ぶことはできない。Pro / Pro+ / Max / Business / Enterprise は手動選択と自動選択の両方が可能である。

ただし Business / Enterprise は既定でオフであり、管理者が Copilot 設定でモデルポリシーを有効化しない限り、VS Code のモデルセレクターにも github.com 上にも現れない。

## できるようになったこと

- MAI-Code-1.1-Flash を GitHub Copilot で利用できる（ネイティブ vision 対応）
- 旧 MAI-Code-1-Flash 比で表示価格が 73% 低い
- 年額契約はプレミアムリクエスト乗数 0.25 倍で消費する
- Pro / Pro+ / Max / Business / Enterprise は手動選択が可能、Free / Student は自動選択のみ

## 影響範囲

- 対象ユーザー: Copilot 利用者全般と、Business / Enterprise の管理者
- 対象プラン: 全プラン（Business / Enterprise は既定オフで管理者の有効化が必要）
- API / UI / 管理者機能: モデルセレクター + 組織のモデルポリシー
