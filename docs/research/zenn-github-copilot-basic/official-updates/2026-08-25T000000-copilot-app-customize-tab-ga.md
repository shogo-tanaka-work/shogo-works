# 2026-08-25 Copilot アプリの Customize タブが一般提供

## 公式内容の日本語要約

GitHub Copilot アプリの **Customize タブが一般提供**になった。カスタマイズの発見と管理を1か所へ集約するもので、公式の説明は「注目のカスタマイズを見る、種類で絞る、チームの働き方に合わせる新しい方法を見つける」。

集約される対象は4種類。**MCP サーバー**（トレンド表示とカテゴリ別ブラウズ）、**プラグイン**、**スキル**、**Canvas**（Azure DevOps のバックログ委譲などが注目枠に出る）である。

## できるようになったこと

- MCP サーバー・プラグイン・スキル・Canvas を Copilot アプリの1タブで探して管理できる
- MCP サーバーをカテゴリから探せる

## 影響範囲

- 対象ユーザー: GitHub Copilot アプリの利用者
- 対象プラン: Copilot 利用者全般
- API / UI / 管理者機能: アプリ UI

## 教材化メモ

- **カスタマイズの「マーケットプレース化」**が各社で同時に進んでいる。Claude Code のプラグインマーケットプレース、Codex のプラグインカタログ、Copilot の Customize タブが同じ週に更新されている。**拡張の供給側をどこまで信用するか**という論点が、ツールを問わず共通の設計課題になっている証拠として使える。
- 記事化はしない（週次確認ソースの通常更新）。
