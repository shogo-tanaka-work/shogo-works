# 2026-09-01 Claude Fable 5.1 が GitHub Copilot で GA

## 公式内容の日本語要約

Anthropic の **Claude Fable 5.1** が GitHub Copilot に統合され、一般提供になった。

対象プランは、同週の weekly releases（2026-09-04）の記載により **Copilot Pro+ / Max / Business / Enterprise**。

同モデルは**同日（2026-09-01）に Claude Code の既定 Fable モデルにもなっており**（Claude Code 2.1.257）、**Microsoft Copilot でも同日に提供が告知されている**。モデル公開と各クライアントへの搭載が同日に揃った形である。

## できるようになったこと

- Copilot Pro+ / Max / Business / Enterprise で Claude Fable 5.1 を選ぶ

## 影響範囲

- 対象ユーザー: Copilot Pro+ / Max / Business / Enterprise の利用者
- 対象プラン: 上記。Pro は対象外
- API / UI / 管理者機能: モデルピッカー、Copilot settings のモデルポリシー

## 教材化メモ

- **同一モデルが同日に GitHub Copilot / Microsoft Copilot / Claude Code の3面へ載った**という事実は、モデル供給とクライアント搭載が分離した現在の構造を示す。**「どのツールを使うか」と「どのモデルを使うか」が独立に決められる**——この分離は、ツール選定の教材で押さえるべき前提である。
- 一方で **Copilot Pro は対象外**という線引きは残る。プラン差はモデル差として現れるため、**同じ製品名でも人によって使えるモデルが違う**。チーム内の再現性を議論するときの材料になる。
