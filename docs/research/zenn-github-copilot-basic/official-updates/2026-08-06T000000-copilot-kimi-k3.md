# 2026-08-06 Kimi K3 が GitHub Copilot に追加

## 公式内容の日本語要約

GitHub Copilot のモデル選択肢に Kimi K3 が追加された。公式は「オープンウェイトモデル」で「エージェント的コーディングにおいてフロンティア級の能力」を持つと説明している。

対象プランは Pro / Pro+ / Max / Business / Enterprise。選択できるサーフェスは広く、Visual Studio Code、Visual Studio、Copilot CLI、GitHub Copilot cloud agent、GitHub Copilot アプリ、github.com、GitHub Mobile（iOS / Android）、JetBrains、Xcode、Eclipse。

Business / Enterprise では **既定でオフ**であり、Copilot 設定で管理者が Kimi K3 のポリシーを有効化するまでメンバーは利用できない。ロールアウトは段階的で、公式は GitHub Actions の incident 対応のためロールアウトを一時停止していると付記している。

課金は従量制で、入力 100万トークンあたり $3、出力 100万トークンあたり $15、キャッシュ済み入力 100万トークンあたり $0.30。

## できるようになったこと

- Copilot の各サーフェスで Kimi K3 をモデルとして選択できる（段階ロールアウト中）
- Business / Enterprise 管理者が組織単位で Kimi K3 の利用可否を制御できる

## 影響範囲

- 対象ユーザー: Copilot Pro / Pro+ / Max / Business / Enterprise 利用者
- 対象プラン: 上記5プラン。Business / Enterprise は既定オフで管理者の有効化が必要
- API / UI / 管理者機能: UI（モデル選択）、管理者機能（ポリシー）

## 教材化メモ

- 「モデルが増える」こと自体より、**Business / Enterprise で既定オフ・管理者が明示的に有効化する**という配布モデルが教材価値の中心。オープンウェイトモデルを組織に入れるかどうかの判断が管理者に降りてくる構造を、Copilot 教材の管理者向け節で扱える。
- 価格（入力 $3 / 出力 $15 / キャッシュ $0.30 per 1M）は変動しやすいため、教材本文に数値を書かず「従量課金でモデルごとに単価が異なる」という原則だけ記す。
- ロールアウトが incident で一時停止された点は、「changelog に載っていても自分の環境に来ているとは限らない」という一般則の実例として使える。
