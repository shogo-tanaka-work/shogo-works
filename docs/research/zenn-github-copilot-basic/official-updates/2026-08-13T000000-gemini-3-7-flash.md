# 2026-08-13 Gemini 3.7 Flash in GitHub Copilot

## 公式内容の日本語要約

GitHub Copilot で **Gemini 3.7 Flash** が使えるようになった。対象プランは Copilot Pro、Pro+、Max、Business、Enterprise。

**Business と Enterprise は既定でオフ**である。管理者が Copilot 設定で「Gemini 3.7 Flash Preview」ポリシーを有効化しない限り、組織内の誰もモデルを選択できない。GitHub Copilot で新モデルが追加される際の定着したパターンで、直近では MAI-Code-1.1-Flash（2026-08-11）や Kimi K3 でも同じ扱いだった。

課金は従量課金のもとでプロバイダーの表示価格が適用される。具体的な倍率は GitHub のモデル価格ドキュメントを参照する形になっている。

利用できる面は広い。Visual Studio Code、Visual Studio、Copilot CLI、GitHub Copilot cloud agent、GitHub Copilot アプリ、JetBrains、Xcode、Eclipse のモデルピッカーから選択できる。

ロールアウトは段階的に進行中で、すぐに見えない場合は後から確認するよう案内されている。

## できるようになったこと

- Copilot Pro / Pro+ / Max / Business / Enterprise で Gemini 3.7 Flash を選択できる
- VS Code、Visual Studio、CLI、cloud agent、Copilot アプリ、JetBrains、Xcode、Eclipse で利用できる

## 影響範囲

- 対象ユーザー: GitHub Copilot 利用者
- 対象プラン: Pro / Pro+ / Max / Business / Enterprise。**Business / Enterprise は既定オフ**
- API / UI / 管理者機能: 各 IDE のモデルピッカー、Copilot 設定のモデルポリシー（管理者）
