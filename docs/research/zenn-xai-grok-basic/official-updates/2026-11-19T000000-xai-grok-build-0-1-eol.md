# xAI - grok-build-0.1 の EOL

## 公式内容の日本語要約

`docs.x.ai` の Release Notes の November 節に、**`grok-build-0.1` が 2026-11-19 に end of life を迎え、API で提供されなくなった**と記載された。xAI / Grok は 8週連続で窓内更新なしだったため、この窓で初めて更新を検出した。代替モデルの明示はこの項目には書かれていない。

同じ November 節に `grok-imagine-image-quality retired` の項目もある。`grok-imagine-image-quality` と `grok-imagine-image-pro` へのリクエストは `grok-imagine-image-2.0-low`（`grok-imagine-image-2.0` の `quality: low`）で処理され、**リクエストの変更は不要**で、1画像あたりの価格は下がる。レスポンスの `usage.cost_in_usd_ticks` は下がった価格を反映し、gRPC レスポンス（xAI SDK）は `model` として `grok-imagine-image-2.0-low` を返す。**ただしこの項目には日付の明記がない。** 2026-09 の節に「2026-11-02 に `grok-imagine-image-quality` を退役」という予告があるため、**掲載自体は窓より前（11-02 前後）の可能性が高く、窓内更新として扱わない**。

## 影響範囲

- 対象ユーザー: xAI API で `grok-build-0.1` を指定していた利用者。11-19 以降リクエストは通らない
- 対象プラン: xAI API
- API / UI / 管理者機能: API のモデルスラッグのみ
