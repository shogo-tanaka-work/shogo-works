# 2026-10-02 grok-voice-transcribe-1.0 の EOL

## 公式内容の日本語要約

xAI の release notes に **October** 節が追加され、記載は1行である。

- 「**`grok-voice-transcribe-1.0` は非推奨であり、2026年10月2日に end of life に達する**」

**あわせて、既定の STT モデルが `grok-voice-transcribe-2.0` に切り替わっていることを確認した。**

これは前週からの継続案件の決着にあたる。2026-09-18 に Grok Voice Transcribe 2.0 が告知され、「数週間のうちに 1.0 を非推奨化して STT 既定を 2.0 へ切り替える」とされていた。**2026-09-28 の週次チェック時点では、release notes の現行記述で既定が依然 1.0 のままで、告知と実装のずれが続いていた。** 本窓で**既定の切替と EOL 日付の明示が同時に確認でき、残日数を計算できない状態が解消した。**

**EOL 日（2026-10-02）は本週次の窓内（2026-09-28〜10-05）であり、既に到来している。**

継続中の退役予告がもう1件ある。**`grok-imagine-image-quality` は 2026-11-02 に退役**し、以後は `grok-imagine-image-2.0` の `quality: low` が同じ slug で応答する（September 節に記載、**残28日**）。

**`x.ai/news` は WebFetch で 403 を返し、確認できていない**（下記「原文確認」参照）。

## できるようになったこと

- （退役のため該当なし。STT 既定は 2.0 へ）

## 影響範囲

- 対象ユーザー: xAI API で STT を使う利用者
- 対象プラン: API 全般
- API / UI / 管理者機能: **`grok-voice-transcribe-1.0` を明示指定しているコードは 2026-10-02 以降動かない。既定指定のコードは 2.0 へ自動的に移っている**

## 教材化メモ

- **前週に「残日数を計算できない」として記録した案件が、1週で解決した。** 2週続けて同じ項目を追い、**告知（09-18）→ ずれの確認（09-28）→ 既定切替と EOL 日の確定（10-02）**という3段を記録できている。**期限が曖昧な予告は、曖昧なまま記録して追い続ける**という扱いが機能した実例である。
- **「既定を切り替える」と「旧版を EOL にする」が同じ日に揃った**ため、**モデルを pin している側だけが止まる**構図になった。既定指定なら自動で移り、明示指定なら動かなくなる。**pin はバージョン固定の手段だが、EOL に対しては逆に脆い**——この非対称は、モデル指定の運用ルールを決めるときの中心論点になる。
- `grok-imagine-image-quality` の退役は**「同じ slug が別の実体を指すようになる」**型である。呼び出し側のコードは変わらないまま出力品質が変わるため、**エラーにならずに結果だけ変わる**。退役の中でも最も気づきにくい形として押さえておきたい。
