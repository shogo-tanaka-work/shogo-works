# 2026-09-21 Grok 4.7

## 公式内容の日本語要約

xAI が **Grok 4.7** を公開した。公式 release notes（`docs.x.ai/docs/release-notes`）の 2026-09 節に掲載されており、**コーディング・エージェント的タスク・専門知識作業向けのフロンティアモデル**という位置づけである。

**仕様。** model slug は **`grok-4.7`**。**コンテキストは 500k**。**入力はテキストと画像、出力はテキストのみ**で、**テキスト出力の上限は撤廃**された。**reasoning effort は low / medium / high（既定）/ xhigh の4段階。** 米国リージョンのエンドポイントでも提供される。

**料金は2段階である。** **プロンプトが 200k トークン未満では入力 $2 / キャッシュ入力 $0.50 / 出力 $6（いずれも per 1M トークン）。200k を超えると入力 $4 / キャッシュ入力 $1 / 出力 $12 で、単価が2倍になる。**

**`Grok 4.7 Fast` という高速版**も存在するが、**トークン単価は2倍で、アクセスは Cursor と Grok Build に限られる。**

**同日に GitHub Copilot 側でも Grok 4.7 が選択可能になっている**（`../zenn-github-copilot-basic/official-updates/2026-09-21T000000-copilot-grok-4-7-available.md`、Pro 以上）。

**前週までの記録との関係。** `grok-voice-transcribe-2.0`（09-18 記録済み）と `grok-imagine-image-quality` の 2026-11-02 退役（09-01 記録済み）は本週の新規ではない。**なお release notes の現行記述では、Speech-to-Text の既定は明示指定しない限り `grok-voice-transcribe-1.0` のままである。** 前週に「既定を 2.0 へ切り替える」と記録した告知に対し、**窓の終端時点でまだ切り替わっていない**ことになる。**`grok-voice-transcribe-1.0` の非推奨化は依然として日付が示されていない。**

## できるようになったこと

- `grok-4.7` を API から利用（500k コンテキスト、テキスト + 画像入力）
- reasoning effort で xhigh を指定できる
- テキスト出力の長さ上限が撤廃

## 影響範囲

- 対象ユーザー: xAI API の利用者、Grok を組み込んでいる開発者
- 対象プラン: API 従量課金
- API / UI / 管理者機能: **200k トークンを境に単価が2倍になるため、長文コンテキスト前提の実装はコスト試算をやり直す必要がある**

## 教材化メモ

- **200k を境に単価が2倍になる2段階料金**は、コスト設計の教材として具体的である。**「コンテキストが 500k 入る」ことと「500k 入れて採算が合う」ことは別**。RAG で詰め込むほど安くなるわけではない、という設計判断に直結する。
- **`Grok 4.7 Fast` が Cursor と Grok Build に限定**されている点は、**モデルの入手経路が製品ごとに違う**実例。API から使える構成と、特定ツール内でしか使えない構成が併存する。
- **前週記録した「既定を 2.0 へ切り替える」が、窓の終端時点で反映されていない**。告知と実装のずれを週次で追える形になっているのは、**毎週同じソースを同じ観点で見ている**からである。追跡の価値がそのまま出た例。
