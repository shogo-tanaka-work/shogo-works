# 2026-10 grok-voice-3.0 の提供開始

※ **日付の精度に注意。** `docs.x.ai/docs/release-notes` は**月単位の見出ししか持たず、日付が無い**。前週の週次確認（2026-10-12）では October 節は `grok-voice-transcribe-1.0` の EOL 1件のみだったため、**本エントリは 2026-10-12〜10-19 の窓内に追加された**と判断した。`date` は検出日（2026-10-19）を入れており、実際の公開日ではない。

## 公式内容の日本語要約

**`grok-voice-3.0` が Speech to Speech で利用できるようになった。** 価格は **Grok Voice 2.0 と同じ**である。

**エイリアス `grok-voice-latest` が `grok-voice-3.0` を指すようになった。** 公式は「`grok-voice-latest` now points to `grok-voice-3.0`, so sessions that use the alias are upgraded automatically」と明記しており、**エイリアスを使っているセッションは自動的に 3.0 へ上がる。** API 自体は変わらない。

**性能・品質の差分、対応言語、レイテンシの数値は記載が無い。**

## できるようになったこと

- Speech to Speech で `grok-voice-3.0` を指定できる（価格は 2.0 と同じ）

## 影響範囲

- 対象ユーザー: xAI API の Speech to Speech 利用者
- 対象プラン: 記載なし（価格は 2.0 と同じ）
- API / UI / 管理者機能: API（モデル指定、エイリアス）

## 教材化メモ

- **何もしなくても変わる種類の更新である。** `grok-voice-latest` を指定している実装は、**コードを変えずにモデルが入れ替わる。** 音声の声質・話し方が変わりうるため、**エンドユーザー向けの音声体験を作っている場合は、切り替わりを前提に検証する必要がある。**
- **エイリアス参照は廃止対応が楽になる一方、挙動の固定ができない**というトレードオフがそのまま出ている。同週の GitHub Copilot のモデル廃止（11-16）と並べると、「エイリアスで追従する」「版を固定する」の選択を考えさせる題材になる。
- 品質差分の数値が無いため、**移行の判断材料は自前の評価しかない**。評価セットを持つことの動機づけに使える。
