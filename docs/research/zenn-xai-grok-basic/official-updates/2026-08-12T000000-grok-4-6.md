# 2026-08-12 Grok 4.6

## 公式内容の日本語要約

SpaceXAI（旧 xAI）が Grok 4.5 の後継となるフラッグシップモデル Grok 4.6 を公開した。重点は「長時間走るエージェント」と「対話的・視覚的な成果物づくり」の2点で、調査・分析・コードベース横断・アプリ化のように多段になるタスクを途中で見失わずに続けることを狙っている。

ベンチマークでは Artificial Analysis Intelligence Index で 61 を記録し、GPT-5.6 Sol Max と同点、Fable 5 Max（62）に僅差で並ぶ位置づけとなった。CursorBench v3.2 は 69.9%、GDPVal-AA v2 は 1753 で Grok 4.5 High（66.7% / 1526）から上昇している。一方 DeepSWE v1.1 は 65.9% で GPT-5.6 Sol Max（73%）に劣り、Terminal-Bench v3.0 は 26% と他社（34%台）に差をつけられている。全面的な優位ではなく、得意領域が偏っている点は読み違えやすい。

学習面では Grok 4.5 より長い追加事前学習を行い、Grok 4.5 自身に SFT 軌跡を再生成させたうえで問題のあるトレースをモデルベースの検査で除外した。RL 段階ではカーネル最適化・Web 開発・CAD などのドメイン特化環境を含む幅広いエージェント課題を使っている。

API では `grok-4.6` として提供され、コンテキストウィンドウ 500k トークン、知識カットオフは 2026-02-01。テキストと画像の入力に対応し出力はテキストのみ、出力長の上限はない。価格は 200k プロンプトトークン未満で入力 $2 / キャッシュ入力 $0.50 / 出力 $6（1M トークンあたり）、200k 超で入力 $4 / キャッシュ入力 $1 / 出力 $12 の二段階制。reasoning effort は low / medium / high（既定）/ xhigh の4段階。

公式は Cursor と Grok Build での提供開始を告知し、最初の1週間は両方で included usage を2倍にする施策を打っている。Cursor 側も同日に自社ブログで Grok 4.6 の提供を発表した。

## できるようになったこと

- `grok-4.6` を xAI API（Responses API / Chat Completions）から利用できる。function calling、web search、X search、code execution に対応
- 500k トークンのコンテキストで長い調査・コードベース横断を1セッションに収められる
- reasoning effort を xhigh まで上げて、難所だけ深く考えさせる運用ができる
- Cursor と Grok Build で即日利用でき、初週は included usage が2倍

## 影響範囲

- 対象ユーザー: xAI API 利用者、Cursor 利用者、Grok Build 利用者
- 対象プラン: API は従量課金。Cursor / Grok Build は既存プランに含まれる（初週2倍施策あり）
- API / UI / 管理者機能: API（新モデル名 `grok-4.6`）、Cursor / Grok Build のモデル選択 UI
