# 2026-08-11 Grok Bot

## 公式内容の日本語要約

SpaceXAI が Grok Bot を公開した。Bot は「実務を任せられる AI チームメイト」という位置づけで、人間と同じようにアプリや Web サイトへサインインして操作する。従来のチャット型エージェントとの最大の違いは、**Bot が自分専用のクラウドコンピュータを持つ**ことにある。

各 Bot はブラウザ・ファイルシステム・ターミナルを備えた永続クラウド VM 上で動く。コネクタや MCP が使える場合はそれを使い、きれいな API がないアプリに対しては computer use で直接操作する。成果がチャットの下書きではなく実際のツール内に残るのが設計思想である。

状態が持続する点も特徴で、名前付きの Bot はメモリ・ファイル・ブラウザセッション・好みをターン間で保持する。タスクごとにまっさらな環境へ戻らず、文脈が積み上がっていく。複数の Bot を並列で走らせることもでき、Bot 同士が直接メッセージを送り合い、スレッドやグループチャットで文脈を共有し、担当を引き継げる。ユーザーがツール間のルーターになる必要がない。

ワークフローの獲得方法も特徴的で、多段・多システムにまたがる手順を一度実演して見せると、Bot はその経路を routine として保持し、スケジュール実行やオンデマンド再実行ができるようになる。

**セキュリティ上の重要な注意点**として、すべての Bot が同一の永続クラウドコンピュータを共有する。この計算機はアカウント単位で分離されており、Bot 単位では分離されていない。公式ドキュメントは「そのコンピュータに置いたログイン情報やファイルは、自分の全 Bot から利用可能だと考えること」と明記している。Bot ごとに画面は分かれるが、セキュリティ境界は分かれない。

提供は SuperGrok Heavy、Cursor Ultra、Cursor Teams Premium の3つの既存サブスクリプションに含まれる形。デスクトップアプリと iOS で利用できる。

## できるようになったこと

- 永続クラウド VM 上で動く名前付き Bot に、複数ツールをまたぐ実務を任せられる
- API のないアプリにも computer use でサインインして操作させられる
- 手順を一度実演して routine 化し、スケジュール実行できる
- 複数 Bot を並列稼働させ、Bot 間で文脈と担当を引き継げる

## 影響範囲

- 対象ユーザー: SuperGrok Heavy / Cursor Ultra / Cursor Teams Premium の契約者
- 対象プラン: 上記3プランに同梱（追加課金なし）
- API / UI / 管理者機能: デスクトップアプリ / iOS アプリ。全 Bot が同一クラウドコンピュータを共有するため、認証情報の配置は組織のセキュリティ方針と照合が必要
