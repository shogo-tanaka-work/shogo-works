# 2026-09-03 Grok Bot for Enterprise

## 公式内容の日本語要約

**Grok Bot が企業向けに提供開始**された。今回のリリースで、**アクセス制御・ネットワーク制御・監査制御**が加わり、Bot を組織規模で統制できるようになった。

**期限つきの提供条件がある。** 公式は「**Grok と Cursor の Enterprise 顧客は今後2週間、無償で利用でき、既存のシートを持たない人を含めて組織全体を招待できる**」としている。告知日 2026-09-03 起算で、**2026-09-17 前後が期限**（残り約10日）。

Bot は**特定の仕事のために作る作業者**という位置づけで、それぞれがクラウド上の自分専用のコンピュータで動き、人間と同じようにアプリや Web サイトを使う。ワークフローを教えるには**一度follow along させる**——Bot が手順を保存し、修正を受け取り、以後は自律的に実行する。うまく動く Bot は**テンプレートとして他人へ渡せる。** Bot 同士がメッセージを送り合い、コンテキストを共有することもできる。

導入企業として Legora、Supermicro、ServiceTitan が挙げられている。

## できるようになったこと

- 組織規模で Grok Bot のアクセス・ネットワーク・監査を統制する
- シート未保有者を含め、組織全体を招待する（無償期間中）
- Bot をテンプレート化して他のメンバーへ渡す

## 影響範囲

- 対象ユーザー: Grok / Cursor の Enterprise 顧客
- 対象プラン: Enterprise。**2週間の無償枠は 2026-09-17 前後まで**
- API / UI / 管理者機能: アクセス制御、ネットワーク制御、監査ログ

## 教材化メモ

- **「Bot を作る」と「Bot を統制する」が別の機能として後から来た**という順序は、エージェント製品に共通する。**先に配ってから統制を足す**のが実態であり、**統制機能が揃う前に業務へ埋め込むと、後から棚卸しができない。** 導入時期の判断材料として使える。
- **一度follow along させて手順を覚えさせる**という教え方は、業務手順の暗黙知を移す方法として現実的である。一方で、**手順書が無いまま Bot だけが手順を知っている**状態を作りうる。**Bot をテンプレートとして渡せる**設計はその緩和だが、**属人化がツール依存に置き換わっただけ**という見方もできる。
- **無償枠が2週間**という短さは、評価としては厳しい。**組織全体を招待できる**条件と合わせると、**広く配って定着させる**ことが狙いと読める。PoC を設計する側は、**無償期間の終了後にどのシート数で継続するかを先に決めておく**必要がある。
- **Cursor Enterprise 顧客も対象**である点は、xAI と Cursor の距離を示す。前週サマリーに記録した「Cursor と OpenAI の契約終了（2026-11-12 シャットオフ提案日）」と並べると、**Cursor の供給元がどう動いているか**の観測材料になる。
