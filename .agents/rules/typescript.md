# TypeScript

- `strict: true` を維持する。
- `any` は禁止。外部入力は `unknown` と型ガード（または zod）で扱う。
- 型アサーションは境界の検証後だけに限定し、二重アサーションを禁止する。
- 純粋関数を優先し、副作用は API ルート・外部アダプタ・UIイベントへ閉じ込める。
- 引数が3つを超える場合は名前付きオブジェクトへまとめる。
- 型だけの import には `import type` を使う。
- 変数と関数は役割が分かる完全な名前にする。
- catch した値は `unknown` として扱う。
- Promise を浮かせない。必ず `await` するか、返り値として返す。
- 型定義は `src/types/index.ts` に集約する。コンポーネントの Props はそのファイル内に置いてよい。
