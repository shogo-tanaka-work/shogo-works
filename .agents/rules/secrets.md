# 秘密情報と環境変数

- API キー・トークンをコードや設定ファイルへ直書きしない。
- `.env` はコミットしない。項目を増やしたら `.env.example` にキー名だけ追加する。
- 環境変数は使用前に存在を検証し、未設定なら起動時または初回利用時に明確なエラーを出す。
- 環境変数の値をログ・エラーメッセージ・レスポンスへ含めない。
- クライアントへ渡る値（`PUBLIC_` 接頭辞）と、サーバーだけで使う値を混同しない。秘密情報を `PUBLIC_` にしない。
- API ルートは外部入力を zod で検証してから使う。検証エラーの詳細は返してよいが、内部エラーの中身は返さない。
- 送信系（メール送信など）のエンドポイントは、失敗を握りつぶさず、利用者に伝わるメッセージへ変換する。
- エージェントは `.env` の内容を読み出さない。ファイル列挙も対象パスを絞る。
