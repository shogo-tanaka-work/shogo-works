# Astro

- デフォルトは Astro コンポーネント（ゼロJS）。クライアント動作が必要な箇所だけ React Islands にする。
- `client:*` ディレクティブは必要最小限の粒度で付ける。ページ全体を Island にしない。
- `client:load` はファーストビューに必要な操作だけ。それ以外は `client:visible` を検討する。
- ページの責務はデータ取得とレイアウトの組み立てに限定し、表示は `components/` へ切り出す。
- `getStaticPaths` はデータの正本（Content Collections または `src/data/`）から生成する。生成元と表示側で条件を二重に持たない。
- Props は `interface Props` として明示する。暗黙の `any` を残さない。
- 同じ表示ロジックを複数ページへ複製しない。3回目のコピーが出たらコンポーネントへ切り出す。
- Astro コンポーネント内の `<script>` は、その要素が存在しない場合に落ちない書き方にする（オプショナルチェーンで受ける）。
- アイコンなどのインラインSVGを複数ファイルへ重複定義しない。共通コンポーネントか単一のマップへ集約する。
- `set:html` は自分で生成した安全な文字列にだけ使う。外部入力へ使わない。

## ページの構成

- レイアウトは `src/layouts/` に置き、ページから直接 `<html>` を書かない。
- `<title>` と `description` はページごとに設定する。使い回しをしない。
- 一覧ページは全件描画を避ける。件数が増える一覧は上限を設け、アーカイブや絞り込みで辿れるようにする。
