# 静的データ

サイトの掲載内容（サービス、実績、ナビゲーション、レビュー等）は `src/data/` に TypeScript として定義し、表示コンポーネントへ直書きしない。

- 型は `src/types/index.ts` に集約し、各データファイルは `import type` で参照する。
- データ間の参照は「href か id」で結び、文字列の一致に依存する箇所はテストで検証する。
  例: `cases.ts` の `serviceHref` が `services.ts` に実在すること。
- 掲載をやめた項目は、参照元（ナビゲーション、事例、レビュー、技術詳細）まで同じ変更セットで追従させる。参照だけ残さない。
- 仮の内容を置く場合は、その旨をコメントに残し、差し替え条件を書く。
- 実績・数値は事実に基づくものだけを書く。誇張しない。
- クライアント名は属性表記にし、実名の固有名詞を出さない。

## 変更時の確認

データを増減したら、次を確認する。

1. 参照している側（`src/data/` の他ファイル、`src/pages/`、`src/components/`）が壊れていないか
2. `tests/data/` の整合性テストが通るか
3. `getStaticPaths` から生成される URL が変わる場合、リンク元が追従しているか
