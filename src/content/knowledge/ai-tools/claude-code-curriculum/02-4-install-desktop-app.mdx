## このレッスンでわかること

2-0 で「デスクトップアプリで始める」を選んだ方向けのレッスンです。

- Claude デスクトップアプリを自分のパソコンに入れられる
- アプリの中の「Code」タブが Claude Code だと理解できる
- インストールでつまずいたときの対処法がわかる

ターミナル（CLI）を選んだ方は、このレッスンは飛ばして **2-1**（Windows）または **2-2**（Mac）へ進んでください。

## まず結論：Claude アプリを入れて、Code タブを開く

先に全体像を示します。やることは3ステップです。

1. Claude デスクトップアプリをダウンロードしてインストールする
2. Claude アカウントでサインインする
3. 画面上部の **Code** タブを開く

**Node.js のような前提ソフトは要りません。**Claude Code はデスクトップアプリに最初から入っています（ターミナルから `claude` コマンドを使いたい場合だけ、別途 CLI のインストールが必要です）。

## 用語の整理：「デスクトップアプリ版 Claude Code」ではない

ここは最初に押さえておくと混乱しません。

正確に言うと、**「Claude Code のデスクトップアプリ」という独立した製品はありません。**あるのは **Claude というデスクトップアプリ**で、その中に3つのタブがあります。

| タブ | 何をするところ |
|---|---|
| **Chat** | ふつうの会話。claude.ai をアプリにしたもの。ファイルは触らない |
| **Cowork** | クラウド上で自律的に作業させる機能 |
| **Code** | **ここが Claude Code。**手元のファイルを直接読み書きする |

本カリキュラムで使うのは **Code タブ**です。以降「デスクトップアプリで作業する」と書いたら、この Code タブを開いている状態を指します。

## 事前準備：有料プランの確認

**Claude の無料プランでは Code タブは使えません。**Pro・Max・Team・Enterprise のいずれかが必要です。

Code タブをクリックしたときにアップグレードを促す画面が出たら、それは「まだ有料プランに入っていない」というサインです。claude.ai の料金ページで手続きを済ませてから戻ってきてください。

### Windows の方：Git が必要です

もうひとつ、**Windows では Git というソフトのインストールが必須**です。これが無いと Code タブが動きません。Mac にはたいてい最初から入っているので、対応が必要なのは Windows だけです。

先に入れておくと後がスムーズです。「Git for Windows」で検索し、公式サイト（git-scm.com）からダウンロードしてインストールしてください。インストール中に多くの選択肢が出ますが、**すべて初期設定のまま「次へ」で問題ありません**。

> **［スクリーンショット］** Git for Windows のインストーラ画面。「Next」を押していけばよいことがわかるもの

インストールが終わったら、**Claude アプリを一度終了して開き直してください**。これをしないと、Git を入れたことがアプリに伝わりません。

## ステップ1：アプリをダウンロードする

ブラウザで claude.ai を開き、デスクトップアプリのダウンロード案内から、自分の OS 用のファイルを取得します。

- **Mac**：`.dmg` という形式のファイルがダウンロードされます。Intel と Apple シリコンの区別は不要で、共通のファイルです
- **Windows**：セットアップ用の `.exe` ファイルがダウンロードされます

> **［スクリーンショット］** ダウンロードページ。自分の OS 用のボタンがどれか分かるもの

## ステップ2：インストールする

### Mac の場合

1. ダウンロードした `.dmg` ファイルをダブルクリックします
2. ウィンドウが開くので、**Claude のアイコンを「Applications」フォルダへドラッグ**します
3. Launchpad または「アプリケーション」フォルダから Claude を起動します

> **［スクリーンショット］** dmg を開いた状態。アイコンを Applications へドラッグする画面

### Windows の場合

1. ダウンロードした `.exe` ファイルをダブルクリックします
2. インストーラの案内に従って進めます
3. スタートメニューから Claude を起動します

> **［スクリーンショット］** Windows のインストーラ画面

## ステップ3：サインインして Code タブを開く

1. アプリが起動したら、**Claude アカウントでサインイン**します。ブラウザで claude.ai にログインするときと同じアカウントです
2. サインインが終わったら、**画面上部中央の「Code」タブ**をクリックします

> **［スクリーンショット］** アプリ上部の Chat / Cowork / Code タブ。Code タブの位置が分かるもの

Code タブの画面が表示されれば、インストールは完了です。実際の使い方は次の **2-5** で確認します。

> **サインインを求められた場合は、完了後にアプリを再起動してください。**認証の状態が正しく反映されないことがあります。

## よくあるつまずきと対処法

### Code タブを押すと「アップグレード」を求められる

有料プラン（Pro 以上）に入っていない状態です。claude.ai の料金ページで手続きをしてから、アプリを再起動してください。

### Windows で Code タブが動かない

**Git がインストールされていない**可能性が高いです。前述の手順で Git for Windows を入れ、**アプリを終了して開き直して**ください。「インストールしたのに直らない」というときは、この再起動を忘れていることがほとんどです。

### Mac で「開発元が未確認のため開けません」と出る

macOS の安全機能によるものです。「システム設定」→「プライバシーとセキュリティ」を開くと、下のほうに「このまま開く」という趣旨のボタンが出ているので、そこから許可してください。

**なお、この操作は「公式サイトからダウンロードしたファイルである」と自分で確認できている場合にのみ行ってください。**出どころの分からないファイルで同じことをしてはいけません。

### 会社のパソコンでインストールできない

管理者権限が必要な場合や、ソフトのインストールが申請制の場合があります。**自己判断で設定を変えず、情報システム部門に相談してください。**「Anthropic 社の Claude というアプリを業務で使いたい」と伝えるのが早道です。

### 画面が説明と違う

アプリは頻繁に更新されるため、ボタンの位置や名前が変わることがあります。メニューから「Check for Updates」（更新を確認）を実行して最新版にしたうえで、それでも分からなければ本文の目的（例：「作業するフォルダを選ぶ」）に相当する操作を探してみてください。

## やってみよう

1. **インストールを完了させる**：本文の手順に従い、アプリを起動して Code タブが開けるところまで進めましょう
2. **3つのタブを見比べる**：Chat・Cowork・Code をそれぞれクリックして、画面がどう違うか眺めてみてください。「Code タブだけが自分のパソコンのファイルを扱う」という違いを目で確認するのが目的です
3. **バージョンを確認する**：メニューから「Check for Updates」を実行し、最新版になっていることを確認しましょう

## まとめ

- 「Claude Code のデスクトップアプリ」ではなく、**Claude アプリの中の Code タブ**が Claude Code
- Chat（会話）/ Cowork（クラウド作業）/ Code（手元のファイルを扱う）の3タブがある
- **Node.js は不要**。Claude Code はアプリに同梱されている
- **無料プランでは Code タブは使えない**。Pro 以上が必要
- **Windows は Git のインストールが必須**。入れたらアプリを再起動する
- 画面の文言は変わるため、迷ったら操作の目的から探す

## 理解度チェック

**Q1. デスクトップアプリで Claude Code を使うために、事前に必要なものはどれでしょう？（Windows の場合）**

1. Node.js のインストール
2. 有料プラン（Pro 以上）と Git のインストール
3. GitHub アカウントの作成
4. ターミナル版 Claude Code のインストール

**正解：2**

Code タブは有料プラン（Pro・Max・Team・Enterprise）が必要で、Windows では Git のインストールも必須です。Node.js は不要で、Claude Code はアプリに同梱されています。GitHub アカウントが要るのは Web 版やデプロイ（6-3）の場面で、ここでは不要です。ターミナル版も別途入れる必要はありません。

**Q2. Claude デスクトップアプリの「Chat」タブと「Code」タブの違いとして正しいものはどれでしょう？**

1. Chat は無料、Code は有料という料金の違いだけ
2. Chat は日本語、Code は英語しか使えない
3. Chat は会話のみでファイルを扱わない。Code は手元のファイルを直接読み書きする
4. Chat は古い機能で、Code に置き換えられた

<details>
<summary>答えを見る</summary>

**正解：3**

Chat は claude.ai と同じ会話用のタブで、あなたのパソコンのファイルには触りません。Code タブが Claude Code にあたり、フォルダを指定して実際にファイルを読み書きします。第3章以降で扱う「ファイルを作らせる」作業は、すべて Code タブで行います。

</details>
