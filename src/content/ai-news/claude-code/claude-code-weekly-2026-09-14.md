## 今週の要点

**更新してください。今週は資格情報まわりの修正が最優先です。**

**エラー画面とサーバー詳細に資格情報が出ていました** (2.1.268)。`plugin/marketplace` のエラー表示が資格情報を含んでいた問題と、**MCP・プラグインのサーバー詳細が secrets を露出していた**問題が、同じリリースで2件修正されています。どちらも**画面共有・CI ログ・バグ報告を経由して外へ出る**形の露出です。更新に加えて、**すでに外へ出した内容を確認してください。**

**シンボリックリンク先で権限ルールが効いていませんでした** (2.1.268)。リンク先ディレクトリに対して権限ルールが正しく適用されていませんでした。前週の 2.1.252 に続く**シンボリックリンク経由の2件目**です。リンクでディレクトリを参照している環境は、そこだけ保護が抜けていた前提で確認してください。

**テレメトリに個人識別情報が入りました** (2.1.265)。Claude Desktop と Cowork の gateway セッションのテレメトリに **`user.email` と `user.groups`** が追加されました。利用実態は見えるようになりますが、**個人識別情報が観測基盤へ流れる構成変更**でもあります。配布している組織は、便利になったではなく**確認事項が増えた**として扱ってください。

**許可リストが読めないときの倒れ方が直りました** (2.1.267)。管理設定の `allowedHttpHookUrls` / `httpHookAllowedEnvVars` / `allowedChannelPlugins` が、**読み取れないときに「全許可」になっていました。** 全拒否へ倒れるよう修正されています。

## 変更一覧

**資格情報とセキュリティ** — `plugin/marketplace` のエラー表示と、MCP・プラグインのサーバー詳細からの secrets 露出を修正 (2.1.268)。**マーケットプレイスのエントリパスにバックスラッシュを含めると macOS / Linux で封じ込めチェックを回避できた**問題を修正 (2.1.267)。

**権限と管理設定** — シンボリックリンク先ディレクトリでの権限ルール不適用、`WebFetch` の deny ルールのスコープ変更、**空のアクセス制御リストと public address リクエストへの起動時警告**を追加 (2.1.268)。管理設定の許可リストが読めない場合に全拒否へ (2.1.267)。組織の管理設定がサンドボックスを要求する場合に Cowork のスケジュール実行がクラウドで起動失敗する問題を修正 (2.1.267)。

**コストと効率の統制** — **`maxEffortLevel` で Bedrock / Vertex / Foundry を含む全プロバイダー横断の効率レベル上限を強制**できるように。利用者はそれより低いレベルを選べます (2.1.267)。ツール結果のディスク保存に **1 GB 上限**と切り詰め表示 (2.1.265)。

**観測とゲートウェイ** — テレメトリへの `user.email` / `user.groups` (2.1.265)。**`OTEL_METRICS_INCLUDE_REPOSITORY` によるリポジトリ属性付きメトリクス**、`CLAUDE_CODE_GATEWAY_MODEL_DISCOVERY_TIMEOUT_MS` (2.1.269)。**`gatewayInternalNetworks`** で内部ゲートウェイからのログインを許可、Claude apps のゲートウェイ価格設定 (2.1.268)。

**プラグインと開発体験** — **`claude plugin eval` でプラグインの eval スイートを実行し、再現可能な JSON / HTML レポートを出力**できるように (2.1.269)。`--plugin-dir` が子フォルダをプラグインとして読み込み、追加・削除をライブ検出 (2.1.265)。`/output-style [name]` でのセッション横断の切り替え、`bashEditDiffEnabled` による Bash 編集の差分表示 (2.1.269)。プラグインコマンドの `--json` (2.1.268)。

**回帰と安定性** — `CLAUDE_CODE_USE_GATEWAY` が gateway サインインを強制し、API キー併用時に `Not signed in` で失敗していた回帰を修正 (2.1.266)。**長時間セッションで Bash の読み取り専用 git コマンドが余分な権限確認を出す**回帰を修正 (2.1.270)。`WebFetch` が無期限にハングせず 300 秒で失敗、アイドル時の CPU 高止まり、組織既定モデルへの無言の切り替わりを修正 (2.1.268)。**プロンプトキャッシュ関連の修正が 2.1.267 に集中**しており、MCP サーバーの再送、セッション中のツール増減、`/model` での切替など、前置きが書き換わってキャッシュを外す経路を系統的に潰しています。
