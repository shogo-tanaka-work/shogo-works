## 要約

Anthropic は 2026-11-24、Claude の artifact を **Mac と Windows のアプリとして取り込める Install as app** を、デスクトップ版 Claude のベータとして発表しました。会議の準備ページや当日出荷分の追跡表のように、日常で使う道具になっている artifact を、他のアプリと並べて使えるようにするものです。

インストールした artifact は専用のアイコンと別ウィンドウで動き、共有もできます。Claude とユーザーのコネクタを使え、通知を出したり、Mac のメニューバーや Windows のシステムトレイに項目を置いたりできます。artifact を編集すると自動で更新されます。アプリからの Claude への要求は、利用者のプランの利用上限に数えられます。

## 何が変わったか

使い方は、Claude に作りたいアプリを説明し、artifact として試してから「Install as app」を選ぶだけです。パッケージ化やコード署名は不要で、ログインも Claude のアカウントをそのまま使うため、API キーや別のログインは要りません。更新するには、最新の Claude for Mac / Windows で artifact を開き、共有メニューから選びます。

権限は3段階です。

- **既定**: ブラウザでできることだけ。
- **アプリ権限**: 常に手前に表示するウィンドウ、グローバルのキーボードショートカット、通知など、Claude が管理する一般的なデスクトップ機能。
- **フルコンピューターアクセス**: プログラムの実行や、ファイルの読み取り・変更・削除を、都度の確認なしに行える。

許可は **その時点のバージョンにだけ有効**で、自分で更新した場合も含め、更新のたびに再確認されます。ただし、アプリの一部が外部サイトの内容を読み込む場合、その内容は新たな確認なしに変わりえます。フルアクセスは、自分で作ったアプリ（Team・Enterprise では組織内の人が作ったアプリ）に限られます。

## 業務インパクト（一般企業向け）

- **プラン別の既定**: すべてのプランでベータ。Team は既定でインストールがオン、フルアクセスはオフ。Enterprise は組織オーナーがオンにするまでオフ。HIPAA 対応の組織とハイブリッド構成は対象外です。
- **管理者の統制**: Team と Enterprise の管理者は、アプリ権限とフルアクセスを組織単位でオン・オフできます。
- **審査がない点に注意**: Anthropic はインストール前にアプリを審査しません。公式も、信頼できるアプリにだけフルアクセスを許可するよう案内しています。**フルアクセスは、組織内で作られたアプリに限って、必要な範囲だけ許可する**運用が現実的です。
- **制限**: 開くにはオンラインでのサインインが必要です。Claude Docs、Slides、Sheets など、インストールできない artifact もあります。

## 副業・個人活用視点

自分用の道具（案件の進捗表、請求の下書き確認、ファイル整理のルール適用など）を、artifact で作ってからアプリとして常駐させる使い方が考えられます。まず既定の権限だけで動くか試し、必要になった権限だけを足す順序にすると、事故を避けられます。

アプリの利用は Claude のプランの上限を消費します。常に開いておく道具ほど消費が増えるため、使い方の頻度を見ながら調整してください。
