## 要約

Anthropic は 2026-10-21、**Claude Security の新版**を **Claude Enterprise 向けの公開ベータ**として提供開始しました。公式によると、2026 年 4 月の公開ベータ開始以降、数千の組織が合計 100 万件超の脆弱性を見つけています。

今回の変更の中心は、「誰かがスキャンを始めるのを待つ」使い方から、**コードの変更に追従し続ける**使い方への移行です。

## 何が変わったか

- **継続監視**: プロジェクトにリポジトリを登録すると、最初に詳細なベースラインスキャンを行い、以降は変更をリスクと複雑さに応じて定期的にスキャンする。1つのプロジェクトに複数のリポジトリを含められ、サービス間にまたがる問題も見つけやすい。接続は Claude の GitHub アプリ（GitHub Enterprise Server を含む）、または GitLab などのアクセストークン
- **修正の追跡**: 変更されたコードと検出事項を照合し、修正が入ると自動で「修正済み」にする。Claude Code で直しても別の手順で直しても同じ。再発すれば自動で再オープンされる
- **チームの知識を反映**: プロジェクトごとの知識ベースに、デプロイ方法やセキュリティポリシーを書ける。コードから脅威モデルが生成され、編集できる。以降のスキャンは脅威モデルで優先度を決め、環境側で対処済みのリスクは飛ばす
- **重大度と攻撃経路**: 各検出に、脅威モデルに照らした重大度と、攻撃者が到達する経路の説明が付く。攻撃経路の図が付くこともある
- **連携**: 新しい API でプロジェクトと検出事項の一覧・参照、解決・再オープン、プロジェクト管理ができる。個人アクセストークンは本人の権限の範囲に限られる。新しい検出が出たときの Webhook もある。Claude.ai と Claude Code の MCP コネクタにも対応する
- **権限**: ロールベースのアクセス制御で、閲覧、トリアージ、プロジェクト作成の権限を分けられる
- **料金**: Enterprise 契約者に月 25,000 ドルの無料利用枠が 2 か月分。2026-12-31 までの利用が対象

## 業務インパクト（一般企業向け）

**脆弱性管理の運用が変わります。** 従来は、定期スキャンの結果を読んで担当者が修正し、再スキャンで直ったかを確認していました。今回の版は、修正の確認と再発の検知までを自動で行うため、セキュリティ担当の作業が「確認」から「判断」に寄ります。

導入時に最初にやるべきことは、**脅威モデルのレビュー**です。公式の説明では、以降の優先度づけが脅威モデルに依存します。ここが現実と離れていると、重要な検出が下がったり、無関係な検出が上がったりします。

権限は、閲覧、トリアージ、作成を分けて、コードを持つチームには閲覧とトリアージだけを渡す構成がとれます。無料枠の期限が年内のため、検証するなら早めに範囲を決めてください。

## 副業・個人活用視点

**Enterprise 契約が前提のため、個人での利用は対象外です。** ただし、受託開発でクライアントが Enterprise を持っている場合は、納品物の脆弱性確認に使える可能性があります。API と MCP があるので、検出を課題管理に流す、修正の進捗を定例で報告する、といった運用も組めます。

提案するときは、脅威モデルを一緒に作る工程を見積もりに入れておくと、検出の質が安定します。
