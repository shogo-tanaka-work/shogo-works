## 要約

Anthropic は2026-11-05、**Claude Enterprise のセキュリティ・管理機能**をまとめて発表しました。中心は、自社の Claude 設定を推奨設定と比べて見られる「セキュリティセンター」です。

- **セキュリティセンター（ベータ）**: 組織設定の新ページ。チャット、Cowork、Claude Code の設定について、現在値、推奨値、設定画面へのリンクを一覧する。ページを開くたびに再チェックされ、レポートとして書き出せる
- **inference hooks（一般提供）**: プロンプトを検査する prompt hooks と、ツール呼び出しを実行前に検査する pre-tool-call hooks。自社が持つ DLP やセキュリティの方針をそのまま適用できる
- **集中管理（ベータ）**: 複数の Claude 組織を束ねる親組織向けに admin.claude.com で SSO、SCIM、ドメイン検証、グループ、Compliance API キーを一括管理
- **アクセス制御（ベータ）**: Admin API でメンバーを全端末からサインアウト、IP 許可リストの自己管理、管理対象 PC の Claude Desktop で個人アカウントを禁止
- **EDR 連携（ベータ）**: Cowork の仮想マシン内で自社の EDR センサーを動かせる

## 何が変わったか

- セキュリティセンターは**認証やコンプライアンスの保証ではなく**、Anthropic の推奨に基づく目安と明記されている。管理者が見直した結果を記録する「アテステーション」の機能もある
- 強制サインアウトは**API キー、実行中のクラウドセッション、予約済みの定期処理を終了させない**。退職者対応では別の手順が要る
- 集中管理は**設定後に取り消せない**。親組織の管理者を先に決めてから始める必要がある
- EDR センサーは**検知モードで動き、報告のみで遮断はしない**。対象はユーザー PC 上の仮想マシンで、クラウド上の Cowork セッションは含まない
- 対象は主に Claude Enterprise。ベータ機能の一部は提供範囲が限られ、Help Center に例外が載っている

## 業務インパクト（一般企業向け）

**設定の棚卸しが1画面で始められます。** これまでは管理画面を項目ごとに見て回る必要がありました。推奨とのずれを洗い出し、「意図して変えた」と「見落とし」に仕分ける作業が現実的になります。監査向けの説明資料にもなります。

**シャドー IT 対策が設定で扱えます。** 会社の PC では、個人や外部の Claude アカウントを Claude Desktop で使わせない設定が可能です。ただしブラウザやスマートフォンからの利用まで止まるとは書かれていないため、社内ルールでの周知も併せて必要です。

導入時に決めておくこと:

- 親組織の管理者を誰にするか（設定は取り消せない）
- inference hooks をつなぐ自社の DLP ツールと、検査で止める条件
- 退職・異動の手順に、サインアウトに加えて API キーと定期処理の停止を入れる
- ベータ機能は画面に未表示のことがあるため、設定ミスと切り分ける

**注意点**: 本記事は Anthropic の公式記事に基づく。利用できる地域・プランの詳細は Help Center で確認が必要。

## 副業・個人活用視点

**企業向けの導入支援で、チェックリストの型として使えます。** セキュリティセンターの項目は、Claude を導入する企業の設定レビューをそのまま構成できます。推奨とのずれの洗い出しと、意図した例外の記録を支援するサービスにしやすい題材です。

**個人利用のアカウントを会社で使う案件では、規程の整備が先です。** 管理対象 PC の個人アカウント禁止が可能になったため、顧客の PC で作業する場合は、どのアカウントで作業してよいかを事前に確認してください。

**情報源の制約**: 本記事は Anthropic の公式記事（2026-11-05）と Claude リリースノートに基づく。実際の管理画面での動作は確認していない。
