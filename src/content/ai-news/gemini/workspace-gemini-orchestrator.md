## 要約

Google は 2026-09-09、**Gemini が Google Workspace 全体を横断する「インテリジェント・オーケストレーター」として動く**ようになったと発表しました。Workspace Intelligence を基盤とし、**Google Chat、Drive、Docs、Slides、Gmail のいずれで作業していても、そこから他アプリにまたがるタスクを Gemini に依頼できます。**

**変わったのは、依頼できる場所ではなく、依頼できる範囲です。**これまでも各アプリには Gemini が入っていました。ただし、Docs の Gemini に頼めるのは Docs の中のことで、スライドを作らせたいなら Slides へ移る必要がありました。今回の変更で、**作業中のアプリを離れずに、別アプリの成果物を作らせられる**ようになりました。公式は「1つのタスクを終えるために集中を切らしてアプリを切り替える必要はない」という言い方をしています。

公式が挙げる用途は5つあります。**コンテンツ作成**では、どのアプリからでも書式付きの Docs / Sheets / Slides を生成し、Drive へ保存できます。**リサーチ**では、複数のフォルダやスレッドを横断してデータを統合し、**出典付きの要約レポート**にまとめます。**メール下書き**では、会議メモやドキュメントを元にメールを作成し、**そのまま送信することもできます。**Google Chat 上で **空き時間を探し、カレンダーの衝突を解消**することもできます。**タスク管理**では、ToDo やリマインダーを作成し、**Google Tasks へ反映**します。

**提供条件は広めです。**Business Standard / Plus、Enterprise Standard / Plus に加え、コンシューマー向けの Google AI Pro / Ultra、Frontline Plus（会議設定のみ）、Education アドオンが対象です。

**ロールアウトはすでに始まっています。**Rapid Release / Scheduled Release の両ドメインで **2026-09-02 に開始**し、最大15日の段階展開のため **2026-09-17 前後に完了見込み**です。つまり、発表の時点で組織によってはすでに使える状態になっています。**現時点では英語のみ**で、他言語対応は「近日」とされています。

## 何が変わったか

- **Chat / Drive / Docs / Slides / Gmail のどこからでも**、他アプリにまたがるタスクを Gemini に依頼できる
- 任意のアプリから**書式付きの Docs / Sheets / Slides を生成**し、Drive へ保存できる
- **フォルダ・スレッドを横断**してデータを統合し、**出典付き**の要約レポートを作れる
- 会議メモやドキュメントから**メールを下書きし、直接送信**できる
- Chat 上で**空き時間の探索とカレンダー衝突の解消**ができる
- **ToDo・リマインダーを Google Tasks へ反映**できる
- 対象: Business Standard / Plus、Enterprise Standard / Plus、Google AI Pro / Ultra、Frontline Plus（会議設定のみ）、Education アドオン
- 段階展開 **2026-09-02 開始 → 2026-09-17 前後完了見込み**。**英語のみ**

## 業務インパクト（一般企業向け）

**まず押さえるべきは、この機能が「作る」だけでなく「実行する」ことです。**

コンテンツ生成やリサーチは、成果物が出てくるだけで、人間が確認してから使います。失敗しても、破棄すればそれで終わりです。**メール送信とカレンダー変更は違います。**公式は「メールを作成し、そのまま送信もできる」「カレンダーの衝突を解消する」と明記しています。**送信されたメールは取り消せませんし、動かされた会議は相手に通知が飛びます。**同じ機能群の中に、確認して使うものと、外部に影響が出るものが混在しています。

**したがって、社内の案内は「何ができるか」ではなく「どこから先は自分で確認するか」を軸に書くべきです。**「Gemini がメールを書いてくれます」と伝えると、送信まで任せる人が必ず出ます。それ自体が悪いわけではありませんが、**宛先を間違えたメールが自動で出ていく**リスクは、生成物の品質とは別の問題です。実務的には、**下書きまでは任せ、送信は人が押す**という運用を最初の既定にして、慣れてから広げるのが妥当です。

**もう1つの論点は、横断リサーチのアクセス範囲です。**「複数のフォルダやスレッドを横断してデータを統合する」ということは、**その利用者がアクセスできる範囲の情報が、1つの要約に集約される**ということです。権限そのものが広がるわけではありません。ただし、**個別に見れば気づかない情報が、統合されると意味を持つ**ことはあります。人事情報の断片、進行中の案件のメモ、部門をまたぐやりとり。これらが1つのレポートに並ぶと、本人が意図せず把握してしまう構図が生まれます。**出典付きである点は救いで、どこから来た情報かは辿れます。**共有ドライブの権限設計を見直したことがない組織は、この機会に一度確認する価値があります。

**展開スケジュールは注意が必要です。**2026-09-02 に開始しており、**発表を読んだ時点ですでに使える組織がある**という状態です。「これから来る機能」ではありません。管理者が把握する前に現場が使い始めている可能性を前提に、**まず自組織で有効になっているかを確認する**ところから始めてください。完了見込みは 2026-09-17 前後です。

**英語のみという制約は、日本語環境では実質的な猶予になります。**現時点で日本語での利用は想定されていないため、日本国内中心の組織では影響が限定的です。ただし、**猶予は準備期間として使うべきもの**です。他言語対応の時期は明示されていませんが、Workspace の機能は英語先行・後追いで多言語化されるのが通例です。日本語対応が来てから運用を考え始めると、現場の利用が先行します。

## 副業・個人活用視点

**個人でも使えます。**対象に **Google AI Pro / Ultra（コンシューマー）**が含まれているため、Workspace の法人契約がなくても利用できます。

**効くのは、細切れの雑務が複数アプリに散っている人です。**副業やフリーランスの実務は、まさにこの形をしています。Gmail でクライアントとやりとりし、Drive に資料を置き、Docs で納品物を書き、Calendar で打ち合わせを入れる。**アプリを行き来する時間そのものは請求できません。**「Gmail のこのスレッドの内容で提案書のたたき台を Docs に作って Drive へ保存」といった依頼が1か所で完結するなら、その分は素直に手元に残ります。

**特に価値があるのは、出典付きの横断リサーチです。**過去案件の資料がフォルダに散らばっている状態は、フリーランスなら誰でも心当たりがあるはずです。「去年やった似た案件の見積もり根拠を集めて」という依頼に対し、**どのファイルから引いたかが付いてくる**なら、そのまま今回の見積もりの裏付けに使えます。出典が付かない要約は、結局元ファイルを探し直すことになるので、ここは実用性に直結する差です。

**一方で、送信まで任せるのは勧めません。**個人の場合、複数クライアントのメールが同じ受信箱にあります。**宛先の取り違えは、信用を一度で失う種類のミスです。**下書きまでで止めて、宛先だけは自分の目で確認する。この一手間は省かないでください。

**支援側として提案する場合、切り口は「アプリ切り替えのコスト」です。**中小企業の担当者は、AI を「文章を書くもの」として理解していることが多く、**アプリを跨ぐ実行**という発想がありません。「Chat から依頼して、Docs が Drive に保存されて、関係者に共有される」という一連の流れを実演すると、理解が一段変わります。そのうえで、**送信・カレンダー変更の扱いをどうするか**という運用ルールまでセットで提示できれば、単なる機能紹介ではない提案になります。**英語のみという現状も、正直に伝えた方が信頼されます。**今はまだ試す段階だと言い切ったうえで、日本語対応時に困らない準備を勧める。そういう順序で持っていく話です。
