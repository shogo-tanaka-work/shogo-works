## 要約

Google は 2026-10-13、**Gemini 4 Argon を有料 API・Gemini アプリ・Google Antigravity へ提供開始**しました。Argon は Gemini 4 ファミリーの第1弾で、公式は「Gemini 4 Argon is just the beginning」と書いています。後続モデルが続く前提の発表です。

**この発表の意味は、2026-09-30 の初回発表と並べて初めて分かります。**

9月30日、Google は Argon を「次世代のフロンティア知能」として発表しました。ただし**そのときの提供先は、Fairwind Program 経由の信頼済みサイバー防御者が中心**でした。一般への提供は「段階的に行う」「米国政府の自主的なプレリリースアクセス手続きと協働している」と書かれていただけで、**日付は示されていませんでした。** 当時の報道も「選ばれたサイバーセキュリティパートナーに渡した」「一般公開の時期は示されていない」という扱いでした。

**2週間で、その段階が終わりました。** 10月13日の発表で提供経路が確定しています。

- **開発者・企業**: AI Studio と Gemini platform 経由で、**有料 API からグローバルに利用可能**
- **Google AI Ultra 加入者**: Google Antigravity で利用可能
- **Google AI Ultra / Pro 加入者**: Gemini アプリと Search の AI Mode で利用可能
- **サイバー防御者**: Fairwind Program へ申請すれば、**cyber guardrails なしの版**を利用可能
- **研究者**: Antigravity 最上位枠の**6か月無償利用**へ申請可能（選考あり）

**料金には期限が付いています。** 導入価格は **入力 $2 / 100万トークン、出力 $10 / 100万トークン、キャッシュ入力は95%引き**。**2026-11-30 を過ぎると、一般公開モデルの標準価格（入力 $4、出力 $20）へ移行します。** つまり**入力も出力も2倍になります。**

ここが実務でいちばん効きます。モデルを評価するとき、精度の検証と**コストの試算は別の作業**です。精度が良くてもトークン単価が見合わなければ採用できません。**導入価格の期間中に取った試算は、11月30日以降そのままでは使えません。** 検証の段取りを組むときは、この日付を先に押さえる必要があります。

**公称性能。** Google は Argon を、コーディング・金融・法務・サイバーセキュリティ・科学といった**多段の複雑な作業**向けと位置づけています。

- **Vals Index**: finance / coding / legal / tax 横断で**1位**
- **ERQA（身体性推論）**: **87%**（比較した他のフロンティアモデルより高いと記載）
- **RareBench（希少疾患の診断支援）**: **57%**（Gamow Labs の私的評価）
- **LabBench（ウェットラボ推論）**: **52.2%**（同評価）
- **Gray Swan 間接プロンプトインジェクションベンチ**: 15回の適応的試行に対する**攻撃成功率 0.7%**
- **コーディングベンチでのエージェントの近道（shortcut）**: **2%**（Gemini 世代で最良と記載）

9月30日の初回発表では、**DeepSWE v1.1 で 77.9%**、**LVBench で 91.7%**、**CWE-bench v1 で 68%（同率1位）**も示されていました。

**Google 社内での実績**も挙がっています。Antigravity 上で**エージェントによるコード提出が35%以上増え、ロールバックが3分の1近く減った**。xTB の構造予測が最大2.3倍速くなり、A100 上の vLLM による Gemma 4 E2B 推論がエンドツーエンドで2.85倍速くなった。C/C++ から Rust への移行例として、**以前の Rust 移植より2.7倍速く動く動画デコーダ**が挙げられています。

**出力トークン上限は 64K から 1M へ**引き上げられました。これは9月30日の発表に明記されています。

## 何が変わったか

- **提供経路が限定から一般へ**: Fairwind 経由のサイバー防御者中心（09-30）→ 有料 API でグローバル、Gemini アプリ、Antigravity（10-13）
- **導入価格に期限**: 入力 $2 / 出力 $10（100万トークン、キャッシュ入力95%引き）。**2026-11-30 以降は入力 $4 / 出力 $20**
- **出力上限 64K → 1M トークン**
- **Gemini アプリ側（Google AI Pro / Ultra 加入者）**:
  - **Antigravity のエージェント型コーディング UI が Gemini macOS アプリへ**入った
  - **チャット → タスクのトグル**。離席中も Gemini が作業を続ける
  - **40以上のアプリ連携**（Instacart、OpenTable、Adobe、Shopify を含む）
  - 回答がより直接的になり、繰り返しが減り、長い作業では進捗の報告が増えた
- **応答スタイル**: 公式は「これまでのどの Gemini モデルよりもスタイル指示に従う」「ぼかさずに直接答える」と記載
- **サイバー防御者向けに guardrails なしの版**（Fairwind Program、申請制）
- **科学者向けに Antigravity 最上位枠の6か月無償利用**（申請・選考制）

## 業務インパクト（一般企業向け）

**1. 検証の締め切りが価格で決まる**

**2026-11-30 がコスト試算の実質的な期限**です。導入価格の期間中に PoC を回してトークン単価を出すなら、そのまま本番の見積もりに使えません。**標準価格（入力 $4 / 出力 $20）で計算し直した数字を併記しておく**のが安全です。「安いうちに試した」結果だけを持って決裁へ上げると、稟議の途中で前提が変わります。

**2. 「限定公開のモデル」を待つ判断の目安が1つ増えた**

今回は**限定公開から一般提供まで2週間**でした。フロンティアモデルの限定公開を見て「うちは対象外だから関係ない」と判断していた組織にとって、**その期間は思ったより短い**という実例です。逆に言えば、限定公開の時点で評価の準備を始めておく価値があります。

**3. Gemini アプリ側は「情シスが把握していない経路」で入ってくる**

Gemini アプリの変更は **Google AI Pro / Ultra 加入者**が対象です。**個人契約の AI Pro を業務で使っている社員**がいる場合、会社の Workspace 管理コンソールからは見えません。**40以上のアプリ連携**と**離席中もタスクを続けるトグル**が入ったことは、業務データが通る経路が増えたことを意味します。社内規程で「どのプランの Gemini を業務で使ってよいか」を決めていない組織は、ここで一度決める必要があります。

**4. macOS アプリにエージェント型コーディング UI が入った**

Antigravity の UI が Gemini macOS アプリへ入りました。**開発環境の管理を情シスが握っている組織では、エージェントがコードを書いて実行する経路が1つ増えた**ことになります。許可するかどうかは、既存の開発ツール管理の延長で決める話です。

**5. ベンチマーク値の読み方**

RareBench と LabBench は **Gamow Labs の私的評価（private evals）**です。公開ベンチマークではないため、**第三者が同じ条件で再現することができません。** Vals Index の1位も、対象領域（finance / coding / legal / tax）が限定されています。**社内の稟議資料へ転記するなら、数字だけでなく出典の性質も一緒に書いてください。** 「業界1位」とだけ書くと、後で根拠を聞かれたときに答えられません。

## 副業・個人活用視点

**1. 導入価格の期間は、API を使った試作のコストが半分**

入力 $2 / 出力 $10 は、**11月30日までの期間限定**です。API を叩く試作を考えているなら、この期間に回すとコストが半分で済みます。キャッシュ入力が95%引きなので、**同じ長いコンテキストを繰り返し使う構成**（社内文書を前提にした QA、長い仕様書に対する連続質問）では差がさらに大きくなります。

**2. Google AI Ultra の価値が変わった**

Argon の Antigravity 利用と、AI Studio での試用は **Google AI Ultra 加入者**が対象です。**Ultra の契約で何が使えるかの中身が入れ替わった**ことになります。すでに Ultra を契約している人は、Antigravity を触る理由が増えました。Pro 加入者は Gemini アプリと Search AI Mode が対象です。

**3. 「限定公開から一般提供までの2週間」は書ける題材**

限定公開（09-30）と一般提供（10-13）の間に何が変わったかを並べた記事は、**一次情報を2つ読んだだけで書けます。** 提供経路・料金・出力上限の3点だけで十分に成立します。発表のたびに「すごい」と書く記事は量産されますが、**2つの発表の差分を取る記事は数が少ない**ので、検索でも生成 AI の引用でも残りやすい形です。

**4. 研究者向けの6か月無償枠**

科学分野の研究をしている人は、**Antigravity 最上位枠の6か月無償利用**へ申請できます（適格性と選考あり）。個人で研究をしている立場なら、申請コストに対して得られるものが大きい枠です。

**5. モデル ID が公式に見えない状態で何を書くか**

この記事自体が例になっています。**モデル ID とコンテキストウィンドウは確認できなかったので、書いていません。** 二次情報には値が出回っていますが、互換性のない数字が並んでいました。**「到達できなかったものを推測で埋めない」**という書き方は、読者が実装でつまずいたときに「この記事は信用できる」と判断される材料になります。急いで書いた記事と差がつくのは、この部分です。
