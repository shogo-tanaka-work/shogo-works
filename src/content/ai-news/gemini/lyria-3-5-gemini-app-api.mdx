## 要約

Google は 2026-09-04、音楽生成モデル **Lyria 3.5** を公開し、**Gemini アプリと Gemini API** で使えるようにしました。公式は「最も良い音の音楽生成モデル」と位置づけ、**より表現力のあるボーカルと、厚みのある編曲**によって忠実度の高いトラックを作れるとしています。

Gemini アプリ側で新しくなったのは3点です。**ジャンルを選ぶか自然文で指定**でき、ボーカルありとインストゥルメンタルを切り替えられること。**テンプレート**が追加され、バックグラウンド音楽から誕生日向けのカスタム曲まで、白紙から始めずに着手できること。そして**短尺・長尺の尺を選べる**ことです。

提供範囲が広い点も押さえておく価値があります。**Web とモバイルアプリで、全世界の全ユーザーに提供**されます。加えて、アーティストや AI クリエイター向けには **Google Flow Music**、開発者・技術者向けには **Google AI Studio**（Gemini API 経由）、そして Workspace の **Google Vids** の中からも使えます。公式が挙げている用途は、動画のバッキングトラック、ブランド用のジングル、着信音のパーソナライズです。

実務目線でいちばん効くのは、この最後の **Google Vids からも使える**という一行です。Workspace 側ではここ数か月、ドキュメントや PDF からの動画生成、AI アバターといった機能が積み上がってきました。そこに音楽生成が入ることで、**社内向け動画や研修コンテンツの素材調達が Workspace の中で完結する**構図になります。

## 何が変わったか

- **Lyria 3.5** が Gemini アプリと Gemini API で利用可能になった
- 従来より**表現力のあるボーカル**と**厚みのある編曲**が生成できるようになった
- Gemini アプリで**ジャンルの選択または自然文での指定**、**ボーカル／インストゥルメンタルの切り替え**ができる
- **テンプレート**が追加された（BGM、誕生日向けのカスタム曲など）
- **短尺・長尺の尺を選べる**ようになった
- 提供範囲: **Web / モバイルアプリで全世界の全ユーザー**
- 併せて利用できる面: **Google Flow Music**（アーティスト・AI クリエイター向け）、**Google AI Studio**（開発者向け、Gemini API）、**Google Vids**（Workspace）

## 業務インパクト（一般企業向け）

**社内コンテンツ制作の「音まわり」が、外部調達から内製へ寄ります。**

企業が動画を作るとき、映像や台本は内製できても、BGM だけは素材サイトの有料ライセンスを買うか制作会社に投げるか、という構図が残りがちでした。研修動画、製品紹介、社内報、展示会用のループ映像——いずれも尺と雰囲気が細かく決まっているのに、既存素材から探すと「近いが合わない」ものを妥協して使うことになります。**Google Vids の中から尺とジャンルを指定して生成できる**なら、この妥協が減ります。テンプレートと尺選択が入ったことで、狙った長さに合わせやすくなった点も実務的です。

**Gemini API / Google AI Studio 経由で使える**ことは、別の意味を持ちます。自社サービスに音楽生成を組み込む選択肢が現実的になるということです。動画編集ツール、eラーニング基盤、イベント向けアプリなど、「ユーザーが作ったコンテンツに音を付ける」機能を持つプロダクトでは、外部の音楽 API を別途契約せずに Gemini の枠内で完結できる可能性があります。既に Gemini API を使っている組織なら、**契約とコスト管理の窓口が増えない**のは地味に効きます。

**一方で、権利と商用利用の確認は自社で行う必要があります。**公式アナウンスは機能と提供範囲を説明したもので、生成物の商用利用条件、権利の帰属、透かしの扱いといった論点までは踏み込んでいません。ブランド用ジングルや公開する製品動画に使うなら、**Gemini および Workspace の利用規約側を必ず確認してから運用に乗せる**べきです。素材ライブラリの契約を即解約してよい、という話にはなりません。当面は「社内限定の用途から試す」「公開物は権利関係を確認済みのものだけに使う」という二段構えが現実的です。

**全ユーザー・全世界提供である点は、統制側の論点でもあります。**Gemini アプリを配布している組織では、従業員が今日から音楽生成を使える状態になります。生成物の業務利用に関する社内ルールが未整備なら、動画制作の実務が走り出す前に方針を決めておくのが安全です。

## 副業・個人活用視点

**個人の制作コストに、そのまま効きます。**

副業で動画編集、SNS 運用、教材制作をしている場合、BGM は毎回発生する固定費でした。月額の素材サイトを契約するか、使うたびに単品購入するか。**Web とモバイルの全ユーザーに全世界提供**なので、まずは自分の Gemini から試せます。ジャンルを自然文で指定できるようになったのは、「素材サイトのタグを手掛かりに探す」という作業がなくなるということで、探す時間そのものが削れます。

とくに効くのは**尺の選択**です。既成素材を使うときの最大の手間は、映像の長さに合わせて音をループさせたりフェードで切ったりする編集作業でした。最初から必要な長さで生成できるなら、この工程が丸ごと減ります。ショート動画のように尺が固定されている形式ほど恩恵が大きいはずです。

**受託案件では、権利まわりを先に整理しておくのを勧めます。**クライアントに納品する制作物へ生成音源を使う場合、「AI 生成である」ことと利用条件をどう説明するかは、後から揉めやすい部分です。**見積もりや仕様書の段階で、BGM を生成で用意するのか既存ライセンスを買うのかを明示しておく**と安全です。逆に、そこを整理できていれば「BGM 込みで内製」は単価を維持したまま原価を下げられる材料になります。

開発寄りの副業なら、**Google AI Studio 経由で API を触っておく**価値があります。個人開発のアプリに音楽生成を載せる構成は、これまで専用サービスの契約が前提でしたが、Gemini API の枠内で試作できるなら着手のハードルが下がります。作るものの候補としては、動画の自動 BGM 付け、ポッドキャストのジングル生成、イベント用の即席テーマ曲あたりが手をつけやすい領域です。
