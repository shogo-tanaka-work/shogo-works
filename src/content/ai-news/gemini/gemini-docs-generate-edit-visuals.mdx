## 要約

Google Docs の Gemini から、ドキュメント内で直接ビジュアルを生成・編集できるようになりました。対象は画像だけでなく、図表やインフォグラフィックも含まれます。Workspace Updates Blog の個別ポストで発表されました。

操作は自然言語のプロンプトで行い、複数のビジュアルをまとめて作成できます。生成後はアスペクト比の変更などの編集も同じ画面内で完結するため、これまでのように別の画像生成ツールで作ってダウンロードし、Docs に貼り直すという往復が不要になります。

ロールアウトは 2026-07-28 開始で、Rapid Release と Scheduled Release の両ドメインが対象です。段階的展開のため、機能が見えるようになるまで最大15日かかります。対象エディションは Business Standard / Plus、Enterprise Standard / Plus、Education Plus、個人向けの Google AI Pro / Ultra、そして Google AI Pro for Education です。

利用にあたっては二段構えの前提があります。管理者側は「Gemini for Workspace in Drive」が有効になっている必要があり（デフォルトで有効ですが、アクセス管理は可能です）、エンドユーザー側は「Workspace smart features」を有効にしておく必要があります。

## 何が変わったか

- Google Docs 内で Gemini による画像・図表・インフォグラフィックの生成が可能に
- 自然言語プロンプトで複数のビジュアルを一括生成できる
- 生成したビジュアルのアスペクト比変更などの編集も Docs 内で完結
- ロールアウト: 2026-07-28 から Rapid Release / Scheduled Release 両ドメイン向けに段階的展開（最大15日）
- 対象エディション: Business Standard/Plus、Enterprise Standard/Plus、Education Plus、Google AI Pro/Ultra、Google AI Pro for Education
- 管理者側は「Gemini for Workspace in Drive」の有効化が前提（デフォルト有効・アクセス管理可）
- エンドユーザー側は「Workspace smart features」の有効化が必要

## 業務インパクト（一般企業向け）

社内資料や提案書の作成において、これまで図解が必要になるたびに別ツールを開いていた工程が Docs 内に閉じます。特に「文章は書けているが図がないので伝わりにくい」タイプのドキュメント（業務マニュアル、社内提案、報告書）で効きます。インフォグラフィックまで対象に入っているため、数値の説明を視覚化する用途も想定されています。

導入担当者が押さえておくべきは、管理者設定とユーザー設定の二段構えです。管理者側の「Gemini for Workspace in Drive」はデフォルト有効ですが、過去にアクセス管理の観点で無効化している組織では機能が出てきません。さらにユーザー側の「Workspace smart features」も有効になっている必要があり、こちらは組織のポリシーやユーザー個人の設定で切られていることがあります。ロールアウトが最大15日かかることと合わさって、「使えるはずなのに見当たらない」という問い合わせが起きやすい構成です。展開前に社内向けの案内へ両方の前提を書いておくとスムーズです。

生成物の取り扱いについては、社外提出資料に AI 生成のビジュアルを含める際のルールを持っている組織であれば、その適用範囲に Docs 内生成が入るかを確認しておくとよいでしょう。

## 副業・個人活用視点

個人向けの Google AI Pro / Ultra も対象に含まれているため、フリーランスや副業でクライアント向け資料を作る人がそのまま使えます。提案書やレポートに図解を入れる作業は、これまで画像生成ツール・作図ツール・Docs の3つを行き来する必要がありましたが、Docs だけで完結できるようになります。

特に効果が出やすいのは、単価は高くないが本数が多い制作案件です。1本あたりの図解作成時間が短縮されれば、そのまま処理できる本数に跳ね返ります。アスペクト比の調整が Docs 内でできる点も、レイアウトに合わせた微修正を外部ツールに戻らず済ませられるという意味で地味に効きます。

なお段階的ロールアウトのため、契約プランが対象でも即日使えるとは限りません。手元に出てこない場合は最大15日待つ、というのが正しい対応です。
