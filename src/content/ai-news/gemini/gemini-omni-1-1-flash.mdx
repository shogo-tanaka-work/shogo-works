## 要約

2026-08-27、Google が動画生成モデル **Gemini Omni 1.1 Flash**（モデル ID `gemini-omni-1.1-flash`）を公開しました。Google I/O で初出したモデルの更新版です。

**追加された機能は、ほぼすべてが制御系です。** 新しい映像表現ができるようになったわけではありません。**狙ったものを出すための手段**が増えました。この方向性自体が、動画生成というジャンルの現在地を示しています。

**シーン延長（Scene Extension）が実用域に入りました。** 従来は延長するときに**直前の1秒しか参照できませんでした**。1秒で判断すると、少し前に映っていた要素は考慮されません。今回、**最大10秒ぶんの文脈を解析する**ようになりました。10秒単位で継ぎ足していき、**合計40秒**まで伸ばせます。視覚的な一貫性と物語の連続性が保たれる、というのが公式の説明です。

**始点／終点フレームの指定**も入りました。開始フレームと終了フレームを与えると、その間の動画が生成されます。使いどころは3つ挙げられています——**トランジション、複雑なカメラワーク、シームレスなループ**。とくにループは、始点と終点を同じフレームにすればいいので、これまで運任せだったものが確実に作れるようになります。

**360p のドラフトモード**が、実務的には最も効く追加かもしれません。標準の 720p と比べて**最大60%高速、コストは3分の1**でプレビューを生成できます。仕上げは **1080p または 4K へアップスケール**。つまり **「安く早く試して、選んでから仕上げる」ワークフローがモデル側でサポートされた**ということです。

**動画リファレンス**も追加されました。最大3秒の動画を入力として与えると、視覚的な文脈とキャラクターの一貫性が保たれます。同じ人物・同じ世界観のカットを複数作るときに効きます。

提供面は4系統です。**Google AI Studio** から直接、**Gemini Enterprise Agent Platform** の Agent Platform API 経由、**Google Flow**（AI Plus / Pro / Ultra 加入者）、そして **Gemini アプリ**（シーン延長が Plus / Pro / Ultra 加入者向けに全世界で利用可能）。価格表は公式ページに掲載されています。

同日、Google Labs の **Google Flow** 側でも同じ機能群（始点終点フレーム、1080p / 4K 書き出し、解像度の段階ワークフロー）が公開されました。**モデルの更新と、それが製品 UI に降りた発表が同日に別記事で出ている**構造です。API を触るなら前者、業務で使うなら後者を読む、という分け方になります。

## 何が変わったか

- **シーン延長の文脈参照が1秒 → 最大10秒**へ。10秒単位で継ぎ足し、**合計40秒**まで延長可能
- **始点／終点フレームの指定**に対応。中間を生成してトランジション・複雑なカメラワーク・シームレスなループを作れる
- **360p ドラフトモード**を追加。720p 比で**最大60%高速・コスト3分の1**
- **4K アップスケール**に対応。1080p / 4K の仕上げ出力
- **動画リファレンス**（最大3秒の動画入力）でキャラクターと視覚的文脈の一貫性を維持
- モデル ID は `gemini-omni-1.1-flash`
- 提供: **Google AI Studio**、**Gemini Enterprise Agent Platform**（Agent Platform API）、**Google Flow**（AI Plus / Pro / Ultra）、**Gemini アプリ**（シーン延長は Plus / Pro / Ultra、全世界）
- 同日、**Google Flow** 側でも始点終点フレーム・1080p / 4K 書き出し・解像度の段階ワークフローが利用可能に

## 業務インパクト（一般企業向け）

**動画生成の業務利用でこれまで採算が合わなかった理由は、品質ではなく試行回数でした。** ここを押さえると、今回の更新の意味が正確に読めます。

1本の動画を作るのに何回生成するか。**イメージ通りのものが出るまで20回、30回と回すのが普通です。** そのすべてが標準解像度で課金されていたら、費用は使い物になりません。**360p のドラフトモードは、この構造に直接効きます。** 試行段階のコストが3分の1で速度が最大60%速いなら、**同じ予算で3倍試せる**。動画生成の実務コストは「1本あたりの単価」ではなく「採用に至るまでの総試行コスト」で決まるので、**ここが下がることの効果は単価が下がるより大きい**です。

**そして、試行回数を減らす側の機能も同時に入っています。** 始点終点フレームの指定と動画リファレンスは、**ガチャを回す回数を減らす**機能です。「何回か回せば良いのが出る」から「指定したものが出る」へ寄せる。安く試せることと、試行回数自体が減ること。**この2つが同時に来たのが今回の更新の実質です。**

**社内での用途としては、まず「短くて反復が多いもの」が現実的です。** 商品紹介、社内研修の導入映像、SNS 向けの短尺、展示会のループ映像。**シームレスなループが確実に作れるようになった**のは、展示・店頭・デジタルサイネージの用途に直接効きます。従来は「ループの継ぎ目が目立つ」ことが実用化の壁でした。

**40秒という上限は、正確に把握しておいてください。** 10秒単位で継ぎ足して合計40秒。**これは「4カット構成の短編は作れるが、1分を超える映像は生成だけでは完結しない」**ということです。実務では編集ツールで繋ぐことになります。**動画生成を「完成品を作る道具」ではなく「素材を作る道具」と位置づける**方が、期待値のずれが起きません。

**発注・制作フローの観点では、レビューの回し方が変わります。** これまで動画制作は「絵コンテで合意 → 撮影・制作 → 修正は高コスト」という構造でした。360p のドラフトを大量に出せるなら、**合意形成の段階で動く映像を見せられます。** 絵コンテで想像してもらうより速く、確実です。**動画制作の工程で最も揉めるのは「イメージと違う」という段階で、そこを前倒しできる**のは実務的に大きい。

**Gemini Enterprise Agent Platform 経由で使えるという点も企業には重要です。** 個人の AI Studio アカウントで試したものを、そのまま組織のガバナンス下で動かせる。**PoC から本番へ移すときにモデルを変えなくてよい**というのは、意思決定のコストを下げます。

## 副業・個人活用視点

**動画制作を請けているなら、提案段階の武器が増えます。** クライアントに「こんな感じです」と口頭やラフで説明するのと、**360p でも実際に動く映像を3案出す**のとでは、通る確率が違います。しかもドラフトのコストは 720p の3分の1です。**提案に映像を付けるコストが、現実的な水準まで下がりました。**

**受注前の提案に工数をかけすぎない**という原則はありますが、それは「かけた工数が無駄になるかもしれない」という前提の話です。**提案コストが3分の1になれば、その計算式自体が変わります。**

**SNS 発信をしている人には、ループ映像が確実に作れる点が効きます。** Instagram、TikTok、X。短尺のループ映像は、静止画より滞在時間を稼ぎます。これまでループの継ぎ目を消すのは手作業でしたが、**始点と終点に同じフレームを指定すれば済む**ようになりました。手作業の工程が1つ消えるということです。

**キャラクター一貫性の維持（動画リファレンス）は、シリーズ物の副業に直結します。** 同じキャラクターで複数本を作る——解説動画、ショート連載、ブランドのマスコット。**毎回違う顔になる**というのが、これまで最大の障害でした。最大3秒のリファレンス動画で一貫性が保てるなら、**シリーズとして成立する**。単発の映像より、シリーズの方が単価も継続性も上です。

**副業の商材として提案するなら、「動画を作ります」より「試作を大量に出して選ぶ工程を回します」の方が値段が付きます。** 動画生成そのものはツールを触れば誰でもできます。**価値があるのは、どの試作を採用するかを判断する目と、40秒の制約の中で構成を組む設計です。** モデルが安く速くなるほど、生成そのものの希少性は下がり、判断と構成の希少性が上がる。**この構造は動画に限りません**が、今回のようにコストが一気に下がったジャンルでは変化が速く出ます。

**支援先へ提案するなら、「制作費」ではなく「試行の設計」を売る形に組み替えるのが現実的です。** クライアント側も動画生成ツールを触り始めています。そこで「作ります」と言い続けると、いずれ内製化されます。**「何を作るべきか」「どこで見切りをつけるか」という判断の部分に軸足を移す**方が、長く続きます。
