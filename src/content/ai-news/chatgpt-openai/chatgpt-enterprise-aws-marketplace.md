## 要約

OpenAI が2026年11月9日、**ChatGPT Enterprise を AWS Marketplace で提供開始**したと発表しました。

AWS の既存の購買・請求の仕組みで ChatGPT Enterprise を見つけ、購入し、管理できます。**対象となる支出を AWS のコミットメントに充当できる**点が中心です。モデル・機能・機能性は OpenAI から直接買う場合と同じで、新機能の提供も同じタイミングとされています。

ChatGPT Enterprise は、ChatGPT、ChatGPT Work、Codex、dots を含む構成として説明されています。**ChatGPT for Healthcare と ChatGPT for Financial Services も、条件を満たせば AWS Marketplace 経由で利用できます。**

OpenAI は、これを **Amazon Bedrock 上の OpenAI モデルと補完関係**にあるものとして説明しています。開発者が Bedrock の OpenAI モデルでアプリやエージェントを作り、事業部門が ChatGPT Enterprise を日常業務で使う、という使い分けです。

## 何が変わったか

- **ChatGPT Enterprise が AWS Marketplace に出品**
- 既存の AWS 購買・請求関係で購入・管理できる
- **対象支出を AWS のコミットメントに充当可能**
- モデル・機能は OpenAI 直販と同一、新機能も同時提供
- ChatGPT for Healthcare / Financial Services も対象
- 導入には、OpenAI または AWS のアカウントチームへの確認が必要

## 業務インパクト（一般企業向け）

**変わるのは機能ではなく調達です。** AWS と大きな年間コミットメントを結んでいる企業は、未消化分を ChatGPT Enterprise に充てられる可能性があります。新規ベンダーの契約審査・購買登録を省ける場合があり、**導入までの社内手続きが短くなる**のが実利です。

**ただし、すべての契約が対象になるわけではありません。** 公式も「対象かどうかはアカウントチームに確認する」としています。コミットメントの充当率や条件は契約ごとに異なるため、経理・調達部門が先に確認する項目になります。

**ガバナンス上の選択肢が増えます。** 開発部門は Bedrock、事業部門は ChatGPT Enterprise という構成を、同じ AWS の請求窓口にまとめられます。一方、利用データの扱いや管理者設定は ChatGPT Enterprise のものなので、**請求が AWS に寄っても、監査やデータ管理の責任範囲は OpenAI の製品仕様に従う**点は変わりません。

## 副業・個人活用視点

個人事業主が直接使う話ではありません。ただし、**法人顧客への提案では背景知識として役立ちます**。AWS を主要クラウドにしている顧客には、「ChatGPT Enterprise も AWS の枠で買える」ことが導入の後押しになります。

AI 導入の相談を受ける場合は、機能比較の前に**顧客の調達経路（AWS Marketplace が使えるか）を最初に聞く**と、話が早くなります。導入できる製品の候補が、技術要件より契約条件で絞られる場面が増えているためです。
