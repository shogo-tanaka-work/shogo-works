## 要約

2026-08-28、OpenAI が「Our decision on Cursor following its acquisition by SpaceX」を公開しました。**Cursor へ OpenAI モデルを提供している契約を巻き取る（wind down）意向を SpaceX へ通知した**という内容です。

**提案しているシャットオフ日は 2026-11-12。** 発表から約2ヶ月半あります。OpenAI はこれを「契約上取れる最大の予告期間」と説明しています。開発者が Cursor 経由で OpenAI モデルを使える期間を最大化するための判断だ、と。

経緯を整理すると、2026-08-14 に **Cursor（Anysphere）の SpaceX による買収が発効**しました。600億ドル相当の全株式取引で、Cursor は SpaceX の完全子会社になっています。今回はそれに対する OpenAI 側の回答です。

**理由として OpenAI が挙げているのは、技術的な問題でも商業的な問題でもなく、契約遵守への信頼です。** 公式文はこう書いています——SpaceX が OpenAI の利用規約の範囲内で技術を使うと確信できない、Musk 氏の会社が契約に違反してきた経験に基づく判断である、と。

根拠として2件が具体的に挙げられています。**1件目は、Musk 氏による Twitter 買収後、同社が OpenAI との契約条件に違反したこと**（OpenAI は Twitter を現在 SpaceX の一部と記述しています）。**2件目は、2026年に入ってから Musk 氏が宣誓のうえで、xAI が OpenAI の利用規約に違反したと認めたこと**です。xAI も現在は SpaceX の一部だと OpenAI は書いています。

**契約構造の説明も入っています。** OpenAI は SpaceX のような大手パートナーとは個別契約（custom contract）を結び、利用規約の遵守と大規模運用時の安全性を担保する形を取ります。Cursor との個別契約には、**支配権の変更（change of control）後、限られた期間内に解約できる条項**が入っていました。今回はその条項を行使した形です。

**もう1つの理由として、次期モデル Astra が挙がっています。** AI の能力が上がるにつれ、モデルが規約に沿って使われることを担保する責任のレベルも上がる、というのが OpenAI の主張です。結果として、**解約日は可能な限り遅くに設定しつつ、今後の新モデルは Cursor へ提供しない**という組み合わせになりました。既存モデルは 11-12 まで、新モデルはもう来ない、ということです。

文末では、Cursor と約4年協業してきたこと、チームと製品への敬意、そして**最も影響を受けるのは Cursor で OpenAI モデルを使ってきた開発者である**ことが明記され、移行支援に踏み込む意向が示されています。

なお、影響規模については Cursor CEO の Michael Truell 氏が**OpenAI モデルは Cursor のユーザートラフィックの約5%**と発言したと報じられています（この数値は公式発表ではなく報道ベースです）。

## 何が変わったか

- OpenAI が **Cursor へのモデル提供契約の巻き取り（wind down）** を SpaceX へ通知した（2026-08-28）
- **提案シャットオフ日は 2026-11-12**。契約上取れる最大の予告期間を使用
- **今後の新モデル（次期モデル Astra を含む）は Cursor へ提供されない**
- 判断理由は「SpaceX が利用規約の範囲内で技術を使うと確信できないこと」。根拠として Twitter 買収後の契約違反と、Musk 氏が宣誓下で認めた xAI の規約違反を挙げている
- 契約解除の法的根拠は、個別契約に含まれる**支配権変更後の解約条項**
- OpenAI は影響を受ける開発者の移行支援に踏み込む意向を表明
- Cursor 側の対応（代替モデルの提示、料金、既存 Enterprise 契約の扱い）は本発表の範囲外

## 業務インパクト（一般企業向け）

**まず確認すべきは、社内で Cursor を使っているチームが、どのモデルを既定にしているかです。** Cursor は複数のモデルプロバイダを選べるツールなので、**OpenAI モデルを使っているかどうかはチームごと・開発者ごとに違う**可能性が高い。「Cursor を導入している」だけでは影響の有無が判断できません。棚卸しの単位は、ツールではなくモデル設定です。

**期限が確定している点は、実務としてはむしろ扱いやすい要素です。** 2026-11-12 という日付が出ています。日付が決まっていれば、逆算して移行計画を立てられる。曖昧に「そのうち使えなくなるかもしれない」より、はるかに管理しやすい状況です。今日から数えて約2ヶ月半あります。

移行の選択肢は3つに整理できます。**1つめ、Cursor に残って別プロバイダのモデルへ切り替える。** Cursor は SpaceXAI 傘下なので Grok 系への誘導が想定されますが、Anthropic モデルなど他の選択肢も継続するかは Cursor 側の発表待ちです。**2つめ、OpenAI モデルを使い続けるために別のツールへ移る。** Codex CLI や、OpenAI モデルを扱える他の IDE 統合が候補になります。**3つめ、この機会にツール構成そのものを見直す。** 2ヶ月半あれば、評価と移行の両方が入る時間です。

**「まだ提案日であって確定ではない」という点は、正確に押さえておく価値があります。** 公式文は "proposed shutoff date" と書いています。SpaceX 側の対応次第で日付が動く可能性はゼロではない。ただし**動くとしても早まる方向を織り込むべき**で、遅れる前提で計画を組むのは危険です。新モデルの提供停止は即時なので、そちらは既に発効していると考えるのが妥当です。

**この件が示している構造的な論点は、ツール選定がベンダーの資本関係に左右されうるということです。** Cursor 自体の製品品質は何も変わっていません。開発チームも製品も同じ。変わったのは所有者だけです。それだけで、上流のモデルプロバイダとの契約が切れた。**調達・情シスの観点では、「このツールは誰が所有していて、その所有者は上流の誰と契約しているか」まで見ないと、供給の継続性が読めない**ということになります。

実務的には、**AI 開発ツールの選定基準に「モデル供給の依存構造」を項目として追加する**のが妥当な対応です。具体的には、そのツールが自前モデルを持つのか、外部から調達しているのか、調達している場合は複数プロバイダを扱えるのか。**単一プロバイダに依存しているツールは、上流の契約1本で使えなくなる**という前例が実際にできました。

**法務・調達に共有すべき論点もあります。** 既存の Cursor 契約に「特定モデルの利用可能性」が前提として書かれている場合、その前提が崩れます。契約書に SLA としてモデル可用性が入っていることは稀ですが、稟議書や導入時の説明資料には「GPT 系モデルが使える」と書かれている可能性がある。**社内向けの説明を訂正しておかないと、11月に問い合わせが集中します。**

## 副業・個人活用視点

**個人で Cursor を使っている場合、やるべきことはシンプルです。設定を開いて、既定モデルを確認してください。** OpenAI モデルを選んでいないなら、今回の件で困ることはありません。選んでいるなら、11-12 までに切り替え先を決めることになります。

**移行コストは、思っているより「慣れ」の部分が大きいはずです。** モデルを変えると、同じプロンプトでも返ってくる書き方が変わります。補完の癖も変わる。**技術的な移行より、手が覚えている使い方の作り直しに時間がかかります。** 期限直前に切り替えるより、今のうちに別モデルを日常的に混ぜて使い、感触を掴んでおく方が結果的に速く済みます。2ヶ月半あるのは、そのための時間として使えます。

**クライアントワークをしている人は、この件を報告材料として使えます。** 「使っているツールの上流契約が切れるので、11月までに移行します」という報告は、**継続的にリスクを見ている証拠**になります。何も起きていないときに「ベンダーリスクを見ています」と言うより、具体的な事案に紐づけて説明する方が伝わります。

**支援先へ提案する立場なら、これは「AI ツールの棚卸し」を持ち込む具体的な入口です。** 多くの企業は AI 開発ツールを部署ごと・個人ごとにバラバラに導入していて、**誰がどのツールで、どのモデルを使っているかを把握していません。** 今回のように上流の契約が切れると、把握していない組織は「誰が影響を受けるか分からない」ところから始めることになります。棚卸しの必要性を抽象論で説くより、期限が切られた実例を示す方が動きます。

**個人の学習投資という観点では、特定ツールへの習熟に全振りしない、という教訓の実例です。** Cursor の使い方を極めても、モデル供給が切れれば体験は変わります。**移植できるのは、ツール固有の操作ではなく、AI コーディングの進め方そのもの**です。プロンプトの組み立て方、レビューの仕方、どこを AI に任せてどこを自分で見るかの判断——これらはツールをまたいで持ち運べます。ツールが変わるたびにゼロからになる人と、そうでない人の差は、この層をどれだけ言語化できているかで決まります。

**なお、Cursor 側からの発表はまだ出ていません。** 代替モデルの案内、料金への影響、既存の年間契約や Enterprise 契約の扱いは、Cursor 側の発表を待つ必要があります。**現時点で分かっているのは OpenAI 側の一方の意思表示だけ**で、移行先の具体案は Cursor の対応が出てから固める形になります。
