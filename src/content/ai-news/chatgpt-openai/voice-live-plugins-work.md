## 要約

OpenAI は 2026-09-23、ChatGPT Release Notes で音声体験の2点の拡張を告知しました。

1つ目は、**Live がプラグインに対応した**ことです。Live は GPT-Live-1 / GPT-Live-1 mini で動く、聞きながら同時に話せる音声モードで、これまでは Web 検索とメモリ、視覚ウィジェットの範囲で完結していました。今回の更新で、**音声会話の途中でアカウントに接続済みのプラグイン・コネクタを呼び出せる**ようになりました。メール、カレンダー、Slack といった業務アプリが対象です。web / iOS / Android の3面で提供され、応答はチャット側にテキストとしても残ります。Free / Go でも、各プランがサポートするプラグインの範囲で Chat 内の Voice から利用できます。

2つ目は、**Voice が ChatGPT Work（web / モバイル）で使えるようになった**ことです。ChatGPT Work は、複数ステップの長い仕事を進めるためのモードで、リサーチと分析を回してドキュメント・スプレッドシート・プレゼン・レポート・Site を作ります。今回、これを**音声で起動できる**ようになりました。話しかけるだけで資料の作成、接続アプリの参照、ブラウザ操作を指示でき、**音声通話を終了しても実行中のタスクはテキスト側で継続**します。

デスクトップアプリでは 2026-07-23 の時点で Voice in Work / Codex が使えていましたが、今回それが web とモバイルへ広がった形です。音声が「質問して答えをもらう道具」から「仕事を始める入口」へ位置づけを変えた、と読めます。

**この記事の情報源には制約があります。** 当環境から `help.openai.com` と `openai.com` は 403 を返し、キャッシュ経由で取得できた Release Notes 本文は 2026-09-10 版で止まっていました。上記の内容は、公式 Release Notes の 2026-09-23 項を引用した複数の報道を突き合わせて再構成したものです。プラン別の上限や対象範囲は、必ず公式ヘルプで確認してください。

## 何が変わったか

- **Live がプラグイン対応**（web / iOS / Android）。音声会話中に接続済みアプリ・コネクタを呼び出せる
- Free / Go でも、プランがサポートするプラグインの範囲で Chat 内の Voice から使える
- 既存のアプリ接続・権限・ワークスペース制限がそのまま適用される
- **Voice が ChatGPT Work で利用可能に**（web / モバイル）。ドキュメント・プレゼン・スプレッドシートの作成、接続アプリ参照、ブラウザ操作を音声で指示できる
- 通話終了後も、開始済みの Work タスクはテキスト側で継続する
- Voice in Work の利用には、アカウントに **Voice と Work の両方のアクセス**が必要
- 消費は通常の Work 利用枠・クレジットに従い、音声側はプランごとの Voice 制限に従う
- Plus / Pro / Business / Enterprise は **Gmail / Google カレンダー / Google 連絡先を複数アカウント同時接続**できる
- Slack は「会話へ文脈を引き込むコネクタ」と「Slack 内で動く ChatGPT アプリ」の2系統。Business ワークスペースでは管理者が有効化してから使える
- **承認が必要なアクションは画面上の確認ダイアログが出る。音声での承認はサポートされていない**
- Live は引き続きビデオ・画面共有に非対応。ChatGPT Library からのファイル検索・追加もできない
- Business Premium の GPT-Live-1 は 1.25 クレジット/分、Enterprise の従量課金は $0.05/分

## 業務インパクト（一般企業向け）

**「移動中に指示を出して、席に戻ったら下書きができている」という運用が現実的になります。** 営業の移動時間、現場から事務所への帰り道、会議と会議の間。これまでは音声で ChatGPT に質問しても、答えを聞いて終わりでした。Work が音声から起動できるということは、その時間に**成果物の生成を開始できる**ということです。通話を切ってもタスクが走り続ける設計なので、10分の移動で2〜3本の資料作成を仕掛けておく、といった使い方が成り立ちます。

一方で、**完全なハンズフリーにはなりません。** 承認が必要なアクションでは画面上の確認が出て、音声での承認は明示的にサポートされていません。これは制約というより設計判断で、「メールを送る」「カレンダーに予定を入れる」「Slack に投稿する」といった外に影響が出る操作には、必ず目で見た確認を挟ませる作りになっています。運転中の完全な音声操作を期待して導入すると、承認待ちで止まっているタスクが溜まる、という結果になります。**「音声で始めて、画面で承認する」という前提でフローを組んでください。**

**情シス・管理者側で確認すべき点が2つあります。** 1つは、Live がプラグイン対応したことで、**音声会話の経路からも接続アプリのデータに触れられるようになった**ことです。既存のアプリ接続・権限・ワークスペース制限がそのまま適用されるとされていますが、これまで「音声は検索とメモリだけ」という前提で権限設計をしていた組織は、前提が変わったことを認識しておく必要があります。もう1つは、**Slack コネクタのアクションが管理者の有効化を必要とする**点です。既定でオンになるわけではないので、使わせるなら明示的な設定が要ります。

**コスト面では、音声の分単位課金が新しい変数になります。** Business Premium で GPT-Live-1 が 1.25 クレジット/分、Enterprise の従量課金で $0.05/分。テキストのトークン課金とは別の軸なので、「音声で長時間の指示出しをする人が数人いる」だけで請求の形が変わります。導入前に、誰がどのくらい音声を使う想定なのかを粗くでも見積もっておくと安全です。

## 副業・個人活用視点

**移動と作業を重ねられるのが最大の価値です。** 本業を持ちながら副業を回している人にとって、最も不足しているのは「机に向かえる時間」です。音声から Work を起動できるということは、**通勤中に提案書の下書きを走らせて、帰宅後に仕上げだけやる**という分業が自分の中で成立するということです。1日30分の移動時間が、そのまま下書き生成の時間に変わります。

**Free / Go でも Live のプラグインが使える**点は見落とさないでください。Work は有料プランが必要ですが、Live からプラグインを呼ぶだけなら、プランがサポートする範囲で無料枠でも試せます。「音声で自分のカレンダーを確認して、その場で調整を依頼する」程度のことは、課金する前に体験できます。使い勝手を確かめてからプランを上げる、という順序を取れます。

**クライアント向けの提案材料としても使えます。** 「音声で AI に仕事を投げる」は、AI 導入に懐疑的な相手にも伝わりやすい変化です。キーボードを打たない層 — 現場職、営業職、経営層 — にとって、入力方法が音声になるだけで心理的な障壁が大きく下がります。**AI 研修や導入支援を副業にしている人は、この更新を「デモとして見せやすいネタ」として押さえておくと使えます。** ただし承認は画面操作が必須という制約を最初に言っておかないと、期待値がずれます。
