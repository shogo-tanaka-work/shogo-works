## 要約

OpenAI は ChatGPT リリースノート（2026-11-23 付）で、**Chat タブ向けに最適化した GPT-6.2** の提供を始めたと告知しました。Plus、Pro、Business、Enterprise に世界で順次展開されます。Enterprise での提供は、ワークスペース管理者の設定に左右されます。

この版は、GPT-6.2 の **Sol** 系を日常会話向けに調整したものです。公式は、より複雑で込み入った依頼（細かい指示への追従、ウェブでの情報探索）に強くなったと説明しています。たとえば、週末旅行のホテルを価格や立地で比べて推薦する、セール中かを尋ねたら値下げ時の通知を提案する、といった使い方です。

## 何が変わったか

公式が示す、GPT-6 から GPT-6.2 への変化は次のとおりです（いずれも OpenAI 社内の評価）。

- Chat タブでの画像理解: 47.4% → **71.7%**
- 難しい指示の追従: 62.5% → **78.1%**
- 最低の推論設定での専門家レベルのタスク評価: 52% → **65%**
- ウェブ上の難問の探索（BrowseComp の社内版）: 4つの推論設定すべてで GPT-6 を上回り、最高設定では 54.4% → 約 **64.5%**
- 安全性: 公式は、10代向けの安全評価が大きく改善したと述べ、難しい会話でポリシーに沿った応答の割合が 77〜80% から 91〜94% に上がったとしています。

**適用範囲に注意が必要です。** 公式は、今回の更新は ChatGPT の Chat 体験に対するもので、**Work と Codex を動かすモデルは変わらない**と明記しています。2026-11-17 に Work と Codex 向けに出た GPT-6.2 Astra / Sol（プレビュー）とは提供面が別で、画面ごとに使われるモデルが異なる状態です。

## 業務インパクト（一般企業向け）

- **社内の確認基準を見直す機会になる**: Chat タブの応答の質が変わるため、定型プロンプトでの回答や、画像を読ませる業務、ウェブ検索を含む調べものを、数件で再確認しておくと安心です。
- **数字の読み方**: 上の数字は OpenAI 社内の評価で、評価条件（推論設定など）が揃った比較です。自社の業務で同じ改善が出る保証はありません。
- **Enterprise は管理者設定しだい**: 利用者に出るかどうかは、ワークスペースの設定に依存します。展開が段階的なため、すぐには見えない利用者がいる点も、問い合わせ対応の前提になります。
- **画面ごとにモデルが違う**: Chat、Work、Codex で使われるモデルが異なるため、「ChatGPT の最新モデルを使っている」という表現が曖昧になります。社内の利用ガイドでは、画面ごとに分けて書いておくほうが誤解を防げます。

**情報源の制約**: 本記事は ChatGPT リリースノート（help.openai.com）の内容に基づきます。システムカードや個別の発表ページは、今回確認できていません。

## 副業・個人活用視点

Plus 以上なら、いつもの定型作業（資料の要約、画像つきの質問、調べものの下調べ）を同じプロンプトで再実行して、前の回答と比べてみるのが手軽です。**公式の数字ではなく、自分の仕事での差を見る**のが判断材料になります。

画像を読ませる作業（スクリーンショットの読み取り、図表の説明など）は、公式が最も大きな改善を示した領域です。受託の成果物に使う場合は、回答の抜けや誤読を人が確認する工程を残してください。
