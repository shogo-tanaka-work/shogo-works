## 要約

OpenAI は2026-10-29、ChatGPT の **Pro と Business Premium** プランに含まれる **Work と Codex の利用枠を引き上げました**。公式の ChatGPT release notes に載った変更です。

- **Pro 100 と Pro 500**: 従来の **2倍**の Work・Codex 枠を含む
- **Pro 200**: 9月29日のメールで案内していた**引き下げは取り消し**。すでに高い枠を持っていた契約者は、そのまま維持する。低い枠だった契約者には、**10月29日から従来の2倍**を適用し、高い枠と同じ上限にそろえる
- **Business Premium**: 利用枠の増加が対象に含まれる（具体的な倍率は、公式の記載では Pro のものだけが明示されている）

同じ日の release notes には、対象の Pro・Business 契約者が**プロモーション用の API クレジット**を有効化できる項目もあります。クレジットは、リンクした API 組織に適用され、**ChatGPT の利用クレジットとは別**です。適用条件と有効化の手順は、公式のヘルプ記事（API credits benefit for eligible ChatGPT subscriptions）にあります。

## 何が変わったか

- Pro 100 / Pro 500 の Work・Codex 枠が従来比 **2倍**
- Pro 200 は、9月29日に案内された**引き下げをなくし**、低い枠の契約者を高い枠に引き上げる（適用開始 10月29日）
- 対象契約者は、**リンクした API 組織向けのプロモーション用 API クレジット**を有効化できる（ChatGPT の利用クレジットとは別枠）

## 業務インパクト（一般企業向け）

**Codex や Work を業務で使っているチームには、実質的な値下げとして働きます。** 月額が変わらないまま上限が広がるため、これまで枠を気にして使い方を絞っていた用途（長いコード作業、複数エージェントの並走など）を試しやすくなります。

**一方で、運用面の確認が3点あります。**

- **契約プランの見直し**: 上位プランに上げる理由だった「枠」が、下位プランでも足りるようになった可能性がある。直近の消費量を見て、プランの選び直しを検討する
- **Pro 200 の契約者は、9月29日のメールの内容が撤回されている点を、社内の周知で訂正しておく**。削減を前提に予算や利用ルールを作っていた場合は、見直しの対象になる
- **API クレジットは、ChatGPT の枠とは別の会計になる**。社内で API の利用部署と ChatGPT の利用部署が分かれている場合、どちらの組織にひも付くかを先に決めておくと混乱が少ない

**注意点**: 本記事の根拠は、ChatGPT release notes の短い記述です。**利用枠の具体的な数値（トークン数や回数）、Business Premium の倍率、API クレジットの金額と期限は、公式の記載から確認できていません。**契約前に、料金ページとヘルプ記事で最新の条件を確認してください。

## 副業・個人活用視点

**個人で Pro を契約して Codex を使っているなら、追加費用なしで使える量が増えます。** 枠が足りなくてモデルや作業量を抑えていた人は、いったん元の使い方に戻して、足りるかを試してみる価値があります。

**Pro 200 を契約している人は、案内メールの内容がそのまま適用されない点に注意してください。** 削減は取り消され、低い枠だった人は10月29日から引き上げられます。ご自身のアカウントでどちらの枠だったかは、設定画面か、案内メールで確認できます。

**API クレジットは、個人開発や検証に使える追加の予算になりえます。** ただし、プロモーションであり、条件と期限があります。受託案件の本番に使う前に、有効期限と対象を確認してください。

**情報源の制約**: 本記事は ChatGPT release notes（2026-10-29）の記述に基づく。利用枠の絶対値、Business Premium の倍率、API クレジットの金額・期限は未確認。
