## 要約

OpenAI は2026-11-04、画像生成の **Images 2.6** を ChatGPT、Codex、API で提供開始しました。

- 生成が**約50%高速**になった
- 編集を重ねても、キャラクター、製品、ブランドの細部を保ちやすくなった
- ChatGPT で **GIF 作成**（ループ再生のアニメーション）が使える。再生速度の調整と共有もできる
- ChatGPT に**保存した参照画像**機能が加わり、後の会話で `@名前` のように呼び出せる
- API では **GPT-Image-2.6 Flare** と **GPT-Image-2.6 Sunburst** の2種類から選べる

OpenAI は、ChatGPT、Codex、API を合わせて週に40億枚の画像が作られていると説明しています。

## 何が変わったか

- **Flare**: 速度重視。品質を low にすると最短約6秒で生成でき、ポスターや製品画像のレイアウト品質も改善した
- **Sunburst**: 品質と編集間の一貫性重視。品質を medium か high にしたときに向く
- API に、画像上で変更箇所を指す**マークアップ**（ChatGPT では既存）と、**SVG 書き出し**が加わった
- 新しい **complexity パラメータ**で、モデルがどれだけ計画に時間を使うかを調整できる。簡単な編集は low が推奨で、要素や制約が多い場面は medium か high を試す
- ChatGPT と Codex では、**全サブスクリプション階層**のデスクトップ、モバイル、Web で利用可能

## 業務インパクト（一般企業向け）

**制作の往復回数が減る可能性があります。** 編集をかけても細部が保たれる前提なら、「少し直して再生成」の繰り返しで素材が変わってしまう問題が軽くなります。社内の制作フローで、修正指示の出し方を見直す余地があります。

**GIF と SVG で、素材の置き場が広がります。** 動くバナーやマスコットは SNS や社内ポータルで使え、SVG は Web とアプリでそのまま使える形式です。

導入時に決めておくこと:

- 生成物の**権利・表示の方針**（社内規程、生成物であることの明示）。GIF は共有されやすいため、公開前の確認手順を決める
- ブランドの人物・キャラクターを**参照画像として保存**する場合の、保存してよい画像の範囲
- API を使うなら、**Flare を下書き、Sunburst を最終版**のように用途で分ける設計と、費用の見積もり

**注意点**: 料金表の詳細は、本記事の根拠にした本文から確認できていない。API の価格は公式ページで確認が必要。

## 副業・個人活用視点

**クライアント向けの素材制作が速くなります。** 下書きを低品質で素早く出し、決まった案だけを高品質で仕上げる進め方が、費用と時間の両方に効きます。

**GIF は、軽い納品物として使えます。** 商品の見せ方、LINE や SNS 用のリアクション素材、動画制作前の絵コンテ確認など、動画ほど重くない案件に向きます。
