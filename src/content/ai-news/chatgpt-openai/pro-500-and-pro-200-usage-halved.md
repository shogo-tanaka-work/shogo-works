## 要約

DevDay 2026 の発表には、**新機能ではなく既存契約者の条件が変わるもの**が含まれていました。ChatGPT の有料プラン構成の変更です。**期限が明記されているため、読み飛ばすと 10月末に気づくことになります。**

**新設されたのが Pro 500、月額500ドルです。**

OpenAI が販売する中で**最大の利用枠**を持ち、**新しい高速ティア Ultrafast（Astra Ultrafast）への独占アクセス**を含みます。Codex では**最大300トークン/秒、標準ティアの約8倍**の生成速度。**Plus と比べて25倍の利用枠**とされています。

**同時に、既存の Pro 200（月額200ドル）が減枠されます。**

**2026-10-30 から、Work と Codex の利用枠が現行の半分**になります。より具体的には、**全体の利用枠が Plus の20倍から10倍へ半減**し、**ChatGPT の週あたり GPT-6 Pro メッセージ数が200から100へ**減ります。**価格は据え置きで、量だけが半分になる**——実質的な値上げです。

**緩和措置が2つあります。**

1つは経過措置で、**既存の Pro 200 契約者は 2026-10-29 まで現行の上限が維持**されます。もう1つは補填で、**一度限りの 2,500 ドルぶんの利用クレジット**が付与されます。**このクレジットは年末で失効します。**

**そしてもう1つ、条件が良くなる変更もあります。**

**5時間の利用ウィンドウが恒久的に撤廃されました。** これまでは一定時間ごとに上限がリセットされる仕組みで、「いま使い切ると数時間待ち」という状況が発生していました。今後は**週あたりの上限を、リセット時刻を気にせず必要なときにまとめて使えます**。

## 何が変わったか

- **Pro 500 を新設**。月額 **500ドル**
- Pro 500 は **Ultrafast（Astra Ultrafast）への独占アクセス**を含む
- Pro 500 の利用枠は **Plus の25倍**、Codex で**最大300トークン/秒（標準の約8倍）**
- **Pro 200 は 2026-10-30 から Work と Codex の利用枠が半減**
- 全体の利用枠が **Plus の20倍 → 10倍**
- 週あたり **GPT-6 Pro メッセージ数 200 → 100**
- **価格は月額200ドルのまま据え置き**（実質値上げ）
- 既存契約者は **2026-10-29 まで現行上限を維持**
- 既存契約者へ**一度限り 2,500ドルぶんの利用クレジット。年末失効**
- **5時間の利用ウィンドウを恒久撤廃**。週次上限を任意のタイミングで消化可能に

## 業務インパクト（一般企業向け）

**この変更で最初にやることは、現在の使用量の把握です。** 抽象的な話ではなく、10月中に終わらせる必要がある作業です。

**確認すべきは3点です。**

1つ目、**Pro 200 を誰が使っているか**。個人契約を経費精算している場合、情シスが把握していないことがあります。2つ目、**その人たちが現在どれくらい使っているか**。現行枠の半分に収まるなら影響はありません。3つ目、**半分に収まらない人が何人いるか**。ここが移行判断の対象です。

**選択肢は実質3つです。**

**Pro 500 へ上げる**（月200ドル → 500ドル、2.5倍の支出）。**Pro 200 のまま使い方を絞る**（半分の枠で回るよう作業を選別）。**API へ寄せる**（従量課金で、使った分だけ払う）。

**3つ目の選択肢を軽視しないでください。** ChatGPT の定額プランは「たくさん使う人ほど得」という構造ですが、**枠が半分になると、その前提が崩れる使用量帯が出ます**。特に、**Codex を業務で回している場合**は API 側の単価と比較する価値があります。ちょうど同じ DevDay で **GPT-6.1 Sol が Astra の5分の1の単価**で出ているため、API 側の原価は下がる方向です。

**2,500ドルの補填クレジットは、設計して使う必要があります。**

**年末失効**という条件が付いているためです。放置すると消えます。使い道として考えられるのは、(1) 移行前に重い処理をまとめて走らせる、(2) Ultrafast を試して速度の価値を測る、(3) 通常なら躊躇する規模の一括処理をこの期間に実行する、あたりです。

**「クレジットがあるうちに、来年以降の運用方針を決めるための検証を済ませる」**という使い方が、最も無駄がないと考えます。減枠後の環境で慌てて検証するより、クレジットのある10〜12月に「実際に必要な枠はどれくらいか」を測っておく方が、来年の予算が根拠を持ちます。

**5時間ウィンドウの撤廃は、地味ですが運用に効きます。**

これまでは「午前に使いすぎると午後が止まる」という制約があり、**作業計画をリセット時刻に合わせる**必要がありました。これが消えます。週単位で見れば総量は決まっていますが、**集中して使う日と使わない日を自由に配分できる**のは、実務ではかなり違います。月末に集中する業務、プロジェクトの立ち上げ期——**波のある使い方をする組織ほど恩恵があります**。

**最後に、この発表の読み方について。**

DevDay 2026 は20件超の発表があった華やかなイベントですが、**その中に既存契約者の条件悪化が含まれていた**という構造は、記録しておく価値があります。新機能の発表と価格改定を同じ日に出すのは珍しいことではありません。**発表を追うときは、「増えたもの」だけでなく「減ったもの」を明示的に探す**という習慣が要ります。

## 副業・個人活用視点

**個人で Pro 200 を払っている人にとって、これは10月中に判断が必要な話です。**

まず**自分の使用量を確認してください**。ChatGPT の設定から利用状況が見られます。**現行枠の半分に収まっているなら、何もしなくて構いません。** 5時間ウィンドウが消える分、むしろ使いやすくなります。

**収まらない場合の判断は、月300ドルの差額に見合うかどうかです。**

Pro 500 は月500ドル。Pro 200 との差は**月300ドル、年間3,600ドル**です。個人事業の経費として、これが正当化できるかは売上規模によります。**「AI に月7万円」を出せる事業規模かどうか**、という素朴な問いに戻ります。

**代替として、API への部分移行は現実的です。**

特に、**定型的な処理を自分でスクリプト化している人**は、そこだけ API へ出すと効きます。ChatGPT の対話は Plus（月20ドル）で回し、重い処理は API で従量。**GPT-6.1 Sol が Astra の5分の1単価**で出たので、この構成の原価は以前より下がっています。合計で Pro 200 を下回るケースは十分あります。

**Ultrafast についての判断は、慎重で良いと思います。**

**標準の6倍の単価（入力60ドル / 出力300ドル per MTok）**です。速度を金で買う機能ですが、**個人の作業で「8倍速い」ことが6倍の価格に見合う場面は限られます**。待ち時間が直接コストになるのは、顧客の目の前でデモをする、締切が時間単位で迫っている、といった状況です。**普段の作業で使うものではありません。**

**受託・コンサルの文脈では、これは短期の相談ネタとして成立します。**

**期限が 2026-10-30 と明確で、対応しないと実害が出る**——この構造は、声をかける理由として自然です。「御社で ChatGPT Pro を使っている方の枠が、10月末から半分になります。使用量の確認はお済みですか」。営業トークとしてではなく、**事実の通知として送れる**のが強みです。

成果物としては、(1) 契約中のプランと利用者の一覧、(2) 各人の現在の使用量、(3) 減枠後に不足する人の特定、(4) Pro 500 / 現状維持 / API 移行の原価比較、(5) 補填クレジット2,500ドルの使い切り計画。**5点とも、この1件の発表から項目立てできます。**

**発信するなら、「実質値上げ」という切り口が最も読まれます。** ただし、**5時間ウィンドウの撤廃という改善も同時に起きている**ことは必ず書いてください。片方だけ書くと、事実として不正確になります。正確に書いたうえで「総合すると自分の使い方にはこう影響する」と自分の判断を示す方が、単に煽るより信頼されます。
