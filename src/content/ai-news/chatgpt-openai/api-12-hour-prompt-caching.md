## 要約

OpenAI は 2026-10-20、API changelog で **12 時間プロンプトキャッシュ**を告知しました。対象は **Responses API（v1/responses）** です。共通の指示・ツール・コンテキストを**長く**キャッシュでき、リクエストの間隔が**数時間空いても**、割安な**キャッシュ入力価格**の恩恵を受けられます。

代償として、**12 時間キャッシュの書き込みは入力トークン価格の 2.5 倍**です。長く保持する分、最初の書き込みが高くつく設計です。

changelog 本文には、**指定方法（パラメーター名）、対象モデル、キャッシュ読み出しの価格**が書かれていません。詳細は公式の解説ページに委ねられており、**本記事ではそのページを取得していません。**

## 何が変わったか

- Responses API で **12 時間のプロンプトキャッシュ**を選べる
- 共通の指示・ツール・コンテキストを長く保持し、間隔の空いたリクエストでも**割安なキャッシュ入力価格**を適用できる
- **12 時間キャッシュの書き込み**は入力トークン価格の **2.5 倍**
- 指定方法、対象モデル、読み出し価格は changelog に記載なし

## 業務インパクト（一般企業向け）

**使いどころは、同じ長いプロンプトを数時間おきに使うシステムです。** 社内問い合わせボット、定期実行のレポート生成、同じツール定義を毎回送るエージェントなどが当てはまります。

判断の軸は**再利用の回数**です。書き込みが 2.5 倍なので、保持中に何回読まれるかで損益が分かれます。1回しか使わないプロンプトに指定すると、通常より高くなります。**自社のログから再利用間隔とヒット率を出して試算**してから切り替えてください。

## 副業・個人活用視点

**自作ツールや受託システムのランニングコストを下げる選択肢が増えます。** 顧客向けの Bot で、毎回同じ長い指示を付けている場合は見直し候補です。

ただし、アクセスが少ない案件では再利用されず、書き込みの割増だけが残る可能性があります。**請求額で効果を確かめてから**、顧客への見積もりに織り込んでください。
