## 今週の要点

**対応が要ります。モデルを設定ファイルで固定していない環境は、更新するだけで使うモデルが変わります。**

**バンドル既定モデルが GPT-6 Astra になりました** (0.153.4)。モデルが明示設定されていない場合に使われるモデルが変わります。**誰も操作していないのに、更新後は別のモデルで動きます。** コストも出力の傾向も変わるため、検証済みのプロンプトを使い回している環境ほど影響が出ます。**更新前に、固定するかどうかを決めてください。**

**Guardian の承認レビューが Node REPL ポリシーを無視していました** (0.152.1)。モデルのメタデータ経由で渡される Node REPL ポリシーが、承認判定に反映されていませんでした。**ポリシーを設定した側は効いていると信じるため、修正されるまで誰も気づきません。** Node REPL を含むワークフローで Guardian の承認制御を使っている環境は、**効いていなかった期間があった**前提で確認してください。

**MCP のツール承認がアプリアカウント単位にスコープされました** (0.153.0)。「このツールを許可した」が「どのアカウントで」まで含むようになります。**複数アカウントを繋いでいる環境は、承認状態の再確認が要ります。**

**Astra 対応は3リリースにわたって段階的に入りました** (0.153.1, 0.153.3, 0.153.4)。設定経由での受け入れ（既定変更なし・ピッカー非表示）→ Amazon Bedrock のピッカー追加 → バンドル既定モデル化、という順序です。**最後の1歩だけが利用者の操作なしに挙動を変えます。**

## 変更一覧

**モデルまわり** — `GPT-6-Astra` を API 経由で設定可能に（**既定は変更せず、モデルピッカーにも表示しない**）(0.153.1)。`GPT-6-Astra Fast` ティアの説明文を `1.5x` から `"2x speed, increased usage"` へ修正（**表示テキストのみ。リクエスト処理に影響なし**と公式が明記）(0.153.2)。**Amazon Bedrock のモデルピッカーに GPT-6-Astra を追加**（Mantle と Runtime の global / US ルート向け）(0.153.3)。**バンドルのモデルピッカーに Astra を表示し、モデル未設定時のバンドル既定モデルを Astra に変更** (0.153.4)。Astra の非同期の確認質問に関するガイダンス修正を2回（対応ツールがテキストのみを受け付ける旨の認識、およびそのツールがセッションで利用可能なときだけ適用する限定）(0.153.3, 0.153.4)。

**Guardian（承認・レビュー機構）** — 承認レビューがモデルメタデータ経由の **Node REPL ポリシーを尊重**するよう修正 (0.152.1)。**Full Access では確認のみの操作に対するレビューをスキップ**し、**承認モードではバックグラウンドのスコアリングをスキップ**するようモードごとに条件を変更。**レビュー履歴がコンパクション・再起動・ユーザー作成のフォークを越えて保持される**（ロールバック境界は尊重）(0.153.0)。

**MCP** — サーバー名が**パッケージ形式の命名規則**に対応。**個々のツールごとに出力トークンの上限**を設定可能に (0.152.0)。**ツール承認が選択したアプリアカウント単位にスコープ**される。macOS で相対パスの MCP 実行ファイルがより確実に起動 (0.153.0)。

**プラグインと拡張** — **プラグイン CLI がリモートマーケットプレイスからの一覧・インストール・削除に対応** (0.153.0)。

**TUI と操作性** — `/` と `?` による **Vim 風のパターン検索** (0.152.0)。**Vim モードで `u` の undo と `Ctrl+R` の redo**（貼り付けた内容や添付を含めドラフト全体を保持）。**自動 recap を無効化しつつ手動の `/recap` は残す**設定。履歴にパッチ全体・バックグラウンドターミナルの入力・完了した個々のコマンドを表示 (0.153.0)。**レート制限バナーが操作可能に**なり、その場で次の選択肢を提示 (0.152.0)。

**使用量とセッション** — **Plus / Team ユーザーへ、残枠が半分を切ったときの警告を約5時間前倒し**。外部 app-server の切断後に **TUI セッションが自動再接続**し、ドラフトとトランスクリプトを保持。ロールアウト圧縮が共有履歴を含むようになり、`codex exec resume` が圧縮済みロールアウトを正しく扱う (0.153.0)。
