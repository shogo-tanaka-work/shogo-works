## 今週の要点

**更新してください。サンドボックスの隔離に3か所の穴がありました。**

**隔離を抜ける経路が3つ塞がれました** (0.156.0)。**Windows の受信接続**、**Linux と macOS の特権ソケット**、**読み取り専用として渡した macOS ファイルハンドル経由の書き込み**です。いずれも「サンドボックスの中で動いているつもりの処理が、外へ出られた」型で、**サンドボックスを前提に権限を緩めている運用ほど影響が大きい**箇所です。

**既定値が2つ同時に変わりました** (0.156.0)。**音声会話**（F8 でトグル、`/voice settings` でピッカー。Linux と Windows にはオーディオランタイムが同梱）と **worktree サポート**が**既定で有効**になりました。**利用者が何も設定しなくても挙動が変わります。** マイクを使わせたくない環境、worktree を前提にしていない手順書がある場合は、更新前に確認してください。

**レート制限に当たったとき、安いモデルへ誘導されます** (0.156.1)。モデルピッカーに **GPT-6 Sol と GPT-6 Luna** が加わり、**上限に達したときのプロンプトが Luna を推奨**します。作業は止まりませんが、**モデルが変わったことに気づかないまま出力品質が変わりうる**点は把握しておいてください。

**それ以外に対応が要るものはありません。** 今週の stable は4件ですが、**0.156.1 と rust-v0.157.1 は小さな追随**です。

## 変更一覧

**サンドボックスと隔離** — Windows の受信接続、Linux / macOS の特権ソケット、読み取り専用 macOS ファイルハンドル経由の書き込みという3つの隔離の穴を修正 (0.156.0)。

**既定値の変更** — **音声会話**と **worktree サポート**が既定で有効 (0.156.0)。**フルスクリーン transcript が既定**になり、Shift クリックでの選択範囲拡張に対応 (0.157.0)。非推奨の `friendly` / `pragmatic` パーソナリティ設定が応答スタイルを選ばなくなった旨をドキュメントで明確化 (0.156.0)。

**モデルと調達経路** — モデルピッカーへ **GPT-6 Sol / GPT-6 Luna** を追加し、レート制限時のプロンプトから Luna を推奨 (0.156.1)。**GPT-6 Sol / Luna を Amazon Bedrock 経由でも利用可能に** (0.157.0)。**どのモデルが使えるかが技術判断ではなく契約経路で決まる**組織には、後者のほうが効きます。

**TUI と操作** — **`/tui`** で次回起動時のフルスクリーンUI を選択（トランスクリプト検索、マウス選択、右クリックコピー）。**`/usage`** でアカウント利用状況・トークン総量・プラグインとスキルの稼働状況を表示。agent command center でタスクを状態で絞り込み、worktree セッションを作成。ターミナルテーマ6種、Mermaid 図と数式の応答内描画 (0.156.0)。**会話の fork**（`F`、下書きを保持）と background-server セッションでの `/import` (0.157.0)。

**デーモンと背景サーバー** — **`/daemon`** でローカルの背景サーバーを更新、`--no-daemon` で迂回 (0.156.0)。**条件を満たす対話セッションで背景サーバーを自動起動** (0.157.0)。

**修正** — ターン失敗・中断・サブエージェント完了時のストリーム応答とプランの保持、tmux / SSH でのクリップボード転送、プロキシ経由のログイン回復、OAuth discovery が 503 を返したときの MCP 資格情報更新 (0.156.0)。
