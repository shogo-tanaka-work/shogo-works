## 今週の要点

**対応が要るのは1つ、それ以外は更新して問題ありません。**

**推論サマリーの既定 ON が、非対応プロバイダを止めました** (0.155.0 → 0.155.1)。0.155.0 で新規ローカル TUI セッションの reasoning summary が既定で有効になり、**それに対応していないプロバイダがリクエストを拒否**しました。OpenAI 以外のエンドポイントや自社ゲートウェイ経由が該当します。**約21時間後の 0.155.1 で既定が `none` へ戻っています。** 明示的に設定している場合はその設定が尊重されるため、影響は既定のまま使っていた環境に限られます。

**Windows のサンドボックスが資格情報露出に対して強化されました** (0.155.0)。Windows で使っている環境は更新対象です。

**MCP の呼び出しに Touch ID を挟めるようになりました** (0.155.0、対応 macOS)。**エージェントが外部ツールを呼ぶ瞬間に生体認証を要求する**形で、有効にするかどうかは運用方針の判断になります。

**今週の stable は2件だけでした。** 0.155.0 は **9日ぶりの安定版**で、その間 alpha が積み上がっていました。0.156.0 系は窓の終端時点でまだ stable 化していません。

## 変更一覧

**統制と資格情報** — 対応 macOS での **MCP リクエストの Touch ID 検証**。**Windows サンドボックスの資格情報露出に対する強化**。**アカウント切り替え時に、キャッシュ済みセッションとモデルカタログを正しく無効化**。Amazon Bedrock 連携向けに、**設定したコマンドから AWS 資格情報を取得**する機能 (いずれも 0.155.0)。

**入出力と TUI** — 対応ビルドでの**実験的な `/voice` 会話**（ライブ文字起こしとマイク操作）。TUI ステータス行への**推論サマリーのライブ表示**（完了時刻併記）。tmux のリサイズ処理とトランスクリプトのビューポート復元の修正 (0.155.0)。**その推論サマリーの既定を `none` へ戻す** (0.155.1)。

**タスクとデーモン** — agents overview での**タスクの非表示・アーカイブ・削除**。**デーモンの更新スケジュールを設定可能に**し、再起動後は保存済みスレッドを自動復旧。compaction 失敗時に受理済みプロンプトを保持。MCP の OAuth トークン更新時の案内改善 (0.155.0)。
