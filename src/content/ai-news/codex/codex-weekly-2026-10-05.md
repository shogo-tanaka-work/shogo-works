## 今週の要点

**更新してください。そのうえで、既定モデルが変わったことを先に確認してください。**

**発表当日に既定モデルが替わりました** (0.159.1)。DevDay 2026 で公開された **GPT-6.1 Sol** が、**同日のうちにバンドルカタログと Amazon Bedrock Mantle / Runtime カタログの既定**へ入りました。**モデルを明示指定していない利用者は自動的に切り替わります。** Bedrock 経由で調達している組織も同時に変わります。**評価済みのモデルで動かし続けたい業務は、モデル名を明示指定してください。**

**資格情報の置き場が既定で守られるようになりました** (0.159.0)。**書き込み可能ルート配下の `.aws` ディレクトリが既定保護**になり、**承認済みのコマンドでも明示的なファイルシステム拒否が維持される**ようになりました。前の版では、**昇格した権限に対するターミナル入力の承認が既定有効**になっています (0.158.0)。**サンドボックスを前提に権限を緩めている運用ほど、更新の効果が大きい箇所です。**

**ローカルで立てた実行サーバーが無認証でした** (0.158.0)。**exec-server の WebSocket 接続が bearer token で保護**されました。自前で exec-server を動かしている場合は、保護が入る前の期間があったことになります。

**ポリシー次第で挙動が変わる変更が1つあります** (0.160.0)。**ポリシーが許す場合、プロジェクト外でもワークスペース既定でセッションを開始できる**ようになり、再開時に保存済みの権限を復元します。**組織でワークスペース外の実行を制限しているなら、ポリシー設定の確認が必要です。**

**設定ファイルの棚卸しが1件あります** (0.159.0)。**`tui.prompt_suggestions` 設定と自動フォローアップ提案が廃止**されました。

## 変更一覧

**モデルと調達経路** — **バンドルカタログと Amazon Bedrock Mantle / Runtime カタログの既定モデルを GPT-6.1 Sol へ変更** (0.159.1)。明示的な provider のモデルカタログに、非対応の同梱モデルや更新失敗後の古いエントリが混ざらないよう修正 (0.160.0)。

**資格情報とサンドボックス** — 書き込み可能ルート配下の **`.aws` ディレクトリを既定保護**し、承認済みコマンドでも明示的なファイルシステム拒否を維持。ネットワーク有効サンドボックスの macOS TLS アクセスを修正 (0.159.0)。**昇格権限に対するターミナル入力の承認を既定有効化**、**exec-server の WebSocket を bearer token で保護**、**OAuth クライアントシークレットを事前登録した MCP サーバー**に対応 (0.158.0)。**ポリシー許可時のプロジェクト外セッション**と保存済み権限の復元 (0.160.0)。

**サンドボックスのプラットフォーム対応** — Windows のサンドボックスが標準パスおよび大きなポリシーで失敗する問題、入れ子の書き込み可能ルートがある場合の Linux のサンドボックス起動、macOS のシステムパスのエイリアスを patch 操作で認識 (0.158.0)。**Windows の PowerShell フォールバックと長いパスの権限問題** (0.160.0)。

**Windows のコンソール窓** — MCP サーバー・code-mode ホスト・パイプコマンドが余計なコンソール窓を出す問題（制約の強いランチャーでは埋め込み実行へフォールバック）(0.159.0)。バックグラウンドプロセスやサンドボックス化されたコマンド起動時の明滅 (0.159.2)。バックグラウンドヘルパーによる不要なコンソール窓 (0.160.0)。**3版にわたって同じ領域を直し続けています。**

**レビューと検証** — **Guardian review のオプトイン機能**を追加。以前のユーザー指示を取得し、**エージェント間の引き継ぎ（handoff）の文脈を含める** (0.160.0)。

**割り込みと操作** — **instant interrupt** をオプトインで有効化（応答中や code-mode の長い処理中でも新しい入力で軌道修正）。提案されたプランを検討しながら会話履歴をスクロール。新規セッションのウェルカム画面の整理、警告ビューアの既読処理（`k` で残す）(0.159.0)。フルスクリーン TUI の **copy-on-select と右クリック貼り付け**の設定 (0.158.0)。Linux X11 ローカルターミナルでのフルスクリーン時のテキスト選択と中クリック貼り付け、agent command center のキーボード操作可能な「Show more」(0.160.0)。

**アカウントと通知** — ChatGPT でサインインした対象のローカルセッションで、**アカウントのセキュリティ設定の完了を促す任意のリマインダー**を表示 (0.159.3)。**0.161 系の alpha が進む中で 0.159 系へ backport**されており、優先度の高さが読み取れます。

**安定性** — 未送信のキューメッセージが再接続後に再開され、送信の重複を避ける。接続設定・ログ中の SQLite の停止を修正し、**初期化エラーをタイムアウトとして隠さず表面化**。サブエージェントが起動中の環境を保持 (0.160.0)。新しいユーザー入力が来たときの承認レビューの再試行 (0.158.0)。
