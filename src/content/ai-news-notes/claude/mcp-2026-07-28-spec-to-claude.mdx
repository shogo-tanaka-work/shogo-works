- MCP教材の「プロトコルの前提」節はステートフル前提（`initialize` / `Mcp-Session-Id`）の説明が古くなる。次回改訂でステートレスコアへ更新が必要。
- Roots / Sampling / Logging を扱う教材には「非推奨・12か月の廃止予定期間あり」の注記を入れる。
- コア仕様と拡張（Tasks / MCP Apps / EMA）の区別は、MCPの構造を説明する新しい導入口として使える。
- 「サーバーレスに載せられる」は非エンジニア向けにも運用コストの話として説明しやすい。ホスティング形態の比較教材に接続できる。
- MCPトンネルはリサーチプレビュー段階のため、教材化はGA後まで待つ。続報を追う。
