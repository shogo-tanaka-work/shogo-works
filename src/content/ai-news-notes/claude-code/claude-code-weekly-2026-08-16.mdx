- **修正が翌日 revert された**という事実は、更新運用のリアルを伝える最良の材料。「最新にすれば安全」ではなく、**何が入って何が戻ったかを追う**必要がある。Cygwin symlink の経路が塞がっていない、という具体まで押さえると実務的。
- **fork の既定化**は、既定値が変わると使い方の前提が変わる例。会話全体とキャッシュを継承するかどうかで、コストも精度も変わる。
- **Todo ツールの無効化**は、「機能が静かに消える」ケース。エージェントに任せていた作業が突然変わったように見えるが、原因はモデル側の対応状況にある。
- **セッション同士が名前で指名し合える**ようになった点は、AI の使い方が単体から複数体へ移る流れの具体例。権限が継承されない設計とセットで理解させたい。
