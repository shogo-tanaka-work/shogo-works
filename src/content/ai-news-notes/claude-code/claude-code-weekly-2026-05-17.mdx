- **`claude agents` と `/goal` の同時投入は、「1セッションに張り付く」から「複数を監督する」への転換点**として説明できる。AI の使い方が個人の作業補助からチーム運用へ移る瞬間を、機能追加という具体で示せる。
- **`/goal`（完了条件を先に決める）は、指示の出し方そのものの教材**になる。人への依頼でも同じで、完了条件が曖昧なまま任せると往復が増える。AI に限らない普遍的なテーマへ接続できる。
- **hooks の exec form（shell を介さない起動）**は、シェル経由の実行が持つリスクを説明する導入に使える。なぜ shell を挟まない選択肢が用意されるのか、という問いから入ると理解が早い。
- **worktree cleanup が `rm -rf` へフォールバックしなくなった修正**は、「便利な後始末が破壊的になりうる」実例。自動化を作るとき、削除処理だけは慎重に設計するという原則の具体例になる。
