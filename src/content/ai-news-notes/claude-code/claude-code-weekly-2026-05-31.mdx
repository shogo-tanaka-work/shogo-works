- **`/model` の「セッション限定 → 既定保存」への反転**は、既定値の設計が利用者の事故率を左右する実例。どちらが正しいかではなく、**変わったことに気づかせる設計**（キーバインド名の変更を強制する）に注目させると学びが深い。
- **カスタムゲートウェイに OAuth 資格情報が渡っていた不具合**は、「経由するものすべてが資格情報を見る可能性がある」という原則の教材。中継を挟む構成では、何がどこまで見えるかを設計時に確定させる必要がある。
- **`.claude/skills` の自動ロード**は、社内配布の現実的な解になる。マーケットプレイスを立てずにリポジトリへ置くだけで配れる、という運用の軽さは組織導入の障壁を下げる。
- **`disallowed-tools` で skill 有効中にツールを外せる**点は、権限を「ユーザー単位」ではなく「作業単位」で絞る発想。最小権限の考え方を、静的な設定ではなく文脈依存で説明できる好例。
