- **統制が「主エージェントには効くがサブエージェントには効かない」状態**は、権限設計で最も見落とされるパターン。委譲先まで制約が伝播するかを必ず確認する、という点検項目として教えられる。
- **`--safe-mode` の存在は、設定を積み上げる運用の裏返し**。カスタマイズが増えるほど切り分けが難しくなるため、全部を止めて起動できる経路が要る。自作の自動化にも同じ発想を持ち込める。
- **`/cd` がプロンプトキャッシュを保つ**点は、コスト構造を理解していないと価値が分からない良い例。何が課金され何が再利用されるかを知ると、操作の選び方が変わる。
- **5階層のサブエージェントネスト**は、設計の自由度と暴走リスクが同時に上がる話。上限値が設けられている理由から、無人実行の安全設計を考えさせられる。
