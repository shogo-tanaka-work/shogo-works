- **「見積もりが約1割低かった」**という修正は、コスト管理の教材として非常に強い。表示された数字を信じて予算を組んでいた場合、前提ごと外れる。**見積もりは実装であり、バグがある**という認識を持たせられる。
- **上限到達で止まらなくなった変更**は、安全装置として上限を使っていた運用の裏をかく。「止まること」を前提にした設計は、止まらなくなった瞬間に破綻する。
- **ゲートウェイ経由でキャッシュが効いていなかった**件は、中継を挟むと最適化が失われる実例。構成を足すと性能特性が変わる、という一般則へ接続できる。
- **Shift+Tab でセッション全体の編集権限を渡してしまう**不具合は、UI 操作と権限付与が結びついている怖さ。閉じたつもりが許可だった、という体験は誰にでも起こりうる。
