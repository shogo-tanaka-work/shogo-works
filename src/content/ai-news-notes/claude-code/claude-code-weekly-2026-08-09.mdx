- **3版連続で権限チェックの回避経路が見つかった**という事実そのものが教材。1つ塞いでも別の経路が残る、という**攻撃面の広さ**を実感させられる。zsh の条件文、PowerShell のクォート、不可視 Unicode、動的 `import()` と、どれも「コマンド文字列を検査する」方式の限界を突いている。
- **`bypassPermissions` が組織ポリシーを無視していた**件は、例外機能が統制の穴になる典型例。例外を設けるなら、例外が上位ポリシーに従うかまで設計する必要がある。
- **Remote Control の有効化がユーザースコープ限定になった**のは、「リポジトリを開いただけで機能が有効になる」危険への対処。設定をどこに置けるかは権限の話である、という視点を教えられる。
- **`ultraplan` の削除**は、機能が減ることもあるという当たり前の事実。教材や手順書は、追加だけでなく削除にも追従が要る。
