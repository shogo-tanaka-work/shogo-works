- **「書けていたのに守られていなかった権限ルール」が1週間に4件**という事実は、統制の教材として非常に強い。設定を書いた時点で安心せず、**効いていることを確認する手順**まで運用に含める必要があるという話へ直結する。
- **バージョン強制（`requiredMinimumVersion`）**は、ツールのガバナンスを「お願い」から「起動拒否」へ変える手段。組織展開の実務では、周知より仕組みで縛るほうが確実という原則の実例。
- **`SendMessage` 経由のメッセージが権限を持たない**設計は、権限昇格の防ぎ方の基本形。中継を挟むと権限も一緒に流れると錯覚しやすい、という誤解の解消に使える。
- **`fallbackModel` は可用性設計の話**。プライマリが落ちたときに止まるか、劣化して続けるかを事前に決めておく——AI に限らない冗長化の考え方として教えられる。
