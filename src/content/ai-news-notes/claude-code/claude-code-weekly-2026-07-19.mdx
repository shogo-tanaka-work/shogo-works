- **権限プレビューの視覚偽装**は、承認 UI そのものが攻撃対象になる実例として強い。人が見て承認する仕組みは、**見せ方を操作されたら成立しない**。ゼロ幅文字や双方向オーバーライドは古典的な手口で、他分野の事例とも接続しやすい。
- **「実質無効な権限ルールへの警告」**は、書いたルールが無意味だったケース。設定は書けば効くという思い込みを崩す教材になる。
- **暴走上限（WebSearch 200回・サブエージェント200件）**は、無人実行の設計原則。止める条件を先に決めておかないと、失敗が高くつく形で表面化する。
- **プロンプトキャッシュの課金バグ**は、コストが自分の操作だけで決まらないことの実例。請求の内訳を読む習慣がないと、こういう差分に気づけない。
- **worktree 分離が git 操作に効いていなかった**件は、「隔離しているつもり」の危うさ。隔離は範囲を明示して検証しないと、どこまで効いているか分からない。
