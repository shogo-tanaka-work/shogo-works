- **既定モデルの変更は、告知されても手元では気づきにくい**。コストも品質も変わるのに、操作は何も変えていない。**既定値の変更を検知する運用**をどう作るか、という問いに使える。
- **Auto mode 設定の読み込み元がプロジェクト単位からユーザー単位へ移った**件は、設定の配布経路が変わると統制が外れる実例。「どこに置けば効くか」はバージョンで変わりうる。
- **`${user_config.*}` 直接展開の拒否**は、テンプレート展開とシェル実行を組み合わせる危険の教材。ユーザーが与えた値をそのままコマンドに展開する構造は、AI ツールに限らず脆弱性の温床になる。
- **`/doctor` が診断から修復まで担うようになった**のは、サポート設計の話。自己解決できる範囲を広げると問い合わせが減る、という運用改善の具体例として使える。
