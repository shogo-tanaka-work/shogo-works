- **`Bash(git * main)` がオプションにもマッチする**件は、「許可ルールは意味ではなく文字列で判定される」ことの決定版。ファイアウォールや IAM の設計と同じ構造なので、他分野の経験者に接続しやすい。
- **警告は出るが自動では直らない**という点まで教えると、運用設計の視点が育つ。気づいて直す人を割り当てない限り、状態は変わらない。
- **第三者ゲートウェイへ API キーが送られていた**件は、資格情報のスコープ設計の教材。修正後もローテーションの判断が要る、というインシデント対応の思考へ繋げられる。
- **契約単価の反映（`modelPricing`）**は、社内コスト集計の前提が定価だったことを可視化する。数字の出どころを確認する習慣の重要性を示せる。
