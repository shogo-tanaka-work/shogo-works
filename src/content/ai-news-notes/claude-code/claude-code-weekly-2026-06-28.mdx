- **`!` コマンドの自動応答は、UX 改善が「情報の流れ」を変える例**。手動で渡していた出力が自動で渡るようになると、渡したくない出力も渡る。オフにする設定が用意されている理由まで含めて教えると、既定値を確認する習慣が身につく。
- **`sandbox.credentials`** は、「サンドボックスは実行を隔離するが、読み取りは隔離しない」という誤解の解消に使える。何から何を守る仕組みなのかを正確に押さえさせる。
- **hook matcher の部分一致修正**は、「バグ修正で既存設定が壊れる」ケース。正しくなった結果として動かなくなるものがある、という更新時の注意として扱える。
- **CJK ペースト文字化け**は、日本語話者にとっての実感を伴う例。グローバル製品では非英語圏固有の不具合が遅れて直ることがあり、**自分の環境で試して報告する価値**の話へ繋げられる。
