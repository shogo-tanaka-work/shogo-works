- **`Tool(param:value)` は「権限＝コスト制御」でもある**という視点を教えられる。`Agent(model:opus)` を止めるのは安全のためではなく費用のため。権限設計の目的が複数あることを具体で示せる。
- **破壊的コマンドの既定ブロック**は、「便利さを削って事故を防ぐ」判断の実例。文脈次第でブロックするという設計（破棄指示があれば通る）は、一律禁止より運用が続きやすいという学びに繋がる。
- **サブエージェント経由の抜け道**が塞がれた件は、権限の穴が「機能の隙間」に生まれる典型。委譲する仕組みを入れたら、委譲先にも同じ検査が要る。
- **非推奨モデルの警告が frontmatter 指定にも及ぶ**点は、設定ファイルへ書いた値が古くなる問題。バージョンや型と違い、モデル名は静かに陳腐化するという注意喚起に使える。
