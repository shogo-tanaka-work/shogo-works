## 教材化ポイント

### 1. 「Workspace で動画制作が完結する」の全体像を、この更新で締める

Vids 系の更新は個別に扱うと散らかる。ドキュメント→動画、AI アバター、そして今回の音楽生成で、**素材の3要素（構成・話者・音）がそろった**。教材ではここで一度まとめるのが自然なタイミングである。

**教材への落とし込み方:**

- 「素材の調達先」の新旧対比表を置く（旧: 台本は内製 / ナレーションは外注か自録り / BGM は素材サイト → 新: いずれも Workspace 内で生成可能）
- 既存の `gemini/google-vids-doc-to-video`、`gemini/google-vids-ai-avatars` へのリンクを張り、**3本セットで読ませる**
- 「完結できる」と「完結すべき」は別、という但し書きを必ず添える。品質要件が高い公開物は依然として外注が妥当な場合がある

### 2. 権利・商用利用を「教材が先に立てる論点」にする

公式アナウンスは機能と提供範囲だけで、**商用利用条件・権利帰属・透かしには触れていない**。ここを教材が黙っていると、受講者はそのまま公開物に使う。

**教材への落とし込み方:**

- 「使う前に確認する項目」チェックリストを置く（商用利用の可否 / 権利の帰属 / 透かしや表示義務の有無 / クライアント納品時の説明方法）
- 用途を3段階で仕分ける演習にする（社内限定 → 自社の公開物 → クライアント納品物）。求められる確認の深さが段階的に上がることを体感させる
- 「素材ライブラリの契約を即解約してよいという話ではない」を明示する。コスト削減の話に短絡させない

### 3. 「尺の選択」を、地味だが効く改善の代表例として扱う

新機能の説明は派手な部分（表現力のあるボーカル）に寄りやすいが、実務で効くのは**尺を選べること**である。既成素材のループ・フェード編集という工程が丸ごと消えるため。

**教材への落とし込み方:**

- 「モデルの品質向上」と「工程が消える改善」を分けて評価する見方を教える。後者の方が業務時間に直結する
- ショート動画のように**尺が固定されている形式**で効果が最大化する、という条件付きの説明にする
- 受講者に自分の制作フローを書き出させ、「どの工程が消えるか」を特定させる演習にすると定着する

### 4. 全ユーザー・全世界提供＝統制の論点でもある

Gemini アプリを配布している組織では、**方針を決める前に従業員が使える状態になっている**。管理者向け教材があれば、この非対称性そのものが題材になる。

**教材への落とし込み方:**

- 「機能提供が先、社内ルールが後」という順序が常態である前提で、**先回りして方針を決める運用**を扱う
- 生成物の業務利用ルールを整備する際の最小項目（用途の範囲 / 確認者 / 記録の残し方）を示す
