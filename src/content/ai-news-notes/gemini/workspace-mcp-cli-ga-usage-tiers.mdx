- **期限付きの移行を題材にする。** 2027-02-01（MCP 必須）と 2027-04-01（Scaled 課金）の2つの日付があり、「何が、いつ、誰の作業になるか」を表にさせる演習に向く。
- **人が確認する仕組みを教える。** 機微な操作に利用者の確認を必須にし、監査ログに残す構造は、エージェント統制の基本形。
- **利用枠の階層化を費用管理の例にする。** 無償の標準枠と、超過分だけの従量課金という構造を、他の SaaS の API 課金と比べさせる。
- **既存の高い上限も自動では続かない点に注意させる。** 「今までどおり使える」と思い込まない確認の習慣づけになる。
- 恒久教材へ反映する場合、**具体的な日付や数字は書かない**（変わりうる）。残すのは「エージェントは MCP 経由で接続する」「利用枠と課金の区分を事前に確認する」「機微な操作は人の確認を挟む」の3点。
