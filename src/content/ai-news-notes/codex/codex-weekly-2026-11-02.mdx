- **Vertex AI の組み込みプロバイダー化（0.165.0）は、「どこで動かすか」の選択肢が増えた話として教えられる。** これまで Google Cloud 上のモデルへ向けるには手前にゲートウェイを立てる構成が必要で、その分だけ運用対象が増えていた。**設定1行（`model_provider = "gcp"`）で済むようになると、「社内のデータを出さない」という要件を、代理サーバーを運用せずに満たせる。** Claude Code が Bedrock / Vertex / Foundry を直接扱うのと同じ方向で、**エージェント CLI が「プロバイダー非依存の実行環境」へ寄っていく**流れとして整理できる。
- **GPT-6.1 Terra が、今週は3製品で同時に出ている。** Codex のモデルカタログ（0.165.0 / 0.166.0）、GitHub Copilot の GA（10-26）、そして日次側で記録した OpenAI 本体の告知。**「安いほうの agentic モデル」という枠が各ハーネスに同時に用意された**ことになる。モデル選定を教えるときは、同じモデルが各ツールで同時に使えるようになるため、**比較軸はモデル名ではなくハーネス側の機能と課金**へ移る、という結論に使える。
- **marketplace URL 検証の修正（0.165.0）は、「検証の対象と実際に接続する主体がずれる」型である。** URL のパターン検証は通ったが、**その後に Git が許可パターンとは別のホストへ接続しうる**隙間だった。検証とアクセスの間に別のプロセス（Git）が入ることで、検証結果が実際の通信を拘束していなかったことになる。**自作のプラグイン機構・MCP サーバー導入経路で同じ穴が開きやすい**（URL を検証してから別のツールへ渡す構成はよくある）。Cursor の Marketplace 事故と同じ週に出ているため、**拡張・プラグインの配布経路が攻撃面である**という話をまとめて扱える。
- **「安全ブロックに説明が付く」（0.166.0）は、ガードレールの可観測性の話である。** 止められたときに理由が分からないと、利用者は回避策を探す。**説明と「安全な追撃プロンプト」を同時に出すのは、回避ではなく言い直しへ誘導する設計**で、前週の Claude Code の `claude_code.safety_event`（止めた記録を取る）と対になる。片方は運用者向けの記録、もう片方は利用者向けの説明で、**ガードレールは「止める」だけでは運用できない**という主張の両面になる。
- **承認・権限の設定が resume / fork をまたいで保持されるようになった修正（0.166.0）は、地味だが重要である。** 直前まで、セッションを再開すると権限設定が引き継がれない可能性があった。**「設定したはずの制限が、再開で消える」はガードレールの不具合として最も気づきにくい型**で、エラーも警告も出ない。自作のセッション管理で、**永続化の対象に権限設定が入っているか**を点検させる題材になる。
- **memory v2 が新規プロファイルで既定になり、外部エージェントのメモリを取り込める（0.165.0）。** エージェント間でメモリを持ち運ぶという発想は、GitHub intelligence の Memory（10-28）と同じ週に出ている。**「セッションごとにゼロから始めない」が各社の共通課題になった**ことの表れ。一方で、**取り込んだメモリの出所と信頼性は別問題**であり、外部エージェントのメモリを取り込む経路は、そのままプロンプトインジェクションの経路になりうる。教材では必ずこの注意を併記する。
- **会話中の reasoning effort 変更が既定で有効になった（0.165.0）**のは、Claude Code の `CLAUDE_CODE_SUBAGENT_EFFORT`（2.1.316）、GitHub Copilot Fusion の Standard / High / Max（10-28）と並ぶ。**「モデルを選ぶ」から「かける手間を選ぶ」への移行が、今週3製品で同時に進んだ。** 研修で「どのモデルを使うべきか」を教える構成は、この時点で古くなりつつある。
- **最小限の Knowledge 反映案**: 既定スキップのままでよい。ただし Codex の設定を扱う教材があれば、**Vertex AI が `model_provider = "gcp"` で組み込み対応になったこと**を1行追記する価値がある。プラグイン・marketplace を扱う箇所には、**0.165.0 で URL 検証の隙間が修正されたため 0.165.0 以上を使う**ことを注記する。
