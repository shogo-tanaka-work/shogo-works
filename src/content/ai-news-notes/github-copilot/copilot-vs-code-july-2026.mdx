- Agents window の刷新（チャット横でのレビュー配置）は、開発の重心が「補完を受ける」から「エージェントの結果をレビューする」へ移ったことの UI 上の証拠。Cursor for iPad（2026-07-29）と並べて、レビュー導線がボトルネックという共通認識として説明できる。
- peer chat への fork は Codex CLI 0.146.0 のスレッド fork と同型。「会話を分岐させて方針を比較する」操作がツール横断で標準化しつつある、という横串の説明に使える。
- Copilot Vision の GA は、教材で正式手順として扱えるようになったタイミング。あわせて「スクリーンショットに写り込む意図しない情報」の注意喚起を必ずセットにする。
- 音声入力の各面対応は、Gemini for macOS（2026-07-29）と同時期。「長い指示を出すエージェント時代にキーボードが律速になっている」という背景として横断的に扱える。
- Git worktree サポートは、複数エージェント並行実行時の作業ツリー競合という具体的な問題への回答。並行実行の教材で前提知識として扱う。
- BYOK の Agents window 対応は、モデル調達を自前で行う構成の説明に使える。Azure OpenAI 等との組み合わせ。
- 月次まとめ形式の changelog（v1.127〜v1.131）なので、個別バージョンごとの機能追加日は特定できない点に注意。
