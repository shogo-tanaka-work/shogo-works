- アカウントウォレット / バーチャルウォレットの2層は、権限委譲の設計パターンとしてそのまま教材化できる。Claude Code の権限設計（親セッションとサブエージェント）や MCP のスコープと同じ構造なので、横並びで比較する節を作ると理解が定着しやすい。
