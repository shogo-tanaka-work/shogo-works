- **HTTP ステータスの読み方。** 410 Gone は「恒久的に無くなった」の意味で、一時障害の 5xx とは対処が違う。エラーの種類で次の一手が変わることを確認する。
- **設定の所在を洗い出す演習。** MCP の URL がどこに書かれているか（個人設定、共有設定、手順書）を受講者に挙げさせる。
- **移行先がレスポンスに入っている設計。** エラーが次の行動を教えてくれる例として扱う。
- **情報源の制約を明示する例。** 発効時刻と対象一覧が未確認である点を、記事側も書いている。
- Knowledge 反映案: MCP 接続方式の教材を整備する際の参照元に残す。
