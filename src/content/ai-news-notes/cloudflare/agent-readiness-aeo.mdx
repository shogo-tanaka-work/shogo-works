- 既存の SEO 教材に対しては、章を新設せず「評価軸の追加」として最小差分で足すのが適切。検索順位の話を否定するのではなく、順位で説明できない流入が増えたという事実から入る。
- Citation Rate / Prominence / Mention Rate / Share of Voice はベンダー固有の指標名だが、概念は汎用。教材には**指標の定義だけ**を置き、計測手段は各社ツールに委ねる書き方にしておくと寿命が延びる。特に Citation Rate（リンクあり）と Mention Rate（リンクなしの言及）の区別は、受講者が最も混同しやすいので図で分ける。
- 測定対象が Claude / GPT の回答である以上、モデル更新で数値が動く。「継続的に測る前提の指標であり、単発のスコアに意味はない」という注意を必ず添える。これを言わずに KPI 化させると、モデル更新のたびに説明不能な増減を報告させることになる。
- Agent Readiness の4カテゴリ（Quick wins / Technical groundwork / Advanced integration / Commerce standards）は、そのままエージェント対応のロードマップとしてチェックリスト化できる。段階が付いているので、演習課題を難度順に並べる骨格として使いやすい。
- 「AI に学習させたくない」と「AI の回答で紹介されたい」が両立しない場面がある点は、経営判断の論点として独立させる価値がある。robots.txt / Content Signals の設定は技術作業に見えて、実際は事業方針の表明になっている。技術教材ではなく企業導入編の題材。
- 決済標準（x402 / ACP / UCP / AP2）は名称の羅列に価値がなく、覚えさせない。「エージェントが自律的に支払う前提の標準が複数走っている」という認識だけ持たせ、個別仕様は必要になったときに調べる方針を示す。
- 受講者の成果物にするなら、自分のサイト・ブログに対する診断結果と改善計画が適している。Cloudflare を使っていない受講者向けには、4カテゴリを手動チェックするワークシート版を用意する必要がある。
