- **「料金が3層に分かれている」構造そのものを、AI コスト設計の教材の題材にする。** セッション $0.05/分・モデル利用料・ツール利用料。**カタログ単価から逆算した見積もりが外れる典型例**であり、受講者が自分で踏みやすい失敗である。演習は「代表的な会話を3パターン選んで実測する」という手順まで落とし込む。単価表を読ませるだけでは身につかない。
- **発表（2026-07-08）と GA（2026-09-10）の2段構えは、リリース情報の読み方の実例。** 7月時点の「API はサインアップ受付のみ」を「使える」と読み違えると、2か月の計画がずれる。**「発表日ではなく提供条件が確定した日で計画する」**という原則を、GPT-6 Astra の 09-03 → 09-09 と並べて示すと、偶然ではなくパターンだと伝わる。
- **「沈黙が消えると AI だと気づかれにくくなる」は、AI 倫理教材の具体例として強い。** 技術的な改善が、そのまま説明責任の論点を生む構図である。抽象的な「透明性が大事」ではなく、**全二重化 → 手がかりの減少 → 冒頭告知の必要**という因果で説明できる。契約・医療・金融・クレーム対応という適用領域まで具体化する。
- **responses delegation と client delegation の使い分けは、アーキテクチャ選択の演習になる。** 「既存の業務ロジックを活かすか、モデル側に任せるか」という判断で、**ゼロから作り直さずに音声を前段へ足せる**という点が実務的に効く。既存システムを持つ企業向けの提案の組み立てに直結する。
- **従量課金サービスを顧客環境で動かす案件の契約論**を、受託向け教材へ入れる。想定利用量の明記、超過時の責任範囲、上限を設ける仕組みの有無。**技術ではなく契約で守る**という発想は、フリーランス向け教材で不足しがちな領域である。
- 個人事業者向けには、**「取りこぼし1件の金額と月額コストを比べる」**という判断軸で教える。問い合わせ単価が低い業態では割に合わず、受注額が大きい業態（受託・コンサル・士業）なら1件で回収できる。**業態によって結論が逆になる**ことを明示すると、「便利だから入れる」という判断を防げる。
- 恒久教材へ反映する場合、**$0.05/分という数字は書かない**（変わる）。書くのは「音声 API の課金は複層で、セッション単価だけでは見積もれない」という構造と、実測して見積もる手順だけにする。
