- **導入は「上限が変わると、最適なプランも変わる」から。** 枠が2倍になれば、上位プランに上げた理由が消える場合がある。**プランは一度決めて終わりではなく、変更のたびに見直す**ものと教える。
- **見直しは実測から。** 直近の消費量を見て、足りているか、余っているかを確認する。**感覚ではなく使用量の記録で判断する**習慣を付ける。
- **案内の撤回を、運用の教材にする。** 9月29日に案内された削減が取り消された。**メールで受けた案内を前提に予算や利用ルールを作ると、後で訂正が要る**。公式の更新履歴を定期的に確認する理由になる。
- **API クレジットは別会計であることを強調する。** ChatGPT の利用クレジットとは別枠で、リンクした API 組織に適用される。**どの組織・部署の予算にひも付くか**を先に決める演習にする。
- **プロモーションの扱い方。** 条件と期限がある特典は、本番の予算に組み込まず、検証や試作に使う。
- **受講者への問い**: 自分のチームの直近1か月の使用量は、今のプランの枠のどれくらいか。枠が倍になったら、使い方を変えるか。
- 恒久教材へ反映する場合は、**プラン名・倍率・日付を書かない**（変わる）。残すのは「変更のたびに使用量でプランを見直す」「案内の撤回に備えて公式で確認する」「API と ChatGPT は別会計」の3点。
